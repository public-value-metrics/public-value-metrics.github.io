# 公共価値指標

政府や社会セクターの組織のために構築するソフトウェアエンジニアのために書かれた、公共価値の数学、事例、そして推論への包括的な入門書である。各ファイルは一つの指標あるいは概念を扱う——定義、重要な理由、手法、計算例、ソフトウェア開発との関連、落とし穴、そして出典である。

初めての方は、[公共価値](locales/en-gb-oxendict/topics/public-value/)、[物有所値（Value for Money, VFM）](locales/en-gb-oxendict/topics/value-for-money/)、[変化の理論](locales/en-gb-oxendict/topics/theory-of-change/)から始めること——他のすべてがその上に築かれる三つの考え方である。

## 公共価値の基礎

- [公共価値](locales/en-gb-oxendict/topics/public-value/) — マーク・ムーアの戦略的三角形：正当性、使命、運用能力を公共価値の試金石として
- [物有所値（Value for Money, VFM）](locales/en-gb-oxendict/topics/value-for-money/) — 経済性、効率性、効果性——そして議論の的となる第四のE、公平性
- [公共支出における機会費用](locales/en-gb-oxendict/topics/opportunity-cost-in-public-spending/) — 省庁が使うすべての1ポンドは、次善のプログラムに使われなかった1ポンドである
- [社会的割引率](locales/en-gb-oxendict/topics/social-discount-rate/) — Green Bookの低減する割引率、そしてなぜ3.5%が現実の政治的争点になったのか
- [分配的加重](locales/en-gb-oxendict/topics/distributional-weighting/) — なぜ1ポンドは貧しい世帯にとってより重要なのか——そしてGreen Bookがそれをどう価格付けするか
- [追加性と死荷重](locales/en-gb-oxendict/topics/additionality-and-deadweight/) — どのみち起こっていただろうか？ ほとんどのインパクトの主張をしぼませる問い
- [置き換えと帰属](locales/en-gb-oxendict/topics/displacement-and-attribution/) — あなたの勝利が誰か他の人の損失であるとき、そしてそれが完全にはあなたの手柄ではないとき
- [反実仮想分析](locales/en-gb-oxendict/topics/counterfactual-analysis/) — 反実仮想なくしてエビデンスなし——介入策のない世界を構築する

## 政府における経済評価

- [グリーンブック評価（五事例モデル）](locales/en-gb-oxendict/topics/green-book-appraisal/) — HM Treasuryの五つのケースモデル：戦略、経済、商業、財務、マネジメントの各ケース
- [社会的費用便益分析（SCBA）](locales/en-gb-oxendict/topics/social-cost-benefit-analysis/) — 市場が決して価格付けしなかったものも含め、すべてを貨幣化すること
- [政府における費用効果分析](locales/en-gb-oxendict/topics/cost-effectiveness-analysis-in-government/) — 成果を正直にお金へ変換できないとき、成果の単位あたりコスト
- [多基準意思決定分析（MCDA）](locales/en-gb-oxendict/topics/multi-criteria-decision-analysis/) — 単一の指標がトレードオフを隠してしまうとき、重み付けされた基準に照らして選択肢を採点する
- [福祉評価（Wellbeing Valuation, WELLBY）](locales/en-gb-oxendict/topics/wellbeing-valuation/) — WELLBYと幸福調整：政策を人生満足度の単位で価格付けする
- [表明選好評価](locales/en-gb-oxendict/topics/stated-preference-valuation/) — 人々に支払う意思額を尋ねること——コンティンジェント評価法とその信頼性の問題
- [顕示選好評価](locales/en-gb-oxendict/topics/revealed-preference-valuation/) — 人々が実際に行うことから価値を推測する、ヘドニック価格法からトラベルコスト法まで
- [影の価格設定](locales/en-gb-oxendict/topics/shadow-pricing/) — 市場価格のないものを価格付けする：炭素、時間、非取引財

## 社会的価値とインパクト測定

- [社会的投資収益率（Social Return on Investment, SROI）](locales/en-gb-oxendict/topics/social-return-on-investment/) — SROI比率、そしてそれがマーケティングの数字になることを防ぐ規律
- [変化の理論](locales/en-gb-oxendict/topics/theory-of-change/) — 何かを測定する前に、活動から長期的な成果までの因果連鎖を地図化すること
- [ロジックモデル](locales/en-gb-oxendict/topics/logic-model/) — インプット、活動、アウトプット、アウトカム、インパクト——プログラムの説明責任の背骨
- [成果とアウトプット](locales/en-gb-oxendict/topics/outcomes-vs-outputs/) — 「500人が参加した」は「500人の人生が改善した」と同じ主張ではない理由
- [社会的価値法（Social Value Act）](locales/en-gb-oxendict/topics/social-value-act/) — 公共調達において社会的価値を考慮する英国の2012年の義務
- [単位コストデータベース](locales/en-gb-oxendict/topics/unit-cost-databases/) — HACTのSocial Value BankとGlobal Value Exchange：誰もゼロから始めなくて済むよう事前にコスト計算された代理指標
- [影響評価手法](locales/en-gb-oxendict/topics/impact-evaluation-methods/) — 実験室で実行できない政策のためのRCT、差分の差分法、傾向スコアマッチング
- [影響評価とプロセス評価](locales/en-gb-oxendict/topics/impact-evaluation-vs-process-evaluation/) — 機能したかどうか対設計通りに起こったかどうか——二つの異なる問い、二つの異なる手法

## 政府の業績と提供に関する指標

- [公共セクターKPI](locales/en-gb-oxendict/topics/public-sector-kpis/) — グッドハートの法則を生き延びる指標を選ぶこと
- [公共価値スコアカード](locales/en-gb-oxendict/topics/public-value-scorecard/) — 利益ではない使命のためにキャプランとノートンのバランスト・スコアカードを適応させる
- [成果主義的説明責任（Outcomes-Based Accountability, OBA）](locales/en-gb-oxendict/topics/outcomes-based-accountability/) — マーク・フリードマンの「結果ベースの説明責任」：母集団の結果対業績の説明責任
- [成果連動型支払いと社会的インパクト債（PbR/SIB）](locales/en-gb-oxendict/topics/payment-by-results-and-social-impact-bonds/) — 活動ではなく成果に対して支払うこと——そしてなぜインセンティブ設計がすべてなのか
- [公共サービスの生産性](locales/en-gb-oxendict/topics/public-service-productivity/) — 市場価格のないサービスにおけるアウトプット成長の測定、ONSの方法論から
- [市民満足度指標](locales/en-gb-oxendict/topics/citizen-satisfaction-metrics/) — 純満足度、信頼調査、そしてサービス品質と知覚価値の間のギャップ
- [サービス標準と取引指標](locales/en-gb-oxendict/topics/service-standards-and-transaction-metrics/) — GOV.UK方式のサービス標準：完了率、取引あたりコスト、デジタル利用
- [信頼と正当性指標](locales/en-gb-oxendict/topics/trust-and-legitimacy-metrics/) — なぜ正当性がムーアの三つの試金石の一つなのか、そして政府はそれをどう測定しようとするか

## 社会セクターとフィランソロピーの指標

- [成果あたりコスト](locales/en-gb-oxendict/topics/cost-per-outcome/) — 慈善団体の単位経済学：接触した人あたりコストではなく、意味のある形で助けた人あたりコスト
- [受益者あたりコスト](locales/en-gb-oxendict/topics/cost-per-beneficiary/) — 成果あたりコストのより粗く速いいとこ、そしてなぜ資金提供者は依然としてそれを求めるのか
- [ブレンデッド・バリュー](locales/en-gb-oxendict/topics/blended-value/) — 財務的、社会的、環境的なリターンを一つの分離不可能なボトムラインとして
- [効果的利他主義の費用対効果](locales/en-gb-oxendict/topics/effective-altruism-cost-effectiveness/) — GiveWell方式の命あたりコストの推論、そしてそのQALY形の系譜
- [慈善団体オーバーヘッド比率](locales/en-gb-oxendict/topics/charity-overhead-ratio/) — 「管理にどれだけ使われているか」という問いが間違った問いである理由、それでも資金提供者はそれを尋ねる
- [寄付者投資収益率](locales/en-gb-oxendict/topics/donor-return-on-investment/) — 寄付者が実際に得るものは何か、そしてなぜそれが慈善団体のROIではないのか
- [助成金成果報告（IRIS+）](locales/en-gb-oxendict/topics/grant-outcomes-reporting/) — IRIS+指標、そして資金提供者が被助成団体に報告を求めるものの標準化
- [ボランティア時間価値](locales/en-gb-oxendict/topics/volunteer-time-value/) — 無給労働を、消し去ることも膨らませることもなく価格付けする

## デジタル政府における公共価値

- [デジタルサービス標準](locales/en-gb-oxendict/topics/digital-service-standard/) — GOV.UKのデザイン原則とサービス評価を公共価値のゲートとして
- [取引あたりコスト](locales/en-gb-oxendict/topics/cost-per-transaction/) — デジタルチャネルの見出しとなる経済学、そして最も一般的な会計上のトリック
- [チャネル移行による節約](locales/en-gb-oxendict/topics/channel-shift-savings/) — サービスがオンラインになるとき、電話回線と窓口に実際に何が起こるか
- [デジタル・インクルージョン](locales/en-gb-oxendict/topics/digital-inclusion/) — 支援付きデジタル、デジタル格差、そして「デフォルトでデジタル」が排除するときに失われる価値
- [プラットフォームとしての政府（GaaP）](locales/en-gb-oxendict/topics/government-as-a-platform/) — 公共インフラとしての共有コンポーネント：GOV.UK Notify、Pay、そして再利用の経済学
- [オープンデータの価値](locales/en-gb-oxendict/topics/open-data-value/) — 価格のないデータを評価する、マッキンゼーの推定値からデータセットごとの事例研究まで
- [公共セクターのサイバーセキュリティの価値](locales/en-gb-oxendict/topics/public-sector-cybersecurity-value/) — 侵害が露出させるであろう市民データのためのリスク低減の価格付け
- [政府におけるAIの価値](locales/en-gb-oxendict/topics/ai-in-government-value/) — 他のすべてと同じバリュー・フォー・マネーのハードルに照らして公共サービスにおけるAI採用を評価する

## 幸福、公平性、社会指標

- [GDPに代わる指標](locales/en-gb-oxendict/topics/gdp-alternatives/) — Genuine Progress Indicator、Gross National Happiness、そしてGDPのよく知られた死角
- [人間開発指数（HDI）](locales/en-gb-oxendict/topics/human-development-index/) — 平均寿命、教育、所得を一つの数字に組み合わせる——そしてそれが平坦化するもの
- [多次元貧困指数（MPI）](locales/en-gb-oxendict/topics/multidimensional-poverty-index/) — 所得だけでなく、健康、教育、生活水準にわたる剥奪を数える
- [幸福調整生存年（WELLBY）](locales/en-gb-oxendict/topics/wellbeing-adjusted-life-years/) — WELLBY：通貨が健康ではなく人生満足度である政策のためのQALY形の単位
- [複合剥奪指数（IMD）](locales/en-gb-oxendict/topics/index-of-multiple-deprivation/) — イングランドの小地域剥奪ランキング、そしてそれが資金と注目をどうルーティングするか
- [社会関係資本指標](locales/en-gb-oxendict/topics/social-capital-metrics/) — 信頼、ネットワーク、市民参加を、台帳に記載のない経済資産として
- [自然資本会計](locales/en-gb-oxendict/topics/natural-capital-accounting/) — 英国の25 Year Environment Planから始まる、環境を貸借対照表に載せること
- [世代間公平性と持続可能性割引](locales/en-gb-oxendict/topics/intergenerational-equity-and-sustainability-discounting/) — なぜどのような正の率であれ遠い未来を割り引くことが、それを分析から消し去りうるのか

- [公共セクターにおけるAI生産性](locales/en-gb-oxendict/topics/ai-productivity-in-the-public-sector/) — AI開発者生産性のエビデンス基盤が公共セクターのエンジニアリングチームに示唆すること
