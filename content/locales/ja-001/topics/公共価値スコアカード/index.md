# 公共価値スコアカード

公共価値スコアカードは、ロバート・キャプランとデビッド・ノートンによる1992年のバランスト・スコアカード——財務、顧客、内部プロセス、学習と成長という視点にわたって利益を最適化する企業のために構築された——を、その最終目標が利益ではなく使命である組織に適応させたものである。これは、公的機関に対して、トレードオフを隠してしまう単一の数字にすべてを圧縮するのではなく、複数の還元不可能な次元にわたって業績を同時に報告することを強制する。

## 重要な理由

キャプランとノートンのHarvard Business Reviewにおける元々の論点は、単一の財務指標は遅行指標であり、次の四半期に業績がなぜ変化するのかについて何も教えてくれないというものであった。民間セクターでは、その解決策は四つの連結した視点であった。政府においては、マーク・ムーアの「戦略的三角形」（『Creating Public Value』、1995年より）が対応する構造を提供する——サービスは、**公共価値**（使命の成果）を提供し、**正当性と支持**（政治的・公的な後ろ盾）を維持し、**運用上実現可能**（実際に利用可能な資源と能力で提供可能）であることを同時に満たさなければならない。ポール・ニヴェンの『Balanced Scorecard: Step-by-Step for Government and Nonprofit Agencies』（2003年）は、キャプランとノートンの四つの箱をこの三角形に翻訳するための実践者向けマニュアルである——通常「財務」は「資源の管理責任」に改名され、「株主価値」ではなく「使命」が下ではなく上に置かれ、顧客とステークホルダーの視点は利益に従属するのではなく同等に扱われる。これが提供チームにとって重要な理由は、財務あるいは効率性の指標（例えば取引あたりコスト）だけで判断される公共デジタルサービスは、その財務指標が見ることのできない正当性と成果の次元に体系的に過少投資してしまうからである。

## 計算式

公共価値スコアカードは公式ではなく枠組みであるが、その構造は固定されており、正確に再現する価値がある。

```
視点              公共セクターの問い                    指標の例
--------------------------------------------------------------------------------
使命/成果          私たちは存在理由である公共価値を       人口レベルの成果測定
                   達成しているか？                      （outcomes-vs-outputs
                                                          を参照）
資源の管理責任     私たちは公金を効率的に、権限の         成果あたりコスト、
                   範囲内で使っているか？                予算の乖離
顧客/利用者        利用者と市民はサービスに               完了率、満足度
                   アクセスし、それから便益を
                   得られているか？
正当性/支持        政治的な当事者、監督機関、             信頼指標、監査結果、
                   一般市民は、まだ私たちを支持           支持された苦情
                   しているか？
内部プロセス/学習  改善し続ける能力とプロセスを           職員の離職率、
                   持っているか？                        サイクルタイム、
                                                          滞留案件の年齢

擁護可能なスコアカードは、視点ごとに3〜5の指標を報告し、単一の
視点だけが、その損害が別の視点に現れることなしに操作できない
ように選ばれる。
```

## 計算例

**地方自治体の成人ソーシャルケア部門**：リエイブルメントサービス（入院後に自立を取り戻すための短期的な支援）のスコアカードが以下を報告する。

```
使命：       サービス利用者の68%が6週間後に継続的なケアを
             必要としない（目標65%）
資源の管理責任：完了したリエイブルメント1件あたりのコスト
             = £1,850（予算想定£2,000）
顧客：       利用者満足度82%、サービス開始までの平均待機
             4.1日
正当性：     1,000件あたり3件の支持された苦情、成人保護
             委員会がサービスを「良好」と評価
プロセス：   職員空席率14%、平均担当件数23（安全な担当件数
             上限：25）
```

孤立して読むと、使命と資源管理責任の数字は明快な成功物語のように見える——予算内で目標を上回っている。プロセスの行と一緒に読むと、担当件数上限25に対する空席率14%は、良い成果が安全性の限界に近い人員配置によって購われていることを示している——これは使命の数字だけでは決して表面化しなかった警告であり、まさに単一視点のKPI（[公共セクターKPI](../公共セクターkpi/)を参照）が招く失敗モードである。

## ソフトウェア開発との関連

内部あるいは市民向けのダッシュボードを構築するチームにとって、このスコアカードは単一の「ヘルススコア」ウィジェットに対する直接的な反論である——視点ごとに一つのパネルを構築し、それらを信号機一つに統合しようとする製品側の圧力に抵抗すること。なぜなら、まさにその統合のステップでトレードオフの情報が破壊されるからである。それはまた、プロダクトチームのOKR構造にもきれいに対応する——資源管理責任やプロセスのOKRとペアになっていない使命のOKRは、キャプランとノートンが1992年に反対していたのとまったく同じ単一指標の失敗モードを再生産する。「使命」の箱が実際に何を含むべきかについてのムーアの根底にある理論については[公共価値](../公共価値/)を、実在する、検証可能な指標で正当性の視点をどう埋めるかについては[信頼と正当性指標](../信頼と正当性指標/)を参照。

## 落とし穴

- **スコアカードを一つのスコアに圧縮すること。** 四つの視点を単一の数字に平均化することは、まさにこのスコアカードが防ごうとしている問題——良い資源管理責任スコアに隠された悪い正当性スコア——を再導入してしまう。
- **民間セクターの「財務」視点をそのままコピーすること。** 公的機関の資源管理責任の視点は、収益の最大化ではなく、権限の範囲内、しばしば使途が限定された予算内に留まることについてである——ニヴェンの改名は表面的なものではない。
- **スコアカードを所有するチームが一方的に動かせる指標を選ぶこと。** それが評価する同じチームから出所した正当性の指標（例えば自己申告の苦情対応）は、独立したエビデンスではない。
- **スコアカードを一度構築して、重みや指標を二度と見直さないこと。** キャプランとノートンは年次の戦略レビューを意図していた——何年も凍結されたスコアカードは、それが追跡するはずだった使命から離れていく。
