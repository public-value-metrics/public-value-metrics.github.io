# 社会的費用便益分析（SCBA）

社会的費用便益分析は、政策やプログラムのあらゆるコストと便益——市場のものも非市場のものも——を共通の金銭単位に変換し、将来のフローを現在価値に割り引き、それらを相殺して単一の数字を出す。この提案は社会をより良くするか、そしてどれだけ良くするか、という問いに答えるのである。

## 重要な理由

SCBAは、[グリーンブック評価](../グリーンブック評価/)の経済事例における既定の定量的方法である。HM Treasuryの指針は、信頼できる形で便益を金銭化できる場合には常に、非市場財に対する基本的な評価原則として支払意思額を用いて、正の社会的純現在価値（NPSV）を示すことを提案に要求している（<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>、第5章）。それが強いる規律は、「社会的」費用便益分析が民間セクターの投資評価と同じ営みではないということである——取引の当事者ではない第三者にかかるコストと便益（外部性）を含まなければならず、商業的な資本コストではなく[社会的割引率](../社会的割引率/)を使わなければならず、富裕な世帯よりも貧しい世帯にとって1ポンドがより重要である場合には[分配的加重](../分配的加重/)を適用すべきである。

SCBAが行き詰まるのは、まさに批判者が予想する場所である——市場の類似物を持たない財、すなわちきれいな空気、社会的結束、救われた命の価値などは、[表明選好](../表明選好評価/)または[顕示選好](../顕示選好評価/)の方法を使って金銭化しなければならず、あるいは[影の価格](../影の価格設定/)を構築しなければならない。金銭化が単に困難であるだけでなく議論の余地がある場合、グリーンブック自体が、誰も信じない数字を無理に出すよりも、[費用効果分析](../政府における費用効果分析/)や[多基準意思決定分析](../多基準意思決定分析/)に戻ることを推奨している。

## 計算式

```
NPSV = Σ [t=0からTまで] (便益_t − コスト_t) / (1 + r)^t

ここで：
  便益_t = 表明選好あるいは顕示選好、あるいは影の価格を通じて
           評価された非市場財を含む、t年目のすべての金銭化された
           便益
  コスト_t = 資源の機会費用を含む、t年目のすべての金銭化された
           コスト（../opportunity-cost-in-public-spending/ を参照）
  r      = 社会的割引率（HM Treasuryは3.5%を設定し、グリーンブック
           付属書Aに従い30年目以降はより低い率に逓減する）
  T      = 評価期間

便益費用比（BCR） = Σ PV(便益) / Σ PV(コスト)
```

BCRが1を超える（あるいはNPSVがゼロを超える）ことは、社会的純価値を示す。グリーンブックの物有所値カテゴリー（交通・インフラ評価で使用される）は、BCRの範囲にラベルをつけている——1.0未満は物有所値が低い、1.0〜1.5は低い、1.5〜2.0は中程度、2.0〜4.0は高い、4.0を超えるのは非常に高い、である。感度分析——悲観的および楽観的な前提の下でNPSVを再計算すること——は任意ではなく必須である。なぜなら、金銭化された非市場的便益は広い不確実性の幅を持つからである。

## 計算例

**地方自治体**：ある自治体が、20年間の評価期間、3.5%の割引率で、新しい自転車・歩行者ネットワークへの300万£の投資を評価する。

```
コスト：0年目に300万£の資本、年間5万£の保守（1〜20年目）
PV(保守) ≈ £50,000 × 14.2（3.5%における20年年金係数）
          ≈ £710,000
総PV(コスト) ≈ 371万£

便益（すべて公表されているDfT/WHOの評価ツールで金銭化）：
  身体活動増加による健康便益：£180,000/年
  欠勤削減：£40,000/年
  渋滞緩和（自動車利用の減少）：£60,000/年
  総便益フロー：£280,000/年
PV(便益) ≈ £280,000 × 14.2 ≈ 398万£

NPSV = 398万£ − 371万£ = +27万£
BCR = 3.98 / 3.71 = 1.07 → 「低い」物有所値
```

この事業はハードルをかろうじて越えている——20%低い健康便益推定値（身体活動の評価における真の不確実性を反映）での感度分析は、BCRを1.0未満に反転させる。これがまさに、グリーンブックが中心的な推定値だけでなく感度表を見出しの数字と並べて公表することを要求する理由である。

**慈善団体**：年間費用50万£の乳児死亡予防プログラムが、統計的生命価値（VSL）——市場価格ではなく影の価格——約210万£（HM Treasuryの2023年更新値、それ自体が表明選好調査から導出されている）を用いて評価される。年間50万£のコストで年間1件の乳児死亡を回避することはBCR4.2を与え、余裕をもって「非常に高い」物有所値となる——しかし、この結果全体はVSLの数字に依存している。だからこそ、VSLを使用するあらゆるSCBAは、それを事実としてではなく前提として開示しなければならない。

## ソフトウェア開発との関連

SCBAは、政府ソフトウェアにおけるプラットフォームおよびインフラ投資の意思決定にとって自然な枠組みである——例えば、共有IDプラットフォームを省庁ごとの個別ソリューションと比較することは、それ自体では市場価格を持たない、重複したオンボーディングコストの削減、不正の削減、サービス提供までの時間短縮のような便益を金銭化することを必要とする。基盤となるサービスを構築するエンジニアは、プログラムリーダーがこの分析への入力値を求めてくることを予期すべきである——取引の単位コスト（[取引あたりコスト](../取引あたりコスト/)を参照）、見込まれる量、劣化/ダウンタイムのコストである。取り入れるべき最も重要な規律は、将来の便益を割り引くこと、反実仮想のベースラインを明示的に名指しすること（[反実仮想分析](../反実仮想分析/)を参照）、そして感度の幅を伴わない単一の点推定を決して提示しないことである。

## 落とし穴

- **便益を二重にカウントすること。** 「節約された時間」と「その時間から得られた生産性」の両方を別々の便益項目としてカウントすることは、ケースを誇張する。節約された時間が便益であり、独立してエビデンスに基づかない限り、その下流の使い道は追加の便益ではない。
- **転嫁されたコストを省略すること。** 混雑をある道路から別の道路へ移動させる、あるいは不正をあるチャネルから別のチャネルへ移動させる制度は、見出しのNPSVが示唆するような純便益を生み出していない——[置き換えと帰属](../置き換えと帰属/)を参照。
- **民間の割引率を使用すること。** 社会的割引率の代わりに商業的な資本コスト（例えば8〜10%）を適用することは、健康や環境の便益のような長期的な公共便益を体系的に過小評価する——[社会的割引率](../社会的割引率/)を参照。
- **争いのないものを金銭化し、争いのあるものを曖昧にすること。** ある提案の便益の三分の二が確信を持って金銭化された効率性の節約であり、三分の一が不安定に金銭化された福祉便益である場合、見出しのNPSVは硬い数字と柔らかい数字を暗黙のうちに混ぜてしまう。それらは別々に報告すること。
