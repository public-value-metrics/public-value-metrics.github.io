# 物有所値（Value for Money, VFM）

物有所値（Value for Money）は、英国公共セクターにおいて、支出がコストと便益の最良のバランスを達成しているかどうかを判定する公式のテストである。HM Treasuryの Green Book は、これを経済性（Economy）、効率性（Efficiency）、有効性（Effectiveness）という三つの「E」を通じて枠組み化しており、公平性（Equity）が第四の争点となるEとしてますます論じられるようになっている。精査に耐えるすべての公共セクターのビジネスケースは、支出が「価値がある」と単に主張するのではなく、三つすべてに明示的に答えなければならない。

## 重要な理由

VFMは「安い」の同義語ではない。Green Book（HM Treasury、2022年版）は、意図した成果を生み出すかどうかを確認せずに最安のオプション（経済性）を選ぶことは、よくある高くつく誤りであると明確に述べている——単価を10%節約する調達が、成果を40%少なくしか生まないなら、それはより良い物有所値ではなく、より悪いものである。三つのEの枠組みは、ビジネスケースに、本当に異なる三つの失敗モードを分離することを強制する。すなわち、インプットに払いすぎること、インプットをアウトプットに変換する過程で無駄にすること、そして誰も望んでいなかった成果につながらないアウトプットを生み出すことである。英国政府の支出管理——Treasuryの承認ポイント、National Audit Office（NAO）の物有所値研究、各省庁の会計責任者による評価——は、まさにこの三部構成のテストを中心に組み立てられているため、コスト（経済性）だけに対応する技術的なビジネスケースは、たとえ技術が健全であっても精査を通らない。

「第四のE」である公平性が論争を呼ぶのは、まさにそれが他の三つと衝突しうるからである。あるサービスを全国的に提供する最も効率的な方法が、最も公平であることはめったにない。なぜなら、市民に最も安く到達できる場所に提供を集中させることは、しばしば最も到達しにくい人々への対応不足を意味するからである。Green Bookの2020年改訂は、純粋な費用便益比が既に豊かな地域を体系的に優遇しているという批判（2020年のTreasury Select Committeeや IPPR North からのものを含む）に応え、評価が分配的影響を明示的に扱うことを要求するようになった——[分配的加重](../分配的加重/)を参照。

## 計算式

VFMは単一の比率ではなく、順に適用される三部（あるいは四部）の診断である。

```
経済性（Economy）：     必要な品質に対して、インプットは
                         妥当な最低コストで調達されているか？
                         （インプット単位あたりの£）

効率性（Efficiency）：  インプットはどれだけうまくアウトプットに
                         変換されているか？
                         （アウトプット / インプット、例えば
                         ケースワーカー1時間あたりの処理件数）

有効性（Effectiveness）： アウトプットは実際に意図した成果を
                         生み出しているか？
                         （達成された成果 / 意図した成果）

［公平性（Equity）］：   コストと便益は人口全体に公平に分配
                         されているか、それとも最も必要としない
                         層に集中しているか？
```

VFMの失敗は、いずれの段階でも独立して起こりうる。経済的な調達だが非効率な提供、効率的な提供だが誤ったアウトプット、有効な成果だが過大なコストで得られたもの、といった具合である。これらがどのように測定可能な指標に変換されるかについては[公共セクターKPI](../公共セクターkpi/)を、正式な比較方法については[政府における費用効果分析](../政府における費用効果分析/)を参照。

## 計算例

**地方自治体のコンタクトセンター**：ある自治体が新しいケース管理システムの二つの選択肢を比較する。

- *選択肢A*：60万£のライセンス（最も安価）だが、システム間で手動での再入力が必要なワークフローのため、担当者は1件あたり平均22分かかる——効率性が低い。
- *選択肢B*：90万£のライセンス、統合されたワークフロー、担当者は1件あたり平均9分。

経済性だけを見ればAが有利（30万£安い）。しかし年間4万件の処理では、Aは40,000×22/60=14,667スタッフ時間を要し、Bは40,000×9/60=6,000スタッフ時間を要する。完全負担のスタッフコストを£28/時間とすると、Aは年間£410,667のスタッフ時間コストがかかり、Bは£168,000で済む——年間£242,667の効率性の差は、14か月以内に30万£の初期経済性の差を凌駕する。効率性を計算に入れると、VFMはAではなくBを支持する。

**慈善団体への助成金交付**：ある資金提供者が、5万£の助成金で200件の雇用実現を達成する案（£250/件——一見優れた経済性）と、12万£の助成金で350件の雇用実現を達成し、その雇用が最初の案の半分が3か月以内に消滅するのに対して12か月以上持続する案とを比較する。有効性——持続的な成果——は、見かけ上のVFMの順位を逆転させる。真の*持続*雇用1件あたりのコストは、最初の助成金では£250÷0.5=£500であるのに対し、二つ目の助成金では£120,000/350≈£343である。

## ソフトウェア開発との関連

VFMは、財務・監査機能が実際に読む形で技術系のビジネスケースを組み立てるための規律をエンジニアリングチームに与える。

- 経済性、効率性、有効性を、単一の混合された「価値」の数字ではなく、ビジネスケースの中で別々の項目として明記すること——Green Bookに精通したレビュアーは、まさにこの内訳を求めてくる。
- 統合とワークフローの効率性を犠牲にして調達コスト（経済性）を最適化しないよう注意すること。これは政府ITにおいて非常によくある偽の節約である（[政府ITにおける総所有コスト](../政府itにおける総所有コスト/)と[政府における自前開発か購入か](../政府における内製か購入か/)を参照）。
- 有効性にはアウトプットの件数ではなく成果データが必要である——提供指標を[成果と産出](../成果とアウトプット/)、そしてアウトプットが成果を意味すると仮定するのではなく[反実仮想分析](../反実仮想分析/)による実際の評価に結びつけること。
- あるシステムが地域や属性によって不均一にサービスを提供している場合、公平性の問題は正当なVFM上の異議であり、別枠の「あれば望ましい」事項ではない——[デジタル・インクルージョン](../デジタル-インクルージョン/)を参照。

## 落とし穴

- **VFMを最安値と同一視すること。** 経済性はテストの三分の一（あるいは四分の一）にすぎない。Green Bookは、効率性と有効性を無視する「最安値」調達ルールに対して明確に警告している。
- **アウトプットを測定して、それを成果と呼ぶこと。** 処理件数（効率性）は、うまく解決された件数（有効性）と同じではない——[成果と産出](../成果とアウトプット/)を参照。
- **公平性を任意事項として扱うこと。** Green Bookの2020年更新以降、分配的影響は従来の三つのEと並行して評価されることが意図されており、後付けで付け加えるものではない。ビジネスケースが承認された後にそれを組み込み直すのは、最初から含めるよりはるかに困難である。
- **規模の異なる選択肢を正規化せずに比較すること。** 異なる規模の対象人口にサービスを提供する選択肢間の単位あたりVFM比較は、規模を統制しなければ効率性の比較として意味をなさない。
