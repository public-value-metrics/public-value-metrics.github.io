# ブレンデッド・バリュー

ブレンデッド・バリューは、ジェド・エマーソンによる命題である——あらゆる組織活動と投資活動は、経済的・社会的・環境的という三つの線に沿って同時に価値を創造しており、これらは互いに取引されるべき三つの別々のリターンではなく、単一の分離不可能な価値提案であるというものである。エマーソンの枠組みにおいては、純粋に財務的なリターンや純粋に社会的なリターンというものは存在しない——費やされ、投資され、あるいは助成されたすべてのポンドは、三つすべての何らかのブレンドを生み出す。

## 重要な理由

エマーソンは「The Blended Value Proposition: Integrating Social and Financial Returns」（California Management Review、2003年）でこの考えを提示した。それは、資本を二つのサイロに分類する20世紀の慣行——社会的リターンを生み出し財務的リターンを完全に放棄することが期待されたフィランソロピーと、財務的リターンを生み出し社会的・環境的な影響を外部性として扱うことが期待された投資——に直接対抗して書かれたものである。エマーソンの主張は、この分類が常に虚構であったというものである——運営の悪い組織に資金を出す助成金は三つすべての線に沿って価値を破壊し、川を汚染する利益を上げる事業も、株主のリターンが紙の上でどう見えようとも、三つすべての線に沿って価値を破壊する。

この考えは、1994年に生まれ1997年の著書『Cannibals with Forks』で発展させられた、ジョン・エルキントンの「トリプルボトムライン」（人・地球・利益）と並行して走っている。エルキントンの考えは、企業に財務業績と並んで社会的・環境的業績に対して報告することを迫った。ブレンデッド・バリューは同じ論理を資本配分そのものへとさらに押し進めており、これがインパクト投資分野の知的な祖先である——2009年に設立されたGlobal Impact Investing Network（GIIN）は、投資家がそのブレンドを主張するのではなく実際に測定できるようにするインフラ——IRIS+指標カタログを含む、[助成金成果報告](../grant-outcomes-reporting/)を参照——を構築するために特に存在している。

## 計算式

ブレンデッド・バリューは枠組みであり公式ではない。エマーソン自身が、これを三つのスコアの単純な足し算に還元することに対して明示的に警告している。それが提案する構造は以下の通りである。

```
展開された資本の各単位（助成金、投資、契約、購入）は以下を生み出す：
  - 経済的効果   （財務的リターン、節約されたコスト、生み出された
                  収益）
  - 社会的効果   （人々の幸福、能力、公平性の変化）
  - 環境的効果   （保護、劣化、あるいは回復した自然資本）

これらは別々に最適化されてから合計されるのではない。経済的な
線を最大化しながら社会的な線を破壊する決定は、「ブレンデッド・
バリュー＋コスト」ではなく——それは端的に、純粋に価値を破壊する
決定である。
```

実務上、組織はスコアカードでこのブレンドを近似する——各線に対する名前付きの指標が、一つの数字に相殺されるのではなく、共に報告される。これは、[社会的投資収益率](../social-return-on-investment/)（貨幣化された相殺を実際に試みる）と[自然資本会計](../natural-capital-accounting/)（環境の線に対して同じことを行う）の背後にあるのと同じ発想である——どちらも、ブレンデッド・バリューが完全な形で提起する問いに対する部分的な単一線の答えである。

## 計算例

あるインパクト投資家が、£500,000の二つの融資の間で選択している。

- **融資A**：元受刑者向けの職業訓練カフェを運営する社会的企業への融資、金利2%（同等リスクの融資に対する市場金利6%を下回る）、年間40人を持続的な仕事へ就かせることが見込まれる。
- **融資B**：社会的あるいは環境的な目標が明示されていない一般的な小売事業への、市場金利6%の融資。

純粋に財務的なレンズはBを好む（6%＞2%）。ブレンデッド・バリューのレンズは、投資家に両方について三つすべての線を述べるよう求める。

| | 経済的（年間） | 社会的（年間） | 環境的 |
|---|---|---|---|
| 融資A | £10,000の利子 | 40人が仕事に就く；一人年あたり、司法省の再犯コスト分析から引き出された、国にとってもっともらしい再犯回避の節約を伴う | 中立 |
| 融資B | £30,000の利子 | 述べられていない | 中立 |

社会的な線が価格付けされれば、融資Aのブレンデッドリターンは明らかに優位である。たとえその財務的な線だけを見れば、年間£20,000で融資Bに負けているとしてもである。ブレンデッド・バリューは、投資家にこの£20,000のギャップを無視せよとは言わない——それが唯一存在する数字であるふりをするなと言っているのである。

## ソフトウェア開発との関連

財団、インパクトファンド、あるいは地方自治体の委託チーム向けの報告あるいはポートフォリオ管理ソフトウェアは、しばしば財務台帳を主要なデータモデルとして構築され、社会的あるいは環境的フィールドは自由記述のメモとして後付けされる。ブレンデッド・バリューはその逆の設計を示唆する——すべての取引あるいは助成金レコードに付随する、第一級で等しく構造化された三つの価値ストリームであり、それぞれが独自の単位、出典、確信度を持ち、単一の誤解を招くほど正確なスコアへと相殺されるのではなく、共に表示される。そのブレンドを崩すことなく表示を構築する二つの構造化された方法については、[社会的投資収益率](../social-return-on-investment/)と[公共価値スコアカード](../public-value-scorecard/)を参照。

## 落とし穴

- **三つの線を一つの数字に合計すること。** エマーソン自身の著作がこれに対して警告している——単一のブレンデッド数値は、実際にどの線が仕事をしているかを隠し、いいとこ取りを招く。
- **ブレンド・ウォッシング。** 名前付きの指標や測定方法なしに強い社会的あるいは環境的な線を主張し、そうでなければ業績不振に見える市場を下回る財務リターンを正当化すること。
- **負のブレンドを無視すること。** 財務的に成功したプログラムが負の社会的あるいは環境的な線を持つことがある。ブレンデッド・バリューは、一方の良い知らせだけでなく、どの線であれ悪い知らせを報告することを求める。
