# 社会的割引率

社会的割引率は、将来のコストと便益を現在価値に変換し、数十年にわたって成果が分散するプログラムを共通の基準で比較できるようにする。HM TreasuryのGreen Bookは、最初の30年間は3.5%に固定された逓減スケジュールを義務づけており、これはラムゼー方程式に基づいている——気候政策やインフラのような長期にわたるコミットメントに適用されるたびに、生きた政治的・倫理的論争となる、具体的で引用可能な数字である。

## 重要な理由

30年後に受け取る1ポンドの便益は、今日受け取る1ポンドの便益と同じ価値ではない。これは部分的には純粋な時間選好によるもの（人々や社会はより早く良いものを得ることを好む）であり、部分的には成長によるもの（将来の社会はより豊かになると予想されるため、限界的に1ポンドの重要性は低くなる）である。Green Bookの付属書6は、ラムゼー方程式から英国の標準割引率を導出しており、純粋時間選好率と消費の期待成長率、消費の限界効用の弾力性を組み合わせて、0〜30年目は年3.5%という公表された率を算出し、31年目以降は公表されたスケジュールに従って逓減する（301年目以降は1%まで下がる）。このスケジュールが存在するのは、まさに一世紀にわたって一定の3.5%を複利計算すると、80年後に人命を救う洪水防御や、100年後の害を回避する二酸化炭素削減など、事実上あらゆる長期的な便益が現在価値ベースでは無視できるほど小さく見えてしまうからである。Treasuryは、これが真に長期にわたるインフラや環境の意思決定に対しては、信じがたい倫理的結論であると判断した。

割引率が争点となるのは、まさにその選択が中立的な技術的パラメーターではないからである。それは、社会が今日、まだ生まれていない人々のためにどれだけ犠牲を払うべきかについての判断をコード化している。気候変動の経済学に関するスターン報告書（2006年）は、ゼロに近い割引率（純粋時間選好率が0.1%近辺）を用い、破滅的な気候変動という不可逆的な害が問題になっている場合、市場金利のようなもので将来世代の福祉を割り引くことは倫理的に擁護できないと主張した。批判者——特にウィリアム・ノードハウス——は、スターンのほぼゼロの割引率は、現在の気候支出への根拠をほぼどんな現在コストも、わずかにしか割り引かれない将来の便益に対して正当化されるように見せることで、過大に主張していると論じた。この不一致は数学の問題ではなく、誰の倫理的枠組みが割引率を決めるべきかという問題であり、割引率が単なる保険数理的な入力値ではなく政策的な選択であることを示す標準的な例であり続けている。

## 計算式

Green Bookの割引率の基礎となるラムゼー方程式：

```
r = ρ + η·g

ここで：
  r = 社会的割引率
  ρ = 純粋時間選好率（せっかちさ＋破滅リスク）
  η = 消費の限界効用の弾力性
  g = 一人当たり消費の期待年間成長率
```

Green Bookの逓減スケジュール（付属書6、例示——正確な公表表は最新版を確認すること）：

```
0〜30年目：    3.5%
31〜75年目：   3.0%
76〜125年目：  2.5%
126〜200年目： 2.0%
201〜300年目： 1.5%
301年目以降：  1.0%
```

将来の金額の現在価値：

```
PV = FV / (1 + r)^t
```

## 計算例

**洪水防御計画**：あるプロジェクトが40年目に1,000万£の回避された洪水被害を生む。

一律3.5%を用いると：PV = 10,000,000 / (1.035)^40 ≈ 252万£——便益は小さく見える。

Green Bookの逓減スケジュール（0〜30年目は3.5%、以降は3.0%）を用いると、計算は最初の30年は3.5%、31〜40年目は3.0%で複利計算される。

```
PV = 10,000,000 / [(1.035)^30 × (1.03)^10]
   = 10,000,000 / [2.807 × 1.344]
   ≈ 10,000,000 / 3.773
   ≈ 265万£
```

逓減スケジュールは、一律の高い率に比べて長期的な便益の現在価値をわずかに引き上げる——これがまさにこのスケジュールの目的である。なぜなら、一世紀にわたる一律3.5%は、100年目の1億£の便益を330万£未満まで割り引いてしまうからである。

**デジタルインフラ**：今すぐ400万£かかる政府クラウド移行は、15年間、年間50万£のレガシー保守コストを回避すると見込まれる。3.5%では、その年金の現在価値は約50万£×11.52（3.5%における15年年金係数）≈576万£となり、400万£のコストを楽に上回る——これは正のネット現在価値のケースであり、素朴に選ばれた高い割引率ではかなり弱く見えるだろう（7%では、同じ年金係数は約9.11に下がり、456万£となる——まだ正であるが、マージンははるかに薄い）。

## ソフトウェア開発との関連

ほとんどのソフトウェアのビジネスケースは3〜5年にわたるもので、一律3.5%の帯の中に十分収まるため、逓減スケジュールが直接影響することはまれである——しかし、その根底にある規律は、資産寿命の長い政府の技術投資（全国的なプラットフォーム、データインフラプログラム、数十年にわたる契約）にとって重要である。

- 民間金融から借用した内部の「ハードルレート」ではなく、Green Bookの公表された率を使用すること——監査人やTreasuryのレビュアーは標準スケジュールを期待する。
- 何年も先に実現する便益（プラットフォームの長期的な保守節約、オープンデータのエコシステムの複利的な価値——[オープンデータの価値](../オープンデータの価値/)を参照）については、割引の選択がビジネスケースを正から負に反転させることがある。率と時間軸を、埋もれたデフォルト値ではなく明示的な前提とすること。
- これは、割引されたキャッシュフローを正式に要求する五事例モデルである[Green Book評価](../グリーンブック評価/)、そして金銭以外の福祉便益について同じ割引の問題が生じる[福祉評価](../福祉評価/)に直接つながる。
- スターン対ノードハウスの論争を環境・気候技術投資に具体的に適用したものについては、[世代間の公平性と持続可能性の割引](../世代間公平性と持続可能性割引/)も参照。

## 落とし穴

- **非常に長い時間軸に一律の率を使うこと。** Green Bookの逓減スケジュールが存在するのは、まさに一定の率が真に長期にわたる便益を過小評価するからである。全期間を通じて3.5%をデフォルトとするのではなく、どの帯が適用されるかを確認すること。
- **割引率を倫理的に中立なものとして扱うこと。** スターン・ノードハウスの論争は、率が将来世代についての価値判断をコード化していることを示している。それを変えることは、どのプログラムが正当化されるように見えるかを変える。したがって、それは表明され擁護されるべきであり、スプレッドシートのデフォルト値に隠すべきではない。
- **社会的割引率と民間の資本コストを混同すること。** 政府の借入コストと民間セクターのハードルレートは、ラムゼー方程式から導かれる社会的な率とは異なる概念であり、公共評価においてどちらかをもう一方に置き換えると、通常は短期的なリターンを優遇する方向に結果が歪む。
- **実質と名目のキャッシュフローを一貫性なく割り引くこと。** Green Bookの率は実質（インフレ調整済み）の率である。それを使って名目のキャッシュフローを割り引くと、現在価値を大きく過小評価する。
