# 多次元貧困指数（MPI）

MPIは、貧困を、単に所得が一線を下回ることとしてではなく、ある人が同時に経験する重複した剥奪——健康、教育、生活水準における——として測定する。これは、サビナ・アルキレとジェームズ・フォスターとともにOxford Poverty and Human Development Initiative（OPHI）によって開発され、2010年以来、[人間開発指数](../人間開発指数/)と並んで、すべてのHuman Development Reportで国連開発計画と共同で公表されている。

## 重要な理由

所得貧困線は、十分な現金収入を持ちながらきれいな水や学校教育を欠いている人、あるいは子どもの死を生き延びた人を見逃す——そして、剥奪が集積するという事実を見逃す。電気のない世帯は、不均衡に衛生設備も欠き、栄養不良の子どもを持つ可能性が高い。MPIが構築されているアルキレ=フォスター方式は、健康、教育、生活水準という3つの等しく重み付けされた次元にグループ化された10の指標にわたって、各人の剥奪をカウントし、その重み付けされた剥奪スコアが固定の閾値を超えた場合にのみ、その人を「MPI貧困」として分類する。これは、別々の単一指標の統計のセットでは捕捉できない重複を捕捉する。OPHIは、完全な方法論と国別データを<https://ophi.org.uk/multidimensional-poverty-index/>で公表しており、国連開発計画と共同で維持しているグローバルMPIは現在110を超える国をカバーしている。反貧困プログラム向けに構築されたソフトウェア——現金給付、ソーシャルケアのトリアージ、援助のターゲティング——にとって、MPIの指標セットは、すでに何十もの国の統計局にわたって検証された標準化された剥奪のスキーマに最も近いものであることが多い。

## 計算式

```
10の指標、3つの次元、各次元は1/3で重み付けされる：

健康（1/3）：            栄養（1/6）、子どもの死亡率（1/6）
教育（1/3）：            就学年数（1/6）、就学出席（1/6）
生活水準（1/3）：        調理用燃料、衛生設備、飲料水、電気、
                        住宅、資産（それぞれ1/18）

剥奪スコア（c） = ある人が剥奪されている指標の重みの合計

その人は、c ≥ 1/3（貧困の切断点、k = 33%）であれば「MPI貧困」

H（頭数比率） = MPI貧困の人数 / 総人口
A（強度）      = MPI貧困者のみの間での平均剥奪スコア

MPI = H × A
```

MPIは貧困である人の*割合*と彼らが*どれだけ*貧困であるかを掛け合わせるため、同じ頭数比率を持つ二つの地域でも、一方でより剥奪が深刻であれば、まったく異なるMPIスコアを持ちうる——これはHDIの幾何平均の背後にあるのと同じ「次元をまたいだ代替なし」の論理である。

## 計算例

**1,000人の全国調査**：350人が多次元的に貧困であると特定される（剥奪スコア≥33%）。その350人の貧困者のうちだけで、平均剥奪スコアは45%である。

```
H = 350 / 1000                = 0.350
A = 0.45
MPI = H × A = 0.350 × 0.45    = 0.1575
```

**頭数が等しい二つの地区を比較する**：地区Aは H=0.30、A=0.40（多くが貧困だが中程度に剥奪されている）；地区Bは H=0.30、A=0.60（同じ人数が貧困だが、より深刻に剥奪されている——電気*と*衛生設備*と*就学出席を同時に欠いている）。

```
MPI_A = 0.30 × 0.40 = 0.120
MPI_B = 0.30 × 0.60 = 0.180
```

同じ頭数比率だが、地区BのMPIは50%高い——頭数貧困だけに基づくターゲティングシステムは、この二つの地区を同一にランク付けし、地区Bがより深いインターベンションを必要とすることを見逃すであろう。

## ソフトウェア開発との関連

- 社会プログラムのケースマネジメントと受給資格システムは、しばしばすでに10の指標のいくつか（住宅、就学出席、健康マーカー）を別々のサイロに保存している。アルキレ=フォスターのカウント方式は、あつらえのスコアリングモデルをゼロから構築するのではなく、それらを一つの剥奪スコアへと組み合わせるための既製のスキーマである。
- 頭数/強度の分割（H×A）は、「何人が影響を受けているか」を「どれだけひどく」と並べて報告するあらゆるダッシュボードにとって一般的に有用なパターンである——生の有病率統計がそうするように両方を一つの数字に潰すことは、まさに最も多くの資源を必要とするケースを隠す。
- MPI方式の指標ダッシュボードは、反貧困プログラムの[受益者あたりコスト](../受益者あたりコスト/)報告と自然に組み合わさる——MPI低下1ポイントあたりのコストは、まったく異なる介入策（現金給付対衛生インフラ）を比較するための擁護可能な単位である。

## 落とし穴

- **10の指標を普遍的なものとして扱うこと**——OPHIのグローバルMPIの指標は、国横断的な比較可能性のために較正されている。国別のMPI（南アジアやアフリカのいくつかの国を含む多くの国が独自のものを公表している）は、指標と重みをローカルな文脈に適応させており、両者は直接比較可能ではない。
- **Hだけを報告すること**——頭数比率は強度を完全に無視する。常にAをそれと並べて、あるいはMPI自体を報告すること。
- **MPI貧困と所得貧困が同じ母集団であると仮定すること**——OPHI自身の国別ブリーフは、通常この二つの間に部分的な重複しか示さない。所得貧困だけを対象とするプログラムは、多次元的に貧困な人々の相当な割合を体系的に見逃すであろう。
