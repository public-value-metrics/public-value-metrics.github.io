# GDPに代わる指標

GDPに代わる指標は、国内総生産が構造的に無視するもの——無給のケア労働、環境の枯渇、所得の分配、そして成長が実際に生活を改善しているかどうか——を捕捉するために構築された指標である。最もよく知られているのはGenuine Progress Indicator（GPI）とブータンのGross National Happiness（GNH）Indexであり、それらを真剣に受け止めるべきだという主張は、2009年のStiglitz-Sen-Fitoussi委員会によって最も影響力を持って行われた。政府のダッシュボードやKPIシステムを構築するエンジニアにとって、「どの数字が進歩とみなされるか」は、何に資金が提供されるかに実際の結果をもたらす設計上の決定である。

## 重要な理由

1930年代に米国の国民経済計算を構築したサイモン・クズネッツは、1934年に議会で「国家の福祉は国民所得の測定からほとんど推測できない」と警告した——これはこの数字がほぼ即座に乗り越えてしまった但し書きであった。GDPは原油流出の清掃を成長としてカウントし、親の無給の育児を何もないものとしてカウントする。それは、持続的な幸福を構築する支出と、すでに生じた害を単に相殺するだけの支出を区別しない。フランスのニコラ・サルコジ大統領によって招集され、ジョセフ・スティグリッツ、アマルティア・セン、ジャン=ポール・フィトゥシが議長を務めたStiglitz-Sen-Fitoussi委員会は、2009年に、統計システムは「経済的生産の測定から人々の幸福の測定へ」重点を移すべきであり、持続可能性は一つの数字に折り込まれるのではなく現在の幸福とは別に追跡されるべきだと報告した。GDPに代わる指標は、その提言を運用可能にする。1990年代にシンクタンクRedefining Progressによって開発され、ウィリアム・ノードハウスとジェームズ・トービンの1972年のMeasure of Economic Welfareを土台とするGPIは、（GDPと同様に）個人消費から出発し、GDPが省略する非市場の便益（家事労働、ボランティア活動）を加え、GDPが誤って正としてカウントする防衛的コストと枯渇コスト（犯罪、汚染、通勤、資源の取り崩し）を差し引く。GNH Centre Bhutan（<https://www.gnhcentre.bt/>）が運営するブータンのGNH Indexはさらに一歩進み、成長をその国が定める憲法上の目標として置き換える——それは、心理的幸福、健康、教育、時間の使い方、文化的多様性、ガバナンス、コミュニティの活力、生態学的多様性、生活水準という9つの領域にわたる33の指標を、政府の政策提案をスクリーニングするために直接使われる単一の充足度ベースのスコアへと集約する。

## 計算式

```
GPI = 個人消費支出
      + 非市場の便益（家事労働、ボランティア活動、高等教育）
      − 防衛的・社会的コスト（犯罪、汚染、通勤、家族の崩壊）
      − 自然資本・社会資本の枯渇（資源の取り崩し、農地の喪失）

GNH充足度スコア、領域ごと：
  人は、各指標でその領域の閾値をクリアした時点でその領域が
  「充足している」
  幸福度指数 = （9領域中6以上で充足している人口の割合）
              +（「まだ幸福でない」少数派の重み付けされた
                平均不足分）
```

## 計算例

**地域、GPI**：個人消費は$500億。推定される家事労働・ボランティア労働の価値$120億（代替コスト賃金率——[ボランティア時間価値](../ボランティア時間価値/)を参照）を加える。通勤渋滞の推定年間コスト（$30億）、犯罪（$40億）、長期的な資源枯渇（$60億）を差し引く。

```
GPI = 50 + 12 − 3 − 4 − 6 = 49（10億ドル）
```

その年GDPが$500億から$550億へ成長した（+10%）としても、防衛的コストと枯渇コストが消費よりも速く成長すれば、GDPが上昇してもGPIは低下しうる——これは、成長が上昇し続ける一方でGPIが横ばいになった1970年代あたり以降の高所得経済について、GPIの研究者が引用する「閾値仮説」である。

**市民、GNH**：ある回答者が9領域中7つ（健康、教育、生活水準、コミュニティの活力、文化的多様性、生態学的多様性、時間の使い方）で充足度の閾値をクリアするが、心理的幸福とガバナンスでは不足する。7≧6であるため、頭数としては「幸福」とカウントされる。この指数は、狭い合格が快適な合格と区別がつかなくならないよう、その二つの不足の深さを別々に追跡する。

## ソフトウェア開発との関連

- スループットあるいは支出だけをモデル化したKPIダッシュボード（GDPのパターン）は、そのスループットを生み出す中で生じた害を体系的に見逃す——サポートチケットの量を「ユーザーの苦悩」ではなく「エンゲージメント」として扱うことは、原油流出を成長としてカウントすることのソフトウェア提供版である。
- GPI方式の会計は、あらゆる[公共セクターKPI](../公共セクターkpi/)のスイートにとって有用な監査パターンである——あらゆる見出しのアウトプット指標について、それが静かに発生させている防衛的コスト（手戻り、インシデント対応、燃え尽き）を問い、GPIが消費から防衛的支出を相殺するのと同じように、それを差し引くこと。
- GNHの領域充足度の手法——次元ごとの合格/不合格、そして集約——は、構造的に[多基準意思決定分析](../多基準意思決定分析/)と同じ技法であり、単一のスカラースコアが致命的に不十分な次元を隠してしまうであろう場所ではどこでも再利用する価値がある。

## 落とし穴

- **GPIを正確な国民経済計算として扱うこと**——GDPとは異なり、GPIには単一の標準化された方法論がない。異なる研究は、通勤コスト、ボランティア時間、資源枯渇を異なる重みで扱うため、研究をまたいだGPIの比較は国をまたいだGDPの比較よりもはるかに信頼性が低い。
- **GNHを異なる政策文化にまるごと輸入すること**——その領域の重みと充足度の閾値は、ブータンでの協議を通じて設定された。根底にある協議プロセスなしにその数字だけをコピーすることは、誰も信頼しない空虚な指標を生み出す。
- **GDPに代わる指標が費用便益評価を置き換えると仮定すること**——これらは診断的な、経済全体にわたる指標であり、単一のプログラムのための意思決定ツールではない。それには代わりに[社会的費用便益分析](../社会的費用便益分析/)を使うこと。
