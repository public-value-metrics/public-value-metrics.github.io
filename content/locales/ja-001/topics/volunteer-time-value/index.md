# ボランティア時間価値

ボランティア時間価値は、無給労働に割り当てられる金銭的な推定値であり、最も多くの場合、慈善団体の真の経済的フットプリント——その会計に加えて支払う必要のなかった労働——を述べるために、あるいはある介入策が現金予算だけが示唆するよりも費用対効果が高いという主張をするために使われる。二つの国別方法論が主流である——米国のIndependent Sectorの推定値と英国のOffice for National Statistics/NCVOのアプローチであり、これらは同じ1時間の労働に対してかなり異なる価格をつける。

## 重要な理由

Independent Sectorは、メリーランド大学のDo Good Instituteと協力して、Bureau of Labor Statisticsの賃金データ——具体的には民間非農業給与における生産・非監督労働者の平均時給に、付加給付の調整を加えたもの——から構築された、全米のボランティア時間の時間あたり価値を毎年公表しており、州別に内訳を出している。最新の発表では、その価値は**2025年で1時間あたり$36.14**とされ、前年比3.9%上昇し、州レベルの価値はワシントンDCの$50超からプエルトリコの$20未満まで幅がある。英国では、Office for National Statisticsが別途、正式なボランティア活動の代替コストを**1時間あたり£14.43**（2017年推定）と推定しており、NCVOのUK Civil Society Almanac 2024は、ボランティア参加データ——2021〜22年に正式にボランティア活動をした約1,420万人——を使って、このセクターの総ボランティア貢献をおよそ**£180億**、英国GDPの約0.8%と推定している。

これが会計上の見栄えを超えて重要である理由は、ボランティア労働に大きく依存するプログラムは、真の資源コスト——その労働を置き換えるのにかかるコスト——が同程度あるいはより高い場合でさえ、純粋な現金の[成果あたりコスト](../cost-per-outcome/)ベースでは、有給スタッフに依存するプログラムよりも劇的に安く見えうるからである。ボランティア時間価値を無視する資金提供者と評価者は、ボランティア中心の提供モデルの真のコストを体系的に過小に数え、同じ成果を提供する有給スタッフモデルとの効率性比較を歪める。

## 計算式

```
ボランティア時間の価値 = 貢献されたボランティア時間 × 時間あたり
                        レート

レートの選択が重要であり、答えを変える：
  - 代替コストアプローチ：同じタスクを行うであろう有給労働者の
    賃金（例えば汎用的な平均賃金ではなく、資格を持つユース
    ワーカーに対する代替コストレート）——タスク固有の評価に
    対して最も擁護可能
  - 機会費用アプローチ：ボランティア自身が失った賃金——
    ボランティアが何を諦めたかを評価するために最も擁護可能
  - 全国平均アプローチ：Independent SectorあるいはONSの単一の
    ブレンドされたレート——見出しの、セクター横断的な
    比較可能性に対して最も擁護可能
```

三つのアプローチは、同じ1時間に対して大きな倍率で異なりうる（理事会の受託者としてボランティアをする弁護士は、全国平均レートとはまったく異なる機会費用レートを持つ）。したがって、報告される数字はどの方法で生み出されたかを明示する必要がある。

## 計算例

**英国の慈善団体、全国平均アプローチ**：1年間に5,000ボランティア時間、£14.43/時間（ONSの代替コスト推定値）で評価。

```
価値 = 5,000 × £14.43 = £72,150
```

その慈善団体のその年の現金支出が£300,000であった場合、その真の資源コスト——現金にボランティア労働を加えたもの——は£372,150であり、現金の数字だけが示唆するよりもおよそ24%高い。£300,000の現金の数字だけを使った成果あたりコストの計算は、同じ幅で真のコストを過小に表す。

**米国の慈善団体、全国平均アプローチ**：2,000ボランティア時間、$36.14/時間（Independent Sector、2025年発表）で評価。

```
価値 = 2,000 × $36.14 = $72,280
```

**同じ米国の慈善団体、機会費用アプローチ**：ボランティアが不均衡に、以前の収入が平均$60/時間であった退職した専門家である場合、機会費用評価は$120,000となり、全国平均の数字より三分の二高くなる。これは、なぜその方法を明示しなければならないかを示している。

## ソフトウェア開発との関連

ボランティア時間を記録するシステム（シフトスケジューリングツール、ボランティア管理プラットフォーム）は、単なる合計ではなく、タスクあるいは役割レベルで時間を捕捉すべきである。そうすることで、混在するボランティア労働力全体に一律の全国平均レートを適用するのではなく、役割ごとに代替コストレートを適用できる（受託者の1時間とスチュワーディングの1時間は経済的に等価ではない）。計算された値とともに使用されたレートと方法論を保存すること——最終的な通貨の数字だけでなく——により、下流の報告（年次会計、[社会的投資収益率](../social-return-on-investment/)の計算、資金提供者向け報告書）は、後でその数字を不透明な定数として扱うのではなく、再現あるいは異議を唱えることができる。ボランティア時間価値を省略することがなぜ真の提供コストを体系的に過小に表すかについては[成果あたりコスト](../cost-per-outcome/)を参照。

## 落とし穴

- **構造的に異なる役割に単一の一律レートを使うこと。** 専門的なプロボノの1時間（法律、財務、臨床）に全国平均賃金レートを適用することは、それを劇的に過小評価する。タスクが専門技能を要する場合はどこでも、そのレートを置き換えられる役割に一致させること。
- **有給スタッフのコストに対して二重計上すること。** ボランティアが本来有給であったであろう仕事を代替する場合、その評価が、すでに膨らんだスタッフ配置の見積もりに重ねられるのではなく、現金支出に対して加算的であることを確認すること。
- **日付なしで古いレートを引用すること。** Independent SectorとONSのレートは毎年変化する（あるいはONSの場合は定期的にしか再推定されない）。日付のないボランティア時間の数字は、報告書における比較としてはほとんど無意味である。
- **ボランティア時間価値を資金調達上の資産として扱うこと。** これは真の資源コストを理解するための費用会計上の調整であり、慈善団体が使える新しいお金ではない。この二つを混同することは、会計を読む理事会を誤解させる。
