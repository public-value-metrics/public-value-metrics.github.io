# 社会的投資収益率（Social Return on Investment, SROI）

社会的投資収益率は、社会的、環境的、経済的という広い価値の概念を測定し、金銭化し、説明するための枠組みであり、それを投入された資源に対する比率として表現する——例えば「投資された1£あたり£1.44の社会的価値」というように。これは、財務会計のロジックを、市場が価格づけしない成果にまで拡張するために設計されたものであり、その会計上の規律を失わずに行われる。すなわち、SROIにおけるあらゆる数字は、ステークホルダーによって定義された成果、エビデンスの基盤、そしてとにかく起きていたであろうことに対する明示的な調整にまでさかのぼれなければならない。

## 重要な理由

SROIは、SROI Networkの後継組織であるSocial Value UKとSocial Value Internationalによって維持されており、その「A Guide to Social Return on Investment」（2012年）は今なお参照される方法論である。この枠組みは七つの原則——ステークホルダーを関与させる、何が変化するかを理解する、重要なものを評価する、重要なものだけを含める、過大に主張しない、透明である、結果を検証する——に基づいており、実際に見られるほとんどのSROI報告書が失敗するのは原則5「過大に主張しない」である。死荷重や帰属の調整を省略して算出された比率はSROIではない——それはSROIの衣をまとったマーケティング上の数字である。慈善団体、社会的企業、あるいは委託機関向けの報告ツールを構築するソフトウェアエンジニアは、この違いを知る必要がある。なぜなら、そのツールは、この規律を強制することも、それを省略しやすくすることもできるからである。

## 計算式

SROIは、どの成果が範囲に入るかを特定するために[変化の理論](../変化の理論/)に依存し、[ロジックモデル](../ロジックモデル/)と同じ説明責任の連鎖を使ってそれらを表現する。

```
SROI比率 = 成果の現在価値 / 投入の価値

プロセス：
 1. 範囲を確立し、成果が測定されるステークホルダーを特定する
 2. 成果をマッピングする（ステークホルダーとともにエビデンスに
    基づく変化の理論であり、想定されたものではない）
 3. 成果にエビデンスを与え、財務代理指標を用いて価値を与える
 4. 影響を確立する：総価値 − 死荷重 − 帰属 − 置き換え、その後
    減衰を適用する
 5. SROIを計算する：影響の純現在価値 ÷ 投入の価値
 6. 報告し、使用し、定着させる——この比率はコミュニケーションの
    手段であり、終着点ではない
```

死荷重、帰属、置き換えについては[追加性と死荷重](../追加性と死荷重/)と[置き換えと帰属](../置き換えと帰属/)で扱われている——これら三つはすべて、総成果から真の[反実仮想](../反実仮想分析/)の影響を分離するために存在する。

## 計算例

**地方自治体の雇用プログラム**：年間投入コスト£250,000。60人が持続的な雇用に移行する。その成果に対する財務代理指標（福祉の向上、給付依存の減少、税収を組み合わせたもの）は、1年目1人あたり£8,500である——このような代理指標がどこから来るかについては[単位コストデータベース](../単位コストデータベース/)を参照。

- 総成果価値：60 × £8,500 = £510,000
- 死荷重を差し引く（40%はプログラムなしでもおそらく仕事を見つけていた）：£510,000 × 0.60 = £306,000
- 帰属を差し引く（残りの変化の30%は他の機関の支援によるもの）：£306,000 × 0.70 = £214,200
- 2年目の成果は減衰率30%で：£214,200 × 0.70 = £149,940、年利3.5%で割引（[社会的割引率](../社会的割引率/)を参照）：£149,940 ÷ 1.035 = £144,870
- 影響の総現在価値：£214,200 + £144,870 = £359,070
- **SROI比率：£359,070 ÷ £250,000 = 1.44**、「投資された1£あたり£1.44の社会的価値」として報告される

**慈善団体**：£60,000のフレンドシップ訪問サービスが、80人の高齢者の孤独を軽減し、1人あたり年間£1,100の代理指標で評価される。総価値£88,000、死荷重35%と帰属15%を控除後、純影響は£88,000×0.65×0.85=£48,620、SROI比率は0.81——損益分岐点を下回る。これは正当で有用な発見であり、報告を控える理由ではない。

## ソフトウェア開発との関連

ユーザーが成果数と代理指標の価値を入力できるが、死荷重、帰属、あるいは連携した変化の理論に対する必須フィールドがないSROI計算機は、デフォルトで誇張された比率を生み出す。なぜなら、調整を省略することが最も抵抗の少ない道だからである。この規律をスキーマに組み込むこと——すべての成果行は、ステークホルダーグループ、エビデンスに基づく数量、出典を伴う財務代理指標、そして任意ではない死荷重/帰属のフィールドを参照すべきである。SROIの成果マッピングが依拠する区別については[成果とアウトプット](../成果とアウトプット/)を、そのツールがデータモデルの中で反映すべき連鎖については[ロジックモデル](../ロジックモデル/)を参照。

## 落とし穴

- **死荷重と帰属を省略すること。** これらの調整なしの見出しの比率は、純影響の数字ではなく総数の数字であり、Social Value UKの原則は両方を明示的に要求している。
- **組織間で比率を比較すること。** SROI比率は、案件ごとに行われた範囲と代理指標の選択に依存する。ある報告書の4:1という比率を別の報告書の2:1という比率より「良い」として扱うことは、その前提が財務会計上の比率のように標準化されていないことを無視している。
- **重複する代理指標を二重にカウントすること。** 同じ受益者に対して「孤独の軽減」の代理指標と「メンタルウェルビーイングの向上」の代理指標を重ねることは、一つの根底にある変化を二重に評価しうる。
- **ステークホルダーの関与を省略すること。** 原則1は、成果が、モデルを構築するアナリストによって想定されるのではなく、それを経験している人々とともに定義されることを要求している。
