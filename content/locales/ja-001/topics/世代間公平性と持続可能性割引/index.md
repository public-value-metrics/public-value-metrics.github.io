# 世代間公平性と持続可能性割引

将来のコストと便益を現在価値へと割り引くことは、公共評価における標準的な実務である——[社会的割引率](../社会的割引率/)を参照——しかし、数十年あるいは数世紀にわたって複利計算される正の割引率は、どのようなものであれ、遠い未来を今日の言葉ではゼロへと縮小させる。1世紀以上先の結果を持つ決定——気候変動、核廃棄物、生物多様性の喪失、年金の持続可能性——にとって、その数学的事実は倫理的な事実になる。標準的な割引は、現在価値の言葉では、将来世代への破滅的な害を、避ける価値がほとんどないように見せかけうる。

## 重要な理由

1928年にフランク・ラムゼイによって導出されたラムゼイ方程式は、割引率を二つの構成要素に分解する——純粋な時間選好（δ、富とは無関係に、私たちが単に今を後よりもどれだけ好むか）と富の成長効果（η×g、将来世代はより豊かになると予想されるため、追加の1ポンドが彼らにとってあまり重要でないという理由でどれだけ割り引くか）。英国のGreen Bookの標準的な長期割引率はこの方程式の上に構築されており、平坦な率ではなく*低減する*スケジュールに従う——これは、マーティン・ワイツマンの「ガンマ割引」に関する研究に根ざした設計であり、将来の割引率自体が不確実な場合、適用すべき確実性等価率は数学的に時間とともに低下することを示している。なぜなら、より遠くを見るほど低い率のシナリオが支配的になるからである。ニコラス・スターン卿が主導した気候変動の経済学に関するスターン・レビュー（2006年）は、倫理的な議論をさらに進めた——スターンは、純粋な時間選好はほぼゼロに設定されるべきだと主張した（彼はδ≈0.1%を使用した。これは、現在を将来よりも真に好むことを反映するのではなく、文明を終わらせる破局のわずかな確率だけを反映している）。これは、従来のGreen Bookの実務よりもはるかに低い実効割引率を生み出し、それに対応して、気候行動に対するはるかに大きな現在時点でのケースを生み出す。批評家（特にウィリアム・ノードハウス）は、スターンのほぼゼロの率は倫理的には擁護可能だが、実際に観測された貯蓄と投資の行動とは整合しないと主張した。この意見の相違は技術的な脚注ではない——それは、同等に厳密な二人の経済学者が、現在の世代が将来のためにどれだけ犠牲を払うべきかについてまったく異なる結論に達しうる最大の単一の理由であり、長期展望の公共投資評価を支えるソフトウェアが、その割引の前提をスプレッドシートのデフォルトの中に埋め込むのではなく公開しなければならない理由である。

## 計算式

```
ラムゼイ方程式：   r = δ + η × g

  r = 社会的割引率
  δ = 純粋な時間選好（せっかちさの率、富とは無関係）
  η = 消費の限界効用の弾力性（人々がより豊かになるにつれて
      追加の消費の価値が逓減すること）
  g = 一人あたり消費の予想成長率

Green Bookの低減する長期スケジュール（およそ、現在公表されて
いる帯）：
  0〜30年：    3.5%
  31〜75年：   3.0%
  76〜125年：  2.5%
  126〜200年： 2.0%
  201〜300年： 1.5%
  301年以降：  1.0%

スターン・レビューのパラメーター：δ ≈ 0.1%、η = 1、g ≈ 1.3%
  → r ≈ 1.4%
```

## 計算例

**100年後に回避される£1の害の今日の価値**、三つの割引制度のもとで。

```
平坦なGreen Bookの短期率（3.5%、100年間一定に保たれる）：
  PV = 1 / (1.035)^100 ≈ 1 / 31.19 ≈ £0.032   （3.2ペンス）

Green Bookの低減するスケジュール（1〜30年で3.5%、31〜75年で
3.0%、76〜100年で2.5%）：
  係数(1〜30)  = 1.035^30  ≈ 2.807
  係数(31〜75) = 1.03^45   ≈ 3.782
  係数(76〜100)= 1.025^25  ≈ 1.854
  総係数 ≈ 2.807 × 3.782 × 1.854 ≈ 19.68
  PV = 1 / 19.68 ≈ £0.051   （5.1ペンス）

スターン方式のほぼゼロの純粋な時間選好（r ≈ 1.4%平坦）：
  PV = 1 / (1.014)^100 ≈ 1 / 3.997 ≈ £0.250   （25.0ペンス）
```

今から1世紀後に回避される同じ£1の害は、純粋にどの割引の慣行が使われるかによって、今日3.2ペンス、5.1ペンス、あるいは25ペンスの価値を持つ——これはほぼ8倍の幅であり、多額の前払いコストと1世紀先の見返りを持つ気候緩和プロジェクトが、そもそも正のNPVのハードルをクリアするかどうかを左右する。これが本章の中心的な警告の背後にある仕組みである——意味のある正の平坦な率であれば、十分に遠い将来の害は、その実際の深刻さにかかわらず、算術的に評価から消し去られる。

## ソフトウェア開発との関連

- あらゆる長期展望の評価あるいはビジネスケースツール（インフラ、気候適応、年金モデリング）は、単一の平坦な率ではなく、Green Bookの*低減する*スケジュールを実装すべきである——平坦な率のデフォルトは、現在の英国政府のガイダンスが定めるよりもはるかに強い反未来バイアスを静かに埋め込む。
- 割引率と期間は、評価ソフトウェアにおいて常に目に見える監査可能なパラメーターとして公開されるべきであり、その計算のそれらへの感度が明示的に示されるべきである（上記の計算例のように）——率を設定ファイルに埋め込むことは、まさにスターン・ノードハウス論争が警告する「隠された倫理的選択」を招く。これは[自然資本会計](../自然資本会計/)で述べられている透明性の論点と対をなし、一般に[社会的割引率](../社会的割引率/)のトピックの根底にある。
- あるプログラムの便益が明示的に世代間にわたる場合（洪水防御、自然資本の回復、長期のデジタルインフラ）、[社会的費用便益分析](../社会的費用便益分析/)は、単一の点推定ではなく、少なくとも二つの割引の前提（Green Bookの標準と低率の感度ケース）のもとで結果を報告すべきであり、意思決定者が割引率の選択だけで答えがどれだけ動くかを見られるようにすべきである。

## 落とし穴

- **感度の範囲なしに単一の割引されたNPVを提示すること**——長期展望のプロジェクトにおいて割引率だけが答えをどれだけ変えるかを考えると、単一の率のNPVは精度を実質的に過大に述べる。常に少なくともGreen Bookの標準と低率のシナリオにまたがる範囲を報告すること。
- **短期の平坦な率（3.5%）を数世紀にわたる評価に適用すること**——Green Book自身のガイダンスが低減するスケジュールを定めているのはまさに、その平坦な率がおよそ30年を超えると不適切だと判断されたからである。それでもそれを使うことは長期的なコストを過小に表す。
- **δ（純粋な時間選好）を純粋に技術的なパラメーターとして扱うこと**——スターンのほぼゼロの値とGreen Bookのより高い暗黙の値は、どちらも、現在が将来にどれだけの重みを負っているかについての倫理的な立場としてのみ擁護可能であり、経験的に「正しい」あるいは「間違っている」数字ではない。ソフトウェアは、一つの数字を客観的に正しいものとして提示するのではなく、その前提を目に見えるようにすべきである。
