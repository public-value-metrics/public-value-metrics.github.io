# 福祉評価（Wellbeing Valuation, WELLBY）

福祉評価は、政策の効果を生活満足度の観点から直接価格づける。その単位としてWELLBY（福祉調整生命年）を用いる——1WELLBYは、0〜10の生活満足度スケールで1ポイントの変化が1年間持続することに等しい。これは、支払意思額を通じてあらゆる便益を金銭化することに対する、HM Treasuryが公式に認めた代替手段である。

## 重要な理由

HM Treasuryの「Wellbeing guidance for appraisal: supplementary Green Book guidance」（2021年、<https://www.gov.uk/government/publications/green-book-supplementary-guidance-wellbeing>）は、主観的福祉データを中央政府の評価に正式に導入し、アナリストに、社会的つながり、メンタルヘルス、安全、市民参加といった、[表明選好](../stated-preference-valuation/)や[顕示選好](../revealed-preference-valuation/)の方法では説得力を持って価格づけることが困難な成果を評価する道を与えた。なぜなら、人々はしばしば、ある財が実際に自分の生活満足度にどれだけ影響するかを予測するのが下手だからである。What Works Centre for Wellbeingと共同で開発されたこの指針は、1WELLBYあたりの推奨金銭価値（約£13,000、2021年価格、定期的に改定）を、大規模な福祉調査（主にONSのAnnual Population Survey、2011年以来ONS4の福祉に関する四つの質問を尋ねている）で観察された所得と生活満足度の関係から導き出し、金銭化された比較が他のグリーンブック評価と必要な場合に、アナリストがポンドへ換算する方法を与える。

この方法が重要なのは、それが通常の評価ロジックを逆転させるからである——人々がある成果に対していくら支払うか（表明選好）を問うのではなく、あるいは関連する市場取引から価値を推測する（顕示選好）のではなく、報告された生活満足度への成果の効果を直接測定し、人々が望むと言うものと実際に彼らをより良くするものとの間のギャップを回避する。これはまた、この方法の中心的な限界でもある——自己申告の生活満足度は、慎重な実務者が制御しなければならない適応効果やフレーミング効果に影響される。

## 計算式

```
WELLBY = 1人の1年間にわたる1生活満足度ポイント（0〜10スケール）
        の持続

ある政策による総WELLBY =
  Σ (生活満足度スコアの変化) × (影響を受ける人数)
    × (変化が持続する年数、社会的割引率で割引)

金銭化された福祉便益 = 生成されたWELLBY × 1WELLBYあたりの価値
  （HM Treasury推奨値：1WELLBYあたり£13,000、2021年価格、
   定期的な改定の対象——使用前に最新の指針を確認すること）
```

これは、保健経済学における[福祉調整生命年](../wellbeing-adjusted-life-years/)とは異なる。後者は通常、一般的な生活満足度ではなく、健康関連の生活の質スケール（EQ-5Dなど）に基づいている。両者は関連しているが互換性はなく、グリーンブック評価は、報告されたWELLBYの数字がどのスケールと引き出し方法に基づいているかを明示すべきである。

## 計算例

**地方自治体**：ある自治体が、孤立した高齢者のための地域友愛訪問制度を運営し、400人にサービスを提供している。ONS4の生活満足度に関する質問を用いた追跡調査は、参加者の平均スコアが5.8から6.0に上昇したこと（0.8ポイントの増加）を示し、その効果はプログラムの資金提供期間である2年間持続すると推定される。

```
生成されたWELLBY = 400人 × 0.8ポイント × 2年 = 640 WELLBY
金銭化された価値 = 640 × £13,000 = 832万£
```

年間プログラムコスト£300,000（2年間で£600,000）に対して、便益費用比はおよそ8,320,000 / 600,000 ≈ **13.9:1**である——この数字は、保健プログラムの1QALYあたりの回避コストや、交通プログラムの移動時間節約と同じ評価表に並べることができる。

## ソフトウェア開発との関連

- 既に生活満足度あるいは福祉調査項目を収集している市民向けサービス（ONSの四つの標準的な福祉質問に従い、多くの自治体や保健・ケアプラットフォームがこれを行っている）は、サービス変更ごとにオーダーメイドの経済評価を委託するのではなく、既存のデータパイプラインから直接WELLBYを計算できる。
- WELLBYは、[Social Value Act](../social-value-act/)報告や[社会的投資収益率](../social-return-on-investment/)を構築する技術チームに、全国的に標準化されHM Treasuryが承認した分母を与える。これにより、契約やサプライヤー間で比較できない、オーダーメイドの「影響力スコア」の乱立を避けられる。
- WELLBYは人と時間にわたって加算可能であるため、[成果主義的説明責任](../outcomes-based-accountability/)システムで使われる種類の人口レベルの成果追跡に自然に組み込まれる——サービスダッシュボードは、保健システムが獲得したQALYを報告するのと同じように、四半期ごとに生成された累積WELLBYを報告できる。

## 落とし穴

- **自己申告の満足度上昇がすべてその介入策に帰属すると仮定すること。** 反実仮想（比較群、あるいは統制を伴う前後デザイン）なしには、そのWELLBY上昇を一般的なトレンドと分離することはできない——[反実仮想分析](../counterfactual-analysis/)を参照。
- **WELLBYとQALYを調整なしに一つの合計に混ぜること。** HM Treasuryの指針は、両者が異なるスケールと異なる価値理論に基づいていることを明確にしている。単純にそれらを合計すると、重複する福祉を二重にカウントしてしまう。
- **基準となる金銭価値を無批判に使用すること。** £とWELLBYの換算値は、市場価格ではなく、所得と福祉の回帰から導出された政策的な慣習である。それは、グリーンブック評価間の比較可能性のために使うべきであり、福祉が「何の価値があるか」についての主張として使うべきではない。
- **WELLBYと保健関連QALYを混同すること。** 両者は異なる構成概念を異なるスケールで測定している。保健経済学の変種については[福祉調整生命年](../wellbeing-adjusted-life-years/)を参照し、両者を平均化しないこと。
