# 幸福調整生存年（WELLBY）

WELLBYは、標準的な0〜10の幸福度スケールにおける、一人の一年間についての人生満足度の追加の1ポイントである。これは、保健経済学で使われるQALYの構造的な類似物である——異なる結果を持つ介入策を比較できるようにする単一の単位だが、臨床的な健康状態ではなく主観的な幸福に基づいて構築されており、HM Treasuryの「Wellbeing guidance for appraisal: supplementary Green Book guidance」（2021年）に定められている。

## 重要な理由

費用便益評価は、青少年クラブへの助成金と道路安全計画とメンタルヘルスサービスを比較するための共通の単位を必要としており、これらはどれも成果指標を共有していない。保健経済学はこれを臨床的な介入策についてQALYで解決した——質調整された生存年であり、0（死亡）から1（完全な健康）まで重み付けされる。HM Treasuryの幸福ガイダンスは、同じ論理を非保健の公共支出にまで拡張し、健康状態指数の代わりに、ONSの調和された人生満足度の質問（「全体として、現在の生活にどれだけ満足していますか？」、0〜10で回答）を成果のはしごとして使う。WELLBY1は、一人の人生満足度が一年間まるまる1ポイント上昇することを意味する（あるいは同等に、10人の満足度がそれぞれ1年間で0.1ポイント上昇すること——WELLBYはQALYがそうするように母集団にわたって合計される）。HM Treasuryのガイダンスは、主観的幸福のデータを人生年の価値に対する他のアプローチと照合することによって導出された、WELLBYあたりの例示的な金銭的価値（およそ£13,000、2019/20年価格）を設定しており、これは評価者に、孤独の削減、コミュニティの結束、緑地へのアクセスといった、以前は[幸福評価](../福祉評価/)の技法が記述することしかできず、健康や安全の支出と共通の立場で比較することができなかった成果を貨幣化する方法を与える。

## 計算式

```
WELLBY = Δ人生満足度（0〜10スケール）× その変化が持続する年数
        （影響を受けたすべての人にわたって合計）

貨幣化された幸福便益 = 生み出されたWELLBY × WELLBYあたり価値
                      （HMTの参照値）

参考：QALY = Δ健康状態の効用（0〜1スケール）× その状態で
             生きた年数
```

0〜10の満足度スケールと0〜1のQALY効用スケールは、変換の段階なしには互換性がない。HM Treasuryのガイダンスは、この二つを照合する方法を論じている。それにより、例えばQALYで評価された健康介入策とWELLBYで評価された社会的介入策が、同じ[Green Book評価](../グリーンブック評価/)の中で、静かに二重計上されたり比較不能なままにされたりしないようにする。

## 計算例

**地方自治体の孤独対策サービス**：ある友愛訪問スキームが400人の孤立した高齢住民にサービスを提供する。フォローアップ調査は、平均人生満足度が5.2から6.0（0.8ポイントの増加）に上昇することを示し、その効果は薄れる前に2年間持続すると推定される。

```
WELLBY = 400人 × 0.8ポイント × 2年 = 640 WELLBY

貨幣化された価値 = 640 × £13,000 = £8,320,000
```

年間プログラムコスト£300,000（2年間で£600,000）に対して、便益費用比率はおよそ8,320,000 / 600,000 ≈ **13.9:1**である——この数字は、健康スキームの回避されたQALYあたりコストや交通スキームの移動時間の節約と同じ評価表に座ることができる。

**慈善団体、より小規模**：あるコミュニティアートプログラムが50人の参加者に到達し、測定された満足度の増加は0.3ポイントで1年間持続する。

```
WELLBY = 50 × 0.3 × 1 = 15 WELLBY
貨幣化された価値 = 15 × £13,000 = £195,000
```

## ソフトウェア開発との関連

- すでに人生満足度あるいは幸福の調査項目を収集している市民向けサービス（多くの地方自治体・保健介護プラットフォームは、ONSの四つの標準的な幸福の質問に従っている）は、あらゆるサービス変更ごとにあつらえの経済評価を委託するのではなく、既存のデータパイプラインから直接WELLBYを計算できる。
- WELLBYは、[社会的価値法](../社会的価値法/)報告あるいは[社会的投資収益率](../社会的投資収益率/)のために構築するエンジニアリングチームに、全国的に標準化された、HM Treasuryが承認した分母を与え、契約や供給業者をまたいで比較できないあつらえの「インパクトスコア」の乱立を回避する。
- WELLBYは人と時間にわたって加算的であるため、[成果ベースの説明責任](../成果主義的説明責任/)システムで使われる種類の母集団レベルの成果追跡へときれいに組み込まれる——サービスダッシュボードは、保健システムが獲得したQALYを報告するのと同じように、四半期ごとに生み出された累積WELLBYを報告できる。

## 落とし穴

- **自己申告の満足度の増加が完全にその介入策に帰属すると仮定すること**——反実仮想（比較グループあるいはコントロールを伴う前後デザイン）なしには、WELLBYの増加を一般的なトレンドから分離することはできない——[反実仮想分析](../反実仮想分析/)を参照。
- **照合なしにWELLBYとQALYを一つの合計に混ぜること**——HM Treasuryのガイダンスは、この二つが異なるスケールと異なる根底にある価値の理論を使うことを明示している。それらを素朴に合計することは、重複する福祉を二重計上する。
- **参照となる金銭的価値を批判的検討なしに使うこと**——WELLBYあたりの£の数字は、実質的な不確実性の帯を伴う全国平均の推定値である。HM Treasuryのガイダンスは、それを固定為替レートとして扱うのではなく感度分析を推奨している。
