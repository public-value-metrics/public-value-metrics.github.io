# 成果連動型支払いと社会的インパクト債（PbR/SIB）

成果連動型支払い（PbR）は、行われた活動ではなく、検証された達成成果に基づいて提供者に支払う。社会的インパクト債（SIB）は、特定のPbR資金調達構造であり、民間あるいは慈善的な投資家がサービス提供を前払いし、独立して測定された成果が合意された閾値を達成した場合にのみ、政府の委託者からリターンとともに払い戻される。これにより、提供のリスクが納税者から投資家へと移転する。

## 重要な理由

世界初のSIBは、2010年9月にHMPピーターバラで開始された——Social Financeは17人の投資家から500万£を調達し、短期刑（12か月未満）の受刑者と協働して再犯を減らす「One Service」に資金を提供した。司法省とBig Lottery Fundは、マッチングされた全国比較コホートに対して再犯事象が少なくとも7.5%減少した場合にのみ投資家に払い戻すことに合意した。ピーターバラ・パイロットの最終コホートは再犯9.7%減少を記録し、閾値を余裕をもって上回り、投資家はリターンとともに払い戻された。この仕組みが重要だったのは、それが特定の委託上の問題を解決したからである——政府はインプットではなく成果に対して支払いたかったが、うまくいかないかもしれない介入策の財務リスクを負担できなかった。そこでSIB構造は、そのリスクを、それを引き受ける意思のある投資家へと移した。オックスフォード大学Blavatnik School of GovernmentのGovernment Outcomes Lab（GO Lab）は現在、世界中のPbRとSIBの業績に関する最も完全な公開エビデンス基盤を維持しており、世界中で200件以上のインパクト債を追跡し、どのような設計上の特徴が成功あるいは失敗と相関しているかについての研究を公表している。このエビデンス基盤が繰り返し立ち返る教訓は、*選ばれた成果指標*と、それを逃した場合のリスクを誰が負うかが、PbR契約が実際にどのように機能するかについて、他のほぼすべてを決定するということである。

## 計算式

```
PbR支払い = 基本支払い（あれば）+ Σ (達成された成果 × 成果あたり
            単価)

社会的インパクト債の投資家リターン：
  投資家の支出   = サービス提供に資金を出す前払い資本
  成果支払い     = 委託者は成果が閾値以上の場合にのみ支払い、
                    閾値をどれだけ上回ったかで金額が変わる
  投資家のリターン = 受け取った成果支払い − 投資家の支出
                    （引き受けたリスクを反映した、しばしば上限が
                    設定された利率）

契約全体の振る舞いを決定する主要な設計パラメーター：
  成果指標           — アウトプットではなく成果でなければならない
                       （outcomes-vs-outputsを参照）
  比較/反実仮想       — 通常マッチングされたコホート
                       （counterfactual-analysisを参照）
  支払い閾値          — 支払いが発動する前の最低限の改善
  支払い曲線          — 閾値以上で線形、段階的、あるいは上限付き
  帰属/死荷重の割引    — additionality-and-deadweightを参照
```

## 計算例

**ピーターバラ・One Service**（公表された評価から引用した例示的な数字）：

```
調達された投資家資本：             £5,000,000
コホート：                         二つのコホートにわたる短期刑の
                                   男性受刑者約3,000人
閾値：                             マッチングされた全国比較群に対して
                                   再犯事象が7.5%以上減少、それ以外は
                                   支払いなし
コホート1の結果：                  8.4%減少——当初のルールでは
                                   そのコホート単独では契約上の
                                   ハードルを下回った
最終コホート合算の結果：           9.7%減少——閾値を上回った
成果支払い：                       政府（司法省/Big Lottery Fund）が
                                   閾値を超えた1ポイントごとに支払い、
                                   投資家の払い戻しとリターンに
                                   充てられる
```

**地方自治体のPbR契約（例示）**：ある家族支援介入サービスが、紹介された家族1件あたり£4,000（活動支払い）に加え、支援終了後12か月間さらなる児童保護紹介がない家族1件あたり£6,000（成果支払い）で委託される。200家族が紹介され、150件がクローズし、96件が12か月時点で紹介なしのままである。

```
活動支払い    = 200 × £4,000 = £800,000
成果支払い    = 96 × £6,000  = £576,000
契約総コスト  = £1,376,000（確認された持続的成果96件に対して）
確認された成果1件あたりコスト ≈ £14,333（cost-per-outcomeを参照）
```

## ソフトウェア開発との関連

成果連動型支払いは、データの問題である前にインセンティブ整合の問題であり、データシステムはその整合が保たれるか壊れるかの場所である。独立した、改ざんの証跡が残る成果検証がすべてである——委託者と提供者は、曖昧な事例がどうコード化されるかについて対立するインセンティブを持っているため、成果を記録するシステムには監査証跡、独立した検証者（しばしば提供者とは別の機関であり、時には警察や給付記録と照合する公式統計機関である）とのデータ共有協定、そして成果定義の不変のバージョン管理が必要である——これは[公共セクターKPI](../公共セクターkpi/)における「指標の再定義」という落とし穴のPbR版である。帰属の計算は、再現可能で監査可能なコードを必要とする[反実仮想分析](../反実仮想分析/)のマッチングコホート手法に依存しており、一回限りのスプレッドシートでは不十分である。そして指標そのものは、代理となる活動ではなく本物の成果でなければならない——[成果とアウトプット](../成果とアウトプット/)を参照——なぜなら、アウトプットに対して支払うPbR契約は、追加の取引コストを伴って通常通りの業務を単に再ラベルづけしているだけだからである。SIBの社会的リターンが事前にモデル化される場合、その評価は通常、[社会的投資収益率](../社会的投資収益率/)の方法論を直接借用する。

## 落とし穴

- **操作されやすい代理成果に対して支払うこと。** 「セッションへの出席」は成果を装った活動である。再犯、雇用、住居の安定性のような、求められている実際の変化を反映する尺度を主張すること。
- **信頼できる反実仮想がないこと。** マッチングされた比較群なしには、改善は回帰現象や広いトレンドであって、プログラムの効果ではないかもしれない——[反実仮想分析](../反実仮想分析/)と[追加性と死荷重](../追加性と死荷重/)を参照。
- **取引・評価コストを過小評価すること。** PbR/SIB制度における独立検証、データ連携、契約管理は、契約価値のパーセンテージとして日常的に二桁に達する——GO Labのエビデンス基盤は、これを制度終了の繰り返し起こる原動力として文書化している。
- **チェリーピッキングあるいは「保留」。** 成果ごとに支払われる提供者は、どのみち成功しそうなクライアントを優先し、最も困難なケースを後回しにする直接的なインセンティブを持つ——それに対抗するため、支払い段階あるいはケースミックスの調整を設計すること。
