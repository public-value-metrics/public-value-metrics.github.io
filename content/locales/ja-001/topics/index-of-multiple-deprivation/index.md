# 複合剥奪指数（IMD）

IMDは、イングランドの小地域における相対的剥奪の公式な尺度であり、国内の32,844のLower-layer Super Output Areas（LSOA、それぞれおよそ1,500人の住民）のすべてを1（最も剥奪されている）から32,844（最も剥奪されていない）までランク付けする。これは現在のMinistry of Housing, Communities and Local Government（MHCLG、旧MHCLG/DCLG）によって公表されており、最新版はEnglish Indices of Deprivation 2019である。これは中央政府の資金提供、公衆衛生の優先順位付け、そして何十もの地方のスキームの受給資格に直接ルーティングされる。

## 重要な理由

剥奪は一つのものではない——ある地域は所得が低いが安全かもしれないし、あるいは所得は十分だが健康上の成果が悪く住宅事情が悪いかもしれない。IMDの前身の指数（1970年代のDepartment of the Environmentの剥奪指標にまで遡る）は、単一指標のターゲティング（例えば失業率だけ）が日常的に別の意味で剥奪されている地域を見逃していたため、まさに今日の7領域モデルへと進化した。IMD 2019は、所得、雇用、教育、健康、犯罪、住宅・サービスへの障壁、生活環境をLSOAごとの単一の複合ランクへと組み合わせ、各領域は独自の指標のバスケットから構築され、MHCLGの方法論によって重み付けされる。それが地方自治体レベルではなく小地域（LSOA）レベルで運用されているため、それ以外の点では裕福な地区の中に隠れた剥奪のポケットを明らかにする——これが、平均的な地方自治体の所得ではなくIMDこそが、NHS England、Department for Educationのpupil premium、そして何十もの地方自治体の資金配分の公式が実際に基づいているものである理由である。イングランドで地域別の受給資格を決定し、アウトリーチを優先順位付けし、インパクトを報告するソフトウェアは、IMDの十分位数あるいはランクを、後付けではなく第一級の入力として扱うべきである——そして、あるプログラムが意図的に最も剥奪された地域を対象とする場合、その評価は、その1ポンドの便益がどこに着地するかにかかわらず同じ価値として評価するのではなく、そのターゲティングと一致する[分配的重みづけ](../distributional-weighting/)を適用すべきである。

## 計算式

```
7つの領域、重み付け：
  所得                              22.5%
  雇用                              22.5%
  教育・スキル・訓練                13.5%
  健康剥奪と障害                    13.5%
  犯罪                               9.3%
  住宅とサービスへの障壁             9.3%
  生活環境                           9.3%

各領域スコア：指標は標準化され（ランク付けされ、正規分布に向けて
変換される）、指数変換によって組み合わされ、その領域内のある
一つの指標での高い剥奪が、他の指標での低い剥奪によって完全には
相殺されないようにする。

IMD複合スコア（LSOA） = Σ（領域スコア × 領域の重み）
複合スコアでLSOAをランク付け → 1（最も剥奪されている）から
32,844（最も剥奪されていない）まで
十分位数：ランク ÷ 3,284（およそ）、十分位数1 = 最も剥奪された
10%のLSOA
```

## 計算例

**LSOAの複合スコア**、例示的な標準化された領域スコアを使用（0=剥奪のシグナルなし、高いほど剥奪が大きい）。

```
所得                0.35 × 0.225 = 0.07875
雇用                0.30 × 0.225 = 0.06750
教育                0.20 × 0.135 = 0.02700
健康                0.15 × 0.135 = 0.02025
犯罪                0.10 × 0.093 = 0.00930
住宅への障壁         0.05 × 0.093 = 0.00465
生活環境            0.08 × 0.093 = 0.00744

複合スコア = 0.07875 + 0.06750 + 0.02700 + 0.02025
           + 0.00930 + 0.00465 + 0.00744  = 0.21489
```

その複合スコアは、その後32,844すべてのLSOAのスコアに対してランク付けされる。それがそのLSOAをランク2,950に位置づける場合、それは十分位数1に入る（2,950 ÷ 3,284 ≈ 0.9、つまりイングランドで最も剥奪された10%の近隣地域の中に入る）——多くの資金配分の公式にとって、これは周囲の地方自治体が平均でどうスコア付けされているかにかかわらず、受給資格を解除する閾値である。

## ソフトウェア開発との関連

- 利用者を郵便番号あるいはLSOAにジオコーディングするあらゆるサービスは、公表されているIMD参照テーブル（MHCLGからの無料の、バージョン管理されたCSV）を結合して、新しい個人データを収集することなく、アウトリーチのターゲティング、ケースロードの優先順位付け、あるいは剥奪帯別の成果報告のために剥奪の十分位数を共変量として加えることができる。
- IMDの十分位数は、公共デジタルサービスに対する標準的な公平性チェックである——IMDの十分位数によってサービスの利用、離脱、あるいは満足度をクロス集計することは、集計された指標が隠すアクセスギャップを表面化させる——[デジタル・インクルージョン](../digital-inclusion/)と[市民満足度指標](../citizen-satisfaction-metrics/)を参照。
- IMDのランクは相対的である（それは常にイングランド全体にわたって固定されたランクのセットに合計される）ため、それは時間の経過とともに全国的に剥奪が上昇しているか低下しているかを示すことはできない——その版において互いに対してどの地域がどこにランクされるかだけを示す。生のIMDランクだけで絶対的なトレンドのダッシュボードを構築しないこと。

## 落とし穴

- **異なる版（2015対2019）をまたいでIMDランクを時系列トレンドとして比較すること**——根底にある指標、地理、方法論はすべて版をまたいで変化する。MHCLGは、ある地域がより剥奪された、あるいはより剥奪されなくなったことの証拠としてランクの変化を使うことに対して明示的に助言している。
- **LSOAレベルのIMDを個人に適用すること**——十分位数1のLSOAには依然として剥奪されていない世帯が含まれ、十分位数10のLSOAには依然として剥奪された世帯が含まれる。IMDは人ではなく地域を記述しており、それを個人の受給資格の代理として使うことは両方向で誤分類を生む。
- **複合ランクを優先して領域レベルの詳細を無視すること**——同一の複合スコアを持つ二つのLSOAは、まったく異なる領域プロファイルを持ちうる（一方は健康剥奪、もう一方は犯罪剥奪）。一つの問題を対象とするターゲティングスキームは、混合された複合スコアではなく関連する領域スコアを使うべきである。
