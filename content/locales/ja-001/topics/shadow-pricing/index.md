# 影の価格設定

影の価格とは、観察可能な市場価格を持たない、あるいは市場価格が歪んでいてその真の社会的価値を反映していない財、資源、外部性に割り当てられる推定価値である。政府評価は、小規模な公式の影の価格のセット——炭素、非労働時間、失業中の労働力——に依存しており、これらはすべての省庁が同じ数字を使うよう中央で公表されている。

## 重要な理由

影の価格が存在するのは、[社会的費用便益分析](../social-cost-benefit-analysis/)がすべてのコストと便益に金銭的価値なしでは機能しないためであり、そして最も重大なもののいくつか——排出される二酸化炭素1トン、通勤者の1時間、それ以外では失業しているであろう労働力の1時間——はまったく市場価格を持たないか、あるいはその真の社会的コストを誤って表す市場価格を持つ。HM TreasuryとDepartment for Energy Security and Net Zeroは、英国政府のあらゆる評価で使用される炭素の影の価格を共同で公表しており（<https://www.gov.uk/government/publications/valuing-greenhouse-gas-emissions-in-policy-appraisal>）、これはいかなる炭素市場価格からも導出されておらず、目標整合的アプローチから導かれている——炭素価値は、英国の法定炭素予算を達成するために必要な限界削減コストに設定されており、これはEUや英国の排出量取引制度で炭素が実際に取引される価格を観察するのとは根本的に異なる論理である。

影の賃金率は、労働側で同様の論理に従う。それ以外では失業していたであろう人を雇用することは、社会にとってその全額の賃金を意味しない——その賃金の一部は、社会の資源への純粋な新規の引き出しではなく、放棄された給付金の支払いや失われた余暇/求職時間からの移転である。したがってグリーンブックの指針は、失業から引き出された労働力に対して市場賃金を下回る影の価格を設定し、その労働力の市場価格ではなく真の機会費用を反映させる（[公共支出における機会費用](../opportunity-cost-in-public-spending/)を参照）。

## 計算式

```
炭素の影の価格（例示的な構造、現在の値は公式のBEIS/DESNZの炭素価値
ツールから——古い数字を使わないこと）：
  取引セクターの価値：ETSの排出枠価格の推移を参考にする
  非取引セクター（目標整合的）の価値：法定炭素予算を達成するために
    必要な限界削減コストに設定され、より容易な削減オプションが
    尽きるにつれて時間とともに上昇する
  適用方法：£/トンCO2e × その選択肢が排出あるいは削減するトン数、
    将来年については社会的割引率で割引

影の賃金率（SWR）：
  SWR = 市場賃金 − (節約された放棄される余暇/求職時間の価値
                    + もはや支払われない福祉給付の価値)
  通常、市場賃金の割合として表現される（例えば、余剰能力のある
    労働市場に関するグリーンブック付属Aの指針に従い、
    高失業地域ではSWR=市場賃金の0.6倍）
```

両方の数字とも、経験的な市場観察ではなく、中央で設定された政策上の慣習である——影の価格の目的全体は、欠けているあるいは歪んだ市場の代わりとなることであるため、それを使用する評価は、独自の数字を導出するのではなく、現在の公式のソースを引用しなければならない。まさに、あらゆる省庁の評価が比較可能であるためである。

## 計算例

**中央政府**：ある洪水防御計画の評価は、「最小限実施」のベースラインと比較して、30年間の評価期間にわたって、年間400トンのCO2e排出（緊急機材の使用削減と、回避された再建からの体現炭素の削減による）を回避すると見積もる。

```
例示的な炭素の影の価格：£280/トンCO2e（1年目、公式の非取引炭素
  価値スケジュールに従い評価期間にわたって上昇）
1年目の炭素便益 = 400 × £280 = £112,000
```

公式のスケジュールは評価期間にわたって炭素価値を*上昇*させる（炭素予算の厳格化を反映）ため、アナリストは30年間のフローの各年について、一律の率ではなく正しい年固有の価値を適用しなければならない——1年目の価値を通して使うと後年の便益を過小評価し、異なる炭素プロファイルを持つ代替の洪水防御設計に対するランキングを歪めてしまう。

**地方自治体**：ある自治体の長期失業者向け雇用支援プログラムが、150人を時給£11の職に就かせる。これを全額の市場賃金で評価すると、プログラムには時給£11×労働時間が社会的便益としてクレジットされるが、影の賃金率アプローチは、これらの人々が他の仕事から引き抜かれたわけではないことを認識する——プログラム前の彼らの労働力の真の機会費用は低かった。

```
市場賃金：£11.00/時間
影の賃金率（例示的、高い地域失業率）：市場賃金の0.6倍
  = £6.60/時間
労働1時間あたりの帰属できる社会的純便益 ≈ £11.00 − £6.60
  = £4.40/時間
  （本当に遊休状態だった労働力を生産に移すことで創出される
   「追加的な」価値であり、それ自体は主に移転である賃金とは
   区別される）
```

これが、高失業地域における雇用プログラムの評価が正の社会的純価値を示すことがある一方で、完全雇用地域で同じプログラムが実施された場合（そこでは置き換えられる労働力が単に他の仕事から引き抜かれるだけである）には示さないことがある理由である。

## ソフトウェア開発との関連

影の価格設定がソフトウェア提供に直接触れることはめったにないが、ITの変更から炭素あるいは社会的便益を主張するビジネスケースにとっては重要である——データセンター統合が炭素節約を主張する場合、あるいはペーパーレスサービスが回避された印刷・郵送による炭素を主張する場合、他のグリーンブック評価の入力値と同様に、独自に作った数字ではなく現在の公式の炭素の影の価格を使用し、一律の率ではなく正しい年ごとのスケジュールを適用しなければならない。しばしば直接コスト計算された項目と並んで、算定困難な入力値（侵害リスク、ダウンタイム）に対する影の価格を必要とする[政府ITにおける総所有コスト](../total-cost-of-ownership-in-government-it/)と[公共セクターにおけるサイバーセキュリティ価値](../public-sector-cybersecurity-value/)を参照。

## 落とし穴

- **古い炭素あるいは賃金の数字を使うこと。** 両方の値とも中央の指針によって定期的に改定される。廃止された数字に基づいて構築された評価はTreasuryの精査に耐えない。
- **数十年にわたる評価に一律の影の炭素価格を適用すること。** 公式のスケジュールは時間とともに上昇する。1年目の値を通して使うと、便益あるいはコストのプロファイルを誤って表す。
- **影の賃金を、労働者の実際の給与に対する割引と混同すること。** 影の賃金率は、労働者が実際に支払われる賃金ではなく、*評価*が労働投入をどう評価するかを調整するものである。両者を混同すると、（誤って）市場を下回る賃金を正当化することにつながりかねない。
- **公式の影の価格を使わずに独自のものを導出すること。** 影の価格はまさに、省庁間で評価が比較可能であるようにするための政策上の慣習である。地元で考案された数字は、どれほど根拠があっても、その比較可能性を損なう。
