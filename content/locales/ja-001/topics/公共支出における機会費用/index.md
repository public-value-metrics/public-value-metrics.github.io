# 公共支出における機会費用

機会費用とは、公共機関が資金、職員の時間、あるいは政治的資本をある選択肢に投じることで放棄する、次善の選択肢の価値のことである。予算が固定された部門では、あるプログラムに使われる1ポンドは、次善のプログラムに使うことができない1ポンドである——ある決定の真のコストは、それが何に使われたかではなく、それが何を締め出したかにある。

## 重要な理由

公共予算は支出見直し期間内で現金として制約されているため——成長する民間企業とは異なり——政府部門は良いアイデアのために単に「もっとお金を見つける」ことができない。それに資金を出すということは、他の何かへの資金を打ち切ることを意味する。HM TreasuryのGreen Bookはこれを基礎的なものとして扱っている。すべての評価は、介入策を「最小限実施」のベースラインと*同時に*、同じ資源の現実的な代替使用とも比較することが求められる。なぜなら、Treasuryの支出チームが実際に問うのは「これは良いことか？」ではなく、「これは、このお金が他に買えたであろうものより優れているか？」だからである。Green Bookの評価の核心原則——公共資源は、1ポンドあたりの社会的純価値が最も高い介入策に流れるべきである——は、機会費用を政策として言い表したものである。

これは言うのは簡単だが適用は難しい。なぜなら「次善の代替案」は、一つのビジネスケースの中ではめったに見えないからである。若者雇用のための200万£の助成プログラムは、ビジネスケースの中では「何もしない」と比較されるが、正直な比較対象は次善の若者雇用の介入策、あるいはポートフォリオ内のどこか別の場所での200万£の次善の使い道——雇用以外の支出も含めて——である。Magenta Book（HM Treasury、2020年）は、「介入策あり」と「介入策なし」を比較する評価が、介入策が越えなければならないハードルを過小評価していると明確に警告している。なぜなら、「この介入策がない」ことは「まったく何もない」ことと同じではないからである——解放された資金は他の何かに使われる。

## 計算式

```
Aを選ぶことの機会費用 = 放棄された最善の代替案Bの価値

Aの公共純価値 = 価値(A) − 価値(B)、価値(A) − 0 ではない
```

放棄される代替案は文脈依存であるため普遍的な公式は存在しないが、その規律は一般化できる——同じ予算枠の現実的な次善の使い道を特定し（理想化された「何もしない」ではなく）、同じ基準で評価し（可能な限り金銭化する、[社会的費用便益分析](../社会的費用便益分析/)を参照）、差し引くことである。

## 計算例

**省庁の予算枠**：500万£のデジタル変革基金は、今会計年度中に二つの提案のうちどちらか一つだけを資金提供できる。

- *選択肢A*：新しいケース管理プラットフォーム、5年間の金銭化された便益720万£（効率性の節約と迅速なケース解決）。
- *選択肢B*：三省庁で共有される本人確認サービス、5年間の金銭化された便益640万£。

Aに対する素朴なビジネスケースは、720万£の便益を500万£のコストと比較し、1.44:1の便益費用比を報告する——一見強力である。しかしAとBは同じ500万£を奪い合っているため、Aを選ぶことの機会費用はBの放棄される640万£の便益である。現実的な代替案に対するAの*純*ケースは、720万£の見出し全体ではなく、720万£−640万£=80万£にすぎない。もし第三の選択肢Cが同じ500万£で750万£の便益を提供するなら、AをCの代わりに資金提供することは、A自体のビジネスケースが単独では十分正当に見えるとしても、30万£の公共価値を破壊することになる。

**地方自治体の職員時間**：ある自治体の3人組のデータチームは、住宅待機リストのダッシュボード（年間400担当者時間の節約を見込む、£28/時間=年間£11,200相当）か、給付不正審査ツール（年間£85,000の誤支給を防止すると見込まれる）のどちらかを構築できる。ダッシュボードの構築は、単にデータチームの給与コストではなく、年間£85,000の放棄される機会費用を伴う——「無料」の社内開発の真のコストは、そのチームが他の場所で生み出せたであろうはるかに大きな便益である。

## ソフトウェア開発との関連

公共機関内の技術的な実装能力自体が、ポンドではなくスプリント容量という制約された予算である。同じ規律が直接適用される。

- 常に比較対象を明記すること——ある機能のビジネスケースは、それ自体のリターンだけでなく、同じチーム週数で他に何が提供できたかを述べるべきである。
- 「実装能力に余裕がある」ことを機会費用分析の終着点ではなく出発点として扱うこと——余裕のある容量にも、たとえそれが技術的負債の返済であっても、最善の代替使用がある（[公共価値の侵食としての技術的負債](../公共価値侵食としての技術的負債/)を参照）。
- これを[物有所値](../物有所値/)と直接結びつけること——VFMの「経済性」テストは、正直な機会費用の比較対象なしには意味をなさない。また[公共プログラムにおける遅延コスト](../公共プログラムにおける遅延コスト/)は、同じ放棄された代替案のロジックの時間的側面を価格づける。

## 落とし穴

- **「何もしない」との比較であって、次善の代替案との比較ではないこと。** Green Bookが「最小限実施」のベースラインを要求するのは、まさに真の機会費用がめったにゼロではないからである。「何もしない」のハードルだけを越えるビジネスケースは、現実的な代替案に勝っていることを示していない。
- **同じ予算枠をめぐる部門横断的な競合を無視すること。** ある部局の中では区切られているように見える予算枠も、より高いレベル（支出見直し、資本プログラム）で競合していることが多く、そこで真の機会費用が実現する。
- **解放された職員時間にそれ以上の価値がないと仮定すること。** 「節約された」時間は、価値あるものに再配置されて初めて価値を生む。代替の使い道が存在しなければ、その節約は名目上のものにすぎない。
