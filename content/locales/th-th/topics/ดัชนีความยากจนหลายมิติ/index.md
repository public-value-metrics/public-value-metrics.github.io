# ดัชนีความยากจนหลายมิติ (MPI)

MPI วัดความยากจนเป็นความขาดแคลนที่ซ้อนทับกันซึ่งบุคคลประสบพร้อมกัน — ด้านสุขภาพ การศึกษา และมาตรฐานการครองชีพ — แทนที่จะเป็นรายได้เพียงอย่างเดียวที่ต่ำกว่าเส้น พัฒนาโดย Oxford Poverty and Human Development Initiative (OPHI) ร่วมกับ ซาบินา อัลไคร์ (Sabina Alkire) และเจมส์ ฟอสเตอร์ (James Foster) และเผยแพร่ร่วมกับ UNDP ใน Human Development Report ทุกฉบับตั้งแต่ปี 2010 ควบคู่กับ [ดัชนีการพัฒนามนุษย์ (HDI)](../ดัชนีการพัฒนามนุษย์/)

## เหตุใดจึงสำคัญ

เส้นความยากจนด้านรายได้พลาดผู้ที่มีรายได้เงินสดเพียงพอแต่ขาดน้ำสะอาด การเรียน หรือประสบการสูญเสียบุตร — และพลาดข้อเท็จจริงที่ว่าความขาดแคลนมักรวมกลุ่มกัน: ครัวเรือนที่ไม่มีไฟฟ้ามีแนวโน้มสูงอย่างไม่สมส่วนที่จะขาดสุขาภิบาลและมีเด็กที่ขาดสารอาหารด้วย วิธีอัลไคร์-ฟอสเตอร์ (Alkire-Foster) ซึ่ง MPI สร้างขึ้นมา นับความขาดแคลนของแต่ละคนข้ามสิบตัวชี้วัดที่จัดเป็นสามมิติถ่วงน้ำหนักเท่ากัน — สุขภาพ การศึกษา มาตรฐานการครองชีพ — และจัดว่าใครเป็น "ผู้ยากจนตาม MPI" ก็ต่อเมื่อคะแนนความขาดแคลนถ่วงน้ำหนักของเขาข้ามเกณฑ์คงที่ ซึ่งจับความซ้อนทับที่ชุดสถิติตัวชี้วัดเดียวแยกกันจับไม่ได้ OPHI เผยแพร่ระเบียบวิธีเต็มและข้อมูลรายประเทศที่ <https://ophi.org.uk/multidimensional-poverty-index/> MPI ระดับโลกที่ดูแลร่วมกับ UNDP ปัจจุบันครอบคลุมกว่า 110 ประเทศ สำหรับซอฟต์แวร์ที่สร้างสำหรับโครงการต่อต้านความยากจน — การโอนเงินสด การคัดกรองงานสังคมสงเคราะห์ การกำหนดเป้าหมายความช่วยเหลือ — ชุดตัวชี้วัดของ MPI มักเป็นสิ่งที่ใกล้เคียงที่สุดกับสคีมาความขาดแคลนมาตรฐานที่ผ่านการตรวจสอบกับสำนักงานสถิติแห่งชาติหลายสิบแห่งแล้ว

## คณิตศาสตร์

```
10 ตัวชี้วัด 3 มิติ แต่ละมิติถ่วงน้ำหนัก 1/3:

สุขภาพ (1/3):             โภชนาการ (1/6) การเสียชีวิตของเด็ก (1/6)
การศึกษา (1/3):           จำนวนปีการศึกษา (1/6) การเข้าเรียน (1/6)
มาตรฐานการครองชีพ (1/3):  เชื้อเพลิงหุงต้ม สุขาภิบาล น้ำดื่ม
                           ไฟฟ้า ที่อยู่อาศัย ทรัพย์สิน (1/18 ต่อตัว)

คะแนนความขาดแคลน (c) = ผลรวมน้ำหนักของตัวชี้วัดที่บุคคลขาดแคลน

บุคคลเป็น "ผู้ยากจนตาม MPI" หาก c ≥ 1/3 (เส้นความยากจน k = 33%)

H (สัดส่วนจำนวนหัว) = จำนวนผู้ยากจนตาม MPI / ประชากรทั้งหมด
A (ความรุนแรง)       = คะแนนความขาดแคลนเฉลี่ยในกลุ่มผู้ยากจนตาม MPI เท่านั้น

MPI = H × A
```

เพราะ MPI คูณ *สัดส่วน* ของผู้ยากจนด้วย *ความรุนแรง* ของความยากจน สองภูมิภาคที่มีสัดส่วนจำนวนหัวเท่ากันอาจมีคะแนน MPI ต่างกันมากหากความขาดแคลนรุนแรงกว่าในภูมิภาคหนึ่ง — ตรรกะ "ไม่มีการทดแทนข้ามมิติ" เดียวกับเบื้องหลังค่าเฉลี่ยเรขาคณิตของ HDI

## ตัวอย่างการคำนวณ

**แบบสำรวจระดับชาติของประชากร 1,000 คน**: 350 คนถูกระบุว่ายากจนหลายมิติ (คะแนนความขาดแคลน ≥ 33%) ในกลุ่มผู้ยากจน 350 คนนั้น คะแนนความขาดแคลนเฉลี่ยคือ 45%

```
H = 350 / 1000                = 0.350
A = 0.45
MPI = H × A = 0.350 × 0.45    = 0.1575
```

**เปรียบเทียบสองอำเภอที่มีสัดส่วนจำนวนหัวเท่ากัน**: อำเภอ A มี H = 0.30 และ A = 0.40 (ผู้ยากจนจำนวนมาก ขาดแคลนปานกลาง); อำเภอ B มี H = 0.30 และ A = 0.60 (จำนวนผู้ยากจนเท่ากัน แต่ขาดแคลนรุนแรงกว่า — ขาดไฟฟ้า *และ* สุขาภิบาล *และ* การเข้าเรียนพร้อมกัน)

```
MPI_A = 0.30 × 0.40 = 0.120
MPI_B = 0.30 × 0.60 = 0.180
```

สัดส่วนจำนวนหัวเท่ากัน MPI ของอำเภอ B สูงกว่า 50% — ระบบกำหนดเป้าหมายที่อิงความยากจนจำนวนหัวเพียงอย่างเดียวจะจัดอันดับสองอำเภอเท่ากันและพลาดว่าอำเภอ B ต้องการการแทรกแซงที่ลึกกว่า

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

- ระบบบริหารจัดการกรณีและตรวจสิทธิ์สำหรับโครงการสังคมมักเก็บตัวชี้วัดบางส่วนจากสิบตัว (ที่อยู่อาศัย การเข้าเรียน ตัวชี้วัดสุขภาพ) ไว้ในไซโลแยกกันอยู่แล้ว วิธีการนับของอัลไคร์-ฟอสเตอร์เป็นสคีมาสำเร็จรูปสำหรับรวมเป็นคะแนนความขาดแคลนเดียว แทนที่จะสร้างแบบจำลองให้คะแนนเฉพาะตั้งแต่ต้น
- การแยกจำนวนหัว/ความรุนแรง (H × A) เป็นรูปแบบที่มีประโยชน์ทั่วไปสำหรับแดชบอร์ดใด ๆ ที่รายงาน "มีผู้ได้รับผลกระทบกี่คน" ควบคู่กับ "รุนแรงแค่ไหน" — การยุบทั้งสองเป็นตัวเลขเดียว อย่างที่สถิติความชุกดิบทำ ซ่อนกรณีที่ต้องการทรัพยากรมากที่สุดพอดี
- แดชบอร์ดตัวชี้วัดแบบ MPI จับคู่ได้ตามธรรมชาติกับการรายงาน [ต้นทุนต่อผู้รับประโยชน์](../ต้นทุนต่อผู้รับประโยชน์/) สำหรับโครงการต่อต้านความยากจน: ต้นทุนต่อหนึ่งจุดที่ MPI ลดลงเป็นหน่วยที่ป้องกันได้ในการเปรียบเทียบการแทรกแซงที่ต่างกันมาก (การโอนเงินสดกับโครงสร้างพื้นฐานสุขาภิบาล)

## ข้อผิดพลาดที่พบบ่อย

- **ถือว่าสิบตัวชี้วัดเป็นสากล** — ตัวชี้วัด MPI ระดับโลกของ OPHI ปรับเทียบเพื่อให้เปรียบเทียบข้ามประเทศได้ MPI ระดับชาติ (หลายประเทศรวมถึงบางประเทศในเอเชียใต้และแอฟริกาเผยแพร่ของตนเอง) ปรับตัวชี้วัดและน้ำหนักให้เข้ากับบริบทท้องถิ่น และทั้งสองเปรียบเทียบตรง ๆ ไม่ได้
- **รายงาน H อย่างเดียว** — สัดส่วนจำนวนหัวเพิกเฉยต่อความรุนแรงโดยสิ้นเชิง รายงานหรือคำนวณ A ควบคู่เสมอ หรือรายงาน MPI เอง
- **สมมติว่าผู้ยากจนตาม MPI และผู้ยากจนด้านรายได้เป็นประชากรกลุ่มเดียวกัน** — สรุปรายประเทศของ OPHI เองมักแสดงความซ้อนทับเพียงบางส่วนระหว่างสองกลุ่ม โครงการที่ตั้งเป้าเฉพาะผู้ยากจนด้านรายได้จะพลาดส่วนสำคัญของผู้ยากจนหลายมิติอย่างเป็นระบบ
