# ผลเพิ่มเติมและส่วนสูญเปล่า (Additionality and Deadweight)

ผลเพิ่มเติม (additionality) ถามว่าการแทรกแซงก่อให้เกิดผลลัพธ์ที่ไม่อาจเกิดขึ้นได้ด้วยวิธีอื่นหรือไม่ ส่วนสูญเปล่า (deadweight) คือด้านตรงข้าม: สัดส่วนของผลลัพธ์ที่จะเกิดขึ้นอยู่แล้ว แม้ไม่มีโครงการ เงินอุดหนุน หรือการให้เงินสนับสนุน ข้อกล่าวอ้างเรื่องผลกระทบจากโครงการของรัฐหรือองค์กรการกุศลเกือบทุกรายการประเมินผลเกินจริงจนกว่าจะหักส่วนสูญเปล่าออก ซึ่งเป็นเหตุผลที่แนวทางการประเมินของสหราชอาณาจักรถือว่าเป็นการปรับแก้ข้อแรกและสำคัญที่สุดสำหรับตัวเลขพาดหัวทุกตัว

## เหตุใดจึงสำคัญ

"เราสนับสนุนธุรกิจ 500 แห่งให้เติบโต" ฟังดูเป็นความสำเร็จ แต่ถ้าธุรกิจ 300 แห่งในจำนวนนั้นจะเติบโตอยู่แล้ว — เพราะเศรษฐกิจท้องถิ่นกำลังฟื้นตัว เพราะมีแหล่งเงินทุนอื่น เพราะอยู่บนเส้นทางการเติบโตอยู่แล้วก่อนโครงการจะเริ่ม — ผลงานเพิ่มเติมที่แท้จริงของโครงการคือ 200 ไม่ใช่ 500 Magenta Book ของ HM Treasury และ "Additionality Guide" ของ HM Treasury/BIS ที่ใช้มาอย่างยาวนาน (พัฒนาขึ้นเดิมสำหรับโครงการพัฒนาภูมิภาคและการฟื้นฟู และถูกใช้อย่างกว้างขวางในการประเมินของรัฐบาลสหราชอาณาจักรตั้งแต่นั้นมา) กำหนดให้ส่วนสูญเปล่าเป็นการปรับแก้ขั้นแรกในลำดับผลกระทบสุทธิมาตรฐาน: ผลรวม (gross) หักส่วนสูญเปล่า หักการเคลื่อนย้ายผล หักการรั่วไหล ปรับด้วยผลตัวคูณ เท่ากับผลกระทบเพิ่มเติมสุทธิ การข้ามขั้นตอนนี้เป็นวิธีเดียวที่พบบ่อยที่สุดที่ทำให้ข้อกล่าวอ้างด้านผลกระทบของภาครัฐและภาคสังคมถูกขยายเกินจริง ไม่ว่าจะตั้งใจหรือไม่ก็ตาม — โครงการเงินอุดหนุนที่วัดเฉพาะผลลัพธ์รวมของผู้เข้าร่วม โดยไม่มีกลุ่มเปรียบเทียบ ไม่สามารถแยกผลของตนเองออกจากสิ่งที่จะเกิดขึ้นอยู่แล้วได้

ส่วนสูญเปล่าไม่ใช่เปอร์เซ็นต์คงที่ แต่ขึ้นอยู่กับสภาพตรงข้ามกับข้อเท็จจริงสำหรับประชากรและการแทรกแซงที่เฉพาะเจาะจงโดยสิ้นเชิง (ดู [การวิเคราะห์สภาพตรงข้ามกับข้อเท็จจริง](../การวิเคราะห์สภาพตรงข้ามกับข้อเท็จจริง/)) การประเมินการพัฒนาภูมิภาคของอังกฤษภายใต้ Regional Development Agencies เดิมพบอัตราส่วนสูญเปล่าอยู่ในช่วง 20–60% ขึ้นอยู่กับประเภทของการสนับสนุนธุรกิจ ซึ่งเป็นเหตุผลที่การประเมินโครงการที่น่าเชื่อถือรายงานเป็นช่วงที่ปรับด้วยส่วนสูญเปล่าแล้วแทนที่จะเป็นตัวเลขเดียวที่สมมติ และเป็นเหตุผลที่ผู้ให้ทุนอย่าง National Lottery Community Fund และ Big Society Capital กำหนดให้ผู้รับทุนจัดการกับส่วนสูญเปล่าอย่างชัดเจนในการรายงานผลลัพธ์ แทนที่จะรายงานจำนวนผู้เข้าร่วมแบบรวม

## คณิตศาสตร์

ลำดับการปรับแก้ผลกระทบสุทธิมาตรฐาน ตามที่กำหนดไว้ในแนวทางการประเมินของสหราชอาณาจักร (Magenta Book; HM Treasury/BIS Additionality Guide; แนวทางการประเมิน ESIF และกองทุนโครงสร้าง):

```
ผลลัพธ์รวม (Gross)
  − ส่วนสูญเปล่า    (สิ่งที่จะเกิดขึ้นอยู่แล้ว)
  − การเคลื่อนย้ายผล (กิจกรรม/ประโยชน์ที่ย้ายมาจากที่อื่น ไม่ได้สร้างขึ้นใหม่ — ดู
                       การเคลื่อนย้ายผลและการระบุที่มา)
  − การรั่วไหล      (ประโยชน์ที่ตกแก่ผู้อยู่นอกกลุ่ม/พื้นที่เป้าหมาย)
  × ตัวคูณ          (กิจกรรมทางเศรษฐกิจทางอ้อม/ที่ถูกเหนี่ยวนำเพิ่มเติม เมื่อเป็นบวก)
  = ผลกระทบเพิ่มเติมสุทธิ
```

อัตราส่วนสูญเปล่าในรูปสัดส่วน:

```
อัตราส่วนสูญเปล่า = ผลลัพธ์ที่จะเกิดขึ้นโดยไม่มีการแทรกแซง
                   / ผลลัพธ์รวมทั้งหมดที่สังเกตได้

ผลลัพธ์เพิ่มเติมสุทธิ = ผลลัพธ์รวม × (1 − อัตราส่วนสูญเปล่า)
```

## ตัวอย่างการคำนวณ

**โครงการเงินอุดหนุนสนับสนุนธุรกิจ**: โครงการเงินอุดหนุนระดับภูมิภาครายงานว่าธุรกิจที่ได้รับการสนับสนุน 500 แห่งเพิ่มการจ้างงานในปีถัดมา เฉลี่ยแห่งละ 3 ตำแหน่ง — ข้อกล่าวอ้างแบบรวม 1,500 ตำแหน่ง

กลุ่มเปรียบเทียบที่จับคู่ของธุรกิจที่คล้ายกันซึ่งไม่ได้รับการสนับสนุน (ดู [การวิเคราะห์สภาพตรงข้ามกับข้อเท็จจริง](../การวิเคราะห์สภาพตรงข้ามกับข้อเท็จจริง/)) แสดงให้เห็นว่า 40% ของการเติบโตด้านการจ้างงานของธุรกิจที่ได้รับการสนับสนุนจะเกิดขึ้นอยู่แล้ว โดยพิจารณาจากผลงานของกลุ่มที่จับคู่ในช่วงเวลาเดียวกัน

```
อัตราส่วนสูญเปล่า = 40%
ตำแหน่งงานเพิ่มเติมสุทธิ = 1,500 × (1 − 0.40) = 900 ตำแหน่ง
```

ความสำเร็จของโครงการที่รายงานได้อย่างซื่อตรงคือ 900 ตำแหน่ง ไม่ใช่ 1,500 — ลดลง 40% จากการปรับส่วนสูญเปล่าเพียงอย่างเดียว ก่อนจะพิจารณาการเคลื่อนย้ายผลหรือการรั่วไหลด้วยซ้ำ

**โครงการจ้างงานขององค์กรการกุศล**: องค์กรการกุศลจัดหางานให้ผู้ว่างงานระยะยาว 200 คน ด้วยต้นทุน 600,000 ปอนด์ (3,000 ปอนด์ต่อการจัดหางานหนึ่งราย แบบรวม) ข้อมูลตลาดแรงงานระดับประเทศแสดงว่า หากไม่มีการแทรกแซงใด ๆ ประมาณ 15% ของกลุ่มผู้ว่างงานระยะยาวที่เทียบเคียงได้จะหางานได้ในช่วงเวลาเดียวกันผ่านการหมุนเวียนตามธรรมชาติของตลาดงาน

```
อัตราส่วนสูญเปล่า = 15%
การจัดหางานเพิ่มเติมสุทธิ = 200 × (1 − 0.15) = 170
ต้นทุนที่แท้จริงต่อการจัดหางานเพิ่มเติม = 600,000 ปอนด์ / 170 ≈ 3,529 ปอนด์
```

ตัวเลขต้นทุนแบบรวมต่อการจัดหางานหนึ่งราย (3,000 ปอนด์) ประเมินต้นทุนที่แท้จริงของผลงานเพิ่มเติมขององค์กรการกุศลต่ำเกินไปประมาณ 15%

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

ผลเพิ่มเติมและส่วนสูญเปล่ามีความสำคัญโดยตรงต่อทุกคนที่สร้างซอฟต์แวร์วัดผลกระทบหรือจัดการเงินอุดหนุนสำหรับภาครัฐหรือภาคสังคม:

- ระบบรายงานผลลัพธ์ควรเก็บกลุ่มเปรียบเทียบหรือกลุ่มฐานเป็นส่วนหนึ่งของการออกแบบ ไม่ใช่แค่ผลลัพธ์ของผู้เข้าร่วม — การเพิ่มสภาพตรงข้ามกับข้อเท็จจริงภายหลังเมื่อระบบเปิดใช้งานโดยไม่มีสิ่งนี้ยากกว่าการสร้างการเก็บข้อมูลตั้งแต่ต้นมาก (ดู [การวิเคราะห์สภาพตรงข้ามกับข้อเท็จจริง](../การวิเคราะห์สภาพตรงข้ามกับข้อเท็จจริง/))
- แดชบอร์ดที่รายงานเฉพาะจำนวนผู้เข้าร่วมแบบรวมจะประเมินผลกระทบสูงเกินจริงต่อผู้ให้ทุนและหน่วยงานกำกับดูแลอย่างเป็นระบบ; เมื่อมีค่าประมาณส่วนสูญเปล่า (จากเอกสารการประเมินหรือกลุ่มเปรียบเทียบ) ซอฟต์แวร์ควรแสดงตัวเลขหลังหักส่วนสูญเปล่าควบคู่กับตัวเลขรวม ไม่ใช่แทนที่
- เรื่องนี้เชื่อมโยงโดยตรงกับ [ผลตอบแทนทางสังคมจากการลงทุน](../ผลตอบแทนทางสังคมจากการลงทุน/) ซึ่งอัตราส่วน SROI จะน่าเชื่อถือก็ต่อเมื่อหักส่วนสูญเปล่า (และการเคลื่อนย้ายผล) ออกจากผลลัพธ์รวมที่อ้างแล้วเท่านั้น — เครื่องคำนวณ SROI ที่ข้ามขั้นตอนนี้จะให้อัตราส่วนที่ขยายเกินจริงซึ่งไม่อาจทนต่อการตรวจสอบ

## ข้อผิดพลาดที่พบบ่อย

- **รายงานผลลัพธ์รวมราวกับว่าเป็นผลเพิ่มเติมทั้งหมด** นี่เป็นข้อผิดพลาดในการวัดผลกระทบที่พบบ่อยที่สุดในการรายงานเงินอุดหนุนและโครงการ; ให้ถามเสมอว่า "สิ่งนี้จะเกิดขึ้นอยู่แล้วหรือไม่?" ก่อนเผยแพร่ตัวเลขพาดหัว
- **สมมติว่าเปอร์เซ็นต์ส่วนสูญเปล่าเดียวใช้ได้ทุกที่** ส่วนสูญเปล่าแตกต่างกันมากตามภาคส่วน ประชากร และสภาวะเศรษฐกิจท้องถิ่น; ใช้กลุ่มเปรียบเทียบหรือหลักฐานเฉพาะภาคส่วน แทนที่จะนำตัวเลขจากการประเมินที่ไม่เกี่ยวข้องมาใช้ซ้ำ
- **สับสนระหว่างส่วนสูญเปล่ากับการเคลื่อนย้ายผล** ส่วนสูญเปล่าเกี่ยวกับผลลัพธ์ตรงข้ามกับข้อเท็จจริงของผู้เข้าร่วมกลุ่มเดียวกัน; การเคลื่อนย้ายผลเกี่ยวกับผลกระทบต่อบุคคลหรือสถานที่อื่น — ดู [การเคลื่อนย้ายผลและการระบุที่มา](../การเคลื่อนย้ายผลและการระบุที่มา/) การสับสนทั้งสองอย่างนำไปสู่การนับซ้ำหรือนับขาดของการปรับแก้
- **ส่วนสูญเปล่าที่ผู้เข้าร่วมรายงานเอง** การถามผู้รับประโยชน์ว่า "สิ่งนี้จะเกิดขึ้นโดยไม่มีความช่วยเหลือของเราหรือไม่?" ให้ค่าประมาณส่วนสูญเปล่าต่ำเกินไปอย่างเป็นระบบ (ผู้เข้าร่วมมักให้เครดิตแก่โครงการ); กลุ่มเปรียบเทียบอิสระน่าเชื่อถือกว่ามาก
