# การวิเคราะห์ต้นทุนประสิทธิผลในภาครัฐ

การวิเคราะห์ต้นทุนประสิทธิผล (CEA) เปรียบเทียบต้นทุนของวิธีทางเลือกในการบรรลุผลลัพธ์ *เดียวกัน* โดยแสดงเป็นหน่วยธรรมชาติ — ต้นทุนต่อคนนอนข้างถนนที่ได้ที่พักอาศัย ต้นทุนต่อนักเรียนที่ยกระดับถึงมาตรฐานที่คาดหวัง ต้นทุนต่อตัน CO2 ที่ลดได้ — โดยไม่แปลงผลลัพธ์เองเป็นเงิน

## เหตุใดจึงสำคัญ

Green Book ถือว่า CEA เป็นวิธีสำรองเมื่อข้อกำหนดของ [การวิเคราะห์ต้นทุนและผลประโยชน์ทางสังคม](../การวิเคราะห์ต้นทุนและผลประโยชน์ทางสังคม/) ที่ให้ประเมินประโยชน์ทุกอย่างเป็นตัวเงินกลายเป็นเรื่องที่ไม่ใช่แค่ยากแต่ไม่ซื่อตรง — คือเมื่อการตั้งราคาที่น่าเชื่อถือให้ผลลัพธ์จำเป็นต้องใช้สมมติฐานที่ไม่มีใครเชื่อจริง (<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>, บทที่ 5 ว่าด้วยการประเมินทางเลือกเมื่อผลลัพธ์ประเมินเป็นตัวเงินได้ไม่ง่าย) CEA เป็นวิธีที่ยืมโดยตรงที่สุดจากเศรษฐศาสตร์สาธารณสุข — โครงสร้างเหมือนกับที่ NICE เปรียบเทียบการรักษาด้วยต้นทุนต่อปีสุขภาวะที่ปรับด้วยคุณภาพ — แต่นำมาใช้กับโครงการสาธารณะนอกด้านสุขภาพ: การแทรกแซงด้านการศึกษาต่อแต้มผลลัพธ์ของนักเรียน โครงการที่อยู่อาศัยต่อครัวเรือนที่ป้องกันไม่ให้ไร้บ้าน โครงการจ้างงานต่อผลลัพธ์การมีงานทำที่ยั่งยืน

เหตุผลที่ CEA ได้ที่ยืนเคียงข้าง SCBA แทนที่จะถูกกลืนไปคือ การบังคับให้ผลลัพธ์บางอย่างมีมูลค่าเป็นเงินให้ตัวเลขที่แม่นยำพอจะดูน่าเชื่อถือ และเป็นที่โต้แย้งมากพอจนไร้ค่าในการอภิปรายสาธารณะ — การตั้งราคาให้ "เด็กที่อ่านได้ตามมาตรฐานที่คาดหวัง" เชิญชวนการท้าทายแบบที่ทำให้กรณีทางธุรกิจพังในคณะกรรมาธิการ CEA เลี่ยงข้อโต้แย้งด้วยการปฏิเสธที่จะเข้าร่วม: จัดอันดับทางเลือกตามต้นทุนต่อหน่วยของ *ผลลัพธ์เอง* และทิ้งการตัดสินใจทางการเมืองที่แยกต่างหากว่าผลลัพธ์นั้นคุ้มค่าแก่การไล่ตามหรือไม่ไว้ให้กรณีเชิงยุทธศาสตร์

## คณิตศาสตร์

```
อัตราส่วนต้นทุนประสิทธิผล (เฉลี่ย) = ต้นทุนรวม / จำนวนหน่วยผลลัพธ์ทั้งหมดที่บรรลุ

อัตราส่วนต้นทุนประสิทธิผลส่วนเพิ่ม (ICER) เปรียบเทียบทางเลือก A กับ B:
ICER = (ต้นทุน_A − ต้นทุน_B) / (ผลลัพธ์_A − ผลลัพธ์_B)

ขั้นตอน:
1. กำหนดหน่วยผลลัพธ์และวิธีวัดให้เหมือนกันทุกทางเลือกที่เปรียบเทียบ
2. คิดต้นทุนทุกทางเลือกบนฐานเดียวกัน (ดู ../green-book-appraisal/ กรณีทางการเงิน)
   ในช่วงเวลาเดียวกัน
3. ตัดทางเลือกที่ถูกเหนือกว่า: ทางเลือกใดที่มีต้นทุนต่อหน่วยสูงกว่า
   ทางเลือกที่ถูกกว่าซึ่งบรรลุผลลัพธ์เท่ากันหรือดีกว่า ให้ตัดทิ้ง
4. จัดอันดับทางเลือกที่เหลือด้วยอัตราส่วนต้นทุนประสิทธิผลส่วนเพิ่ม ไม่ใช่ค่าเฉลี่ย
```

CEA เพียงลำพังบอกไม่ได้ว่าโครงการสมควรได้รับเงินทุนหรือไม่ — บอกได้เพียงว่าวิธีใดในหลายวิธีสู่เป้าหมายเดียวกันถูกที่สุดต่อหน่วย การตัดสินว่าเป้าหมายเองคุ้มค่ากับการใช้จ่ายหรือไม่ ต้องอาศัยการแปลงกลับเป็น SCBA (หากมีการประเมินมูลค่าที่น่าเชื่อถือ) หรือการตัดสินใจทางการเมือง/ยุทธศาสตร์นอกเหนือจากคณิตศาสตร์ ในกรณีที่ผลลัพธ์ลดทอนเป็นหน่วยเดียวไม่ได้จริง ๆ — เพราะโครงการสร้างหลายผลลัพธ์ที่สำคัญคนละแบบ — ให้ใช้ [การวิเคราะห์การตัดสินใจหลายเกณฑ์](../การวิเคราะห์การตัดสินใจหลายเกณฑ์/) แทน

## ตัวอย่างการคำนวณ

**หน่วยงานท้องถิ่น**: สภาเปรียบเทียบสามวิธีลดการนอนข้างถนน โดยแต่ละวิธีคิดต้นทุนในหนึ่งปีเทียบกับผลลัพธ์ "บุคคลที่ย้ายเข้าที่พักอาศัยมั่นคงนาน 6+ เดือน":

```
ทางเลือก                        ต้นทุน        ผลลัพธ์ที่บรรลุ   CER เฉลี่ย
Housing First (เข้มข้น)         900,000 ปอนด์   60              15,000 ปอนด์/ผลลัพธ์
หอพักสงเคราะห์ + สนับสนุนการย้ายออก 600,000 ปอนด์ 50            12,000 ปอนด์/ผลลัพธ์
งานเชิงรุก + ภาคเช่าเอกชน        350,000 ปอนด์   20              17,500 ปอนด์/ผลลัพธ์

ICER, หอพักสงเคราะห์เทียบงานเชิงรุก:  (600k−350k)/(50−20) = 8,333 ปอนด์ต่อผลลัพธ์ที่เพิ่ม
ICER, Housing First เทียบหอพักสงเคราะห์: (900k−600k)/(60−50) = 30,000 ปอนด์ต่อผลลัพธ์ที่เพิ่ม
```

งานเชิงรุกถูกหอพักสงเคราะห์เหนือกว่าในต้นทุนเฉลี่ย แต่ก้าว *ส่วนเพิ่ม* จากงานเชิงรุกไปหอพักสงเคราะห์มีต้นทุนเพียง 8,333 ปอนด์ต่อคนที่ได้ที่พักเพิ่ม — ถูกเมื่อเทียบกับก้าวไป Housing First ซึ่งมีต้นทุน 30,000 ปอนด์ต่อคนที่เพิ่มเกินกว่าที่หอพักสงเคราะห์ทำได้ หน่วยงานที่มีงบจำกัดและกำลังขยายควรเลือกขยายหอพักสงเคราะห์ก่อน Housing First แม้ Housing First จะดูดีกว่าในอัตราส่วนเฉลี่ยของตนเอง

**รัฐบาลกลาง**: โครงการเร่งรัดการอ่านเปรียบเทียบสามรูปแบบการส่งมอบด้าน "ต้นทุนต่อนักเรียนที่อ่านถึงมาตรฐานตามวัย": การสอนตัวต่อตัว (1,800 ปอนด์/นักเรียน) การสอนกลุ่มย่อย (700 ปอนด์/นักเรียน) และการแทรกแซงดิจิทัลล้วน (150 ปอนด์/นักเรียน แต่มีอัตราผลลัพธ์เพียง 40% ของการสอนกลุ่มย่อยต่อนักเรียนที่ลงทะเบียน เมื่อปรับตามการหลุดจากการมีส่วนร่วม) เมื่อปรับตามการเรียนจบจริง ดิจิทัลล้วนมีต้นทุน 375 ปอนด์ต่อนักเรียนที่ถึงมาตรฐาน — ยังคงถูกที่สุด แต่ CEA บอกไม่ได้ว่าจำนวนนักเรียนสัมบูรณ์ที่น้อยกว่าที่ได้รับความช่วยเหลือจากดิจิทัลล้วน หากส่งมอบด้วยงบเท่ากับกลุ่มย่อย เป็นการแลกเปลี่ยนที่ยอมรับได้กับการเข้าถึงนักเรียนน้อยลงแต่ลึกขึ้นหรือไม่; นั่นเป็นการตัดสินด้านการกระจายที่ CEA ส่งคืนให้ผู้ตัดสินใจ

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

CEA เป็นกรอบที่ถูกต้องเมื่อใดก็ตามที่ทีมวิศวกรรมประเมินแนวทางการส่งมอบสำหรับผลลัพธ์บริการ *เดียวกัน* — ต้นทุนต่อการยืนยันตัวตนที่สำเร็จข้ามผู้ขายยืนยันตัวตนสามราย ต้นทุนต่อกรณีที่คัดแยกถูกต้องข้ามการออกแบบระบบอัตโนมัติงานธุรการสองแบบ ต้นทุนต่อข้อบกพร่องด้านการเข้าถึงที่แก้ไขแล้วระหว่างการแก้ไขภายในกับการจ้างภายนอก วินัยที่นำเข้ามาโดยตรง: กำหนดหน่วยผลลัพธ์ก่อนเปรียบเทียบต้นทุน (ไม่ใช่ "ตั๋วที่ปิด" ซึ่งเป็นผลผลิต แต่เป็น "ความต้องการของผู้ใช้ที่แก้ไขได้จริง") และคำนวณอัตราส่วนส่วนเพิ่มระหว่างระบบที่ใช้อยู่กับตัวแทนที่เสนอเสมอ ไม่ใช่ต้นทุนเฉลี่ยของแต่ละระบบโดด ๆ ดู [ผลลัพธ์กับผลผลิต](../ผลลัพธ์กับผลผลิต/) และ [ต้นทุนต่อผลลัพธ์](../ต้นทุนต่อผลลัพธ์/)

## ข้อผิดพลาดที่พบบ่อย

- **เปรียบเทียบอัตราส่วนเฉลี่ย ไม่ใช่ส่วนเพิ่ม เมื่อตัดสินใจขยาย** ดังตัวอย่างคนนอนข้างถนนแสดง ทางเลือกที่มีอัตราส่วนเฉลี่ยดีที่สุดไม่ใช่หน่วยผลลัพธ์ถัดไปที่ถูกที่สุดเสมอไป
- **เลือกหน่วยผลลัพธ์ที่จริง ๆ เป็นผลผลิต** "การส่งต่อที่ทำ" หรือ "ครั้งการให้บริการที่ส่งมอบ" วัดกิจกรรม ไม่ใช่ผลลัพธ์ที่โครงการมีไว้เพื่อสร้าง; CEA บนผลผลิตให้ตัวเลขที่ดูมั่นใจซึ่งตอบคำถามผิด
- **เปรียบเทียบข้ามผลลัพธ์ที่ต่างกันอย่างแท้จริง** CEA ใช้ได้เมื่อทุกทางเลือกมุ่งไปที่ผลลัพธ์เดียวกันที่วัดแบบเดียวกัน; การเปรียบเทียบ "ต้นทุนต่อคนนอนข้างถนนที่ได้ที่พัก" กับ "ต้นทุนต่อเยาวชนที่ออกจากการดูแลและเช่าที่อยู่ได้มั่นคง" ต้องใช้มาตรวัดผลลัพธ์ทั่วไปหรือ [การวิเคราะห์การตัดสินใจหลายเกณฑ์](../การวิเคราะห์การตัดสินใจหลายเกณฑ์/) ไม่ใช่ CEA
- **ละเลยความคงทนของผลลัพธ์** ทางเลือกที่ถูกกว่าซึ่งสร้างผลลัพธ์ที่ไม่คงอยู่ (นักเรียนที่ถดถอยหลังการแทรกแซงสิ้นสุด) ไม่ได้คุ้มค่าจริงเมื่อวัดในช่วงเวลาเทียบเคียง; ควรจับคู่ช่วงเวลาติดตามผลข้ามทางเลือกที่เปรียบเทียบ
