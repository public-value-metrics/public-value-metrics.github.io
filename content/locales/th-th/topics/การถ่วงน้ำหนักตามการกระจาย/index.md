# การถ่วงน้ำหนักตามการกระจาย

การถ่วงน้ำหนักตามการกระจาย (distributional weighting) ปรับมูลค่าเป็นตัวเงินของต้นทุนหรือประโยชน์ตามว่าใครเป็นผู้ได้รับ ด้วยหลักการที่ว่าเงินปอนด์เพิ่มอีกหนึ่งปอนด์มีค่ามากกว่าสำหรับครัวเรือนยากจนเมื่อเทียบกับครัวเรือนร่ำรวย Green Book ของ HM Treasury ให้วิธีการที่ชัดเจนในการใช้การถ่วงน้ำหนักนี้ โดยอิงอรรถประโยชน์ส่วนเพิ่มของรายได้ที่ลดลง เพื่อไม่ให้การประเมินปฏิบัติต่อหนึ่งปอนด์ที่คนรวยที่สุดหนึ่งในสิบได้รับเท่ากับหนึ่งปอนด์ที่คนจนที่สุดได้รับอย่างเงียบ ๆ

## เหตุใดจึงสำคัญ

การวิเคราะห์ต้นทุนและผลประโยชน์มาตรฐานรวมเงินปอนด์โดยไม่ถามว่าเป็นปอนด์ของใคร ซึ่งสันนิษฐานโดยนัยว่าหนึ่งปอนด์มีค่าเท่ากันสำหรับทุกคน — สมมติฐานที่นักเศรษฐศาสตร์รู้มานานแล้วว่าไม่จริง ครัวเรือนที่มีรายได้ 15,000 ปอนด์/ปี รู้สึกถึงกำไร 1,000 ปอนด์ต่างจากครัวเรือนที่มีรายได้ 150,000 ปอนด์/ปีมาก เพราะอรรถประโยชน์ส่วนเพิ่มของรายได้ลดลงเมื่อรายได้สูงขึ้น หากไม่ถ่วงน้ำหนัก การประเมินมาตรฐานจะเอื้อต่อการแทรกแซงที่เป็นประโยชน์ต่อกลุ่มที่ร่ำรวยกว่าและอยู่ในฐานะดีอยู่แล้วอย่างเป็นระบบ เพราะอำนาจซื้อที่สูงกว่าทำให้การประเมินมูลค่าเป็นตัวเงินของประโยชน์ที่ไปถึงพวกเขาพองขึ้น (การปรับปรุงสวนสาธารณะใกล้บ้านราคาแพง "แสดง" ประโยชน์ต่อมูลค่าทรัพย์สินที่ใหญ่กว่าการปรับปรุงเดียวกันใกล้บ้านราคาถูก เพียงเพราะราคาสูงกว่า ไม่ใช่เพราะสวัสดิการที่เพิ่มขึ้นมากกว่า)

แนวทางเสริมของ Green Book เรื่องการวิเคราะห์การกระจาย ซึ่งเสริมความแข็งแรงหลังการทบทวนของกระทรวงการคลังปี 2020 ที่ตอบสนองต่อคำวิจารณ์ว่าระเบียบวิธีประเมินเอื้อต่อลอนดอนและตะวันออกเฉียงใต้อย่างเป็นระบบ วางแนวทางการถ่วงน้ำหนักอย่างเป็นทางการบนสมมติฐานความยืดหยุ่นของอรรถประโยชน์ส่วนเพิ่มของรายได้ประมาณ 1.3 — หมายความว่ารายได้ที่เพิ่มเป็นสองเท่าลดมูลค่าส่วนเพิ่มของหนึ่งปอนด์ที่เพิ่มลงประมาณครึ่งหนึ่ง (กล่าวให้ชัดคือ 2^-1.3 ≈ 0.41 เท่า) นี่ไม่ใช่การปรับปัดเศษ: การใช้อาจเปลี่ยนว่าโครงการแข่งขันสองโครงการใดแสดงมูลค่าปัจจุบันสุทธิสูงกว่า โดยเฉพาะเมื่อเปรียบเทียบการแทรกแซงที่กระจุกตัวในพื้นที่ขาดแคลนกับการแทรกแซงที่กระจายทั่วประชากรทั่วไป

## คณิตศาสตร์

น้ำหนักการกระจายของ Green Book สำหรับหนึ่งปอนด์ของประโยชน์ที่ตกแก่ครัวเรือนที่ระดับรายได้ y เทียบกับหนึ่งปอนด์ที่ระดับรายได้เฉลี่ยของประเทศ ȳ:

```
น้ำหนัก(y) = (ȳ / y)^e

โดยที่:
  y  = รายได้ครัวเรือน (หรือรายได้ของกลุ่มที่ได้รับผลกระทบ)
  ȳ  = รายได้ครัวเรือนเฉลี่ย (อ้างอิง)
  e  = ความยืดหยุ่นของอรรถประโยชน์ส่วนเพิ่มของรายได้ (Green Book: ประมาณ 1.3)
```

การใช้น้ำหนักกับประโยชน์สุทธิ:

```
ประโยชน์ที่ถ่วงน้ำหนัก = Σ [ประโยชน์ที่ไม่ถ่วงน้ำหนักของกลุ่ม i × น้ำหนัก(y_i)]
```

กลุ่มที่มีรายได้ครึ่งหนึ่งของค่าเฉลี่ยประเทศ (y = 0.5ȳ) ได้น้ำหนัก (1/0.5)^1.3 = 2^1.3 ≈ 2.46 — แต่ละปอนด์ของประโยชน์ต่อกลุ่มนั้นนับว่ามีค่าประมาณ 2.46 เท่าของหนึ่งปอนด์สำหรับครัวเรือนรายได้เฉลี่ย

## ตัวอย่างการคำนวณ

**สองโครงการท้องถิ่นที่แข่งขันกัน** แต่ละโครงการมีประโยชน์สุทธิที่ไม่ถ่วงน้ำหนัก 2 ล้านปอนด์/ปี แข่งขันกองทุนการเติบโตระดับภูมิภาคเดียวกัน:

- *โครงการ A*: โครงการสนับสนุนธุรกิจในเมืองที่มั่งคั่ง รายได้ครัวเรือนเฉลี่ย 45,000 ปอนด์ (ประมาณ 1.3 เท่าของค่าเฉลี่ยประเทศที่สมมติ 35,000 ปอนด์)
- *โครงการ B*: โครงการทักษะในเขตที่ขาดแคลน รายได้ครัวเรือนเฉลี่ย 18,000 ปอนด์ (ประมาณ 0.51 เท่าของค่าเฉลี่ยประเทศ)

```
น้ำหนัก(A) = (35,000 / 45,000)^1.3 = (0.778)^1.3 ≈ 0.72
น้ำหนัก(B) = (35,000 / 18,000)^1.3 = (1.944)^1.3 ≈ 2.53

ประโยชน์ที่ถ่วงน้ำหนัก A = 2,000,000 ปอนด์ × 0.72 = 1.44 ล้านปอนด์
ประโยชน์ที่ถ่วงน้ำหนัก B = 2,000,000 ปอนด์ × 2.53 = 5.06 ล้านปอนด์
```

เมื่อไม่ถ่วงน้ำหนัก ทั้งสองโครงการเสมอกัน เมื่อถ่วงน้ำหนักตามผลกระทบเชิงการกระจาย ประโยชน์ของโครงการ B ใหญ่กว่ามากกว่าสามเท่า — ผลลัพธ์ที่กลับข้อเสนอแนะด้านเงินทุนและสะท้อนวัตถุประสงค์ที่ชัดเจนของ Green Book ในการกำหนดให้แสดงการถ่วงน้ำหนัก ไม่ใช่เพียงอัตราส่วนประโยชน์ต่อต้นทุนที่ไม่ถ่วงน้ำหนัก

**การจัดสรรเงินอุดหนุนขององค์กรการกุศล**: ผู้ให้ทุนที่เปรียบเทียบเงินอุดหนุน 500,000 ปอนด์ที่ไปถึง 1,000 ครัวเรือนรายได้ต่ำ (น้ำหนัก ≈ 2.0 มูลค่าที่ถ่วงน้ำหนักเทียบเท่า 1 ล้านปอนด์) กับ 500,000 ปอนด์เดียวกันที่ไปถึง 1,000 ครัวเรือนรายได้ปานกลาง (น้ำหนัก ≈ 1.0 มูลค่าที่ถ่วงน้ำหนักเทียบเท่า 500,000 ปอนด์) ควรแสดงเหตุผลด้านการกระจายอย่างชัดเจนในเอกสารคณะกรรมการ ไม่ปล่อยให้ผู้อ่านอนุมานเอง

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

การถ่วงน้ำหนักตามการกระจายแทบไม่ปรากฏโดยตรงในตัวชี้วัดการส่งมอบซอฟต์แวร์ แต่ควรกำหนดรูปแบบที่ทีมวิศวกรรมและข้อมูลออกแบบการวัดและการกำหนดกลุ่มเป้าหมาย:

- เมื่อสร้างแดชบอร์ดผลกระทบหรือเครื่องคำนวณประโยชน์ ให้แสดงโปรไฟล์รายได้หรือความขาดแคลนของผู้ได้รับผลกระทบ ไม่ใช่แค่ยอดรวมประโยชน์ — ตัวเลขรวมที่ไม่มีการแยกตามการกระจายซ่อนการกลับด้านดังที่แสดงข้างต้นพอดี
- เชื่อมตรรกะการกำหนดกลุ่มเป้าหมายในการออกแบบบริการกับข้อมูลความขาดแคลนเดียวกับที่ Green Book ใช้ — ดู [ดัชนีความขาดแคลนหลายมิติ (IMD)](../ดัชนีความขาดแคลนหลายมิติ/) — เพื่อให้ประเมินขอบเขตการเข้าถึงของบริการดิจิทัลด้านความเสมอภาคได้ ไม่ใช่แค่ประสิทธิภาพ (E ตัวที่สี่ซึ่งเป็นที่ถกเถียงใน [ความคุ้มค่าของเงิน (VFM)](../ความคุ้มค่าของเงิน/))
- เมื่ออัลกอริทึมจัดสรรทรัพยากรที่มีจำกัด (ช่วงเวลานัด เวลาเจ้าหน้าที่ เงินอุดหนุน) ฟังก์ชันเป้าหมายที่ไม่ถ่วงน้ำหนักอย่าง "เพิ่มประโยชน์รวมสูงสุด" จะสร้างอคติเดียวกับที่การถ่วงน้ำหนักของ Green Book มีไว้แก้ไขซ้ำ โดยโครงสร้าง — แจ้งเจ้าของนโยบายอย่างชัดเจนก่อนทำการหาค่าที่เหมาะสมที่สุด

## ข้อผิดพลาดที่พบบ่อย

- **ใช้น้ำหนักการกระจายไม่สม่ำเสมอข้ามพอร์ตโฟลิโอ** การถ่วงน้ำหนักประโยชน์ของโครงการหนึ่งแต่ไม่ถ่วงน้ำหนักของตัวเปรียบเทียบ ให้การเปรียบเทียบที่เอนเอียง ไม่ใช่ยุติธรรมกว่า; Green Book ต้องการการปฏิบัติที่เทียบเท่ากัน
- **ใช้มูลค่าทรัพย์สินหรือมูลค่าตลาดเป็นตัวแทนสวัสดิการโดยไม่ปรับ** ราคาตลาดเองถูกบิดเบือนโดยความเหลื่อมล้ำของรายได้ที่มีอยู่ ซึ่งเป็นสิ่งที่การถ่วงน้ำหนักตามการกระจายมีไว้แก้ไข — การใช้มูลค่าตลาดที่ไม่ปรับอาจนับอคติซ้ำสอง
- **มองข้ามความแปรผันภายในกลุ่ม** การถ่วงน้ำหนักด้วยรายได้เฉลี่ยของพื้นที่ (เช่น เดไซล์ของ Index of Multiple Deprivation) อาจบิดเบือนบุคคลที่ไม่ตรงกับค่าเฉลี่ยของพื้นที่ตน ใช้ข้อมูลรายได้ที่ละเอียดที่สุดเท่าที่หาได้อย่างสมเหตุสมผล
- **ถือว่าความยืดหยุ่น 1.3 เป็นค่าคงที่สากล** Green Book เองระบุว่าเป็นค่าประมาณที่มีช่วงที่สมเหตุสมผล ทดสอบความไวของการตัดสินใจสำคัญกับความยืดหยุ่นทางเลือกอื่น แทนที่จะถือว่า 1.3 แม่นยำ
