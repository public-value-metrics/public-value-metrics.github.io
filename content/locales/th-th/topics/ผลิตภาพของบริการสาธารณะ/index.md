# ผลิตภาพของบริการสาธารณะ

ผลิตภาพของบริการสาธารณะวัดว่ารายจ่ายภาครัฐแปลงปัจจัยนำเข้า (บุคลากร ทุน สินค้าและบริการ) เป็นผลผลิตที่ปรับตามคุณภาพได้มีประสิทธิภาพเพียงใด สำหรับบริการ — สุขภาพ การศึกษา ตำรวจ การดูแลทางสังคม — ที่ไม่มีราคาตลาดและจึงไม่มีตัวเลขรายได้ไว้หารต้นทุน สำนักงานสถิติแห่งชาติของสหราชอาณาจักร (ONS) เผยแพร่อนุกรมนี้ตั้งแต่กลางทศวรรษ 2000 และยังคงเป็นความพยายามระดับชาติที่พัฒนาทางระเบียบวิธีมากที่สุดในการตอบคำถาม "รัฐบาลกำลังดีขึ้นหรือแย่ลงในการแปลงเงินเป็นบริการสาธารณะ?"

## เหตุใดจึงสำคัญ

ในตลาด ผลิตภาพคือ (มูลค่าผลผลิต) / (ต้นทุนปัจจัยนำเข้า) และมูลค่าผลผลิตสังเกตได้เพราะมีคนจ่าย การผ่าตัดเปลี่ยนสะโพก ที่นั่งเรียน และการลาดตระเวนของตำรวจไม่มีราคาขาย ดังนั้นอย่างไร้เดียงสาคุณวัดได้เพียง *ปัจจัยนำเข้า* (สิ่งที่ใช้จ่าย) — ซึ่งล่อให้ผู้วิจารณ์ถือว่ารายจ่ายภาครัฐที่เพิ่มขึ้นเป็นเรื่องไม่ดีโดยอัตโนมัติ เพราะปัจจัยนำเข้าที่มากขึ้นโดยกิจกรรมพาดหัวคงที่ดูเหมือนผลิตภาพที่ลดลง ระเบียบวิธีของ ONS ที่ระบุในสิ่งพิมพ์ "Sources and Methods" เกี่ยวกับผลิตภาพบริการสาธารณะ แก้ปัญหานี้โดยสร้างดัชนี *ผลผลิต* จากปริมาณกิจกรรม (การผ่าตัดที่ทำ นักเรียนที่สอน อาชญากรรมที่สืบสวน) แล้ว *ปรับคุณภาพ* ดัชนีผลผลิตนั้น — สำหรับสุขภาพ รวมอัตราการรอดชีวิตและเวลารอ; สำหรับการศึกษา รวมผลสัมฤทธิ์; สำหรับตำรวจ รวมผลลัพธ์เช่นการคลี่คลายคดี — เพื่อให้บริการที่ทำการผ่าตัดจำนวนเท่ากันแต่ได้อัตราการรอดชีวิตดีกว่าบันทึกเป็นผลิตภาพสูงกว่า ไม่ใช่เพียงแพงกว่า ข้อค้นพบพาดหัวที่ซ้ำในรายงาน ONS น่าตระหนกสำหรับภาคส่วนนี้: ผลิตภาพบริการสาธารณะของสหราชอาณาจักรลดลงอย่างรวดเร็วในช่วงการระบาดของ COVID-19 และตามรายงาน ONS ช่วงกลางทศวรรษ 2020 เองยังไม่ฟื้นกลับสู่ระดับปี 2019 ในภาคย่อยหลายภาค รวมถึงการดูแลสุขภาพ แม้รายจ่ายจะเพิ่ม — ช่องว่างที่เปลี่ยนกรอบ "เงินทุนมากขึ้น" และ "ผลิตภาพมากขึ้น" ให้เป็นสองคำถามที่แยกจากกันโดยสิ้นเชิง

## คณิตศาสตร์

```
ดัชนีผลผลิต (ปริมาณ) = Σ (กิจกรรม_i × น้ำหนักต้นทุนต่อหน่วยสัมพัทธ์_i) ถ่วงน้ำหนักปีฐาน
                        ข้ามกิจกรรมบริการทั้งหมด (เช่น ผ่าตัดสะโพก ผ่าตัดต้อกระจก
                        การปรึกษาแพทย์ทั่วไป) คล้ายดัชนีปริมาณแบบ Laspeyres/Paasche

การปรับคุณภาพ        = ดัชนีผลผลิต × ตัวประกอบการปรับคุณภาพ
                        (เช่น รวมการเปลี่ยนแปลงอัตรารอดชีวิต เวลารอ
                        ผลสัมฤทธิ์ หรือการกระทำผิดซ้ำ เป็นตัวคูณกับปริมาณดิบ)

ดัชนีปัจจัยนำเข้า     = Σ (ชั่วโมงแรงงาน × น้ำหนักต้นทุนแรงงาน) + (ต้นทุนสินค้า/บริการ
                        ปรับด้วยตัวลดราคา) + (การใช้ทุน)

การเติบโตของผลิตภาพปัจจัยรวม = % การเปลี่ยนแปลงของดัชนีผลผลิตที่ปรับคุณภาพ
                                − % การเปลี่ยนแปลงของดัชนีปัจจัยนำเข้า
```

## ตัวอย่างการคำนวณ

**การคำนวณผลิตภาพภาคบริการเฉียบพลันของ NHS เพื่อการอธิบาย** (โครงสร้างตามระเบียบวิธี ONS):

```
ปีที่ 1: ดัชนีปริมาณผลผลิต = 100.0 (ปีฐาน) ดัชนีปัจจัยนำเข้า = 100.0
         → ดัชนีผลิตภาพ = 100.0

ปีที่ 2: ปริมาณกิจกรรมเพิ่ม 3.0% (ผ่าตัดมากขึ้น นัดหมายมากขึ้น)
         แต่เวลารอเฉลี่ยแย่ลง ใช้ส่วนลดการปรับคุณภาพ −1.0%
         ดัชนีผลผลิตที่ปรับคุณภาพ = 100 × 1.030 × 0.990 = 101.97

         ปัจจัยนำเข้าเพิ่ม: จำนวนบุคลากร +4.0% ต้นทุนอื่น (ปรับตัวลดราคา) +1.5%
         ดัชนีปัจจัยนำเข้าถ่วงน้ำหนัก = 100 × 1.032 = 103.2

การเติบโตของผลิตภาพ = (101.97 / 100 − 1) − (103.2 / 100 − 1)
                     = 1.97% − 3.2% = −1.23 จุดเปอร์เซ็นต์

การตีความ: กิจกรรมเพิ่มขึ้น แต่ปัจจัยนำเข้าเพิ่มเร็วกว่าและคุณภาพ
ลดลงเล็กน้อย ผลิตภาพ — ผลผลิตต่อหน่วยปัจจัยนำเข้า — จึงลดลง
แม้ "มีการดูแลมากขึ้น"
```

นี่คือรูปแบบที่รายงาน ONS รายงานซ้ำสำหรับบางส่วนของ NHS หลังการระบาด: รายจ่ายที่เพิ่มและกิจกรรมดิบที่เพิ่มอยู่ร่วมกับผลิตภาพที่วัดได้ลดลง เมื่อคิดทั้งการปรับคุณภาพและการเติบโตของปัจจัยนำเข้า

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

ผลิตภาพของบริการสาธารณะเป็นคู่ระดับประชากรของการถกเถียงเรื่องผลิตภาพวิศวกรรม (สตอรีพอยต์ที่ส่งมอบเทียบกับ [ตัวชี้วัด DORA เพื่อคุณค่าสาธารณะ](../ตัวชี้วัด-dora-เพื่อคุณค่าสาธารณะ/) เทียบกับ [ตัวชี้วัดการไหลในการส่งมอบของภาครัฐ](../ตัวชี้วัดการไหลในการส่งมอบของภาครัฐ/)): ปริมาณงานดิบโดยไม่ปรับคุณภาพชวนเข้าใจผิดในโรงพยาบาลพอ ๆ กับ "จำนวนบรรทัดโค้ดที่ส่งมอบ" ในทีมซอฟต์แวร์ ทีมที่สร้างไปป์ไลน์ข้อมูลผลการดำเนินงานให้กระทรวงควรถือการปรับคุณภาพเป็นขั้นตอนการแปลงชั้นหนึ่งที่มีเวอร์ชัน ไม่ใช่เชิงอรรถ — เพราะความน่าเชื่อถือของ ONS เองขึ้นกับการปรับนั้นที่โปร่งใส ทำซ้ำได้ และปรับปรุงเมื่อข้อมูลคุณภาพที่ดีกว่ามาถึง (ONS ปรับประมาณการผลิตภาพของปีก่อนหน้าเมื่อข้อมูลคุณภาพพื้นฐาน — เช่น อัตรารอดชีวิต — เสร็จสมบูรณ์ ระบบปลายน้ำใดที่ใช้สถิติเหล่านี้จึงต้องรองรับการปรับย้อนหลัง ไม่ใช่เพียงต่อช่วงเวลาใหม่) ยังตัดกับ [ต้นทุนรวมของการเป็นเจ้าของ (TCO) ในไอทีภาครัฐ](../ต้นทุนรวมของการเป็นเจ้าของ-ในไอทีภาครัฐ/) และ [ผลิตภาพของ AI ในภาครัฐ](../ผลิตภาพของ-ai-ในภาครัฐ/) โดยตรง: ระบบที่เพิ่มปริมาณกิจกรรมดิบโดยไม่ปรับปรุงหรือรักษาคุณภาพ ไม่ใช่การปรับปรุงผลิตภาพตามนิยามของ ONS เอง

## ข้อผิดพลาดที่พบบ่อย

- **ถือการเติบโตของปัจจัยนำเข้าเป็นการเติบโตของผลิตภาพ**: รายจ่ายมากขึ้นที่ให้ทุนบุคลากรมากขึ้นสร้าง *กิจกรรม* มากขึ้น ไม่ใช่ *ผลิตภาพ* มากขึ้น เว้นแต่ผลผลิตต่อหน่วยปัจจัยนำเข้าเพิ่มด้วย — สองสิ่งนี้ถูกปนกันเป็นประจำในความเห็นทางการเมือง
- **ละเลยการปรับคุณภาพโดยสิ้นเชิง**: ดัชนีผลผลิตที่สร้างจากจำนวนกิจกรรมดิบเท่านั้นจะแสดง "ผลิตภาพที่เพิ่มขึ้น" จากการทำสิ่งที่มีมูลค่าต่ำกว่าหรือคุณภาพต่ำกว่าให้มากขึ้น การปรับคุณภาพของ ONS มีอยู่เพื่อจับสิ่งนี้
- **เปรียบเทียบดัชนีผลิตภาพข้ามภาคย่อยโดยไม่จับคู่อายุของระเบียบวิธี**: ผลิตภาพด้านสุขภาพ การศึกษา และตำรวจ แต่ละอย่างสร้างจากแหล่งข้อมูลกิจกรรมและคุณภาพต่างกันในรอบการปรับปรุงต่างกัน — การเปรียบเทียบข้ามภาคแบบไร้เดียงสาเปรียบเทียบเครื่องมือที่เข้ากันไม่ได้
- **อ่านผลิตภาพที่ลดลงในปีเดียวเป็นแนวโน้มถาวร**: ตัวเลขผลิตภาพช่วงการระบาดและหลังการระบาดแสดงความผันผวนปีต่อปีอย่างมีนัยสำคัญเมื่อข้อมูลคุณภาพ (เช่น บัญชีรอรักษา การฟื้นตัวของการผ่าตัดตามนัด) เองเปลี่ยนไป ONS เตือนอย่างสม่ำเสมอไม่ให้ตีความการเคลื่อนไหวปีเดียวเกินจริง
