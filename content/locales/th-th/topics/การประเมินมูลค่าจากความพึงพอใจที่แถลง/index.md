# การประเมินมูลค่าจากความพึงพอใจที่แถลง

วิธีความพึงพอใจที่แถลง (stated preference) ประเมินมูลค่าของสินค้านอกตลาดโดยถามผู้คนโดยตรงว่าเต็มใจจ่ายเท่าใดเพื่อมัน หรือเต็มใจรับค่าชดเชยเท่าใดเพื่อสละมัน โดยทั่วไปผ่านแบบสำรวจที่มีโครงสร้างซึ่งอธิบายสถานการณ์สมมติ การประเมินมูลค่าตามเงื่อนไข (contingent valuation) เป็นเทคนิคที่รู้จักกันดีที่สุดในกลุ่มนี้

## เหตุใดจึงสำคัญ

Annex 2 ของ Green Book (แนวทางเสริมว่าด้วยการประเมินมูลค่าผลกระทบนอกตลาด) รับรองวิธีความพึงพอใจที่แถลงสำหรับสินค้าที่ไม่มีธุรกรรมตลาดที่สังเกตได้เลยที่จะอนุมานมูลค่า — คุณภาพอากาศ ความหลากหลายทางชีวภาพ การป้องกันน้ำท่วม มูลค่าการดำรงอยู่ของภูมิทัศน์ที่บางคนอาจไม่เคยไปเยือน (<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>) Defra เผยแพร่แนวทางความพึงพอใจที่แถลงของตนเองสำหรับการประเมินสิ่งแวดล้อม ก็เพราะมูลค่าด้านสิ่งแวดล้อมจำนวนมาก (การอนุรักษ์ถิ่นที่อยู่ คุณภาพน้ำ) ไม่มีตลาดตัวแทนเลย ต่างจากเสียงรบกวน ที่อย่างน้อยก็สัมพันธ์กับราคาบ้านที่สังเกตได้ (ดู [การประเมินมูลค่าจากความพึงพอใจที่เปิดเผย](../การประเมินมูลค่าจากความพึงพอใจที่เปิดเผย/))

จุดดึงดูดหลักของความพึงพอใจที่แถลง — ประเมินมูลค่าได้แทบทุกอย่าง รวมถึงสินค้าที่ไม่เคยมีใครทำธุรกรรม — ก็เป็นต้นตอของปัญหาความน่าเชื่อถือด้วย เนื่องจากผู้ตอบไม่ได้ใช้จ่ายเงินจริง แบบสำรวจการประเมินมูลค่าตามเงื่อนไขจึงเสี่ยงต่ออคติจากสถานการณ์สมมติ (ผู้คนประเมินความเต็มใจจ่ายสูงเกินเมื่อไม่มีข้อจำกัดงบประมาณจริง) ผลของการฝัง (สินค้าเดียวกันได้รับมูลค่าต่างกันขึ้นกับสิ่งอื่นในแบบสำรวจ) และอคติจุดเริ่มต้นในการออกแบบเกมประมูล คณะกรรมการ NOAA ปี 1993 ว่าด้วยการประเมินมูลค่าตามเงื่อนไข ซึ่งประชุมหลังการฟ้องร้องกรณีน้ำมันรั่ว Exxon Valdez วางมาตรฐานการออกแบบ — รูปแบบประชามติเลือกสองทาง "คุณจะจ่าย X ปอนด์ไหม ใช่/ไม่" แทนการประมูลปลายเปิด และการเตือนให้ระลึกถึงข้อจำกัดงบประมาณจริงของผู้ตอบเป็นข้อบังคับ — ซึ่งยังเป็นมาตรฐานอ้างอิงของแบบสำรวจที่ป้องกันได้

## คณิตศาสตร์

```
การประเมินมูลค่าตามเงื่อนไข (รูปแบบประชามติ):
  นำเสนอทางเลือกสองทาง: "คุณจะจ่าย X ปอนด์ต่อปีเพื่อผลลัพธ์ Y ไหม? ใช่/ไม่"
  เปลี่ยน X แบบสุ่มข้ามผู้ตอบ
  ประมาณความเต็มใจจ่ายเป็นฟังก์ชันของอัตราการตอบ ใช่/ไม่ ที่แต่ละ X

WTP เฉลี่ย = พื้นที่ใต้เส้นอุปสงค์ที่ประมาณ
มูลค่ารวม = WTP เฉลี่ย × ประชากรที่ได้รับผลกระทบ

ตัวแปรการทดลองเลือก (discrete choice modelling):
  นำเสนอผู้ตอบด้วยทางเลือกซ้ำ ๆ ระหว่างชุดคุณลักษณะ
  (รวมคุณลักษณะด้านต้นทุน) ประมาณราคาโดยนัยสำหรับแต่ละ
  คุณลักษณะที่ไม่ใช่ต้นทุนจากการแลกเปลี่ยนที่ผู้ตอบเปิดเผย
```

ตัวแปรการทดลองเลือกเป็นที่นิยมกว่าโดยทั่วไปในแนวปฏิบัติของสหราชอาณาจักรปัจจุบัน เหนือการประเมินมูลค่าตามเงื่อนไขแบบคำถามเดียว เพราะการบังคับให้ผู้ตอบแลกเปลี่ยนคุณลักษณะหลายอย่างกับต้นทุนซ้ำ ๆ ให้ค่าประมาณที่สอดคล้องภายในมากกว่าและเล่นแร่แปรธาตุยากกว่าคำถามใช่/ไม่เพียงข้อเดียว

## ตัวอย่างการคำนวณ

**รัฐบาลระดับชาติ**: Defra ว่าจ้างแบบสำรวจการประเมินมูลค่าตามเงื่อนไขเพื่อประเมินมูลค่าโครงการปรับปรุงคุณภาพน้ำในแม่น้ำ แบบสำรวจรูปแบบประชามติของ 2,000 ครัวเรือนพบว่า 62% จะจ่าย 40 ปอนด์/ปีผ่านส่วนเพิ่มในบิลค่าน้ำสมมติ และเส้นอุปสงค์ที่ประมาณให้ความเต็มใจจ่ายเฉลี่ย 28 ปอนด์/ปีต่อครัวเรือน

```
WTP เฉลี่ย = 28 ปอนด์/ครัวเรือน/ปี
ครัวเรือนในลุ่มน้ำ = 340,000
มูลค่ารวมรายปี = 28 × 340,000 = 9.52 ล้านปอนด์/ปี

ตลอดช่วงประเมิน 20 ปีที่อัตราคิดลด 3.5% (ตัวประกอบเงินงวด ≈ 14.2):
PV(ประโยชน์) ≈ 9.52 ล้าน × 14.2 ≈ 135 ล้านปอนด์
```

ตัวเลขรวมนี้ถูกนำไปเทียบกับด้านต้นทุนของ [การวิเคราะห์ต้นทุนและผลประโยชน์ทางสังคม](../การวิเคราะห์ต้นทุนและผลประโยชน์ทางสังคม/) ของโครงการ Green Book กำหนดให้รายงานหลักฐานความพึงพอใจที่แถลงเช่นนี้พร้อมช่วงความเชื่อมั่นและระเบียบวิธีสำรวจ ไม่ใช่เป็นค่าประมาณจุดเดียวล้วน ๆ ก็เพราะตัวเลขเบื้องหลังเปราะบางกว่าราคาตลาด

**องค์กรการกุศล**: ทรัสต์มรดกวัฒนธรรมสำรวจผู้เยี่ยมชมและผู้ไม่เยี่ยมชมเกี่ยวกับความเต็มใจจ่ายเพื่อป้องกันการปิดอาคารประวัติศาสตร์ที่ทั้งสองกลุ่มไม่จำเป็นต้องไปเยือน (มูลค่าการดำรงอยู่) เพราะผู้ไม่เยี่ยมชมที่จะไม่เคยเห็นอาคารยังรายงาน WTP เป็นบวก แบบสำรวจจึงจับมูลค่าการดำรงอยู่และการสืบทอดที่การนับรายได้ค่าเข้าชมอย่างง่าย (ตัวแทนความพึงพอใจที่เปิดเผย) จะพลาดไปทั้งหมด — แสดงข้อได้เปรียบแท้จริงของความพึงพอใจที่แถลงเมื่อไม่มีธุรกรรมตลาดใดเลยที่จะเปิดเผยมูลค่า

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

วิธีความพึงพอใจที่แถลงแทบไม่ใช้โดยตรงกับงานวิศวกรรมซอฟต์แวร์ แต่วิศวกรที่สร้างแพลตฟอร์มรับฟังความเห็นประชาชน เครื่องมือมีส่วนร่วมในงบประมาณ หรือโครงสร้างพื้นฐานแบบสำรวจสาธารณะ มักกำลังสร้างเครื่องมือที่เศรษฐศาสตร์พึ่งพา การทำรายละเอียดการออกแบบแบบสำรวจให้ถูกต้อง — จำนวนเงินประมูลแบบสุ่ม รูปแบบประชามติสองทางแทนคำถามปลายเปิด การเตือนข้อจำกัดงบประมาณอย่างชัดเจน — ไม่ใช่ความประณีตด้าน UX แต่เป็นสิ่งที่ทำให้การประเมินมูลค่าที่ได้ป้องกันได้ภายใต้การตรวจสอบ แบบสำรวจในแอปที่ออกแบบไม่ดีอาจทำให้การวิเคราะห์เศรษฐศาสตร์ในเวลาหลายเดือนต่อมาเป็นโมฆะ ดู [ตัวชี้วัดความพึงพอใจของประชาชน](../ตัวชี้วัดความพึงพอใจของประชาชน/) สำหรับวินัยทั่วไปมากขึ้นของการดึงข้อมูลความเห็นสาธารณะที่จะรับน้ำหนักการวิเคราะห์

## ข้อผิดพลาดที่พบบ่อย

- **คำถามปลายเปิด "คุณจะจ่ายเท่าไร?"** เสี่ยงต่ออคติเชิงกลยุทธ์และการยึดค่ามากกว่ารูปแบบประชามติสองทางมาก ข้อเสนอแนะของคณะกรรมการ NOAA ให้ใช้รูปแบบประชามติมีอยู่ก็เพราะการดึงข้อมูลแบบปลายเปิดทำได้ไม่ดี
- **ไม่เตือนข้อจำกัดงบประมาณจริงของผู้ตอบ** หากไม่มี WTP ที่แถลงมักเกินกว่าที่คนกลุ่มเดียวกันจะจ่ายเมื่อมีการแลกเปลี่ยนงบประมาณจริง — อคติจากสถานการณ์สมมติ
- **ละเลยผลของการฝัง** สินค้าเดียวกันที่ประเมินโดดเดี่ยวเทียบกับประเมินเป็นส่วนของชุดใหญ่ให้ค่าประมาณ WTP ต่างกัน รายงานว่ามีอะไรอื่น หากมี อยู่ในกรอบแบบสำรวจ
- **ถือค่าประมาณจุดเดียวของแบบสำรวจเดียวเป็นข้อสรุป** แนวปฏิบัติของ Green Book คาดหวังช่วงและการอภิปรายอคติที่ทราบ ไม่ใช่ตัวเลขล้วนที่ยกไปใส่ตารางต้นทุน-ผลประโยชน์ราวกับเป็นราคาตลาด
