# การประเมินมูลค่าจากความพึงพอใจที่เปิดเผย

วิธีการความพึงพอใจที่เปิดเผย (revealed preference) อนุมานมูลค่าของสินค้านอกตลาดจากพฤติกรรมที่สังเกตได้ในตลาดที่เกี่ยวข้อง แทนที่จะถามผู้คนโดยตรง การกำหนดราคาแบบเฮโดนิก (hedonic pricing) และวิธีต้นทุนการเดินทางเป็นสองเทคนิคหลัก: ทั้งสองเริ่มจากธุรกรรมจริงและหาราคาโดยนัยของสิ่งที่ไม่เคยถูกขายโดยตรง

## เหตุใดจึงสำคัญ

ในขณะที่วิธี [ความพึงพอใจที่แถลง](../การประเมินมูลค่าจากความพึงพอใจที่แถลง/) ถามคำถามสมมติ วิธีความพึงพอใจที่เปิดเผยสังเกตสิ่งที่ผู้คนจ่ายจริง ซึ่ง Green Book ถือว่าเป็นหลักฐานที่น่าเชื่อถือกว่าโดยทั่วไป เมื่อสิ่งอื่นเท่ากัน เพราะไม่ถูกกระทบโดยอคติจากสถานการณ์สมมติ — ผู้ตอบในการศึกษาราคาบ้านแบบเฮโดนิกจ่ายส่วนเพิ่มหรือส่วนลดที่กำลังวัดอยู่จริง (<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>, Annex 2) การกำหนดราคาแบบเฮโดนิกแยกราคาตลาด — โดยทั่วไปคือราคาบ้าน — เป็นราคาโดยนัยสำหรับแต่ละคุณลักษณะของสินค้า ทำให้นักวิเคราะห์แยกได้ เช่น ส่วนเพิ่มราคาที่ครัวเรือนจ่ายจริงเพื่ออยู่ในที่เงียบกว่าหรืออากาศดีกว่า โดยควบคุมทางสถิติสำหรับคุณลักษณะอื่นทั้งหมดที่ส่งผลต่อราคาบ้านด้วย (ขนาด ทำเล เขตโรงเรียน) วิธีต้นทุนการเดินทางทำสิ่งคล้ายกันสำหรับสถานที่นันทนาการที่ไม่มีค่าเข้า: เวลาและเงินที่ผู้คนใช้เดินทางไปสถานที่เปิดเผยขอบเขตล่างของมูลค่าสถานที่นั้นสำหรับเขา เพราะไม่มีใครเสียต้นทุนเกินกว่าที่การเยี่ยมชมมีค่าสำหรับตน

ทั้งสองวิธีมีข้อจำกัดเชิงโครงสร้างร่วมกัน: ประเมินได้เฉพาะสิ่งที่ฝังอยู่ในธุรกรรมตลาดที่มีอยู่ เสียงรบกวนใกล้รันเวย์ปรากฏในราคาบ้านเพราะผู้ที่แคร์เรื่องเสียงเลือกไปอยู่ที่อยู่อาศัยที่เงียบกว่า; มูลค่าการดำรงอยู่ของสปีชีส์ที่ไม่มีใครไปเยือนหรืออยู่ใกล้ไม่ปรากฏในธุรกรรมใดเลย ซึ่งเป็นช่องว่างที่วิธี [ความพึงพอใจที่แถลง](../การประเมินมูลค่าจากความพึงพอใจที่แถลง/) มีไว้เติม

## คณิตศาสตร์

```
การกำหนดราคาแบบเฮโดนิก:
  ราคาบ้าน = f(คุณลักษณะโครงสร้าง คุณลักษณะทำเล
               คุณลักษณะด้านสิ่งแวดล้อมที่สนใจ, ...)
  ประมาณด้วยการถดถอย; สัมประสิทธิ์ของคุณลักษณะด้านสิ่งแวดล้อม
  (ถือสิ่งอื่นคงที่) คือราคาโดยนัยของมัน

  ราคาโดยนัยของคุณลักษณะ X = ∂(ราคาบ้าน) / ∂X

วิธีต้นทุนการเดินทาง:
  อัตราการเยี่ยมชม (การเยี่ยมชมต่อหัวจากโซน i) = f(ต้นทุนการเดินทางจากโซน i
               สถานที่ทดแทน ตัวควบคุมทางเศรษฐกิจสังคม)
  ประมาณเส้นอุปสงค์ของการเยี่ยมชมเป็นฟังก์ชันของต้นทุนการเดินทาง
  ส่วนเกินผู้บริโภค = พื้นที่ใต้เส้นอุปสงค์ที่ประมาณ
                    = มูลค่าของสถานที่สำหรับผู้เยี่ยมชม
```

ทั้งสองวิธีต้องการชุดตัวควบคุมที่แข็งแกร่งทางสถิติ — การละเว้นคุณลักษณะที่เป็นตัวแปรกวน (เฮโดนิก) หรือสถานที่ทดแทนใกล้เคียง (ต้นทุนการเดินทาง) ทำให้ราคาโดยนัยเอนเอียงในทิศทางที่ไม่ชัดเจนเสมอไปล่วงหน้า ซึ่งเป็นเหตุผลที่ Annex 2 ของ Green Book กำหนดให้รายงานรายละเอียดของสมการถดถอยและตัวควบคุม ไม่ใช่แค่สัมประสิทธิ์พาดหัว

## ตัวอย่างการคำนวณ

**รัฐบาลระดับชาติ**: ระเบียบวิธีราคาเงาของคาร์บอนของ Green Book เองอิงหลักฐานเฮโดนิกบางส่วน แต่กรณีตัวอย่างที่ง่ายกว่าคือเสียงอากาศยาน การศึกษาเฮโดนิกที่ถดถอยราคาขายบ้านในพื้นที่แนวบินเทียบกับการสัมผัสเสียงที่ถ่วงน้ำหนักด้วยระยะทาง โดยควบคุมขนาด อายุ และเขตโรงเรียน พบว่าเสียงเฉลี่ยที่เพิ่มขึ้นทุก 1 เดซิเบลสัมพันธ์กับราคาบ้านที่ลดลง 0.5% สำหรับบ้านทั่วไปราคา 280,000 ปอนด์ในพื้นที่ที่ได้รับผลกระทบ:

```
ราคาโดยนัยต่อเดซิเบล = 280,000 ปอนด์ × 0.5% = 1,400 ปอนด์ต่อครัวเรือน
ครัวเรือนที่ได้รับผลกระทบจากเสียงเพิ่ม 3dB จากรันเวย์ใหม่ = 18,000
ต้นทุนโดยนัยรวมของเสียงที่เพิ่มขึ้น = 1,400 ปอนด์ × 3 × 18,000 = 75.6 ล้านปอนด์
```

นี่คือต้นทุนครั้งเดียวที่ถูกทำให้เป็นทุน (ฝังอยู่ในราคาบ้าน) ซึ่งการประเมินต้องระวังไม่ให้นับซ้ำกับกระแสต้นทุนความรำคาญจากเสียงรายปีที่ประมาณแยกต่างหาก

**องค์กรการกุศล**: องค์กรการกุศลด้านสิ่งแวดล้อมใช้วิธีต้นทุนการเดินทางเพื่อประเมินมูลค่าเขตอนุรักษ์ธรรมชาติที่เข้าฟรี ข้อมูลสำรวจรหัสไปรษณีย์ผู้เยี่ยมชมให้ต้นทุนการเดินทางไปกลับเฉลี่ย (เวลาคิดตามมูลค่าเวลานอกงานที่ Green Book แนะนำ บวกเชื้อเพลิง) 14 ปอนด์ต่อการเยี่ยมชม โดยมีการเยี่ยมชม 40,000 ครั้งต่อปี เส้นอุปสงค์ที่ประมาณ — อัตราการเยี่ยมชมที่ลดลงเมื่อต้นทุนการเดินทางจากโซนสูงขึ้น — บ่งชี้ส่วนเกินผู้บริโภคต่อการเยี่ยมชม เกินกว่า 14 ปอนด์ที่จ่ายจริง ประมาณ 9 ปอนด์

```
มูลค่ารวมรายปี = 40,000 การเยี่ยมชม × (14 ปอนด์ที่จ่าย + 9 ปอนด์ส่วนเกินผู้บริโภค)
               = 40,000 × 23 ปอนด์ ≈ 920,000 ปอนด์/ปี
```

ตัวเลขนี้เกินรายได้ค่าเข้าศูนย์ของเขตอนุรักษ์มาก และให้กรรมการองค์กรการกุศลมีตัวเลขที่ป้องกันได้สำหรับมูลค่านันทนาการของสถานที่ เมื่อนำเสนอต่อผู้ให้ทุน

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

การคิดแบบความพึงพอใจที่เปิดเผยปรากฏในการวิเคราะห์ผลิตภัณฑ์ภาครัฐบ่อยกว่าที่ผู้ปฏิบัติตระหนัก: ข้อมูลการใช้งานจากบริการดิจิทัลภาครัฐที่ใช้ฟรีเป็นหลักฐานความพึงพอใจที่เปิดเผยของคุณค่าอยู่แล้ว (ความถี่ ความยาวเซสชัน และ — ที่บอกมากที่สุด — รูปแบบการใช้ซ้ำเทียบกับครั้งเดียว วิเคราะห์ได้แบบเดียวกับที่แบบจำลองต้นทุนการเดินทางจัดการความถี่การเยี่ยมชมเทียบกับระยะทาง) เมื่อบริการมีตัวทดแทนจริง (ช่องทางกระดาษ สายโทรศัพท์) "ต้นทุน" ที่ประชาชนแบกเพื่อใช้ช่องทางดิจิทัลแทน (เวลา ข้อมูล อุปกรณ์) ประมาณและเปรียบเทียบกับการใช้งานได้ สะท้อนตรรกะต้นทุนการเดินทางโดยตรง ดู [มาตรฐานบริการดิจิทัล](../มาตรฐานบริการดิจิทัล/) และ [คุณค่าของข้อมูลเปิด](../คุณค่าของข้อมูลเปิด/) ซึ่งเผชิญปัญหาการประเมินมูลค่าเดียวกันสำหรับสินค้าที่ไม่มีราคาตลาดโดยตรง

## ข้อผิดพลาดที่พบบ่อย

- **อคติจากตัวแปรที่ถูกละเว้นในแบบจำลองเฮโดนิก** การละเว้นคุณลักษณะที่สัมพันธ์กัน (คุณภาพโรงเรียนที่สัมพันธ์กับทั้งราคาบ้านและตัวแปรสิ่งแวดล้อมที่สนใจ) ทำให้ค่าประมาณราคาโดยนัยเอนเอียง ต้องรายงานและตรวจสอบรายละเอียดแบบจำลอง ไม่ใช่แค่ผลลัพธ์
- **มองข้ามสถานที่ทดแทนในการศึกษาต้นทุนการเดินทาง** มูลค่าที่เปิดเผยของผู้เยี่ยมชมต่อสถานที่ถูกประเมินต่ำเกินไป หากมีสถานที่ทดแทนที่ใกล้กว่าและไม่ได้ควบคุม — เขาอาจเยี่ยมชมเพราะเข้าฟรีเป็นหลัก ไม่ใช่เพราะสถานที่มีค่าเป็นพิเศษ
- **ใช้ความพึงพอใจที่เปิดเผยกับสินค้าที่ไม่มีเสียงสะท้อนในตลาดเลย** มูลค่าการดำรงอยู่ มูลค่าทางเลือก และมูลค่าการสืบทอดไม่ปรากฏในธุรกรรมใดและกู้คืนไม่ได้ด้วยวิธีเฮโดนิกหรือต้นทุนการเดินทาง — ช่องว่างนั้นเป็นของ [การประเมินมูลค่าจากความพึงพอใจที่แถลง](../การประเมินมูลค่าจากความพึงพอใจที่แถลง/)
- **สับสนมูลค่าที่ถูกทำให้เป็นทุน (ครั้งเดียว) กับกระแสรายปี** ผลเฮโดนิกต่อราคาบ้านโดยปกติเป็นมูลค่าที่ถูกทำให้เป็นทุนครั้งเดียว การถือเป็นกระแสประโยชน์รายปีทำให้การประเมินพองเกินจริง
