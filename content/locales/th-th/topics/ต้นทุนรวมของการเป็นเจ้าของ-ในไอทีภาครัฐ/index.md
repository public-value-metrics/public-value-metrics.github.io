# ต้นทุนรวมของการเป็นเจ้าของ (TCO) ในไอทีภาครัฐ

ต้นทุนรวมของการเป็นเจ้าของ (total cost of ownership) คือต้นทุนตลอดวงจรชีวิตเต็มของระบบ — การจัดหาบวกการดำเนินงานทุกปี — คิดลดเป็นวันที่ร่วมกัน ในไอทีภาครัฐ ข้อผิดพลาดในการพยากรณ์ที่เชื่อถือได้มากที่สุดคือการเปรียบเทียบผู้ขายหรือทางเลือกด้วยราคาจัดหาเพียงอย่างเดียว ทั้งที่การดำเนินงานและการบำรุงรักษาโดยทั่วไปคิดเป็นระหว่างครึ่งหนึ่งถึงสี่ในห้าของใบเรียกเก็บเงินตลอดอายุ

## เหตุใดจึงสำคัญ

Green Book ของ HM Treasury กำหนดให้กรณีทางการเงินในกรณีทางธุรกิจแบบจำลองห้ากรณีใด ๆ ครอบคลุมต้นทุนตลอดอายุ ไม่ใช่เพียงรายจ่ายลงทุน — แต่ National Audit Office พบซ้ำแล้วซ้ำเล่าว่ากระทรวงอนุมัติการลงทุนไอทีโดยอิงการคาดการณ์ต้นทุนดำเนินงานที่ไม่สมบูรณ์หรือมองโลกในแง่ดีเกินไป แล้วค้นพบต้นทุนดำเนินงานที่แท้จริงเมื่อระบบใช้งานจริงและบรรทัดงบประมาณลงทุนปิดไปแล้ว Technology Code of Practice ของ Government Digital Service และ Central Digital and Data Office (<https://www.gov.uk/guidance/the-technology-code-of-practice>) ผลักดันกระทรวงไปสู่คลาวด์และโฮสติ้งสินค้าโภคภัณฑ์ส่วนหนึ่งเพราะทำให้ต้นทุนต่อเนื่องมองเห็นและเปรียบเทียบได้ แทนที่จะถูกฝังอยู่ในตัวเลขการจัดซื้อลงทุนตัวเดียวที่ดูต่ำน่าดึงดูดตอนอนุมัติและผิดอย่างแพงในอีกสามปีต่อมา

## คณิตศาสตร์

```
TCO = ต้นทุนการจัดหา + Σ(t=1..N) ต้นทุนดำเนินงานรายปี_t / (1+r)^t
      − มูลค่าคงเหลือ (คิดลด)

r = อัตราคิดลดทางสังคมมาตรฐานของ Green Book โดย HM Treasury 3.5%/ปี
    (ตารางอัตราที่ลดลงสำหรับขอบเขตเวลาเกิน 30 ปี)

องค์ประกอบต้นทุนดำเนินงาน: โฮสติ้ง/ใบอนุญาต การสนับสนุนและบำรุงรักษา
การแพตช์ความมั่นคงปลอดภัยและการปฏิบัติตามกฎเกณฑ์ เวลาบุคลากร การเปลี่ยนใหม่/ย้ายระบบตามแผน
```

ดู [อัตราคิดลดทางสังคม](../อัตราคิดลดทางสังคม/) ว่าทำไมตัวประกอบการคิดลดจึงสำคัญตลอดอายุระบบทั่วไป 5–10 ปี และ [สร้างเองหรือซื้อในภาครัฐ](../สร้างเองหรือซื้อในภาครัฐ/) ว่า TCO ป้อนการตัดสินใจสร้างหรือซื้ออย่างไร

## ตัวอย่างการคำนวณ

กระทรวงเปรียบเทียบสองระบบบริหารจัดการกรณีในช่วง 5 ปีที่อัตราคิดลด 3.5% ของ Green Book

```
ระบบ A: ลงทุน 3,500,000 ปอนด์ ดำเนินงาน 250,000 ปอนด์/ปี
ระบบ B: ลงทุน 1,800,000 ปอนด์ (ดูถูกกว่า) ดำเนินงาน 650,000 ปอนด์/ปี
        (ภาระการสนับสนุนจากผู้ขายและการบูรณาการที่หนักกว่า)

การเปรียบเทียบอย่างไร้เดียงสาจากเงินลงทุนอย่างเดียว: B ชนะ 1.8 ล้าน < 3.5 ล้านปอนด์

ผลรวมตัวประกอบการคิดลด 5 ปีที่ 3.5%: 0.966+0.934+0.902+0.871+0.842 ≈ 4.515

TCO_A = 3,500,000 + 250,000 × 4.515 = 3,500,000 + 1,128,750 = 4,628,750 ปอนด์
TCO_B = 1,800,000 + 650,000 × 4.515 = 1,800,000 + 2,934,750 = 4,734,750 ปอนด์
```

TCO พลิกการตัดสินใจอย่างไร้เดียงสา: ระบบ B แพงกว่าเล็กน้อยตลอดห้าปีเมื่อคิดลดและรวมต้นทุนดำเนินงาน เพราะสัดส่วนต้นทุนดำเนินงานของมันต่อต้นทุนตลอดอายุคือ 62% (2,934,750 / 4,734,750) เทียบกับ 24% ของระบบ A — ตัวอย่างรูปธรรมของข้อค้นพบ "การบำรุงรักษาคือส่วนใหญ่ของใบเรียกเก็บ" ที่ซ่อนอยู่ทั้งหมดเมื่อเปรียบเทียบราคาป้าย

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

TCO คือตัวเลขที่ควรสร้างวินัยแก่ทุกการตัดสินใจ [สร้างเองหรือซื้อ](../สร้างเองหรือซื้อในภาครัฐ/) และทุกกรณีการชำระ [หนี้ทางเทคนิค](../หนี้ทางเทคนิคในฐานะการกัดกร่อนคุณค่าสาธารณะ/) เพราะดอกเบี้ยหนี้และการบำรุงรักษาที่เลื่อนออกไปเป็นรายการต้นทุนดำเนินงานที่อยู่ในยอดรวมคิดลดเดียวกัน ไม่ว่าจะมีใครติดตามอยู่หรือไม่ วิศวกรที่เสนอการเลือกแพลตฟอร์มหรือผู้ขายควรนำเสนอตาราง TCO เต็ม ไม่ใช่ราคาจัดซื้อ เพราะราคาจัดซื้อคือตัวเลขที่กรณีทางการเงินของ Green Book ถูกออกแบบมาเพื่อหยุดกระทรวงจากการพึ่งพาเพียงอย่างเดียว TCO ยังเป็นตัวหารที่ซื่อตรงสำหรับการตัดสิน [ความคุ้มค่าของเงิน (VFM)](../ความคุ้มค่าของเงิน/) — VFM เปรียบเทียบประโยชน์กับต้นทุน และบรรทัดต้นทุนที่นับน้อยเกินไปทำให้ทุกอัตราส่วน VFM ในกรณีทางธุรกิจพองขึ้น

## ข้อผิดพลาดที่พบบ่อย

- **เปรียบเทียบเฉพาะเงินลงทุน**: ข้อผิดพลาดการจัดซื้อที่พบบ่อยที่สุด — การเปรียบเทียบราคาตามรายการของผู้ขายโดยไม่มีการคาดการณ์ต้นทุนดำเนินงานที่จับคู่กันสำหรับแต่ละทางเลือก
- **ไม่รวมต้นทุนการออกและการย้ายระบบ**: การดึงข้อมูลเมื่อสิ้นสัญญา การย้ายแพลตฟอร์ม และค่าปรับจากการผูกมัดกับผู้ขายเป็นบรรทัด TCO จริงที่แทบไม่ปรากฏในกรณีทางธุรกิจเดิม
- **ไม่รวมต้นทุนความมั่นคงปลอดภัยและการปฏิบัติตามกฎเกณฑ์**: จังหวะการแพตช์ การต่ออายุการรับรอง และต้นทุนการตรวจสอบเพิ่มขึ้นตามอายุและความซับซ้อนของระบบ — ดู [คุณค่าของความมั่นคงปลอดภัยไซเบอร์ในภาครัฐ](../คุณค่าของความมั่นคงปลอดภัยไซเบอร์ในภาครัฐ/) — และถูกละออกจากการคาดการณ์ต้นทุนดำเนินงานเป็นประจำ
- **เปรียบเทียบโดยไม่คิดลดข้ามทางเลือกที่มีรูปแบบต้นทุนต่างกัน**: การเปรียบเทียบทางเลือกที่หนักด้านเงินลงทุนกับทางเลือกที่หนักด้านต้นทุนดำเนินงานโดยไม่คิดลดเอื้อต่อทางเลือกที่เลื่อนต้นทุนไปปีหลังมากกว่าอย่างเป็นระบบ
