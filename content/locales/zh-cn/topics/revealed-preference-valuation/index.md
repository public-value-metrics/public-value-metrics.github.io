# 显示性偏好估值（Revealed Preference Valuation）

显示性偏好方法，从相关市场中可观察到的行为、而不是直接询问人们的意见，来推断一项非市场性物品的价值。享乐定价法（hedonic pricing）和旅行成本法是两种主力技术：两者都从一笔真实的交易出发，为一件从未被直接出售过的东西反推出一个隐含价格。

## 为何重要

[陈述性偏好](../stated-preference-valuation/)方法提出的是一个假设性问题，而显示性偏好方法观察的是人们实际为之付费的行为，在其他条件相同的情况下，《绿皮书》通常将后者视为更为可信的证据，因为它不受假设性偏差的影响——一项享乐式房价研究中的受访者，是真实支付了正在被测量的那份溢价或折价的（<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>，附录 2）。享乐定价法将一个市场价格——通常是房价——分解为该商品每一个属性的隐含价格，使分析人员能够分离出，例如，家庭为居住在更安静或空气质量更好的地方而实际支付的价格溢价，同时以统计方式控制其他所有同样影响房价的属性（面积、地段、学区）。旅行成本法对没有门票的休闲游憩场所做类似的事情：人们前往某地所花费的时间和金钱，揭示了该地对他们而言价值的一个下限，因为没有人会承担超出这次到访对自己价值的成本。

这两种方法都有一个共同的结构性局限：它们只能为已经嵌入某笔现有市场交易中的价值进行估值。跑道附近的噪音会体现在房价中，因为在意噪音的人会自行选择更安静的住房；而一个无人到访、也无人居住其附近的物种的存在价值，则根本不会体现在任何交易中——这正是[陈述性偏好](../stated-preference-valuation/)方法所要填补的空白。

## 数学原理

```
享乐定价法：
  房价 = f(结构属性, 地段属性,
           所关注的环境属性, ...)
  通过回归估计；在保持其他一切不变的情况下，
  环境属性的系数就是其隐含价格。

  属性 X 的隐含价格 = ∂(房价) / ∂X

旅行成本法：
  到访率（来自地区 i 的人均到访次数）= f(来自地区 i 的
           旅行成本, 替代场所, 社会经济控制变量)
  估计到访次数作为旅行成本函数的需求曲线。
  消费者剩余 = 估计需求曲线下方的面积
             = 该场所对到访者的价值
```

这两种方法都需要一套统计上合理的控制变量集合——遗漏一个混杂属性（享乐定价法）或一个邻近的替代场所（旅行成本法），会使隐含价格产生偏差，而这种偏差的方向往往事先并不明显，这正是《绿皮书》附录 2 要求报告回归设定和控制变量、而不仅仅是头条系数的原因。

## 实例演算

**中央政府**：《绿皮书》自身的碳影子价格方法论，部分借鉴了享乐性证据，但一个更简单的示例性案例是飞机噪音。一项享乐性研究，将航线区域内的房屋售价对按距离加权的噪音暴露进行回归，同时控制面积、房龄和学区，发现平均噪音暴露每增加 1 分贝，房价就下降 0.5%。以受影响地区一栋典型的 28 万英镑房屋为例：

```
每分贝的隐含价格 = 280,000 英镑 × 0.5% = 每户 1,400 英镑
因新跑道导致噪音增加 3 分贝而受影响的家庭数 = 18,000
噪音增加所隐含的总成本 = 1,400 × 3 × 18,000 = 7,560万英镑
```

这是一次性的资本化成本（已嵌入房价之中），评估时必须注意不要将其与一个单独估计的年度噪音困扰成本流重复计算。

**慈善机构**：一家环保慈善机构使用旅行成本法，为一处免费入场的自然保护区估值。基于到访者邮编的调查数据显示，平均往返旅行成本（时间按《绿皮书》建议的非工作时间价值计价，另加燃油费）为每次到访 14 英镑，每年到访 40,000 人次。所估计的需求曲线——随着来自某地区的旅行成本上升，到访率下降——表明每次到访的消费者剩余，在实际花费的 14 英镑之上，约为 9 英镑。

```
年度总价值 = 40,000 次到访 × (14 英镑花费 + 9 英镑消费者剩余)
           = 40,000 × 23 英镑 ≈ 920,000 英镑/年
```

这远远超过该保护区零门票收入的规模，为该慈善机构的受托人在向资助方论证该场地的休闲游憩价值时，提供了一个站得住脚的数字。

## 与软件工程的关联

显示性偏好思维在公共部门产品分析中出现的频率，比从业者所意识到的要高：一项免费政府数字服务的使用数据，本身就是价值的显示性偏好证据（使用频率、会话时长，以及——最能说明问题的——重复使用与一次性使用模式，可以用旅行成本模型处理到访频率与距离关系的同一种方式来分析）。当一项服务存在真正的替代方案（纸质渠道、电话热线）时，公民为改用数字渠道所付出的"成本"（时间、流量、设备）可以被估算出来，并与使用情况相比较，这直接呼应了旅行成本法的逻辑。参见[数字服务标准](../digital-service-standard/)，以及面临着完全相同的无直接市场价格物品估值问题的[开放数据的价值](../open-data-value/)。

## 常见陷阱

- **享乐模型中的遗漏变量偏差。** 遗漏一个相关属性（例如学校质量，它同时与房价和所关注的环境变量相关）会使隐含价格估计产生偏差；应报告并审查模型设定，而不仅仅是结果。
- **旅行成本研究中忽视替代场所。** 如果存在一个更近的替代场所却未加以控制，到访者对该场所的显示性价值就会被低估——他们到访可能主要是因为它是免费的，而不是因为它具有独特价值。
- **将显示性偏好方法应用于完全没有市场回声的物品。** 存在价值、选择价值和遗赠价值都不会体现在任何交易中，也无法通过享乐定价法或旅行成本法恢复出来——这一空白属于[陈述性偏好估值](../stated-preference-valuation/)的范畴。
- **将资本化的（一次性）价值与年度流量相混淆。** 享乐性房价效应通常是一次性的资本化价值；将其当作年度效益流来对待，会夸大评估结果。
