# 政府中的成本效果分析（Cost-Effectiveness Analysis）

成本效果分析（Cost-Effectiveness Analysis，CEA）比较实现*同一*成果的不同方案的成本，以自然单位表示——每安置一名露宿者的成本、每让一名学生达到预期标准的成本、每减排一吨二氧化碳的成本——而不将成果本身折算成货币。

## 为何重要

当[社会成本效益分析](../social-cost-benefit-analysis/)要求将每一项效益都货币化的做法不仅变得困难、而且变得不诚实时——即对该成果给出可信定价将需要一些实际上根本无人认同的假设——《绿皮书》将 CEA 视为退而求其次的方法（<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>，第五章，关于成果不易货币化情形下的方案评估）。CEA 是从卫生经济学中借用得最为直接的一种方法——其结构与英国国家卫生与临床优化研究所（NICE）使用每质量调整生命年（QALY）成本比较治疗方案的方式完全相同——但被应用于非卫生类公共项目：教育干预以每学生成果分为单位、住房项目以每防止一户陷入无家可归为单位、就业项目以每一个持续性就业成果为单位。

CEA 之所以能与 SCBA 并列而不被其取代，是因为强行为某些成果赋予货币价值，会产生一个精确得看似权威、却又充满争议得毫无价值的数字——为"一名儿童达到预期阅读水平"定价，恰恰会招致那种在特别委员会审议中使商业论证脱轨的质疑。CEA 干脆回避了这场争论：它按每单位*成果本身*的成本对各方案进行排序，而将该成果本身是否值得追求这一独立的政治判断，留给战略性论证去处理。

## 数学原理

```
成本效果比（平均） = 总成本 / 已实现的总成果单位数

增量成本效果比（ICER），比较方案 A 与方案 B：
ICER = (成本_A − 成本_B) / (成果_A − 成果_B)

流程：
1. 在所比较的所有方案之间，固定成果单位与测量方法。
2. 在同一基础上（参见 ../green-book-appraisal/，财务论证部分）、
   在相同的时间跨度内，为每个方案计算成本。
3. 剔除被支配的方案：任何一个方案，若其每单位成本高于
   一个能实现相同或更好成果、成本更低的替代方案，则将其剔除。
4. 按增量而非平均成本效果比，对剩余方案进行排序。
```

CEA 本身无法回答一个项目是否值得资助——它只能回答，在实现同一目标的若干方法中，哪一种每单位成本最低。而该目标本身是否值得这笔支出，则需要要么折回到 SCBA（若存在可信的估值方法），要么依靠数学之外的政治/战略判断。当成果确实无法归约为单一单位——因为一个项目会产生若干种以不同方式各具重要性的成果——则应改用[多准则决策分析](../multi-criteria-decision-analysis/)。

## 实例演算

**地方政府**：某议会比较三种减少露宿人数的方法，均按一年计算成本，对照成果为"个人迁入稳定住所并维持 6 个月以上"：

```
方案                            成本        已实现成果   平均CER
housing First（密集支持）        900,000英镑  60          15,000英镑/成果
旅馆过渡+后续支持                 600,000英镑  50          12,000英镑/成果
外展+私人租赁部门                 350,000英镑  20          17,500英镑/成果

增量CER，旅馆过渡 vs 外展：(60万−35万)/(50−20) = 每新增一个成果 8,333英镑
增量CER，Housing First vs 旅馆过渡：(90万−60万)/(60−50) = 每新增一个成果 30,000英镑
```

从平均成本角度看，外展方案被旅馆过渡方案支配，但从外展方案*增量*升级到旅馆过渡方案，每多安置一人的成本仅为 8,333 英镑——相对于从旅馆过渡升级到 Housing First 的那一步而言便宜得多，后者每多安置一人的成本为 30,000 英镑。一个预算有限、准备扩大规模的政府机构，应当优先扩大旅馆过渡方案，而不是 Housing First，即便 Housing First 就其自身平均比率而言看起来更优。

**中央政府**：一项识字补救项目在三种交付模式之间以"每让一名学生达到该年龄段预期阅读水平的成本"进行比较：一对一辅导（每生 1,800 英镑）、小组辅导（每生 700 英镑）、纯数字化干预（每生 150 英镑，但按报名学生计算的成果达成率，在经参与度流失调整后，仅为小组辅导的 40%）。经实际完成率调整后，纯数字化干预每达标学生的成本为 375 英镑——仍是最便宜的，但 CEA 无法回答：如果以与小组辅导相同的预算投入纯数字化方案，那种能帮到的学生绝对数量较少，是否是相对于以更大深度帮到较少学生的一种可接受权衡；这是 CEA 交还给决策者的一项分配性判断。

## 与软件工程的关联

每当工程团队评估针对*同一*服务成果的不同交付方式时，CEA 都是正确的分析框架——比如在三家身份验证供应商之间比较每一个成功验证身份的成本、在两种个案自动化设计之间比较每一个被正确分诊案件的成本、在内部处理与外包补救之间比较每一个已解决无障碍缺陷的成本。它直接可以借鉴的纪律是：在比较成本之前先定义成果单位（不是"已关闭的工单"这种产出，而是"用户需求真正得到解决"），并且始终计算现行系统与拟议替代方案之间的增量比率，而不是孤立地计算每个系统各自的平均成本。参见[成果与产出](../outcomes-vs-outputs/)与[单位成果成本](../cost-per-outcome/)。

## 常见陷阱

- **在决定是否扩大规模时比较平均比率而非增量比率。** 正如露宿人数示例所示，平均比率最优的方案，未必是购买下一单位成果最便宜的选择。
- **选择实质上是产出而非成果的成果单位。** "已转介人数"或"已开展的辅导场次"衡量的是活动，而不是项目存在的目的所要产生的成果；对产出进行 CEA 会得出一个看似可信、却回答了错误问题的数字。
- **在真正不同的成果之间进行比较。** CEA 只有在所有方案都针对以相同方式测量的同一成果时才有效；比较"每安置一名露宿者的成本"与"每让一名离开照护体系的青年获得稳定租约的成本"需要一个通用的成果测量方法或[多准则决策分析](../multi-criteria-decision-analysis/)，而不是 CEA。
- **忽视成果的持久性。** 一个成本更低、但所产生成果不能持续的方案（比如干预结束后学生成绩回退），一旦在可比时间跨度上测量，实际上并不更具成本效果；应在所比较的各方案之间统一跟踪期。
