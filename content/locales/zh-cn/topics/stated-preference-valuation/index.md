# 陈述性偏好估值（Stated Preference Valuation）

陈述性偏好方法，通过直接询问人们愿意为一件非市场性物品支付多少、或愿意接受多少补偿来放弃它，来估计其价值，通常通过一份描述假设情景的结构化调查来进行。或有价值评估法（Contingent valuation）是这一方法家族中最著名的技术。

## 为何重要

《绿皮书》附录 2（关于非市场性影响估值的补充指南）认可将陈述性偏好方法用于那些根本没有可观察市场交易可供推断价值的物品——空气质量、生物多样性、防洪保护，以及一处某人可能永远不会造访的景观的存在价值（<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>）。环境、食品与乡村事务部（Defra）已发布了自己针对环境评估的陈述性偏好指南，正是因为大量的环境价值（栖息地保护、水质）根本没有代理市场存在，这与噪音（至少与可观察的房价相关，参见[显示性偏好估值](../revealed-preference-valuation/)）不同。

陈述性偏好方法的核心吸引力——它几乎可以为任何东西估值，包括从未有人交易过的物品——同时也是其可信度问题的根源。由于受访者并未真正花钱，或有价值评估调查容易受到假设性偏差（在没有真实预算约束的情况下，人们会夸大自己的支付意愿）、嵌入效应（同一件物品，根据调查中还包含了什么其他内容而被赋予不同的价值），以及竞价博弈设计中起点偏差的影响。1993 年，在埃克森·瓦尔迪兹号漏油事件诉讼之后召集的 NOAA 或有价值评估专家小组，提出了一套设计标准——采用二元的"你愿意支付 X 英镑吗？是/否"公投式格式，而非开放式竞价，并强制提醒受访者其实际的预算约束——这些标准至今仍是站得住脚调查的参考标准。

## 数学原理

```
或有价值评估（公投格式）：
  提出一个二元选择："你愿意每年为结果 Y 支付 X 英镑吗？是/否"
  在受访者之间随机变化 X 的数值。
  以每个 X 值下"是"的应答率为函数拟合支付意愿。

平均支付意愿 = 估计需求曲线下方的面积
总体价值 = 平均支付意愿 × 受影响人口

选择实验（离散选择建模）变体：
  向受访者反复展示若干组属性组合（包括一个成本属性）
  之间的选择，从受访者所揭示的权衡取舍中估计出
  每个非成本属性的隐含价格。
```

在当前英国实践中，相较于单一问题的或有价值评估，选择实验变体通常更受青睐，因为反复迫使受访者在若干属性与成本之间进行权衡，所产出的估计值内部一致性更强、也更难被操纵，优于单一的是/否问题。

## 实例演算

**中央政府**：Defra 委托开展一项或有价值评估调查，为一项河流水质改善项目估值。一份公投格式的调查，针对 2,000 户家庭，发现 62% 的家庭愿意通过一项假设性的水费附加费每年支付 40 英镑，估计得出的需求曲线给出每户平均支付意愿为每年 28 英镑。

```
平均支付意愿 = 每户每年 28 英镑
流域内家庭数 = 340,000
年度总体价值 = 28 × 340,000 = 952万英镑/年

按 3.5% 折现率计算的 20 年评估周期（年金系数 ≈ 14.2）：
PV(效益) ≈ 952万 × 14.2 ≈ 1.35亿英镑
```

这一总体数字随后会与该项目[社会成本效益分析](../social-cost-benefit-analysis/)中的成本一侧相比较。《绿皮书》要求将此类陈述性偏好证据连同其置信区间和调查方法一并报告，而不是作为一个裸露的点估计值，正是因为其底层数字比市场价格要脆弱得多。

**慈善机构**：某遗产信托机构对到访者和非到访者都进行了支付意愿调查，询问他们是否愿意支付以防止一座历史建筑（两个群体都未必会去参观）关闭（即其存在价值）。因为那些永远不会去看这座建筑的非到访者，依然报告了正的支付意愿，该调查捕捉到了一种简单的门票收入统计（一种显示性偏好代理指标）会完全遗漏的存在价值和遗赠价值——这正体现了在根本不存在任何市场交易可揭示价值的情况下，陈述性偏好方法的真正优势。

## 与软件工程的关联

陈述性偏好方法很少直接应用于软件工程工作本身，但构建公民咨询平台、预算参与工具或公共调查基础设施的工程师，往往正在构建这一经济学方法所依赖的工具。正确设计调查细节——随机化的竞价金额、二元公投式框架而非开放式问题、明确的预算约束提醒——不是一个 UX 层面的锦上添花之举，而是使最终估值经得起审查的关键所在；一份设计糟糕的应用内调查，可能会使后续数月的经济分析全部失效。关于获取能够承载分析权重的公众意见数据这一更普遍的纪律，参见[公民满意度指标](../citizen-satisfaction-metrics/)。

## 常见陷阱

- **开放式的"你愿意支付多少？"问题。** 相较于二元公投式框架，这类问题远更容易受到策略性偏差和锚定偏差的影响；NOAA 专家小组建议采用公投格式，正是因为开放式询问表现不佳。
- **没有提醒受访者其实际的预算约束。** 若无此提醒，陈述的支付意愿通常会超过同一批人在面对真实预算权衡时愿意支付的金额——即假设性偏差。
- **忽视嵌入效应。** 同一件物品单独估值与作为更大一揽子内容的一部分来估值，会产出不同的支付意愿估计值；应报告调查框架中还包含了哪些其他内容（如果有的话）。
- **将单次调查的点估计值当作定论。** 《绿皮书》的实践期望提供一个区间以及对已知偏差的讨论，而不是把一个裸露的数字直接带入成本效益表格，仿佛它是一个市场价格。
