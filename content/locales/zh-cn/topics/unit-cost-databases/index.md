# 单位成本数据库（Unit Cost Databases）

单位成本数据库，是一个由预先研究、有证据支撑的社会成果财务代理指标组成的资料库——从失业转向就业的价值、孤独感减轻的价值、一份稳定租约的价值——使从业者能够为一项成果货币化，而无需每次都委托定制的估值研究。它们之所以存在，是为了让一家撰写拨款申请的小型慈善机构，能够通过复用他人已经推导并发表的代理指标，达到与一家资源充足的咨询公司同等的严谨程度。

## 为何重要

由经济学家 Daniel Fujiwara 使用福祉估值方法开发的 HACT 英国社会价值银行（UK Social Value Bank），以及 Global Value Exchange（一个开放的、众包的财务代理指标数据库），是英国第三部门和公共部门中使用最广泛的两个数据库。两者之所以存在，是因为底层的估值工作——[福祉估值](../wellbeing-valuation/)和[陈述性偏好估值](../stated-preference-valuation/)——成本高昂、方法论要求严苛，而且每个项目都从零开始进行既缓慢又费力。一个共享的、已发布的代理指标库，将原本需要数月的研究工作变成了一次查询，这正是它们对[社会投资回报](../social-return-on-investment/)计算和[社会价值法](../social-value-act/)投标评估都至关重要的原因：如果没有它们，严谨的货币化工作将只有规模足够大、能够委托自己研究的组织才能负担得起。

## 数学原理

单位成本数据库本身不进行任何计算；它为别处进行的一次计算提供一项输入：

```
财务代理值 = 市场价格，或影子价格，或福祉估值，
             或陈述性偏好价值
             针对一个既定的成果变化单位
             （例如"每有一人从失业转向就业，每年"）

应用价值 = 已实现的成果数量 × 单位代理值
```

关于在没有市场价格存在时如何构建一个代理指标，参见[影子定价](../shadow-pricing/)；关于应用价值在经过无谓损失和归因调整后如何输入到一个比率中，参见[社会投资回报](../social-return-on-investment/)。

## 实例演算

**慈善机构（陪伴服务 SROI）**：单位成本数据库中"孤独感减轻"这一条目，给出了示例性代理值每人每年 1,100 英镑。应用于 80 名受益人：80 × 1,100 英镑 = 88,000 英镑总体价值。如果同一数据库中还有一个"心理福祉改善"的代理指标，且该指标借鉴了一项重叠的福祉调查项目，那么对同一批 80 人叠加使用这两个代理指标，会对同一潜在变化的一部分重复计算——数据库提供的是数字，但避免这种重叠是分析人员的责任。

**地方政府（求职俱乐部 SROI）**：单位成本数据库中"从失业转向持续性就业"这一条目，以示例性代理值每人每年 8,500 英镑应用于 45 名参与者：45 × 8,500 英镑 = 382,500 英镑总体价值，这还未经过[社会投资回报](../social-return-on-investment/)中所示的无谓损失和归因调整。

## 与软件工程的关联

为慈善机构或采购方构建报告工具的团队，受益于建立一份内部的"成果目录"——一张表格，将产品或服务能够合理声称的每一项成果，映射到一个具名的代理指标、其来源数据库、发布日期和版本标识符——从而使组织内不同的团队不会各自为同一项成果挑选略有出入的数值。将 Global Value Exchange 的开放数据包装在一个查询服务背后，并始终在数字旁边显示来源和日期，能使该代理指标保持可审计性，而不是一个埋藏在电子表格中的魔法数字。关于这些代理指标被使用的两个主要场景，参见[社会投资回报](../social-return-on-investment/)和[社会价值法](../social-value-act/)。

## 常见陷阱

- **将代理指标当作精确数值。** 大多数已发布的代理指标，是源自置信区间很宽的福祉估值研究的建模平均值；将其精确到英镑来引用，会夸大底层研究所能支撑的精确度。
- **对重叠的代理指标重复计算。** 将源自重叠调查构念的代理指标（例如"孤独感减轻"和"心理福祉改善"）叠加组合，会对同一潜在变化进行两次估值。
- **未经调整就使用脱离语境的代理指标。** 一个针对某一国家人群和年份校准的代理指标，在未经通胀或情境调整的情况下应用于别处，会在不知不觉中错误地陈述价值。
- **不核实来源。** Global Value Exchange 是开放且众包的，因此条目质量因贡献者而异；在拨款申请或采购提交中引用一个数字之前，应核实其底层来源。
