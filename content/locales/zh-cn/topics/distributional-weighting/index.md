# 分布性加权（Distributional Weighting）

分布性加权根据受益者是谁来调整一项成本或效益的货币价值，其原则是：对一个贫困家庭而言，多一英镑的价值高于对一个富裕家庭而言的价值。英国财政部《绿皮书》提供了应用这种加权的明确方法，建立在收入边际效用递减这一原理之上，使评估不会在不知不觉中把最富裕十分位人群多得的一英镑，等同于最贫困人群多得的一英镑。

## 为何重要

标准成本效益分析在加总英镑数额时，并不追问这些英镑属于谁，这隐含地假定一英镑对每个人的价值都相同——而经济学家早已知道这一假设是错误的。一个年收入 15,000 英镑的家庭，对获得 1,000 英镑收益的体验，与一个年收入 150,000 英镑的家庭截然不同，因为收入的边际效用随收入增加而递减。如果不加权，标准评估会系统性地偏向那些惠及更富裕、境况已然更好群体的干预措施，因为这些群体更高的消费能力，会抬高其所获效益的货币估值（一处昂贵住宅附近的公园升级，"显示出"的房产价值收益，会比同样的升级发生在廉价住宅附近时更大，这纯粹是因为价格更高，而不是因为福祉增益更大）。

《绿皮书》关于分布性分析的补充指南，在财政部 2020 年评估方法审查回应了"评估方法系统性偏向伦敦及东南部地区"的批评之后得到了强化，提出了一种基于假定的收入边际效用弹性约为 1.3 的正式加权方法——意味着收入翻倍大致会使额外一英镑的边际价值减半（具体而言，是 2^-1.3 ≈ 0.41 倍）。这不是一项舍入调整：应用它可能会改变两个竞争项目中哪一个显示出更高的净现值，尤其是在将一项集中于贫困地区的干预措施与一项面向一般人群的干预措施进行比较时。

## 数学原理

《绿皮书》为收入水平为 y 的家庭所获得的一英镑效益、相对于全国平均收入水平 ȳ 所设定的分布性权重：

```
权重(y) = (ȳ / y)^e

其中：
  y  = 家庭收入（或受影响群体的收入）
  ȳ  = 平均（参照）家庭收入
  e  = 收入边际效用弹性（《绿皮书》：约为 1.3）
```

将权重应用于净效益：

```
加权效益 = Σ [群体 i 的未加权效益 × 权重(y_i)]
```

一个收入为全国平均水平一半（y = 0.5ȳ）的群体，权重为 (1/0.5)^1.3 = 2^1.3 ≈ 2.46——该群体每获得一英镑效益，其价值大致相当于平均收入家庭获得的 2.46 英镑。

## 实例演算

**两个竞争性地方项目**，未加权净效益均为每年 200 万英镑，正在争夺同一笔区域增长基金：

- **项目 A**：位于一个富裕城镇的企业支持计划，平均家庭收入 45,000 英镑（约为假定全国平均水平 35,000 英镑的 1.3 倍）。
- **项目 B**：位于一个贫困选区的技能培训项目，平均家庭收入 18,000 英镑（约为全国平均水平的 0.51 倍）。

```
权重(A) = (35,000 / 45,000)^1.3 = (0.778)^1.3 ≈ 0.72
权重(B) = (35,000 / 18,000)^1.3 = (1.944)^1.3 ≈ 2.53

加权效益 A = 2,000,000 英镑 × 0.72 = 144 万英镑
加权效益 B = 2,000,000 英镑 × 2.53 = 506 万英镑
```

未加权时，两个项目打成平手。经过分布性影响加权后，项目 B 的效益是项目 A 的三倍多——这一结果逆转了资助建议，也正体现了《绿皮书》要求展示加权结果、而不仅仅是未加权效益成本比的明确用意。

**慈善拨款分配**：一个资助方在比较一笔 50 万英镑的拨款惠及 1,000 户低收入家庭（权重 ≈ 2.0，加权价值相当于 100 万英镑）与同样 50 万英镑惠及 1,000 户中等收入家庭（权重 ≈ 1.0，加权价值相当于 50 万英镑）时，应当在董事会文件中明确展示这一分布性论证，而不是留待他人自行推断。

## 与软件工程的关联

分布性加权很少直接出现在软件交付指标中，但它应当塑造工程和数据团队设计测量与定位方式的方式：

- 在构建影响力仪表盘或效益计算器时，应当展示受影响人群的收入或贫困程度概况，而不仅仅是一个汇总效益总数——没有分布性细分的汇总数字，恰恰会掩盖上文所示的那种逆转结果。
- 将服务设计中的定位逻辑与《绿皮书》所使用的同一套贫困数据关联起来——参见[多重贫困指数](../index-of-multiple-deprivation/)——使一项数字服务的触达范围能够按公平性（[物有所值](../value-for-money/)中饱受争议的第四个"E"）而非仅按效率来评估。
- 当一个算法用于分配稀缺资源（预约名额、个案工作人员的时间、一项补贴）时，一个未加权的"最大化总效益"目标函数，从其构造方式上就会复现《绿皮书》加权机制原本要纠正的那种偏差——应在优化之前明确向政策负责人标注这一点。

## 常见陷阱

- **在一个项目组合中不一致地应用分布性权重。** 只为某一个项目的效益加权、而不为其对照项目加权，会产出一个有偏差、而非更公平的比较；《绿皮书》要求进行同等对待。
- **未经调整地使用房产或市场价值作为福祉的代理指标。** 市场价格本身就受到既有收入不平等的扭曲，而这正是分布性加权本应纠正的问题；使用未经调整的市场价值可能会使这种偏差被重复计算。
- **忽视群体内部的差异。** 按地区平均收入（例如某个多重贫困指数十分位）加权，可能无法准确代表与所在地区平均水平不符的个体；应使用合理可得的、最细粒度的收入数据。
- **将 1.3 这一弹性系数视为普适常数。** 《绿皮书》本身也指出这只是一个具有合理区间的估计值；对重大决策应针对不同弹性系数进行敏感性检验，而不是将 1.3 视为精确值。
