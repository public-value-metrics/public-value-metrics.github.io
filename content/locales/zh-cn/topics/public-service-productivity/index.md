# 公共服务生产力（Public Service Productivity）

公共服务生产力衡量的是公共支出将投入（人员、资本、货物与服务）转化为经质量调整后产出的效率，适用于那些没有市场价格、因此也就没有一个可用来分摊成本的收入数字的服务——医疗、教育、治安、社会关怀。英国国家统计局（ONS）自 2000 年代中期以来一直发布这一系列数据，它仍然是方法论上最为成熟的、试图回答"政府将资金转化为公共服务的能力是在变好还是变差"这一问题的国家级尝试。

## 为何重要

在市场中，生产力是（产出价值）/（投入成本），而产出价值是可观察的，因为有人为之付费。一次髋关节置换手术、一个学位名额、一次警察巡逻都没有销售价格，因此朴素地看，你只能测量*投入*（花费了什么）——这诱使评论者把不断上升的公共支出自动当作坏事，因为投入增加而头条活动量持平看起来就像生产力下降。ONS 在其关于公共服务生产力的《数据来源与方法》出版物中所阐述的方法论，通过从活动量（进行的手术数、教授的学生数、调查的犯罪案件数）构建一个*产出*指数，再对该产出指数进行*质量调整*来解决这一问题——对医疗领域，纳入存活率和候诊时间；对教育领域，纳入学业成就；对治安领域，纳入案件结案等成果——从而使一项完成同样数量手术、却取得了更高存活率的服务被记录为生产力更高，而不仅仅是花费更多。ONS 各版发布中反复出现的头条发现令人警醒：英国公共服务生产力在新冠疫情期间急剧下降，而根据 ONS 自己在 2020 年代中期发布的数据，包括医疗保健在内的若干子行业至今仍未恢复到 2019 年的水平，即便支出一直在上升——这一差距使"更多资金"和"更高生产力"成为两个完全独立的问题。

## 数学原理

```
产出指数（量）= Σ (活动量_i × 相对单位成本权重_i)，以基年为
                权重，涵盖所有服务活动（例如髋关节手术、白内障
                手术、全科医生问诊），类似于拉斯拜尔/帕歇量指数

质量调整      = 产出指数 × 质量调整系数
                （例如将存活率、候诊时间、学业成就或再犯率
                的变化，作为原始量的一个乘数纳入计算）

投入指数      = Σ (劳动工时 × 劳动成本权重) + （已折现的
                货物/服务成本） + （资本消耗）

全要素生产力增长 = 经质量调整后产出指数的百分比变化
                   − 投入指数的百分比变化
```

## 实例演算

**示例性的 NHS 急症部门生产力计算**（结构遵循 ONS 方法论）：

```
第一年：产出量指数 = 100.0（基年），投入指数 = 100.0
        → 生产力指数 = 100.0

第二年：活动量上升 3.0%（更多手术，更多预约），
        但平均候诊时间恶化，施加 −1.0% 的质量调整折扣
        经质量调整后的产出指数 = 100 × 1.030 × 0.990 = 101.97

        投入上升：员工人数 +4.0%，其他成本（已折现）+1.5%，
        加权投入指数 = 100 × 1.032 = 103.2

生产力增长 = (101.97 / 100 − 1) − (103.2 / 100 − 1)
           = 1.97% − 3.2% = −1.23 个百分点

解读：活动量上升了，但投入上升得更快、质量也略有下降，
因此生产力——每单位投入的产出——是下降的，即便
"提供了更多的关怀服务"。
```

这正是 ONS 各版发布反复报告的、疫情后 NHS 部分领域所呈现的模式：支出上升、原始活动量上升，但一旦同时计入质量调整和投入增长，测得的生产力却在下降。

## 与软件工程的关联

公共服务生产力是工程生产力争论（已交付的故事点数 vs [DORA 指标](../dora-metrics-for-public-value/) vs [流动指标](../flow-metrics-in-government-delivery/)）在人群层面的对应物：没有质量调整的原始吞吐量，在一家医院里和在一个软件团队里同样具有误导性，就像"已交付的代码行数"一样。为各部门构建绩效数据流水线的团队，应将质量调整视为一个一等的、有版本管理的转换阶段，而不是一条脚注——因为 ONS 自身的可信度，正建立在该调整过程透明、可复现、并能随着更优质数据的到来而修订这一基础之上（ONS 会随着底层质量数据——例如存活率——的最终确定而修订以往年份的生产力估计，因此任何消费这些统计数据的下游系统都必须能够处理追溯性修订，而不仅仅是追加新周期的数据）。它也与[总拥有成本](../total-cost-of-ownership-in-government-it/)和[公共部门中的 AI 生产力](../ai-productivity-in-the-public-sector/)直接相关：按 ONS 自己的定义，一个在不改善或维持质量的情况下提高原始活动量的系统，并不算是生产力的提升。

## 常见陷阱

- **将投入增长当作生产力增长。** 更多支出资助更多员工，产生的是更多的*活动*，而不是更高的*生产力*，除非每单位投入的产出也随之上升——这两者在政治评论中经常被混为一谈。
- **完全忽视质量调整。** 一个仅由原始活动计数构建的产出指数，会将从事更多低价值或低质量工作显示为"生产力提升"；ONS 的质量调整机制正是专门为捕捉这一点而设的。
- **在未匹配方法论版本的情况下跨子行业比较生产力指数。** 医疗、教育和治安的生产力各自由不同的活动和质量数据来源、按不同的修订周期构建而成——朴素的跨行业比较是在比较不可兼容的度量工具。
- **将单一年份的生产力下降解读为永久趋势。** 疫情期间及疫情后的生产力数字，随着质量数据本身（例如候诊名单、择期手术恢复情况）的变化而呈现出显著的逐年波动；ONS 一贯提醒不要过度解读单一年份的变动。
