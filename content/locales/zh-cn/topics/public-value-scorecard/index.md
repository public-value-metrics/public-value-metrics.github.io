# 公共价值计分卡（Public Value Scorecard）

公共价值计分卡，改编自 Robert Kaplan 和 David Norton 于 1992 年提出的平衡计分卡——该计分卡最初是为在财务、客户、内部流程和学习与成长四个视角之间优化利润的企业而设计的——使其适用于那些以使命而非利润为底线的组织。它迫使一个公共机构同时在若干个不可归约的维度上报告绩效，而不是将一切压缩成一个掩盖了权衡取舍的单一数字。

## 为何重要

Kaplan 和 Norton 在《哈佛商业评论》上提出的原始论点是：单一的财务指标是一项滞后指标，它丝毫说明不了*为什么*下个季度的业绩会发生变化。在私营部门，解决方案是四个相互关联的视角。在政府领域，Mark Moore 的"战略三角"（出自《创造公共价值》，1995）提供了对应的结构：一项服务必须同时交付**公共价值**（使命成果）、维持**正当性与支持**（政治和公众的支持），并且**在操作上可行**（能够凭借实际可获得的资源和能力交付）。Paul Niven 的《平衡计分卡：政府与非营利机构逐步指南》（*Balanced Scorecard: Step-by-Step for Government and Nonprofit Agencies*，2003）是将 Kaplan 和 Norton 的四个方框转化为这一三角结构的实践手册——通常将"财务"重新标注为"资源管理"，将"使命"置于顶端，而非将"股东价值"置于底端，并将客户和利益相关方视角视为与其他视角同等重要，而不是从属于利润。这一点之所以对交付团队而言至关重要，是因为一项仅按财务或效率指标（比如单笔交易成本）来评判的公共数字服务，会系统性地对财务指标无法看见的正当性和成果维度投入不足。

## 数学原理

公共价值计分卡是一个框架，而非一个公式，但其结构是固定的，值得原样复现：

```
视角              公共部门的问题                            示例指标
--------------------------------------------------------------------------------
使命/成果          我们是否正在实现我们存在的目的所要       人群成果衡量指标
                   创造的公共价值？                        （参见 outcomes-vs-outputs）
资源管理           我们是否在授权限额内高效使用了公共资金？  单位成果成本、预算差异
客户/用户          用户和公民能否获取并从该服务中受益？      完成率、满意度
正当性/支持        政治负责人、监督机构和公众是否仍然        信任指标、审计发现、
                   支持我们？                              获支持的投诉数
内部流程/学习      我们是否具备持续改进所需的能力和流程？    员工流动率、周期时间、
                                                           积压案件账龄

一份站得住脚的计分卡，每个视角报告 3-5 项指标，
其选择应确保没有任何一个视角能够被单独操纵，
而不在另一个视角上留下可见的损害痕迹。
```

## 实例演算

**地方政府成人社会关怀部门**：一份针对康复支持服务（帮助人们在住院后短期内恢复独立生活能力）的计分卡报告：

```
使命：      68% 的服务使用者在 6 周后不再需要持续性关怀（目标 65%）
资源管理：  每次完成的康复支持成本 = 1,850 英镑（预算假设为 2,000 英镑）
客户：      用户满意度 82%，服务启动平均等待时间 4.1 天
正当性：    每 1,000 次服务中有 3 起获支持的投诉；成人安全保障
           委员会将该服务评为"良好"
流程：      员工空缺率 14%，平均案件负荷 23（安全案件负荷上限：25）
```

单独解读时，使命和资源管理这两项数字看起来是一个简单明了的成功故事：低于预算、高于成果目标。但结合流程这一行来看，14% 的空缺率相对于 25 的案件负荷上限，显示出这一良好成果，是以接近不安全人员配备水平为代价换来的——这是一个使命数字本身永远不会揭示出来的警示，也正是单一视角 KPI（参见[公共部门关键绩效指标](../public-sector-kpis/)）所招致的那种失败模式。

## 与软件工程的关联

对于构建内部或面向公众仪表盘的团队而言，该计分卡直接反对使用单一的"健康分数"小组件：应为每个视角构建一个独立面板，并抵制将它们综合成一盏红绿灯的产品压力，因为综合这一步骤恰恰是权衡取舍信息被摧毁的地方。它也与产品团队的 OKR 结构清晰对应：一个没有配对资源管理或流程 OKR 的使命 OKR，会重现 Kaplan 和 Norton 在 1992 年所反对的那种单一指标失败模式。关于 Moore 提出的"使命"方框本应包含什么内容的基础理论，参见[公共价值](../public-value/)；关于如何用真实的、有据可查的指标（而不是一个无人能为之辩护的代理指标）来填充正当性视角，参见[信任与正当性指标](../trust-and-legitimacy-metrics/)。

## 常见陷阱

- **将计分卡压缩成一个分数。** 将四个视角平均成一个数字，会重新引入该计分卡本应防止的确切问题——一个糟糕的正当性分数被一个良好的资源管理分数所掩盖。
- **原封不动地照搬私营部门的"财务"视角。** 一个公共机构的资源管理视角关注的是留在获授权的、往往是专款专用的预算之内，而不是最大化收入——Niven 的重新标注绝非表面文章。
- **选择计分卡所有者团队能够单方面左右的指标。** 一项来自被评判团队自身的正当性指标（例如自我报告的投诉处理情况）算不上独立证据。
- **一次性构建计分卡后就再也不重新审视权重或指标。** Kaplan 和 Norton 本意是要进行年度战略复核；一份被冻结多年的计分卡，会逐渐偏离它本应跟踪的使命。
