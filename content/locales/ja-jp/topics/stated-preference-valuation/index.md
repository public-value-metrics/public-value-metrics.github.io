# 表明選好評価

表明選好法は、人々に、それに対していくら支払う意思があるか、あるいはそれを手放すことに対していくらの補償を受け入れるかを直接尋ねることによって、非市場財の価値を推定する——通常、仮想的なシナリオを描いた構造化された調査を通じて行われる。仮想評価法は、この手法群の中で最もよく知られた手法である。

## 重要な理由

グリーンブック付属書2（非市場的影響の評価に関する補足指針）は、価値を推測する観察可能な市場取引がまったく存在しない財——大気質、生物多様性、洪水防護、人が訪れることのない景観の存在価値など——について、表明選好法を認めている（<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>）。Defraは、環境評価のために独自の表明選好指針を公表している。それは、まさに環境価値の多く（生息地の保全、水質）に代理市場がまったく存在しないためであり、少なくとも観察可能な住宅価格と相関する騒音などとは異なる（[顕示選好評価](../revealed-preference-valuation/)を参照）。

表明選好の中心的な魅力——それは文字通りあらゆるもの、誰も取引したことのない財さえも評価できる——は、同時にその信頼性問題の源でもある。回答者は実際にはお金を使っていないため、仮想評価調査は、仮想バイアス（実際の予算制約がない場合、人々は支払意思を過大に主張する）、埋め込み効果（同じ財が、調査の中に他に何が含まれるかによって異なる評価を受ける）、入札ゲーム型の設計における起点バイアスに脆弱である。Exxon Valdez号の原油流出訴訟の後に招集された1993年のNOAA仮想評価パネルは、設計基準を定めた——自由回答形式の入札ではなく二択の「あなたは£Xを払いますか、はい/いいえ」というレファレンダム形式、そして回答者の実際の予算制約についての義務的なリマインダーであり、これは擁護可能な調査の基準として現在も残っている。

## 計算式

```
仮想評価（レファレンダム形式）：
  二択の選択肢を提示する：「あなたは成果Yのために年間£Xを
  払いますか？はい/いいえ」
  回答者間でXを無作為に変える。
  各Xにおけるはい/いいえの回答率の関数として支払意思額を
  フィットさせる。

平均支払意思額 = 推定された需要曲線の下の面積
総価値 = 平均支払意思額 × 影響を受ける人口

選択実験（離散選択モデリング）の変種：
  回答者に、属性のバンドル（コスト属性を含む）間の選択を
  繰り返し提示し、回答者が示すトレードオフから各非コスト属性の
  暗黙の価格を推定する。
```

選択実験の変種は、現在の英国の実務において、単一質問の仮想評価よりも一般的に好まれる。なぜなら、回答者にコストに対して複数の属性を繰り返しトレードオフさせることは、単一のはい/いいえの質問よりも内的に一貫性があり、操作しにくい推定値を生み出すからである。

## 計算例

**中央政府**：Defraが、河川水質改善プログラムを評価するための仮想評価調査を委託する。2,000世帯を対象としたレファレンダム形式の調査は、62%が仮想の水道料金加算を通じて年間£40を支払うと回答し、推定された需要曲線は世帯あたり平均支払意思額£28/年を与える。

```
平均支払意思額 = £28/世帯/年
流域内の世帯数 = 340,000
総年間価値 = £28 × 340,000 = £9.52m/年

3.5%の割引率での20年評価期間にわたって（年金係数≈14.2）：
PV(便益) ≈ £9.52m × 14.2 ≈ £135m
```

この総額は、その後プログラムの[社会的費用便益分析](../social-cost-benefit-analysis/)のコスト側と比較される。グリーンブックは、この種の表明選好エビデンスが、裸の点推定値としてではなく、信頼区間と調査方法論とともに報告されることを要求している。なぜなら、その根底にある数字は市場価格よりも脆いからである。

**慈善団体**：ある文化財トラストが、どちらの群も必ずしも訪れることのない（その存在価値のある）歴史的建造物の閉鎖を防ぐための支払意思額について、訪問者と非訪問者の両方に調査する。その建物を決して見ることのない非訪問者が依然としてプラスの支払意思額を報告するため、この調査は、単純な訪問者料金収入のカウント（顕示選好の代理指標）が完全に見逃してしまう存在価値と遺贈価値を捕捉する——これは、いかなる種類の市場取引も存在しない場合における表明選好の真の優位性を示している。

## ソフトウェア開発との関連

表明選好法がソフトウェア開発の仕事に直接適用されることはめったにないが、市民コンサルテーションプラットフォーム、参加型予算ツール、あるいは公的調査インフラを構築するエンジニアは、しばしば経済学が依存する測定手段そのものを構築している。調査設計の細部を正しく仕上げること——無作為化された入札金額、自由回答質問ではなく二択のレファレンダム形式のフレーミング、明示的な予算制約のリマインダー——は、UXの気の利かせではなく、結果として得られる評価を精査に耐えるものにするために不可欠である。設計の悪いアプリ内調査は、その後何か月にもわたる経済分析を無効にしうる。分析的な重みに耐える世論データを引き出すより一般的な規律については[市民満足度指標](../citizen-satisfaction-metrics/)を参照。

## 落とし穴

- **自由回答の「いくら払いますか？」という質問。** これらは、二択のレファレンダム形式のフレーミングよりも、戦略的バイアスやアンカリングバイアスにはるかに脆弱である。NOAAパネルがレファレンダム形式の使用を推奨したのは、まさに自由回答の引き出し方が悪い成績を示すからである。
- **回答者の実際の予算制約のリマインダーがないこと。** それがなければ、表明された支払意思額は、実際の予算のトレードオフが問題になる場合に同じ人々が支払うであろう額を日常的に超える——仮想バイアスである。
- **埋め込み効果を無視すること。** 同じ財が単独で評価される場合と、より大きなバンドルの一部として評価される場合とでは、異なる支払意思額推定値が生み出される。調査の枠組みの中に他に何が含まれていたか（あれば）を報告すること。
- **単一の調査の点推定値を確定したものとして扱うこと。** グリーンブックの実務は、単なる裸の数字を市場価格であるかのようにコスト便益表に持ち込むのではなく、範囲と既知のバイアスについての議論を期待している。
