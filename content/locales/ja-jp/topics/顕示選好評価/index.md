# 顕示選好評価

顕示選好法は、人々に直接尋ねるのではなく、関連する市場における観察可能な行動から非市場財の価値を推測する。ヘドニック価格法と旅行費用法は、この分野における二つの主力の手法であり、どちらも実際の取引から出発して、直接には販売されたことのないものの暗黙の価格を逆算する。

## 重要な理由

[表明選好](../表明選好評価/)法が仮想的な質問をするのに対し、顕示選好法は人々が実際に支払ったものを観察する。これは、グリーンブックが、他の条件が同じであれば、一般により信頼できるエビデンスとして扱うものである。なぜなら、それは仮想バイアスの影響を受けないからである——ヘドニック住宅価格研究の回答者は、測定されているプレミアムやディスカウントを実際に支払った（<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>、付属書2）。ヘドニック価格法は、市場価格——通常は住宅価格——をその財の各属性についての暗黙の価格に分解し、アナリストが、例えば世帯が実際により静かな場所やより良い大気質の場所に住むために支払うプレミアムを、住宅価格に影響する他のすべての属性（広さ、立地、学区）を統計的に制御しながら分離することを可能にする。旅行費用法は、入場料のないレクリエーション施設に対して類似のことを行う——人々がある場所を訪れるために費やす時間とお金は、その場所が彼らにとって価値のある下限を明らかにする。なぜなら、誰も訪問の価値を超えるコストを負担しないからである。

両方の手法は同じ構造的な限界を共有している——それらは既存の市場取引に組み込まれているものしか評価できない。滑走路近くの騒音は住宅価格に現れる。なぜなら、騒音を気にする人々はより静かな住宅を選んで住んでいるからである。誰も訪れず、その近くに誰も住んでいない種の存在価値は、いかなる取引にもまったく現れない——これはまさに[表明選好](../表明選好評価/)法が埋めようとするギャップである。

## 計算式

```
ヘドニック価格法：
  住宅価格 = f(構造的属性、立地属性、関心のある環境属性、...)
  回帰によって推定する。環境属性の係数（他をすべて一定に保った
  場合）がその暗黙の価格である。

  属性Xの暗黙の価格 = ∂(住宅価格) / ∂X

旅行費用法：
  訪問率（ゾーンiからの1人あたり訪問回数）= f(ゾーンiからの
  旅行コスト、代替施設、社会経済的統制変数)
  旅行コストの関数として訪問の需要曲線を推定する。
  消費者余剰 = 推定された需要曲線の下の面積
              = 訪問者にとってのその施設の価値
```

両方の手法とも、統計的に健全な統制変数のセットが必要である——交絡する属性（ヘドニック）や近隣の代替施設（旅行費用法）を省略すると、暗黙の価格が事前には必ずしも明らかでない方向に偏る。これがまさに、グリーンブック付属書2が、見出しの係数だけでなく回帰の仕様と統制変数を報告することを要求している理由である。

## 計算例

**中央政府**：グリーンブック自体の影の炭素価格の方法論は部分的にヘドニックエビデンスを利用しているが、より単純な例示的ケースは航空機騒音である。飛行経路地域の住宅売却価格を、広さ、築年数、学区を制御しながら距離加重された騒音曝露に対して回帰したヘドニック研究が、平均騒音曝露の1デシベル増加ごとに住宅価格が0.5%減少することと関連していることを発見する。その影響地域の典型的な£280,000の住宅について：

```
1デシベルあたりの暗黙の価格 = £280,000 × 0.5% = 世帯あたり£1,400
新滑走路による3dB増加の影響を受ける世帯 = 18,000
騒音増加の総推定コスト = £1,400 × 3 × 18,000 = £75.6m
```

これは（住宅価格に組み込まれた）一回限りの資本化されたコストであり、評価は別途推定される年間の騒音迷惑コストのフローに対してこれを二重にカウントしないよう注意しなければならない。

**慈善団体**：ある環境慈善団体が、無料で入場できる自然保護区を評価するために旅行費用法を使用する。訪問者の郵便番号に関する調査データは、訪問1回あたりの平均往復旅行コスト（非労働時間の価値をグリーンブックの推奨値で評価し、燃料費を加えたもの）が£14であり、年間訪問回数は40,000回であることを示している。推定された需要曲線——ゾーンからの旅行コストが上がるにつれて訪問率が低下する——は、実際に支出された£14を超える、訪問1回あたりの消費者余剰がおよそ£9であることを示唆している。

```
総年間価値 = 40,000回 × (£14の支出 + £9の消費者余剰)
           = 40,000 × £23 ≈ £920,000/年
```

これは、その保護区のゼロである入場料収入をはるかに凌駕し、その慈善団体の理事たちに、資金提供者に対してケースを主張する際の、その施設のレクリエーション価値についての擁護可能な数字を与える。

## ソフトウェア開発との関連

顕示選好的な思考は、実務者が気づいている以上に、公共セクターの製品分析において頻繁に現れる——無料の政府デジタルサービスからの利用データそれ自体が、価値の顕示選好エビデンスである（頻度、セッション長、そして最も示唆的な、繰り返し利用対一回限りの利用のパターンは、旅行費用モデルが距離に対する訪問頻度を扱うのと同じ方法で分析できる）。あるサービスに真の代替手段がある場合（紙のチャネル、電話回線）、市民がデジタルチャネルを代わりに使うために負担する「コスト」（時間、データ通信量、端末）は、推定して利用と比較することができ、旅行費用のロジックを直接反映している。[デジタルサービス標準](../デジタルサービス標準/)と、直接の市場価格を持たない財についてまさにこの評価問題に直面している[オープンデータの価値](../オープンデータの価値/)を参照。

## 落とし穴

- **ヘドニックモデルにおける省略変数バイアス。** 相関する属性（学校の質は住宅価格と関心のある環境変数の両方と相関する）を省略すると、暗黙の価格の推定値が偏る。仕様は報告され精査される必要があり、結果だけでは不十分である。
- **旅行費用研究における代替施設の無視。** より近い代替施設が存在し統制されていない場合、ある施設に対する訪問者の顕示された価値は過小評価される——彼らは、その施設が独自に価値があるからではなく、単に無料だから主に訪れているのかもしれない。
- **まったく市場のエコーを持たない財に顕示選好を適用すること。** 存在価値、オプション価値、遺贈価値はいかなる取引にも現れず、ヘドニックあるいは旅行費用法では回収できない——そのギャップは[表明選好評価](../表明選好評価/)に属する。
- **資本化された（一回限りの）価値を年間フローと混同すること。** ヘドニックな住宅価格効果は通常、一回限りの資本化された価値である。それを年間便益フローとして扱うと、評価が膨らむ。
