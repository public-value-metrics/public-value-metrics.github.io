# 政府における費用効果分析

費用効果分析（CEA）は、*同じ*成果を達成するための代替的な方法のコストを、自然な単位で表現して比較する——路上生活者1人あたりの住居確保コスト、生徒1人を期待水準まで引き上げるコスト、CO2 1トンを削減するコストなど——その成果自体を金銭に変換することはしない。

## 重要な理由

グリーンブックは、[社会的費用便益分析](../social-cost-benefit-analysis/)があらゆる便益を金銭化することを求める要件が、単に困難であるだけでなく不誠実になる場合の予備的方法としてCEAを扱っている——成果に信頼できる価格をつけることが、実際には誰も持っていない前提を必要とする場合である（<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>、第5章、成果を容易に金銭化できない場合の選択肢評価について）。CEAは、保健経済学から最も直接的に借用された方法である——NICEが質調整生存年あたりのコストを用いて治療法を比較する方法と構造的に同一であるが、それを保健以外の公共プログラムに適用している——教育の介入策は生徒1人の成果ポイントあたり、住宅プログラムはホームレスを免れた世帯あたり、雇用プログラムは持続的な雇用成果あたりで評価される。

CEAがSCBAに吸収されるのではなく、その隣に自らの居場所を得ているのは、一部の成果に金銭的価値を強いることが、権威があるように見えるほど精緻でありながら、公的な議論では無価値になるほど議論の余地があるという数字を生み出すからである——「期待水準で読める子ども」に価格をつけることは、まさに選択委員会でビジネスケースを頓挫させる種類の異議を招く。CEAは、その議論を避けるのではなく、そもそも行わないことでこれを回避する——選択肢を*成果そのもの*の単位あたりコストでランクづけし、その成果を追求する価値がそもそもあるかどうかという別の政治的判断は戦略事例に委ねる。

## 計算式

```
費用効果比（平均） = 総コスト / 達成された総成果単位

増分費用効果比（ICER）、選択肢Aと選択肢Bの比較：
ICER = (コスト_A − コスト_B) / (成果_A − 成果_B)

手順：
1. 比較されるすべての選択肢について成果単位と測定方法を固定する。
2. 同じ時間軸で、同じ基準ですべての選択肢のコストを計算する
   （../green-book-appraisal/ の財務事例を参照）。
3. 支配される選択肢を除外する——同じかそれ以上の成果を達成する
   より安価な代替案よりも単位あたりコストが高い選択肢は除外される。
4. 残った選択肢を、平均ではなく増分の費用効果比でランクづける。
```

CEAはそれ自体では、あるプログラムがそもそも資金提供に値するかどうかを言うことはできない——同じ目標に対する複数のアプローチのうち、単位あたりで最も安いのはどれかだけを言うことができる。その目標自体が支出に値するかどうかを決めるには、SCBAに戻す（信頼できる評価が存在する場合）か、計算の外での政治的・戦略的判断が必要である。成果が本当に一つの単位に還元できない場合——プログラムが異なる意味で重要な複数の成果を生み出す場合——は、代わりに[多基準意思決定分析](../multi-criteria-decision-analysis/)を使用すること。

## 計算例

**地方自治体**：ある自治体が、路上生活を減らすための三つのアプローチを比較する。それぞれ1年間のコストを、「6か月以上安定した住居に移った個人」という成果に対して計算する。

```
選択肢                     コスト     達成された成果   平均CER
Housing First（集中型）    £900,000   60              £15,000/成果
シェルター＋移行支援       £600,000   50              £12,000/成果
アウトリーチ＋民間賃貸市場 £350,000   20              £17,500/成果

ICER、シェルター対アウトリーチ：(600k−350k)/(50−20) = £8,333
（追加成果1件あたり）
ICER、Housing First対シェルター：(900k−600k)/(60−50) = £30,000
（追加成果1件あたり）
```

アウトリーチは平均コストではシェルターに劣後するが、アウトリーチからシェルターへの*増分*ステップは、追加で1人を住居確保するのに£8,333しかかからない——これは、シェルターが達成する以上に追加1人あたり£30,000かかるHousing Firstのステップに比べて安い。予算に制約のある自治体が拡大する場合、Housing Firstよりもシェルターの拡大を優先すべきである。たとえHousing Firstがそれ自体の平均比率では良く見えるとしても。

**中央政府**：ある識字力補習プログラムが、「年齢相応の読解水準に達した生徒あたりのコスト」で三つの提供モデルを比較される——個別指導（£1,800/生徒）、少人数グループ指導（£700/生徒）、デジタルのみの介入（£150/生徒、ただし関与の低下を調整すると、登録した生徒あたりの成果率は少人数グループ指導の40%にすぎない）。実際の修了率で調整すると、デジタルのみは水準に達した生徒あたり£375となり——それでも最も安いが、CEAは、デジタルのみによって助けられた生徒の絶対数が少人数グループ指導と同じ予算で提供された場合により少なくなることが、より深く助ける少数の生徒に到達することと比べて許容できるトレードオフかどうかは言えない。それは、CEAが意思決定者に返す分配的な判断である。

## ソフトウェア開発との関連

CEAは、技術チームが*同じ*サービス成果に対する提供アプローチを評価する際に常に正しい枠組みである——三つの本人確認ベンダーにわたる、正常に確認された本人1件あたりのコスト、二つのケースワーク自動化設計にわたる、正しくトリアージされた案件1件あたりのコスト、社内対請負によるアクセシビリティ不具合の修正1件あたりのコストなど。ここで直接取り入れるべき規律は、コストを比較する前に成果単位を定義すること（「クローズしたチケット数」——アウトプット——ではなく「実際に解決されたユーザーニーズ」）、そして稼働中のシステムと提案されている代替との間の増分比率を、各システムを単独で見た平均コストではなく常に計算することである。[成果とアウトプット](../outcomes-vs-outputs/)と[成果あたりコスト](../cost-per-outcome/)を参照。

## 落とし穴

- **拡張を決定する際に、増分比率ではなく平均比率を比較すること。** 路上生活の例が示すように、平均比率が最良の選択肢が、常に次の成果単位を購入するのに最も安いとは限らない。
- **実際にはアウトプットである成果単位を選ぶこと。** 「行った紹介数」や「実施したセッション数」は活動を測定しており、そのプログラムが生み出すために存在している成果を測定していない。アウトプットに対するCEAは、間違った問いに答える自信満々な数字を生み出す。
- **本質的に異なる成果を比較すること。** CEAは、すべての選択肢が同じ方法で測定された同じ成果を目指している場合にのみ有効である。「住居確保した路上生活者1人あたりコスト」を「安定した居住形態にある施設退所児童1人あたりコスト」と比較するには、汎用的な成果指標か、CEAではなく[多基準意思決定分析](../multi-criteria-decision-analysis/)が必要である。
- **成果の持続性を無視すること。** 持続しない成果を生み出すより安価な選択肢（介入策終了後に後退する生徒）は、比較可能な期間で測定すると実際にはより費用対効果が高いわけではない。比較される選択肢間で追跡期間を一致させること。
