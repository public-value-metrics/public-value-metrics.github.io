# 人間開発指数（HDI）

HDIは、国を所得だけでランク付けすることに対する国連の代表的な代替指標である——それは平均寿命、教育、所得を0から1の間の単一の数字へと組み合わせる。これは、経済学者アマルティア・センが主張し、国連のためにマブーブル・ハックが開発した前提——開発とは人々が稼ぐものだけでなく、人々ができること・なれることの拡大であるという前提——に基づいている。これは1990年以来、国連開発計画のHuman Development Reportで毎年公表されている。

## 重要な理由

HDI以前、「開発」はほとんど完全に一人あたりGNPで測定されており、これは成長が普通の人々の健康や教育に届いているかどうかについては何も語らない。センのケイパビリティ・アプローチは、開発を実質的な自由の拡大として再構成し、ハックはそれを国連開発計画があらゆる国をランク付けできる公表可能な指数へと変えた。これは、所得だけで豊かになりながら健康や教育を怠った政府に、そのGDPが示唆するよりも悪いランクに直面することを強制した（湾岸の産油国といくつかの採掘経済がその標準的な例である）。HDIの三方向の構造はまた、[多次元貧困指数](../多次元貧困指数/)の直系の方法論的祖先でもある——どちらも、ある次元が別の次元の不足を買い戻すことを、算術平均ではなく幾何平均を使うことで拒否する。国連開発計画は、それぞれの版について完全な技術ノートと根底にあるデータを公表しており（<https://hdr.undp.org/data-center/human-development-index>）、これはその指数を再導出するのではなくそれを土台に構築する人にとっての正典的な情報源である。

## 計算式

```
平均寿命指数（LEI）           = (平均寿命 − 20) / (85 − 20)

平均就学年数指数              = 平均就学年数 / 15
期待就学年数指数              = 期待就学年数 / 18
教育指数（EI）                = (平均年数指数 + 期待年数指数) / 2

所得指数（II）                 = (ln(一人あたりGNI) − ln(100))
                               / (ln(75000) − ln(100))

HDI = (LEI × EI × II) ^ (1/3)     [三つの副指数の幾何平均]
```

幾何平均は意図的である——それは平均するのではなく乗算するため、ある次元での非常に高いスコアが、別の次元での非常に低いスコアを完全には相殺できない——これは、国連開発計画が不均衡を罰するために2010年に特に採用した設計であり、以前の算術平均の公式を置き換えた。

## 計算例

**中所得国**：平均寿命72歳、平均就学年数8年、期待就学年数13年、一人あたりGNI $12,000。

```
LEI = (72 − 20) / (85 − 20)              = 52 / 65   = 0.800
平均就学年数指数 = 8 / 15                              = 0.533
期待就学年数指数 = 13 / 18                             = 0.722
EI = (0.533 + 0.722) / 2                             = 0.628
II = (ln(12000) − ln(100)) / (ln(75000) − ln(100))
   = (9.393 − 4.605) / (11.225 − 4.605)
   = 4.788 / 6.620                                   = 0.723

HDI = (0.800 × 0.628 × 0.723) ^ (1/3)
    = (0.363) ^ (1/3)                                ≈ 0.713
```

0.713のHDIは、国連開発計画の「高い人間開発」帯（0.700〜0.799）に入る。「非常に高い」は0.800から始まる。結果が最も弱い副指数にどれほど敏感かに注目すること——平均就学年数が8ではなく4であったなら（平均就学年数指数=0.267、EI=0.494）、他は何も変わらなくても、HDIは(0.800×0.494×0.723)^(1/3)≈0.639まで低下する——1帯まるごと下落する。

## ソフトウェア開発との関連

- 幾何平均のパターンは、ある強い次元に致命的な弱い次元をごまかされたくないあらゆる複合サービス/製品スコアに直接再利用可能である——例えば、公共デジタルサービスのアクセシビリティ、パフォーマンス、信頼性のスコアを、加重平均ではなく乗法的に組み合わせることで、速いがアクセスできないサービスが「良い」とスコア付けされないようにする。
- HDIの所得の対数変換（追加の1ポンドの逓減する限界価値）は、評価における[分配的重みづけ](../分配的加重/)の背後にあるのと同じ論理である——追加の$1,000は貧しい世帯にとって豊かな世帯よりもはるかに大きな意味を持ち、両方を線形に扱うことはインパクトの価格を誤らせる。
- 単一の混合された「デジタル・インクルージョン」あるいは「市民の成果」スコアを報告するあらゆるダッシュボードは、国連開発計画の技術ノートと同じくらい明示的にその集計公式を文書化すべきである——[公共セクターKPI](../公共セクターkpi/)と[公共価値スコアカード](../公共価値スコアカード/)を参照。

## 落とし穴

- **幾何平均ではなく平均を使うこと**——算術平均は、高い所得が貧しい健康や教育を完全に覆い隠すことを許す。2010年の方法論変更の要点全体は、その代替を止めることだった。
- **HDIをインフレ調整されたGDPであるかのように年をまたいで比較すること**——国連開発計画は定期的にその指数を再基準化する（新しい最小/最大の境界、改定された就学上限）ため、ランクの変化は方法論の更新を反映しているのであって、実際の変化ではないことがある。ある数字がどのHDRの版から来ているかを常に確認すること。
- **HDIを貧困の尺度として扱うこと**——それは国全体の平均であり、国内の分配については何も語らない。そのためには[多次元貧困指数](../多次元貧困指数/)あるいは国連開発計画の別のInequality-adjusted HDIを使うこと。
