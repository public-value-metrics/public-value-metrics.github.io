# 公共サービスの生産性

公共サービスの生産性は、公共支出が投入（人員、資本、財・サービス）をどれだけ効率的に品質調整されたアウトプットに変換しているかを測定する。保健、教育、警察、ソーシャルケアのようなサービスは市場価格を持たず、したがってコストを割るための収益の数字も持たない。英国のOffice for National Statisticsは2000年代半ばからこの系列を公表しており、それは「政府はお金を公共サービスに変換するのが上手くなっているのか、下手になっているのか」という問いに答える、方法論的に最も発展した全国的な試みであり続けている。

## 重要な理由

市場においては、生産性は（アウトプットの価値）/（投入コスト）であり、アウトプットの価値は誰かがそれに対して支払うため観察可能である。股関節置換手術、学校の定員、警察の巡回には販売価格がないため、単純に考えると*投入*（何が使われたか）しか測定できない——これは、評論家に、より多くの投入と横ばいの見かけ上の活動が生産性の低下のように見えるという理由で、公共支出の増加を自動的に悪いものとして扱わせる誘惑を与える。ONSの方法論は、公共サービス生産性の「出典と方法」の出版物に示されており、活動量（実施された手術、教えた生徒、捜査した犯罪）から*アウトプット*指数を構築し、そのアウトプット指数を*品質調整*することでこれを解決する——保健については生存率と待機時間を、教育については達成度を、警察については事件解決のような成果を組み込む。これにより、同じ回数の手術を行いながらより良い生存率を達成するサービスは、単に高くつくだけではなく、より生産的であると記録される。ONSの発表全体で繰り返される見出しの発見は、このセクターにとって厳しいものである——英国の公共サービス生産性はCOVID-19パンデミック中に急落し、2020年代半ばのONSの発表時点でも、保健医療を含むいくつかの下位セクターで2019年水準に回復していない。支出が増加しているにもかかわらずである——このギャップは、「より多くの資金」と「より多くの生産性」を完全に別の二つの問いとして再構成する。

## 計算式

```
アウトプット指数（量） = Σ (活動_i × 相対単位コスト重み_i)、基準年で
                        重み付けされ、すべてのサービス活動（例えば
                        股関節手術、白内障手術、GP診察）にわたる、
                        ラスパイレス/パーシェ数量指数に類似

品質調整         = アウトプット指数 × 品質調整係数（例えば
                   生存率、待機時間、達成度、あるいは再犯率の
                   変化を生の量に対する乗数として組み込む）

投入指数         = Σ (労働時間 × 労働コスト重み) + （デフレートされた
                   財・サービスコスト）+（資本消費）

全要素生産性の成長 = 品質調整されたアウトプット指数の%変化 −
                    投入指数の%変化
```

## 計算例

**NHS急性期セクターの生産性計算の例示**（構造はONSの方法論に従う）：

```
1年目：アウトプット量指数=100.0（基準年）、投入指数=100.0
        → 生産性指数=100.0

2年目：活動量が3.0%上昇（より多くの手術、より多くの予約）
        するが、平均待機時間が悪化し、−1.0%の品質調整
        割引が適用される
        品質調整されたアウトプット指数 = 100 × 1.030 × 0.990
                                        = 101.97

        投入が上昇：職員数+4.0%、その他のコスト（デフレート後）
        +1.5%、重み付き投入指数 = 100 × 1.032 = 103.2

生産性の成長 = (101.97 / 100 − 1) − (103.2 / 100 − 1)
             = 1.97% − 3.2% = −1.23ポイント

解釈：活動は上昇したが、投入がより速く上昇し、品質がわずかに
低下したため、「より多くのケアが提供された」にもかかわらず、
投入単位あたりのアウトプットである生産性は低下した。
```

これはまさに、パンデミック後のNHSの一部について、ONSの発表が繰り返し報告してきたパターンである——品質調整と投入成長の両方が考慮されると、支出と生の活動の上昇が、測定された生産性の低下と共存する。

## ソフトウェア開発との関連

公共サービスの生産性は、エンジニアリングの生産性論争（出荷されたストーリーポイント対[DORA指標](../dora-metrics-for-public-value/)対[フロー指標](../flow-metrics-in-government-delivery/)）の人口レベルの対応物である——品質調整のない生の処理量は、病院においてもソフトウェアチームにおける「出荷されたコード行数」とまったく同じように誤解を招く。省庁向けの業績データパイプラインを構築するチームは、品質調整を脚注ではなく、第一級のバージョン管理された変換段階として扱うべきである——なぜなら、ONS自身の信頼性は、その調整が透明で、再現可能で、より良い品質データが届くにつれて改定されることに依拠しているからである（ONSは、基礎となる品質データ——例えば生存率——が確定するにつれて過去年の生産性推定値を改定するため、この統計を消費する下流のシステムは新しい期間を追加するだけでなく、遡及的な改定を処理しなければならない）。これはまた、[政府ITにおける総所有コスト](../total-cost-of-ownership-in-government-it/)と[公共セクターにおけるAI生産性](../ai-productivity-in-the-public-sector/)にも直接関わる——品質を向上あるいは維持することなく生の活動量を増やすシステムは、ONS自身の定義では生産性の向上ではない。

## 落とし穴

- **投入の成長を生産性の成長として扱うこと。** より多くの支出がより多くの職員に資金を出すことは、単位あたりのアウトプットも上昇しない限り、より多くの*活動*を生み出すのであり、より多くの*生産性*を生み出すのではない——この二つは政治的な論評で日常的に混同される。
- **品質調整を完全に無視すること。** 生の活動数だけから構築されたアウトプット指数は、より低い価値あるいはより低い品質のものをより多く行うことによる「生産性向上」を示してしまう——ONSの品質調整はまさにこれを捕捉するために存在する。
- **方法論のバージョンを一致させずに下位セクター間で生産性指数を比較すること。** 保健、教育、警察の生産性は、それぞれ異なる活動・品質データソースから、異なる改定サイクルで構築されている——素朴なセクター横断比較は互換性のない道具を比較していることになる。
- **単一年の生産性低下を恒久的なトレンドとして読むこと。** パンデミック期とパンデミック後の生産性数値は、待機リストや選択的手術の回復のような品質データ自体が変動するにつれて、大きな年次変動を示してきた。ONSは単一年の動きを過剰に解釈しないよう一貫して警告している。
