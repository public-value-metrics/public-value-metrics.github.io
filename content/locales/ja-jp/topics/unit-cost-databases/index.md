# 単位コストデータベース

単位コストデータベースは、社会的成果——失業から雇用への移行の価値、孤独の軽減、安定した賃貸契約——について、事前に調査されエビデンスに基づいた財務代理指標のライブラリであり、実務者が毎回オーダーメイドの評価調査を委託することなく成果を金銭化できるようにする。これらが存在するのは、資金の少ない慈善団体が、誰か他の人が既に導出し公表した代理指標を再利用することで、資金の豊富なコンサルティング会社と同じ厳密さを、資金提供申請を書く際に適用できるようにするためである。

## 重要な理由

経済学者ダニエル・フジワラとともに福祉評価の手法を用いて開発されたHACTのUK Social Value Bankと、財務代理指標のオープンでクラウドソースされたデータベースであるGlobal Value Exchangeは、英国の第三セクターと公共セクターで最も広く使われている二つである。両方とも存在するのは、根底にある評価作業——[福祉評価](../wellbeing-valuation/)と[表明選好評価](../stated-preference-valuation/)——が高価で、方法論的に要求が厳しく、すべてのプロジェクトについてゼロから行うには時間がかかりすぎるからである。共有された、公表された代理指標のライブラリは、本来なら何か月もかかる調査作業を検索に変える——これがまさに、[社会的投資収益率](../social-return-on-investment/)計算と[社会的価値法](../social-value-act/)入札評価の両方にとってこれらが重要である理由である。それらがなければ、厳密な金銭化は、独自の調査を委託できるほど大きな組織にしか手が届かないであろう。

## 計算式

単位コストデータベース自体は何も計算しない——それは他の場所で行われる計算に一つの入力値を提供する。

```
財務代理指標の値 = 市場価格、あるいは影の価格、あるいは福祉評価、
                    あるいは表明選好の値
                    （定義された成果変化の単位に対して、例えば
                    「失業から雇用に移った1人あたり、年間」）

適用された値 = 達成された成果の数 × 単位あたりの代理指標の値
```

市場価格が存在しない場合に代理指標がどのように構築されるかについては[影の価格設定](../shadow-pricing/)を、適用された値が死荷重と帰属の調整の後にどのように比率に反映されるかについては[社会的投資収益率](../social-return-on-investment/)を参照。

## 計算例

**慈善団体（フレンドシップ訪問サービスのSROI）**：単位コストデータベースの「孤独の軽減」に関するエントリは、1人あたり年間£1,100という例示的な代理指標を与える。80人の受益者に適用すると：80×£1,100=£88,000の総価値。もし同じデータベースが、重複する福祉調査項目に基づく「メンタルウェルビーイングの向上」の代理指標も持っている場合、同じ80人に対して両方の代理指標を積み重ねると、同じ根底にある変化の一部を二重にカウントしてしまう——データベースは数字を提供するが、この重複を避けることはアナリストの責任である。

**地方自治体（ジョブクラブのSROI）**：「失業から持続的な雇用への移行」に関する単位コストデータベースのエントリが、45人の参加者に対して1人あたり年間£8,500という例示的な代理指標で適用される：45×£8,500=£382,500の総価値であり、これは[社会的投資収益率](../social-return-on-investment/)で示されている死荷重と帰属の調整の前の数字である。

## ソフトウェア開発との関連

慈善団体あるいは委託機関向けの報告ツールを構築するチームは、内部の「成果カタログ」——製品やサービスがもっともらしく主張できる各成果を、名前のついた代理指標、その出典データベース、公表日、バージョン識別子に対応づける表——から恩恵を受ける。これにより、組織内の異なるチームが同じ成果に対してそれぞれわずかに異なる値を選ぶことがなくなる。Global Value Exchangeのオープンデータを、出典と日付を常に数字とともに表示しながら検索サービスの背後にラップすることは、代理指標をスプレッドシートに埋もれた魔法の数字ではなく監査可能なものに保つ。これらの代理指標が使われる主な二つの場所については[社会的投資収益率](../social-return-on-investment/)と[社会的価値法](../social-value-act/)を参照。

## 落とし穴

- **代理指標を正確なものとして扱うこと。** 公表されている代理指標のほとんどは、広い信頼区間を持つ福祉評価研究からのモデル化された平均値である。それをポンド単位まで正確に引用することは、根底にある研究が支える精度を誇張する。
- **重複する代理指標を二重にカウントすること。** 重複する調査構成概念から導出された代理指標（例えば「孤独の軽減」と「メンタルウェルビーイングの向上」）を組み合わせることは、同じ根底にある変化を二回評価してしまう。
- **文脈から外れた代理指標を調整せずに使うこと。** ある年の、ある国全体の人口に対して較正された代理指標を、インフレや文脈の調整なしに別の場所に適用することは、静かに価値を誤って表す。
- **出所を確認しないこと。** Global Value Exchangeはオープンでクラウドソースされているため、エントリの質は寄稿者によって異なる。資金提供申請や調達提出物で数字を引用する前に、根底にある出典を確認すること。
