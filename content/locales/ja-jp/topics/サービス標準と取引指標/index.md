# サービス標準と取引指標

GOV.UKサービス標準は、英国政府の公共デジタルサービスを構築・運用するための14項目のチェックリストであり、取引あたりコスト、完了率、デジタル利用率、利用者満足度という、小さな必須の定量的取引指標セットとペアになっている。これらは、すべての稼働中の中央政府サービスがチームが公表しなければならない。標準と指標は合わせて、このリポジトリのより広い公共価値とKPIの枠組みを、まさにソフトウェア提供チームに向けた運用上の日常的な特化として位置づける。

## 重要な理由

GOV.UKのサービスマニュアルに維持されているサービス標準は、政府デジタルサービスのあらゆる時点評価（アルファ、ベータ、ライブ）に対して、その14項目——利用者のニーズを理解している、複数の専門分野からなるチームで働いている、頻繁に反復・改善している、そして*ツール、システム、作業方法を評価している*——を実証することを要求する。歴史的にはこれは、すべての稼働中のサービスが取引データを公開していた公開Performance Platformと並んでいたが、そのプラットフォームは以降廃止されている。しかしこの四つの核となる指標を測定・公表する根底にある義務は、サービスマニュアルの「成功の測定」指針を通じて存続している。これが汎用的なソフトウェアKPIダッシュボードと異なる理由は、これらの指標が四つの独立したスコアとしてではなく、一つの連結した経済モデルとして明示的に設計されたことにある——デジタル政府全体の節約ケースは、Government Digital ServiceのDigital Efficiency Reportが、比較可能な地方自治体サービスについて電話より約20倍、対面より約50倍安いことを発見したデジタル取引について、完了率が高いまま保たれ、デジタル利用率が本当に上昇して初めて実現する。単に、変わらない高価なチャネルと並べて安価なチャネルを追加するだけでは実現しない。

## 計算式

```
取引あたりコスト   = サービスの総運用コスト / 完了した取引数
完了率             = 完了した取引数 / 開始した取引数 × 100
デジタル利用率     = デジタルチャネルの取引数 / 全チャネルの取引数
                    × 100
利用者満足度       = %満足+非常に満足、サービス内5段階調査

チャネル移行による節約 = 取引量 × 利用率の移行 × (旧チャネルの
                        取引あたりコスト − デジタルの取引あたり
                        コスト)

対応不能需要コスト = (1 − 完了率) × デジタルで試みられた取引数 ×
                    完了できなかった利用者がその代わりに使う
                    フォールバックチャネルのコスト
```

## 計算例

**例示的な中央政府の免許更新サービス**、年間200万件の取引、現在65%が電話（£3.00/取引）、35%がデジタル（£0.30/取引）、完了率80%。14項目のサービス標準に沿った再設計により、デジタル利用率が60%に、完了率が92%に上昇する。

```
利用率移行による節約 = 2,000,000 × 0.25 × (3.00 − 0.30)
                      = £1,350,000/年

対応不能需要コスト、以前：
  2,000,000 × 0.35 × (1 − 0.80) × £3.00 = £420,000/年
  （放棄者は電話に戻る）

対応不能需要コスト、以降：
  2,000,000 × 0.60 × (1 − 0.92) × £3.00 = £288,000/年

対応不能需要の純節約 = £420,000 − £288,000 = £132,000/年

総年間節約 ≈ £1,350,000 + £132,000 = £1,482,000/年
```

この計算は、なぜ完了率が二次的な指標ではないかを明確にする——80%から92%への改善なしには、利用率移行による節約は、フラストレーションを感じたデジタル利用者を高価な電話チャネルへ直接送り返す対応不能需要によって部分的に取り戻されてしまうであろう。

## ソフトウェア開発との関連

これら四つの指標は、コスト結果ダッシュボードの実働例である——一つのコスト指標が三つの成果/品質指標から意図的に切り離され、一つのスコアに決して圧縮されない——これは[公共セクターKPI](../公共セクターkpi/)で主張されているのと同じ規律である。エンジニアにとって、これは具体的で担当可能な作業に分解される——完了率は漏斗の計装問題であり、ジャーニーのすべての放棄点は原則として特定・修正可能である。取引あたりコストには、クラウドホスティング費用だけでなく、支援付き・紙チャネルのコストを含む真の単位コスト会計が必要である（[取引あたりコスト](../取引あたりコスト/)と[政府ITにおける総所有コスト](../政府itにおける総所有コスト/)を参照）。そしてデジタル利用率は効率性の衣をまとった公平性指標である——チャネルを移行できない、あるいは移行したくない市民は、不均衡に高齢者、障害者、あるいはデジタル排除された人々である。したがって攻撃的なチャネル閉鎖は「節約」をアクセス上の害に変えてしまう（[デジタル・インクルージョン](../デジタル-インクルージョン/)と[チャネル移行による節約](../チャネル移行による節約/)を参照）。14項目の標準自体は、これらの数字の背後にあるプロセス仕様である——標準の全体については[デジタルサービス標準](../デジタルサービス標準/)を、満足度の数字がより広い信頼測定とどう関係するかについては[市民満足度指標](../市民満足度指標/)を参照。

## 落とし穴

- **代替チャネルを閉鎖することで得られた利用率。** 電話回線を閉鎖することは、デジタル利用率のパーセンテージを算術的に押し上げる一方で、残されたどのチャネルにも対応不能需要を押し付ける（しばしばより高価な支援付きデジタルあるいは対面ルート）——常に比率だけでなくシステム全体のコストを測定すること。
- **漏斗の第二段階から完了率を測定すること。** 最初の本当の離脱点の後に「開始」のカウントを始めることは、完了率を良く見せかけ、最大の修正可能な損失を隠してしまう。
- **支援付きデジタルサポートを除外した取引あたりコスト。** セルフサービスできない利用者を支援するために費やされたスタッフの時間を無視した、デジタルのみの単位コストは、そのチャネルの真のコストを過小評価する。
- **サービス間で共有される定義なしに指標を公表すること。** 「取引」や「完了」は、定義が標準化されバージョン管理されていない限り、異なるサービスチームで異なる意味を持ち、サービス間比較を信頼できないものにする。
