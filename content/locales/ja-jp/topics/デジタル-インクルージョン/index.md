# デジタル・インクルージョン

デジタル・インクルージョンは、「デフォルトでデジタル」が「デジタルのみ」にならないようにする規律である——最も安価なチャネルを中心に設計された公共サービスが、それを支援なしに使えない、あるいは使いたくない市民にとっても機能し続けるようにする。GDSは、支援付きデジタルという特定の提供メカニズムを、任意のおまけとしてではなく、すべての政府デジタルサービスの必須要件として作り出した。

## 重要な理由

2012年のGovernment Digital Strategyは、その野心を明確に定めた——デジタルサービスはデフォルトでデジタルとして構築されるべきであるが、その戦略自体が、英国の成人のおよそ10%が支援なしにそれらを使えないであろうことを認め、各省庁に、後から後付けされる別のフォールバックとしてではなく、サービスの一部として、支援付きデジタルサポート——電話、対面、あるいは仲介者を通じた人間が介在する経路——を提供することを約束させた。その約束は現在、[デジタルサービス標準](../デジタルサービス標準/)の第5項目「誰もがそのサービスを使えるようにする」である。継続する排除の規模は、Lloyds Banking Groupの年次UK Consumer Digital Indexによって追跡されている——2024年版は、英国でおよそ160万人がオフラインのままであること、そしてこのグループが70〜79歳の人々、£35,000未満の収入の人々、退職あるいは失業している人々に大きく偏っていることを発見した——まさに、再設計されている公共サービスに依存する可能性が最も高い母集団である。同じ報告書は、Essential Digital Skillsフレームワークの20のタスクすべてを完了できる英国の労働力はわずか48%にすぎないことを発見しており、これは排除が二値の接続性ではなく、単純な「ブロードバンドがある」という指標が完全に見逃すスキル、自信、信頼のスペクトラムであることを意味する。

## 計算式

デジタル・インクルージョンは、単一の公式というよりも枠組みと公平性チェックであるが、[分配的重みづけ](../分配的加重/)を通じて定量的な価値評価と組み合わさる。

```
素朴なチャネル移行の価値：
  価値 = 移行した量 × (コスト_旧 − コスト_デジタル)
        [channel-shift-savingsを参照]

インクルージョン調整後の価値：
  価値 = (移行した量 × 重み付けされていない節約)
        − (除外された利用者数 × 支援付きデジタル提供のコスト)
        − (アクセスを失う、あるいはサービス品質の低下に直面する
           除外されたグループへの害に対する分配的重みづけの調整)

支援付きデジタルは失敗の残余コストではない——それは独自の
[取引あたりコスト](../取引あたりコスト/)を持つ設計された
チャネルであり、通常セルフサービスデジタルよりも取引あたり
はるかに高いが、それでも通常それが部分的に置き換えるレガシー
チャネルよりは安い。
```

## 計算例

**Universal Credit方式の全国給付サービス**：年間250万件の請求、Government Digital Strategyの計画上の前提によれば、請求者の推定10%に支援付きデジタルサポートが必要と評価される。

```
除外された/支援付きデジタルのコホート = 2,500,000 × 10%
                                        = 250,000件/年

支援付きデジタルチャネルのコスト（脆弱性と複雑さに対応する人員
配置をされた電話＋対面サポート） ≈ £9.50/請求
  = 250,000 × £9.50 = £2,375,000/年

残り90%に対するセルフサービスデジタルのコスト ≈ £0.40/請求
  = 2,250,000 × £0.40 = £900,000/年

ブレンドされた取引あたりコスト = (2,375,000 + 900,000)
                                / 2,500,000 = £1.31/請求

より低い見出しの取引あたりコストを達成するために支援付き
デジタルを省略する設計（例えば、除外された25万人の請求者を
無視して£0.40のブレンド値）は、その£237.5万のコストを排除
するのではない——それを、まったく別の予算に着地する、未請求の
受給資格、不服申立て、そして下流の危機サービス需要へと変換
するだけである。
```

## ソフトウェア開発との関連

支援付きデジタルは設計されたチャネルであり、これは他のあらゆるチャネルと同様にインターフェース、SLA、計装を持つことを意味する——電話ベースのケースワーカーツール、Citizens Adviceや地方自治体向けの仲介者ポータル、あるいは対面のキオスクフローである。それを、発見の段階から検討されたチャネルとしてではなく、小さな文字の電話番号のような後付けとして扱うことは、サービスが評価において[デジタルサービス標準](../デジタルサービス標準/)の第5項目に失敗する最も一般的な単一の方法である。デジタル・インクルージョンは、本章の他のすべてのトピックにおける公平性のレンズである——それは[チャネル移行による節約](../チャネル移行による節約/)がどれだけ積極的に実現できるかに上限を設け、[取引あたりコスト](../取引あたりコスト/)に正直に含まれなければならない項目であり、デジタルサービスの文脈への[分配的重みづけ](../分配的加重/)の直接的な応用である——すでにデジタル的・経済的に排除されている人々に不均衡に着地する節約は、下方に重み付けされるべきであり、母集団全体に均等に広がる節約と同等として扱われるべきではない。

## 落とし穴

- **「デフォルトでデジタル」を「デジタルのみ」と読むこと**：デジタル利用が閾値を超えたら、残りのコホートが真に使用可能な代替手段を持っているかどうかを検証せずに、電話回線や窓口を閉鎖すること。
- **二値の接続性でインクルージョンを測定すること**：「ブロードバンドがある」あるいは「スマートフォンを所有している」は、特定の取引を完了する能力の貧弱な代理である——Essential Digital Skillsのギャップ（Lloyds 2024によれば英国の労働力のわずか48%しか20のタスクすべてを完了できない）は、スキルと自信がアクセスと同じくらい重要であることを示している。
- **支援付きデジタルを誤差として計上すること**：それを、独自の[取引あたりコスト](../取引あたりコスト/)を持つ適切なチャネルとしてではなく、小さな予備費の項目として予算計上し、それがローンチ時に資金不足・人員不足であることに驚くこと。
- **成功したデジタル完了者だけを調査すること**：サービス内でのみ実施された満足度とユーザビリティの調査は、そこまで到達しなかった人々を見逃す。それはまさに、デジタル・インクルージョンの取り組みが保護しようとしている母集団である。
