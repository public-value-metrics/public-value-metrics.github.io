# 慈善団体オーバーヘッド比率

慈善団体オーバーヘッド比率は、総支出のパーセンテージとして表現された管理費と資金調達費である。これは慈善的寄付において最も求められる単一の数字である——寄付者、監視団体、そして一部の資金提供者でさえ効率性の代理として使う——そしてこれはまた、この分野で最も徹底的に信用を失った効率性指標の一つでもあり、それを普及させた組織自身が2013年に公然とそれを否定した。

## 重要な理由

2013年6月17日、米国最大の非営利団体格付け・情報機関三団体——GuideStar、BBB Wise Giving Alliance、Charity Navigator——は、アメリカの寄付者に向けた共同公開書簡「The Overhead Myth」を公表し、オーバーヘッド比率が慈善団体の業績の貧弱な尺度であることを明示的に述べ、寄付者に代わりに透明性、ガバナンス、成果を見るよう強く促した。これら三団体自身の歴史的な格付けが、オーバーヘッド比率を慈善団体の質を表す略記として定着させる一助となっていたにもかかわらずである。これは、10年間にわたってその比率を中心に寄付文化を築いてきた当の機関による、直接的な方向転換であった。

根底にある問題は、単に見栄えの問題ではなく構造的なものである——低いオーバーヘッド比率は、まさに慈善団体を効果的にするもの——まともなケースマネジメントシステム、訓練されたスタッフ、モニタリングと評価——への過少投資によって達成されうる。なぜなら、それらはしばしば「プログラム」コストではなく「管理」コストとして計上されるからである。オーバーヘッド5%を報告するために後方部門を飢えさせる慈善団体は、適切に資源を配分された運営に20%を費やす慈善団体よりも、成果を提供する能力が低いかもしれない。イングランドとウェールズでは、Charity Commissionの受託者向けガイダンスは、効率性テストとして単一のオーバーヘッド・パーセンテージから離れ、代わりに受託者に、慈善団体が目標に対して何を達成したかを報告するよう求めている——[受益者あたりコスト](../cost-per-beneficiary/)で論じられているSORP報告要件を参照。

## 計算式

```
オーバーヘッド比率 = (管理コスト + 資金調達コスト) / 総支出

一般的な変種：
  プログラム比率     = プログラム（直接的な慈善）支出 / 総支出
                      = 1 − オーバーヘッド比率
  資金調達効率       = 資金調達コスト / 調達された資金
```

これらの公式のいずれも、達成された成果についての情報を一切含んでいない。慈善団体はこれらすべてを最小化しながら、それでもすべての受益者を失敗させることができる。お金が実際に機能したかどうかに実際に取り組む指標については[成果あたりコスト](../cost-per-outcome/)を参照。

## 計算例

同じ総支出を持つ二つの慈善団体。

- **慈善団体A**：総支出£1,000,000、管理費＋資金調達費£80,000 → オーバーヘッド比率8%。モニタリング・評価機能はなく、過労気味の会計担当者が一人おり、ケースマネジメントシステムもない。スタッフの離職率は高く、成果データは収集されていない。
- **慈善団体B**：総支出£1,000,000、管理費＋資金調達費£220,000 → オーバーヘッド比率22%。小規模な評価チーム、成果のフォローアップを捕捉するケースマネジメントシステム、適切な保護研修に資金を出している。

オーバーヘッド比率だけでスクリーニングする寄付者はAを選びBを却下する——[成果あたりコスト](../cost-per-outcome/)のエビデンスがおそらく示すであろうこととは正反対である。なぜなら、二つのうちBだけが、その実際の成果を実証あるいは改善する立場にあるからである。

## ソフトウェア開発との関連

このセクター向けの財務・助成金報告ソフトウェアは、しばしばオーバーヘッド/プログラムの区分を、すべてのコスト行の分類フィールドとしてハードコードする。なぜなら、それは規制当局や一部の資金提供者が法定報告で依然として要求しているものだからである。これらのシステムを構築するエンジニアは、その要件をコンプライアンス上の義務として扱うべきであり、オーバーヘッド比率がダッシュボードに目立つように表示する価値のある指標であるという設計上のシグナルとして扱うべきではない。それが表示される場所ではどこでも、成果ベースの指標とペアにし、閲覧者がオーバーヘッド比率を単独で読めないようにすること。その隣に置くべき指標については[寄付者投資収益率](../donor-return-on-investment/)を、単一比率の効率性代理指標に対する公共セクターにおける同等の反論については[バリュー・フォー・マネー](../value-for-money/)を参照。

## 落とし穴

- **オーバーヘッド比率をスクリーニングの足切り基準として使うこと。** 恣意的な閾値（例えば「オーバーヘッド15%以下」）を上回る慈善団体を却下することは、適切に資源を配分され、よく評価された組織を体系的に罰し、過少投資に報いる。
- **直接提供コストをオーバーヘッドとして誤分類すること**、あるいはその逆——何が「プログラム」対「管理」としてカウントされるかについての会計慣行は、慈善団体間で十分に異なるため、比率はしばしば額面通りに比較可能でさえない。
- **低いオーバーヘッドが高いインパクトを意味すると仮定すること。** この二つは、よく言っても無相関である——2013年のOverhead Mythの書簡の中核的な主張を参照。
- **一部の正当な戦略が短期的により高いオーバーヘッドを必要とすることを無視すること。** 能力構築あるいは組織開発の段階は、その後の提供を改善するために意図的に管理費支出を引き上げる。
