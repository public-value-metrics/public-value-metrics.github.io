# 分配的加重

分配的加重は、コストや便益の金銭的価値を、それを誰が受け取るかに応じて調整するものであり、追加の1ポンドは富裕な世帯よりも貧しい世帯にとって価値が高いという原則に基づいている。HM TreasuryのGreen Bookは、所得の限界効用逓減に基づいて、この加重を適用するための明示的な方法を提供しており、これにより評価は、最も裕福な十分位が得る1ポンドを、最も貧しい層が得る1ポンドと暗黙のうちに同等に扱うことがないようにしている。

## 重要な理由

標準的な費用便益分析は、それが誰のポンドであるかを問わずにポンドを合計する。これは、1ポンドが誰にとっても同じ価値であると暗黙のうちに仮定していることになる——経済学者が以前から誤りであると知っている仮定である。年収15,000£の世帯は、年収150,000£の世帯とはまったく異なる形で1,000£の増加を経験する。なぜなら、所得の限界効用は所得が上がるにつれて低下するからである。加重されないままでは、標準的な評価は、より豊かで既に恵まれた層に便益をもたらす介入策を体系的に優遇する。なぜなら、その層のより高い購買力が、彼らに届く便益の金銭的評価を膨らませるからである（高価な住宅地の近くの公園改修は、単に価格が高いというだけで、同じ改修が安価な住宅地の近くで行われる場合よりも大きな不動産価値の便益を「示す」が、それは福祉の向上が大きいからではない）。

Green Bookの分配分析に関する補足指針は、評価の方法論がロンドンと南東部を体系的に優遇しているという批判を受けた2020年のTreasuryのレビュー後に強化されたが、所得の限界効用の弾力性を約1.3と仮定した正式な加重アプローチを定めている——これは、所得が倍になると、追加の1ポンドの限界価値がおおよそ半分になる（正確には2^-1.3≈0.41倍になる）ことを意味する。これは単なる丸め調整ではない。これを適用することで、特に恵まれない地域に集中した介入策と一般人口全体に分散した介入策を比較する場合、二つの競合するプログラムのうちどちらがより高い純現在価値を示すかが変わることがある。

## 計算式

平均所得ȳの世帯の1ポンドに対する、所得水準yの世帯に発生する1ポンドの便益についてのGreen Bookの分配的加重：

```
加重(y) = (ȳ / y)^e

ここで：
  y  = 世帯所得（あるいは影響を受けるグループの所得）
  ȳ  = 平均（基準）世帯所得
  e  = 所得の限界効用の弾力性（Green Book：約1.3）
```

純便益への加重の適用：

```
加重された便益 = Σ [グループiへの非加重便益 × 加重(y_i)]
```

全国平均の半分の所得のグループ（y=0.5ȳ）は、(1/0.5)^1.3=2^1.3≈2.46の加重を受ける——そのグループへの1ポンドの便益は、平均所得世帯への1ポンドのおよそ2.46倍の価値としてカウントされる。

## 計算例

**同じ地域成長基金を競合する二つの地方プログラム**、それぞれ非加重の年間純便益が200万£：

- *プログラムA*：裕福な町における企業支援制度、平均世帯所得£45,000（想定される全国平均£35,000の約1.3倍）。
- *プログラムB*：恵まれない地区におけるスキルプログラム、平均世帯所得£18,000（全国平均の約0.51倍）。

```
加重(A) = (35,000 / 45,000)^1.3 = (0.778)^1.3 ≈ 0.72
加重(B) = (35,000 / 18,000)^1.3 = (1.944)^1.3 ≈ 2.53

加重された便益A = £2,000,000 × 0.72 = 144万£
加重された便益B = £2,000,000 × 2.53 = 506万£
```

非加重では、二つのプログラムは同点である。分配的影響で加重すると、プログラムBの便益は3倍以上大きくなる——これは資金配分の推奨を逆転させる結果であり、非加重の費用便益比だけでなく加重を示すことを求めるGreen Bookの明確な目的を反映している。

**慈善団体への助成金配分**：50万£の助成金で1,000の低所得世帯に届く場合（加重≈2.0、加重価値100万£相当）と、同じ50万£で1,000の中所得世帯に届く場合（加重≈1.0、加重価値50万£相当）を比較する資金提供者は、その分配的なケースを理事会向け文書で明示的に示すべきであり、推測に任せるべきではない。

## ソフトウェア開発との関連

分配的加重がソフトウェア提供指標に直接現れることはめったにないが、技術チームやデータチームがどのように測定とターゲティングを設計するかを形づくるべきである。

- 影響力ダッシュボードや給付計算ツールを構築する際は、単なる集計された便益の合計だけでなく、影響を受ける人々の所得や貧困プロファイルを開示すること——分配の内訳のない集計値は、上記で示したような逆転を正確に隠してしまう。
- サービス設計におけるターゲティングロジックを、Green Bookが使用しているのと同じ貧困データに結びつけること——[複合貧困指標](../複合剥奪指数/)を参照——これにより、デジタルサービスの到達範囲を、単なる効率性だけでなく公平性（[物有所値](../物有所値/)における争点の第四のE）についても評価できるようにする。
- アルゴリズムが希少な資源（予約枠、担当者の時間、補助金）を配分する場合、非加重の「総便益を最大化する」目的関数は、その構造上、Green Bookの加重が是正しようとしているのと同じ偏りを再生産する——最適化の前に、これを政策所有者に明示的に指摘すること。

## 落とし穴

- **ポートフォリオ全体で分配的加重を一貫性なく適用すること。** あるプログラムの便益には加重を適用し、その比較対象には適用しないと、より公平ではなく偏った比較になる。Green Bookは同等の扱いを要求している。
- **不動産や市場価値を調整なしに福祉の代理指標として使うこと。** 市場価格自体が既存の所得不平等によって歪められている——これはまさに分配的加重が是正しようとしているものである。調整されていない市場価値を使うと、この偏りを二重に数えてしまう可能性がある。
- **グループ内のばらつきを無視すること。** 地域平均所得（例えば複合貧困指標の十分位）による加重は、その地域の平均と一致しない個人を誤って表すことがある。合理的に入手可能な最も細かい所得データを使用すること。
- **1.3という弾力性を普遍的な定数として扱うこと。** Green Book自体が、これは妥当な範囲を持つ推定値であると指摘している。主要な意思決定は、1.3を正確なものとして扱うのではなく、代替の弾力性に対して感度分析を行うこと。
