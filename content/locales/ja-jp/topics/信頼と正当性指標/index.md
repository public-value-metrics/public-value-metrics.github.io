# 信頼と正当性指標

正当性と支持は、マーク・ムーアの『Creating Public Value』（1995年）における「戦略的三角形」の三つの辺の一つである——公共価値そのものと運用能力と並ぶものである——そしてこれは最もよく測定されずに残される辺である。なぜなら、予算やアウトプット数とは異なり、正当性には明白な単一の数字がついていないからである。信頼と正当性指標は、政府がそのギャップを埋めるために使う代理指標のファミリーである——制度信頼調査、監督機関の信頼度評価、苦情と不服申立てのデータ、政治的/立法的な支持指標である。

## 重要な理由

ムーアの主張は、真の価値を提供しながら政治的・公的な正当性を失う公共マネージャーは、最終的に、それを提供し続けるために必要な承認環境を失うというものである——資金は削減され、権限は狭められ、そのサービスの成果がどれほど優れていても、そのサービスは飢えさせられる。したがって正当性は、提供のスコアカードに付け加えられた広報上の後付けではなく、そもそも使命が継続できるかどうかを支える基盤的な入力値である——だからこそ、それは[公共価値スコアカード](../公共価値スコアカード/)において脚注ではなく同等の視点として位置づけられる。OECDの「Trust in Government」調査プログラムは、これを定量化する主要な国際横断的試みである——それは、OECD加盟国全体で自国の政府に信頼を持つと答える市民の割合を追跡しており、その長期データは、信頼が衝撃に対して非常に敏感であることを示している——2008年の金融危機とCOVID-19パンデミックの両方が、国レベルで急激な変動を生み、しばしば部分的な回復しか続かなかった。OECDの分析は一貫して、知覚された*能力*（政府が言うことを実行するか）と知覚された*公正さ・誠実さ*（政府が汚職や依怙贔屓なしに行動していると見なされているか）が、単一の取引に対する満足度とは別に、信頼の数字の二つの最も強い原動力であることを発見している。政府はまた、より細かいレベルでも正当性を運用可能にしようとますます試みている——英国の独立した規制機関や監督機関（National Audit Office、Parliamentary and Health Service Ombudsman、OfstedやCare Quality Commissionのようなセクター規制機関）は、制度化された正当性チェックとして機能し、「一般市民はまだこのサービスを信頼しているか」を監査可能な評価へと変換している。

## 計算式

信頼と正当性は枠組み形式の主題であり、その使用可能な定量的代理指標は以下の通りである。

```
制度信頼指標（OECD方式）
  = 信頼に関する質問に「はい」と答えた調査回答者の割合、時系列で
    追跡され、人口統計グループで細分化される

正当性代理指標セット（その構成概念を単一の数字で代替できるものはない）：
  - サービス利用者1,000人あたりの支持された苦情数
    （オンブズマンあるいは内部苦情データ）
  - その機関の決定に対する司法審査/不服申立ての成功率
  - 独立した規制当局/監督機関による評価（例えば「卓越」から
    「不十分」までの区分）
  - 立法/監督委員会の信任投票あるいは批判的報告書の頻度
  - 情報公開請求の件数と開示/拒否率、知覚された透明性の代理指標として

正当性は計算されるのではなく裏付けられるものである——擁護可能な
正当性評価は、単一の代理指標に頼るのではなく、上記のいくつかを
三角測量する。
```

## 計算例

**国税当局**：年次公共価値報告書のための正当性の三角測量。

```
OECD方式の信頼代理指標（省庁固有の信頼調査）：
  回答者の58%が、当局が「自分を公正に扱う」と信頼していると
  回答（2年前の64%から低下）

苦情データ：
  支持された苦情：納税者との対応1,000件あたり4.2件
  （1,000件あたり3.1件から上昇）

オンブズマンへの照会：
  独立したAdjudicator's Officeへの照会：年間1,850件、うち61%が
  当局に対して全部あるいは一部支持された（前年の48%から上昇）

三つすべてを横断的に読む：信頼は低下し、支持された苦情は増加し、
独立したオンブズマンの判断はますます当局に不利になっている——
三つの独立したシグナルが同じ方向に収束しており、これがまさに、
この発見を単一の系列における雑音ではなく信頼できる正当性の
発見にしている。
```

これらのうち単一のものが動くことは弱いエビデンスであろう——三つの独立した測定値が同じ期間にわたって共に動くことが、正当性の主張を擁護可能にするパターンである。

## ソフトウェア開発との関連

正当性指標は、単一のチームのダッシュボードから生み出されることはめったにない——これ自体が設計上の教訓である。正当性報告を社内限定の指標として設計するのではなく、独立した外部ソース（オンブズマンの案件システム、規制当局の評価フィード、調査ベンダー）からデータを取り込み照合できる報告パイプラインを構築すること。なぜなら、内部で得られた正当性の主張（「私たちは自分自身を信頼できると評価します」）はほとんど証拠力を持たないからである——これは、[公共価値スコアカード](../公共価値スコアカード/)の正当性の視点について指摘されているのと同じ独立性の問題である。苦情・不服申立てデータのパイプラインは、[成果連動型支払い](../成果連動型支払いと社会的インパクト債/)契約に供給される成果パイプラインと同じデータ品質の厳密さに値する。なぜなら、過少報告あるいは不適切に分類された苦情データセットは、1年後に信頼調査で目に見える形になる前に、正当性の問題を静かに過小評価するからである。このサービスレベルの指標に対する取引レベルの対応物については[市民満足度指標](../市民満足度指標/)を、この辺が属する戦略的三角形の完全な枠組みについては[公共価値](../公共価値/)を参照。

## 落とし穴

- **満足度を正当性の代理として扱うこと。** 市民は、単一の取引のインターフェースに満足しながら、制度全体を信頼しないことがある（あるいはその逆）——なぜこの二つが別々に報告されなければならないかについては[市民満足度指標](../市民満足度指標/)を参照。
- **単一の自己申告指標に頼ること。** 独立した裏付け（オンブズマンデータ、規制当局の評価）を伴わない社内で実施された信頼調査は、自己採点として容易に退けられる。三角測量すること。
- **人口統計的な細分化を無視すること。** 集計された全国的な信頼数値は、特定のグループ（年齢、民族、所得、地域による）間で大きく異なる正当性を隠しうる——OECD自身のTrust in Governmentの発表は、まさにこの理由で細分化している。
- **単一の衝撃駆動の落ち込みを恒久的なトレンドとして読むこと。** 信頼数値は、危機（金融破綻、パンデミック、注目度の高いスキャンダル）の周辺で急激に動き、部分的に回復する。衝撃後の単一のデータポイントを、さらなるデータなしに長期的な下落へと外挿すべきではない。
