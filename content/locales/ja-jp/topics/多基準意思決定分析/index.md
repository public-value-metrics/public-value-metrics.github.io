# 多基準意思決定分析（MCDA）

MCDAは、いくつかの別個の重み付けされた基準に対して選択肢を同時に採点・評価し、すべての基準を単一の金銭あるいは自然単位のスケールに強制することなく、順位づけられた比較を生み出す。これは、重要な成果が本当に単一の数字に還元できない意思決定のための評価方法である。

## 重要な理由

グリーンブックは、[社会的費用便益分析](../社会的費用便益分析/)を通じてすべてを金銭に変換すること、あるいは[費用効果分析](../政府における費用効果分析/)を通じて一つの成果に変換することが、意思決定を明確化するのではなく歪めてしまうような、便益が「本当に通約不可能」な評価に対して、MCDAを明示的に認めている（グリーンブックのBox 2のケーススタディ付録と付属書Aの両方が直接扱っている）。例えば新しい刑務所の立地選定は、資本コストを地域社会への影響、交通の利便性、環境への影響、職員採用のしやすさと引き換える。これらの基準は共通の単位を共有しておらず、共通の単位（通常は金銭）を強制することは、例えば環境影響と費用の相対的な重要性についての価値判断を、客観的な算術を装って持ち込んでしまう。

MCDAの誠実さは、その最大の弱点でもある——重みは評価を実施する人（あるいは委員会）によって割り当てられるため、この方法は重み付けのプロセスと同程度にしか正当性を持たない。グリーンブックの指針は、選択肢が採点される*前に*基準と重みが合意され公表されなければならないことを明確にしている。まさに、審査員が好みの選択肢からそれを正当化する重みへと逆算することを防ぐためである。

## 計算式

```
各選択肢iと各基準jについて：
  得点_ij   = その基準に対するその選択肢のパフォーマンス
             （エビデンス、専門家の判断、あるいはステークホルダーの
             採点から、しばしば0〜100あるいは1〜10）
  重み_j    = 基準jの相対的重要性、重みの合計は1（あるいは100）

選択肢iの重み付き得点 = Σ_j (得点_ij × 重み_j)

手順：
1. いずれかの選択肢を採点する「前に」基準セットと重みを合意する
   （スウィング・ウェイティングやAHPのような対比較が一般的な
   引き出し方法である）。
2. 可能な限りエビデンスに基づいて、すべての選択肢をすべての基準に
   対して共通のスケールで採点する。
3. 重み付き合計を計算し、選択肢をランクづける。
4. 重みを感度検証する——それぞれの基準がどれだけ重要であるべきかに
   ついての妥当な意見の相違を、このランキングは乗り越えられるか？
```

MCDAは、SCBAの純現在価値のような擁護可能な絶対値を生み出さない——それは合意された重みに条件づけられたランキングのみを生み出す。これは、意思決定が本当に通約不可能な財のトレードオフに関するものである場合には利点であり、実際には金銭化が可能だった、より困難な作業を回避するために使われる場合には欠点である。

## 計算例

**地方自治体**：新しい家庭ごみリサイクルセンターの立地を選定する自治体が、現地視察の前に部門横断的な委員会によって重み付けされた四つの基準に対して三つの候補地を採点する。

```
基準（重み）：      資本コスト（30%）  交通アクセス（25%）
                    地域社会への影響（25%）  環境影響（20%）

候補地の得点（0〜100、高いほど良い）：
候補地A：コスト80、アクセス60、地域社会40、環境70
候補地B：コスト60、アクセス90、地域社会70、環境50
候補地C：コスト90、アクセス50、地域社会80、環境60

重み付き合計：
候補地A = 80(.30) + 60(.25) + 40(.25) + 70(.20) = 24+15+10+14 = 63
候補地B = 60(.30) + 90(.25) + 70(.25) + 50(.20) = 18+22.5+17.5+10 = 68
候補地C = 90(.30) + 50(.25) + 80(.25) + 60(.20) = 27+12.5+20+12 = 71.5
```

候補地Cが最高順位である。地域社会への影響の重みを25%から35%へ移す感度検証（資本コストから10ポイントを取る）は、候補地Cの合計を71.5−3+8=76.5に、候補地Bの合計を68−6+7=69に変える——候補地Cは依然として首位であり、したがってこのランキングは重み付けについてのその妥当な意見の相違に対して頑健である。これはまさに、グリーンブックが報告を期待するチェックである。

**慈善団体**：債務相談サービス、フードバンクのネットワーク、金融リテラシープログラムのいずれに資金を提供するかを選ぶ助成財団が、SROI（[社会的投資収益率](../社会的投資収益率/)を参照）ではなくMCDAを使うのは、まさに理事たちが、危機救済と予防のどちらをより重く見るべきかについて、誠実に意見が分かれているからである——MCDAは、単一のSROI比率がそれを解決すると装うのではなく、その意見の相違の*形*（重みの範囲）を合意させてくれる。

## ソフトウェア開発との関連

MCDAは、基準が本当に対立するときのベンダー選定やアーキテクチャ選定の自然なツールである——クラウドホスト型とオンプレミス型のケース管理システムの選択は、コスト、データ主権リスク、アクセシビリティ、提供速度を、一つの数字に還元できない形でトレードオフする。技術リーダーは、グリーンブックが要求する通り、選択肢が採点される前に重み付けが行われることを主張すべきである。なぜなら、候補リストを見た後に行われる重み付けの演習は、その場が既に好んでいた選択肢の方へと確実に流されてしまうからである。MCDAの一般的な応用例については[政府における自前開発か購入か](../政府における内製か購入か/)を、意思決定後（意思決定前ではなく）に使われる関連する構造化採点ツールについては[公共価値スコアカード](../公共価値スコアカード/)を参照。

## 落とし穴

- **選択肢を見た後に重みを設定すること。** これはMCDAが操作される最も一般的な方法である。意図的であるかどうかにかかわらず、採点の前に重みを公表し、誰がそれを設定したかを記録すること。
- **重み付き合計を確定した数字として扱うこと。** 71.5対68という得点は、感度分析がそのランキングが安定していることを確認しない限り、統計的に有意な差ではない。誤った精度ではなく、範囲を報告すること。
- **実際には実行可能だった金銭化を回避するためにMCDAを使うこと。** ほとんどの基準が信頼できる形で価格づけできたのであれば、[SCBA](../社会的費用便益分析/)の代わりにMCDAをデフォルトとすることは、評価が使えたはずの情報を捨ててしまう。
- **一人の支配的なステークホルダーに重みをすべて単独で設定させること。** グリーンブックの良い実践は、重みが委託した部長ではなく代表的な委員会から引き出されることを期待している。これにより、評価がその人が既に望んでいたものを単に再導出するだけになることを避ける。
