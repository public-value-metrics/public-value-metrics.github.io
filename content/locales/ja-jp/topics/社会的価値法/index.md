# 社会的価値法（Social Value Act）

Public Services (Social Value) Act 2012は、イングランドおよびウェールズの公的機関に対し、公共サービス契約の調達プロセスを開始する前に、調達しようとしているものが関連地域の経済的、社会的、環境的福祉をどのように向上させうるかを検討し、これについてコンサルテーションを行うことを検討するよう求める英国の法定義務である。これは2013年1月に、比較的軽度な「考慮する」義務として施行され、2021年1月のProcurement Policy Note（PPN）06/20によって大幅に強化された。同ノートは、中央政府の契約に対して、社会的価値を単に考慮するだけでなく、明示的に評価し、落札基準の中で最低限の重みづけを行うことを義務づけている。

## 重要な理由

PPN 06/20以前は、社会的価値を「考慮すること」は、委託者がそれについて考えたと記すことで満たすことができ、それが落札の決定に影響する必要はなかった——書面上は容易に果たせ、実務上は無視できる義務であった。PPN 06/20は中央政府の調達についてこのギャップを埋めた。それは、社会的価値が入札評価の一部として採点されることを義務づけ、五つの国家的優先テーマ——COVID-19からの回復、経済的不平等への対処、気候変動対策、機会の平等、福祉——を中心に組み立てられ、一般にSocial Value Portalが維持するNational TOMs（Themes, Outcomes, Measures）枠組みを用いて測定される。公共セクター向けの調達、契約管理、あるいは入札支援ツールを構築するソフトウェアエンジニアにとって、これは、あなたのクライアントが対応して構築することを法的に求められている根拠であり、任意の付加機能ではない。

## 計算式

社会的価値は枠組み形式の主題であり、その「計算式」はほとんどの機関が使用する採点構造である。

```
総入札スコア = 価格/コストの重み + 品質の重み + 社会的価値の重み

PPN 06/20（中央政府）：社会的価値の重み ≥ 総スコアの10%

社会的価値のテーマ（PPN 06/20）：
 1. COVID-19からの回復
 2. 経済的不平等への対処
 3. 気候変動対策
 4. 機会の平等
 5. 福祉
```

入札者は通常、[単位コストデータベース](../単位コストデータベース/)を使ってこれらのテーマに対する自らのコミットメントを金銭化する。[社会的投資収益率](../社会的投資収益率/)で使われるのと同じ金銭化のロジックが適用される——コミットメントは立証され、契約に帰属し、他の資金と二重にカウントされるべきではない。

## 計算例

**地方自治体のIT契約**：300万年の3年間契約が、品質60%、価格30%、社会的価値10%で採点される。入札者Aは、2件の見習い制度、£150,000の地元下請け支出、地元校向けの200時間のプロボノデジタルスキル研修をコミットし、単位コストデータベースの代理指標を使って合計£90,000の追加的な社会的価値として金銭化される。入札者Bは、£40,000で金銭化されたより小規模なパッケージをコミットする。もし自治体が最も強い入札に対して比例的に社会的価値を採点するなら、入札者Aは満点の10ポイントを受け取り、入札者Bは10×(£40,000÷£90,000)=4.4ポイントを受け取る——5.6ポイントの差は、品質と価格が近接している場合でも契約を左右しうる。

**ボランタリーセクターの入札者**：商業的な競合相手と競う緑地管理契約に入札する小規模なVCSE（ボランタリー、コミュニティ、ソーシャルエンタープライズ）は、単価だけでは競争できないが、Global Value Exchangeの代理指標を使って、既存のコミュニティ雇用とボランティアのコミットメントを金銭化し、価格・品質と並んで採点される、立証された社会的価値のケースを作る。

## ソフトウェア開発との関連

金銭化された社会的価値のコミットメントを伴う入札を落札することは、契約管理を通じてそれに対する提供を立証する義務を生み出す——見習いの開始、地元での支出、研修時間を、契約が署名された後に忘れられるのではなく、契約レビュー会議にフィードバックされる形で、入札時に採点された具体的なコミットメントに対して記録するツールが必要である。G-CloudとDigital Marketplaceの出品は、出品時点で社会的価値の声明をますます要求するようになっている。コミットメントの背後にある評価方法については[社会的投資収益率](../社会的投資収益率/)を、入札者が利用する代理指標については[単位コストデータベース](../単位コストデータベース/)を、そして提供されたコミットメントが単なる活動数ではなく成果であることを確認することについては[成果とアウトプット](../成果とアウトプット/)を参照。

## 落とし穴

- **ソーシャルウォッシュの入札。** 「私たちは地域社会を支援する」といった、測定できず契約管理の中で問いただすこともできない曖昧なコミットメントは、良い採点を得るが、検証可能なものを何も提供しない。
- **社会的価値をタイブレーカーとして扱うこと。** PPN 06/20は、社会的価値が落札基準の中で明示的に評価されることを要求しており、それ以外は同等の入札間のタイブレークとして非公式に使われるべきではない。
- **契約管理でのフォローアップがないこと。** 入札で採点されたコミットメントは、提供期間中に追跡されないことが多い——[便益実現](../便益実現/)を参照。
- **契約ごとに一貫性のない測定枠組み。** 異なる契約で類似のコミットメントに異なる代理指標のソースを使うことは、ポートフォリオレベルでの比較を意味のないものにする——だからこそNational TOMsや共有の単位コストデータベースのような共通の枠組みが存在する。
