# 置换与归因（Displacement and Attribution）

置换（displacement）是指一个项目表面上的效益，是通过从别处夺走活动或效益、而不是创造出新事物而实现的——你的胜利是别人的损失。归因（attribution）是一个相关的问题：当其他行动者和因素也做出了贡献时，一项被观察到的成果中，究竟有多少可以真正归功于你的干预。这两者都是英国公共部门评估指南中的标准调整项，与无谓损失和泄漏并列，但两者也都经常被那些看起来远比实际情况强劲的影响力声明所忽略。

## 为何重要

某地方政府的企业拨款计划，帮助 50 家商铺迁入一个再生区，可以报告"支持了 50 家企业，创造了 200 个就业岗位"——但如果这些企业只是从邻近的商业街搬过来，而不是真正扩张，那么这些岗位就是被置换的，而非新创造的，全区（或全地区）层面的净效应可能接近于零。英国财政部《洋红皮书》以及历史悠久的《增益性指南》都将置换视为一项必须扣除的调整项，正是因为即便没有产生任何全国或区域层面的净效益，地方性的成功故事也屡见不鲜——价值只是发生了转移，往往还对失去它的地区或行动者不利。结构性基金评估指南（用于原欧盟区域发展基金项目及其国内后继项目，例如英国共同繁荣基金）将这一问题正式确立在三个空间尺度上：地方性置换（城镇内部）、区域性置换（地区内部）和全国性置换（英国范围内），因为一项干预措施可能在一个尺度上是增益性的，而在更大的尺度上却纯粹是置换——一个从邻镇吸引工人的就业项目，在全国层面是中性的，即便它在地方层面看起来是一项成功。

归因是伙伴关系密集型交付中的姐妹问题，而这如今已是社会部门和跨机构公共服务工作的常态。当三家机构联合交付一项无家可归预防服务时，每一家机构的年度报告都可能各自独立地宣称对同一项露宿人数下降的成果拥有功劳——将各报告的数字相加，所宣称的影响力可能超过观察到的实际变化，有时会超出好几倍。《洋红皮书》关于贡献分析（contribution analysis）的指南之所以存在，正是因为在多机构交付中，将结果随机归因于单一行动者往往是不可能的，而诚实的答案往往是"我们为这一成果做出了贡献"，而不是"这一成果是我们造成的"。

## 数学原理

置换作为标准净影响序列的一部分（完整链条参见[增益性与无谓损失](../additionality-and-deadweight/)）：

```
净增益影响 = 总产出 − 无谓损失 − 置换 − 泄漏，× 乘数

置换率 = 从别处转移而来的效益/活动
        / 观察到的总体效益/活动
```

当多个行动者共同为同一成果做出贡献时，归因通常以贡献份额而非精确百分比来表示，因为它通常无法以与置换相同的严谨程度来测量：

```
可归因份额 ≈ f(因果贡献的强度、其他行动者的贡献、
              外部/情境因素)

所宣称的影响力永远不应超过：
  Σ (各合作方的可归因份额) ≤ 观察到的总成果的 100%
```

## 实例演算

**再生拨款**：某议会的商业街拨款计划报告称，在受资助区域内创造了 200 个新零售岗位。后续跟踪调查研究发现，其中 60 个岗位来自同一自治市内一条未受资助的邻近商业街上企业的迁入，另有 30 个岗位来自全国连锁企业开设的分店，而这些分店无论有无该项拨款，本来都会在该地区某处开设。

```
宣称的总体岗位数 = 200
地方性置换 = 60（在自治市内部迁移）
区域性置换 = 30（本来就会在区域内开设）

净增益岗位数（自治市层面） = 200 − 60 = 140
净增益岗位数（区域层面） = 200 − 60 − 30 = 110
```

诚实的头条数字取决于资助方所关心的地理尺度——一份在全国或区域层面评估的财政部商业论证应当使用 110，而不是自治市层面的 140，更不能使用原始的 200。

**多机构无家可归服务**：三家合作机构（一家议会、一家住房慈善机构、一家医疗信托机构）联合交付一项减少露宿人数的服务。该地区当年露宿人数下降了 30 人。每家机构各自的年度报告都宣称"我们减少了 30 人的露宿"——三份报告相加，共宣称帮助了 90 人，是实际降幅的三倍。一项贡献分析，根据已记录的角色和独立评估为各合作方分配份额（例如议会 40%、慈善机构 35%、医疗信托机构 25%），将分别报告 12 人、10.5 人和 7.5 人，正确地加总为观察到的 30 人。

## 与软件工程的关联

置换与归因决定了多站点或多合作方交付的影响力跟踪和成果报告系统应当如何设计：

- 地理和组织范围应当是任何影响力仪表盘中明确的一等字段——"针对自治市"报告的数字与"针对区域"报告的同一数字是不同的数字，一个将两者混为一谈的系统会产出在项目组合层面无法调和的数字。
- 当多个合作方联合交付时，成果系统应当记录贡献份额（或至少标注联合归因），而不是让每个合作方的报告模块各自独立地对同一共享成果宣称 100% 的功劳——否则项目组合层面的汇总将高估总体影响力，有时会严重高估。
- 这与[社会投资回报](../social-return-on-investment/)和[拨款成果报告](../grant-outcomes-reporting/)相关：一项忽视置换或对共享成果过度归因的 SROI 或 IRIS+ 计算，会产出一个经不起审计或复现的虚高比率。

## 常见陷阱

- **报告地方性成功却不核查更广泛的置换。** 一个项目在最小的报告尺度上可能看起来非常成功，而在更大的尺度上却是中性甚至负面的；应当始终明确说明净值数字所适用的地理尺度。
- **让联合交付中的每个合作方都宣称全部功劳。** 除非贡献份额已经商定并记录在案，否则跨合作方的汇总报告会高估总体影响力——应核实各合作方层面的声明相加不超过观察到的总数。
- **将归因当作一个精确百分比，而它实际上是一种判断。** 与随机化的反事实情形不同，贡献分析产出的是一个可辩护的估计值，而非一个已测量的事实；应以恰当的不确定性来呈现它，而不是假装精确。
- **忽视面向市场的干预措施中的置换问题。** 企业支持、就业计划和以地方为基础的再生项目是典型的高置换类别；对这些项目，置换检查应当是强制性的，而非可选的。
