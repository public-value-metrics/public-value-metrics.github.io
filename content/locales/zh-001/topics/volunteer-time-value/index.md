# 志愿者时间价值（Volunteer Time Value）

志愿者时间价值，是赋予无偿劳动的货币化估计，最常用于陈述一家慈善机构真实的经济足迹——其账目加上其本无需支付的劳动——或用于论证某项特定干预措施比其现金预算单独所暗示的更具成本效益。有两套全国性方法论占据主导地位：美国的 Independent Sector 估算法和英国国家统计局/NCVO 方法，二者对同一小时劳动的定价相当不同。

## 为何重要

Independent Sector 每年与马里兰大学 Do Good Institute 合作，基于劳工统计局的工资数据——具体而言是私营非农业薪资单上生产和非监督人员的平均时薪，加上一项附加福利调整——发布全国性的志愿者时间小时价值，并按美国各州细分。其最新一版数据将该价值定为**2025 年每小时 36.14 美元**，较上一年上升 3.9%，各州数值从华盛顿特区的超过 50 美元到波多黎各的不足 20 美元不等。在英国，国家统计局单独估算了正式志愿服务的替代成本为**每小时 14.43 英镑**（2017 年估算），NCVO 的《英国公民社会年鉴 2024》则使用志愿服务参与数据——2021-22 年间约有 1,420 万人正式参与志愿服务——估算该部门志愿服务的总贡献约为**180 亿英镑**，约占英国 GDP 的 0.8%。

这一点之所以重要，而不仅仅是会计上的表面文章：一个高度依赖志愿者劳动的项目，在纯现金的[单位成果成本](../cost-per-outcome/)基础上，可能看起来比一个依赖带薪员工的项目便宜得多，即便真实的资源成本——即替换这份劳动所需的花费——相近甚至更高。忽视志愿者时间价值的资助方和评估人员，会系统性地低估以志愿者为主的交付模式的真实成本，从而扭曲与实现同一成果的带薪员工模式之间的效率比较。

## 数学原理

```
志愿者时间价值 = 贡献的志愿工时 × 每小时费率

费率的选择会影响结果，而且很重要：
  - 替代成本法：由一名带薪员工完成同样任务所需的工资
    （例如一名合格青年工作者的替代成本费率，而非
    通用平均工资）——对具体任务估值最具说服力
  - 机会成本法：志愿者自身被放弃的工资——对衡量
    志愿者所付出的代价最具说服力
  - 全国平均法：Independent Sector 或 ONS 的单一
    混合费率——对头条数字、跨行业可比性最具说服力
```

对于同样的一小时，这三种方法可能相差数倍之多（一位以董事会受托人身份提供志愿服务的律师，其机会成本费率与全国平均费率截然不同），因此任何报告出的数字都需要说明是用哪种方法得出的。

## 实例演算

**英国慈善机构，全国平均法**：一年内 5,000 志愿工时，按每小时 14.43 英镑（ONS 替代成本估算）估值：

```
价值 = 5,000 × 14.43 英镑 = 72,150 英镑
```

如果该慈善机构当年的现金支出为 300,000 英镑，其真实资源成本——现金加志愿者劳动——为 372,150 英镑，比单纯的现金数字高出约 24%。仅使用 300,000 英镑现金数字计算的单位成果成本，会以同样的幅度低估真实成本。

**美国慈善机构，全国平均法**：2,000 志愿工时，按每小时 36.14 美元（Independent Sector，2025 年发布）估值：

```
价值 = 2,000 × 36.14 美元 = 72,280 美元
```

**同一家美国慈善机构，机会成本法**：如果志愿者中不成比例地包含收入曾平均达每小时 60 美元的退休专业人士，机会成本估值将为 120,000 美元——比全国平均数字高出三分之二，这说明了为何必须明确说明所用的方法。

## 与软件工程的关联

记录志愿工时的系统（排班工具、志愿者管理平台）应当在任务或角色层面捕获工时，而不仅仅是一个总数，从而使替代成本费率能够按角色分别应用，而不是对一支构成混杂的志愿者队伍统一套用一个全国平均费率（一名受托人的一小时与一名引导员的一小时，在经济学意义上并不等价）。将所用的费率和方法论与计算出的价值一并存储——而不仅仅是最终的货币数字——使下游报告（年度账目、[社会投资回报](../social-return-on-investment/)计算、资助方报告）日后能够复现或质疑这个数字，而不是将其当作一个不透明的常数来对待。关于省略志愿者时间价值为何会系统性地低估真实交付成本，参见[单位成果成本](../cost-per-outcome/)。

## 常见陷阱

- **对结构上不同的角色使用单一的统一费率。** 将全国平均工资费率应用于一小时专业无偿服务（法律、财务、临床），会严重低估其价值；只要任务具有专业技能性，就应将费率与被替代的角色相匹配。
- **与带薪员工成本重复计算。** 如果志愿者替代的是原本需要付费的工作，应确保该估值是现金支出之外的附加项，而不是叠加在一个已经被夸大的人员配置估算之上。
- **引用过时的费率却不注明日期。** Independent Sector 和 ONS 的费率每年都会变化（在 ONS 的情况下，只是定期重新估算）；报告中一个未标注日期的志愿者时间数字，对比较而言几乎毫无意义。
- **将志愿者时间价值当作筹款资产。** 它是一项用于理解真实资源成本的成本核算调整，而不是一笔慈善机构可以支配的新资金；将两者混为一谈会误导阅读账目的董事会成员。
