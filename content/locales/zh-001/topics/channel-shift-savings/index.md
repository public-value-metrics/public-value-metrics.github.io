# 渠道转移节约（Channel Shift Savings）

渠道转移节约，是指将交易量从昂贵渠道——电话、面对面柜台、纸质邮寄——转移到廉价数字自助服务所预计带来的成本降低。它是"数字优先"（digital by default）背后的财务引擎，同时也是商业论证中最容易出错的一项，因为它所依赖的假设——线下渠道会随着数字化采用率上升而萎缩——只是有时成立而已。

## 为何重要

用《数字效率报告》（Digital Efficiency Report）中的[单笔交易成本](../cost-per-transaction/)数字来算，这笔账看上去无可争辩：将一百万笔交易从每笔 8.62 英镑的面对面办理转移到每笔 0.15 英镑的数字渠道，节省超过 800 万英镑。但只有当萎缩渠道的*固定产能*真正被削减——呼叫中心的坐席、柜台工作人员、电话合同分钟数——节省才能真正转化为可重新调配的现金，而地方政府的数字化转型项目一再发现，总接触量并不会随着数字化采用率上升而按比例下降。来自地方政府数字化转型项目以及 Socitm 和地方政府协会（Local Government Association）等机构的研究记录了一种反复出现的模式：数字渠道会吸引真正的新增接触量（原本不会打电话或到访的公民，因为更方便而这样做了），而相当一部分"数字"交易会在办理过程中失败、进而仍然产生一通电话——因此电话量的下降幅度会远小于数字化采用率所暗示的比例，有时即便电话在总接触量中的*占比*下降，其绝对值也完全不降。

## 数学原理

```
渠道转移的总体节约 = 转移量 × (旧渠道成本 − 数字渠道成本)

净（已实现）节约 = 总体节约
                  − 由更便捷渠道所催生的新增/影子需求
                  − 失败需求成本（数字渠道办理失败后
                    仍然产生的电话或柜台到访）
                  − 未削减固定产能的成本（呼叫中心只能
                    以离散单位削减人员；交易量下降 15%
                    很少能让你裁减 15% 的人头）

节约兑现门槛：只有当交易量降到低于旧渠道下一个更小的
离散产能阶梯所需人力时（例如减少一整班次、一整个工位、
一个合同人头档位），节约才能真正兑现为现金
```

## 实例演算

**某郡议会蓝色徽章（残障停车证）续证服务**：每年 60,000 宗续证，此前 100% 通过电话/纸质方式办理，每笔交易成本 6.40 英镑。一项新的数字化服务上线，一年内数字化采用率达到 65%，每笔数字交易成本 0.30 英镑。

```
朴素（总体）节约计算：
  39,000 笔转移 × (6.40 − 0.30) 英镑 = 237,900 英镑/年

根据议会呼叫中心数据，实际发生的情况：
  电话量从每年 60,000 笔降至 46,000 笔（−23%，而非 −65%）
  原因：9,000 次数字化办理失败并产生了后续电话
        （失败需求泄漏）；另有 4,000 人此前根本不曾续证，
        因为发现线上办理很方便，现在开始续证了
        （影子需求——这是真实的可及性改善，但不是节约）

  电话呼叫中心按每 8,000 通电话/全职员工的阶梯配置人员；
  减少 14,000 通电话（60,000 → 46,000）可释放 1.75 名全职员工，
  实际向下取整为 1 名全职员工真正被重新调配 = 34,000 英镑/年

已实现节约 = 34,000 英镑/年，加上在 39,000 笔交易上避免的
  数字渠道建设/运行成本 ≈ 34,000 英镑 +（39,000 × 0.30 英镑的
  数字成本，已计入）——只是 237,900 英镑头条数字的一小部分，
  尽管这项服务对用户而言无疑仍然更好了。
```

## 与软件工程的关联

工程层面的教训是：渠道转移节约是由*运营*决策（排班、产能削减、合同重新谈判）而非软件上线本身实现的——一个团队可以满足[数字服务标准](../digital-service-standard/)的每一条要求，却仍然可能实现零净节约，只要没有人真正削减旧渠道的固定产能。为失败需求建立仪表化能力（用户在数字化旅程的哪个环节放弃、之后又做了什么）是一个可以解决的漏斗分析问题，也是工程团队能够采取的、对保护节约论证杠杆效应最大的举措；这也与[单笔交易成本](../cost-per-transaction/)直接相关——失败需求会在不知不觉中推高这一数字。关于检验商业论证中的节约是否真正落地这一更广泛的纪律，参见[效益实现](../benefits-realization/)；关于为何线下渠道通常无法、也不应完全退出，参见[数字包容](../digital-inclusion/)。

## 常见陷阱

- **假定渠道之间是一对一替代关系**：将数字化采用率直接从电话/柜台交易量中扣减，忽视了地方政府渠道转移研究中记录的影子需求和失败需求泄漏。
- **在产能削减之前就计入总体节约**：在采用率上升的那一年就将节约计入商业论证，而不是（如果确实发生的话）旧渠道产能真正被削减的那一年。
- **忽视人力成本的阶梯函数特性**：交易量下降 20% 很少能转化为成本下降 20%，因为呼叫中心和柜台是按离散档位配置人员的，而非连续调整。
- **将影子需求视为浪费**：来自此前被排斥或被劝退用户的新增接触量，是[公共价值](../public-value/)的真实增长，而不是建模误差——应当将其作为可及性成果来报告，而不是作为噪音被抵消掉。
