# 影子定价（Shadow Pricing）

影子价格，是为一件没有可观察市场价格、或市场价格被扭曲而无法反映其真实社会价值的商品、资源或外部性所赋予的估计价值。政府评估依赖于一小套官方影子价格——碳、非工作时间、失业劳动力——由中央统一发布，使每个部门使用同一个数字。

## 为何重要

影子价格之所以存在，是因为[社会成本效益分析](../social-cost-benefit-analysis/)如果没有为每一项成本和效益赋予一个货币价值就无法运作，而其中一些影响最为深远的项目——排放一吨碳、通勤者的一小时时间、一小时原本处于失业状态的劳动力——根本没有市场价格，或其市场价格无法真实反映其社会成本。财政部与能源安全与净零排放部联合发布了用于英国政府所有评估的碳影子价格（<https://www.gov.uk/government/publications/valuing-greenhouse-gas-emissions-in-policy-appraisal>），它并非源自任何碳市场价格，而是源自一种与目标一致的方法：碳价值被设定为实现英国法定碳预算所需的边际减排成本，这与观察碳在欧盟或英国排放交易体系中的实际交易价格，在逻辑上是根本不同的。

影子工资率在劳动力方面遵循类似的逻辑。雇用一个原本会失业的人，并不会让社会付出其全部工资的代价——这笔工资的一部分，是从被放弃的福利支付和损失的闲暇/求职时间中转移而来的，而不是对社会资源的净新增占用——因此《绿皮书》指南为从失业状态中抽取的劳动力设定了一个低于市场工资的影子价格，反映的是这份劳动力的真实机会成本（参见[公共支出中的机会成本](../opportunity-cost-in-public-spending/)），而不是其市场价格。

## 数学原理

```
碳影子价格（示例性结构，当前数值来自能源安全与净零排放部/
商业、能源和产业战略部官方碳价值工具——切勿使用过时数字）：
  可交易部门价值：参考排放交易体系配额价格走势设定
  不可交易部门（与目标一致）价值：设定为实现法定碳预算
    所需的边际减排成本，随时间推移而上升，因为较容易的
    减排选项会逐渐被用尽
  应用方式为：每吨二氧化碳当量的英镑价格 × 该方案排放或
    减少的吨数，未来年份按社会折现率折现

影子工资率（SWR）：
  SWR = 市场工资 − （节省下来的被放弃闲暇/求职时间的价值
                     + 不再需要支付的福利金价值）
  通常表示为市场工资的一个分数（例如，根据《绿皮书》附录 A
    关于存在闲置产能的劳动力市场的指南，在高失业率地区
    SWR = 市场工资 × 0.6）
```

这两个数字都是中央统一设定的政策惯例，而不是实证市场观察值——影子价格的全部意义就在于替代一个缺失或被扭曲的市场，因此使用它的评估必须引用当前的官方数据来源，而不是自行推导数字，这正是为了确保每个部门的评估都具有可比性。

## 实例演算

**中央政府**：某防洪方案评估估计，与"最低限度行动"基线相比，在 30 年评估周期内，每年可避免 400 吨二氧化碳当量的排放（通过减少应急设备使用和减少因避免重建而产生的隐含碳排放）。

```
示例性碳影子价格：每吨二氧化碳当量 280 英镑（第 1 年，
  按官方不可交易碳价值时间表，在评估周期内上升）
第 1 年碳效益 = 400 × 280 英镑 = 112,000 英镑
```

由于官方时间表规定碳价值在评估周期内会*上升*（反映日益收紧的碳预算），分析人员必须在 30 年周期的每一年都应用该年份对应的正确数值，而不是使用一个平坦的固定利率——若全程使用第 1 年的数值，将低估后期年份的效益，并扭曲与具有不同碳排放特征的其他防洪设计方案之间的排名比较。

**地方政府**：某议会针对长期失业居民的就业支持项目，帮助 150 人找到了时薪 11 英镑的工作。若使用全额市场工资对此进行估值，会将 11 英镑 × 工作小时数计为该项目的社会效益，但影子工资率方法认识到，这些人并非从其他工作岗位中被抽调而来——他们在参加该项目之前，其劳动力的真实机会成本很低。

```
市场工资：11.00 英镑/小时
影子工资率（示例性，当地高失业率情况下）：市场工资 × 0.6 = 6.60 英镑/小时
每工作小时可归因的净社会效益 ≈ 11.00 − 6.60 = 4.40 英镑/小时
  （将真正闲置的劳动力投入生产所创造的"额外"价值，
   区别于工资本身——工资在很大程度上只是一种转移支付）
```

这正是为什么在高失业率地区，就业项目的评估可能显示出正的净社会价值，而同样的项目若在充分就业地区运行——那里被替换的劳动力只会从其他工作岗位中被抽调过来——却不会显示出正的净社会价值。

## 与软件工程的关联

影子定价很少直接触及软件交付本身，但每当一份商业论证声称一项 IT 变更带来了碳或社会效益时，它就变得重要——一次数据中心整合声称节省了碳排放，或一项无纸化服务声称避免了印刷和邮寄的碳排放，都必须使用当前的官方碳影子价格，而不是自行编造一个数字，并且必须应用正确的逐年时间表，而不是一个固定利率，这与任何其他《绿皮书》评估输入项的要求完全一致。参见[政府 IT 中的总拥有成本](../total-cost-of-ownership-in-government-it/)和[公共部门网络安全价值](../public-sector-cybersecurity-value/)，两者除了直接计价的项目之外，往往也需要为一个难以货币化的输入项（泄露风险、停机时间）确定一个影子价格。

## 常见陷阱

- **使用过时的碳价值或工资数字。** 这两个数值都会由中央指南定期修订；一份建立在已被取代数字之上的评估，无法经受住财政部的审查。
- **在跨越数十年的评估中应用一个固定的碳影子价格。** 官方时间表规定该价值会随时间上升；全程使用第 1 年的数值会错误地陈述效益或成本的走势。
- **将影子工资率与劳动者实际薪酬的折扣相混淆。** 影子工资率调整的是*评估*对劳动力投入的估值，而不是劳动者实际获得的薪酬——将两者混为一谈，会（错误地）为低于市场水平的薪酬提供辩护。
- **推导一个定制的影子价格，而不是使用官方数字。** 影子价格之所以是一种政策惯例，正是为了使各部门的评估具有可比性；一个本地自行编造的数字，无论论证多么充分，都会破坏这种可比性。
