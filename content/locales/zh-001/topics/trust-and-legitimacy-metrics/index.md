# 信任与正当性指标（Trust and Legitimacy Metrics）

正当性与支持，是 Mark Moore 在《创造公共价值》（1995）中提出的"战略三角"三条边之一——与公共价值本身和操作能力并列——也是最经常未被测量的一条边，因为与预算或产出计数不同，正当性没有一个显而易见的单一数字与之对应。信任与正当性指标，是各国政府用来填补这一空白的一系列代理衡量指标：机构信任调查、监督机构信心评级、投诉与上诉数据，以及政治/立法支持指标。

## 为何重要

Moore 的论点是：一位交付了真实价值、却失去了政治和公众正当性的公共管理者，最终会失去维持这种交付所需的授权环境——资金被削减，授权被收窄，无论其成果多么优秀，该服务都会被断粮。因此，正当性不是附加在交付计分卡上的公关事后考量；它是决定该使命能否继续存在的承重输入，这正是它在[公共价值计分卡](../public-value-scorecard/)中作为一个同等重要的视角、而非一条脚注的原因所在。OECD 的"政府信任"调查项目，是量化这一点最领先的跨国尝试：它跟踪 OECD 各成员国中表示信任本国政府的公民占比，其长期数据显示，信任对冲击高度敏感——2008 年金融危机和新冠疫情都造成了剧烈的国家层面波动，且往往只出现部分回升，OECD 的分析一贯发现，感知到的*能力*（政府是否兑现其承诺）和感知到的*公平性/廉洁性*（政府是否被认为不偏不倚、不徇私舞弊）是信任数字最强的两个驱动因素，与对任何单笔交易的满意度截然不同。各国政府也日益尝试在更细粒度的层面将正当性付诸实践——英国的独立监管机构和督察机构（国家审计署、议会与卫生服务申诉专员、Ofsted 和护理质量委员会等行业监管机构）发挥着制度化正当性检验的作用，将"公众是否依然信任这项服务"转化为可审计的评级。

## 数学原理

信任与正当性是一个框架性的话题，其可用的定量代理指标包括：

```
机构信任指数（OECD 式）
  = 在一项政府信心问题上回答"是"的受访者百分比，
    随时间跟踪，按人口统计学群体分类

正当性代理指标集（没有单一数字能替代这一构念）：
  - 每 1,000 名服务使用者中获支持的投诉数（申诉专员
    或内部投诉数据）
  - 针对该机构决定的司法复核/上诉成功率
  - 独立监管机构/督察机构评级（例如从"卓越"到"不合格"的分级）
  - 立法/监督委员会的信任投票或批评性报告的频率
  - 信息公开请求量及披露/拒绝率，作为感知透明度的代理指标

正当性是通过相互印证得出的，而非计算出来的：一份站得住脚
的正当性评估，会综合以上若干项进行三角验证，而不是依赖
任何单一的代理指标。
```

## 实例演算

**国家税务机关**：为一份年度公共价值报告进行正当性三角验证。

```
OECD 式信任代理指标（部门专属信心调查）：
  58% 的受访者表示信任该机构"公平对待我"
  （两年前为 64%，有所下降）

投诉数据：
  获支持的投诉：每 1,000 次纳税人互动 4.2 起
  （较此前的每 1,000 次 3.1 起有所上升）

申诉专员转介：
  当年向独立裁决办公室（Adjudicator's Office）的转介
  共 1,850 起，其中 61% 全部或部分支持申诉人、反对该机构
  （较上一年的 48% 有所上升）

综合来看这三项：信任度在下降，获支持的投诉在上升，独立
申诉专员的裁决也日益不利于该机构——三个独立信号朝着同一
方向趋同，这正是使这成为一项可信的正当性发现、而非任何
单一数据系列中的噪音的原因所在。
```

这三项数字中任何一项单独变动都是薄弱的证据；而三项独立指标在同一时期内同步变动，才是使一项正当性主张站得住脚的模式。

## 与软件工程的关联

正当性指标很少由某一个团队的仪表盘单独产出，这本身就是一条设计教训：应构建能够摄取并核对来自独立外部来源（申诉专员个案系统、监管机构评级数据流、调查供应商）数据的报告流水线，而不是将正当性报告架构为一项纯内部指标，因为内部来源的正当性主张（"我们自评为值得信赖"）几乎没有证据分量——这与[公共价值计分卡](../public-value-scorecard/)中针对正当性视角所指出的独立性问题如出一辙。投诉和上诉数据流水线，理应获得与任何输入[按效果付费](../payment-by-results-and-social-impact-bonds/)合同的成果流水线同等的数据质量严谨度，因为一个漏报或分类不当的投诉数据集，会在一年后的信任调查中显现出来之前，悄悄低估一个正当性问题。关于这一机构层面衡量指标在交易层面的对应物，参见[公民满意度指标](../citizen-satisfaction-metrics/)；关于这条边所属的 Moore 完整战略三角框架，参见[公共价值](../public-value/)。

## 常见陷阱

- **将满意度当作正当性的代理指标。** 一位公民可能对某一笔交易的界面感到满意，却对该机构整体不信任（反之亦然）——参见[公民满意度指标](../citizen-satisfaction-metrics/)，了解为何两者必须分开报告。
- **依赖单一的自我报告指标。** 一项没有独立佐证（申诉专员数据、监管机构评级）的内部信任调查，很容易被视为自我评分而遭到质疑；应进行三角验证。
- **忽视人口统计学层面的分类。** 汇总的全国信任数字可能掩盖特定群体（按年龄、族裔、收入或地区）之间截然不同的正当性状况——OECD 自身发布的"政府信任"报告正是出于这一原因进行分类的。
- **将单次冲击驱动的下滑解读为永久趋势。** 信任数字会围绕危机（金融崩溃、疫情、高关注度丑闻）剧烈波动，并部分回升；在没有更多数据支撑的情况下，不应将冲击后的单一数据点外推为长期下滑趋势。
