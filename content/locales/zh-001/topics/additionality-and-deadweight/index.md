# 增益性与无谓损失

增益性（additionality）追问的是：某项干预是否促成了一个原本不会发生的结果。无谓损失（deadweight）则是它的镜像：即便没有该项目、拨款或补贴，某一结果原本也会发生的那部分比例。几乎所有来自政府项目或慈善机构的影响力声明，在扣除无谓损失之前都会高估其效果，这正是英国评估指南将其视为任何头条数字第一项、也是最重要一项调整的原因。

## 为何重要

"我们支持了 500 家企业实现增长"听起来是一项成就，但如果其中 300 家企业本来就会增长——因为当地经济正在复苏，因为它们还有其他融资渠道，因为它们在项目开始前就已处于增长轨道——那么该项目真正的增益性贡献是 200 家，而不是 500 家。英国财政部（HM Treasury）的《洋红皮书》（Magenta Book）以及历史悠久的财政部/BIS《增益性指南》（Additionality Guide，最初为区域发展与再生项目而制定，此后被广泛用于英国政府评估）将无谓损失确立为标准净影响序列中的起始调整项：总效果减去无谓损失，再减去置换，再减去泄漏，并按乘数效应调整，等于净增益影响。跳过这一步骤，是公共部门和社会部门影响力声明被夸大（无论是否出于故意）最常见的方式——一个只衡量参与者总体结果、没有对照组的拨款项目，根本无法区分自身的效果与本来就会发生的情况。

无谓损失不是一个固定百分比；它完全取决于特定人群和干预措施的反事实情形（参见[反事实分析](../counterfactual-analysis/)）。在此前的区域发展局（Regional Development Agencies）体制下，英格兰区域发展评估发现，根据企业支持类型的不同，无谓损失率通常在 20% 至 60% 之间，这正是可信的项目评估报告使用经无谓损失调整后的区间、而非单一假设数字的原因，也是国家彩票社区基金（National Lottery Community Fund）和 Big Society Capital 等资助方要求受助方在成果报告中明确处理无谓损失、而不是仅报告参与者总数的原因。

## 数学原理

英国评估指南（《洋红皮书》；财政部/BIS《增益性指南》；欧洲结构与投资基金评估指南）所规定的标准净影响调整序列：

```
总产出
  − 无谓损失      （原本就会发生的部分）
  − 置换          （从别处转移而来、并非新创造的活动/效益——参见
                    displacement-and-attribution）
  − 泄漏          （惠及目标群体/地区之外的效益）
  × 乘数           （若为正值，指额外的间接/引致经济活动）
  = 净增益影响
```

无谓损失率作为比例：

```
无谓损失率 = 若无该干预本也会发生的结果数
              / 观察到的总产出数

净增益产出 = 总产出 × (1 − 无谓损失率)
```

## 实例演算

**企业支持拨款项目**：某区域拨款计划报告称，500 家受支持企业在次年增加了就业，平均每家增加 3 个岗位——总体声明为 1,500 个工作岗位。

一个由类似的未受支持企业组成的匹配对照组（参见[反事实分析](../counterfactual-analysis/)）显示，根据该对照组在同一时期的表现，受支持企业就业增长中有 40% 原本也会发生。

```
无谓损失率 = 40%
净增益岗位 = 1,500 × (1 − 0.40) = 900 个岗位
```

该项目可如实报告的成就是 900 个岗位，而非 1,500 个——仅无谓损失调整一项就使数字减少了 40%，这还没有考虑置换或泄漏。

**慈善就业项目**：某慈善机构以 60 万英镑的成本（每个安置岗位总成本 3,000 英镑）帮助 200 名长期失业者找到工作。全国劳动力市场数据显示，若无任何干预，一个可比的长期失业群体中约有 15% 会在同一时期内通过自然的劳动力市场流动找到工作。

```
无谓损失率 = 15%
净增益安置人数 = 200 × (1 − 0.15) = 170
真实的每个增益安置岗位成本 = 600,000 英镑 / 170 ≈ 3,529 英镑
```

总体的每岗位成本数字（3,000 英镑）将该慈善机构真实增益贡献的成本低估了约 15%。

## 与软件工程的关联

对于任何为公共或社会部门构建影响力衡量或拨款管理软件的人而言，增益性与无谓损失都有直接的现实意义：

- 成果报告系统在设计之初就应当捕获对照组或基线数据，而不只是参与者的结果——在系统上线后再为其补建反事实机制，要比从一开始就纳入这种捕获能力困难得多（参见[反事实分析](../counterfactual-analysis/)）。
- 只报告参与者总数的仪表盘，会系统性地向资助方和监督机构夸大影响力；当存在无谓损失估算（来自评估文献或对照组）时，软件应当同时展示扣除无谓损失后的净值与总体数字，而不是只展示其中一个。
- 这与[社会投资回报](../social-return-on-investment/)直接相关：其 SROI 比率只有在从总体声明的结果中扣除无谓损失（以及置换）之后才可信——省略这一步骤的 SROI 计算器会产生虚高的比率，经不起推敲。

## 常见陷阱

- **将总体产出当作全部都是增益性的来报告。** 这是拨款和项目报告中最常见的影响力衡量错误；在公布头条数字之前，务必先问"这原本是否也会发生？"
- **假定单一的无谓损失百分比适用于所有情况。** 无谓损失因行业、人群和当地经济状况而差异巨大；应使用对照组或行业专属证据，而不是套用一个来自不相关评估的数字。
- **将无谓损失与置换混淆。** 无谓损失关注的是同一批参与者的反事实结果；置换关注的是对其他人或其他地方的影响——参见[置换与归因](../displacement-and-attribution/)。混淆两者会导致调整时重复计算或漏算。
- **由参与者自行报告无谓损失。** 询问受益人"如果没有我们的帮助，这会发生吗？"通常会系统性地得出偏低的无谓损失估算（参与者往往倾向于将功劳归于项目本身）；独立的对照组要可靠得多。
