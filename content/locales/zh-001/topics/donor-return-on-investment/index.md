# 捐赠者投资回报（Donor Return on Investment）

捐赠者投资回报衡量的是某位特定捐赠者的每一英镑实际换来了什么成果——它不是慈善机构的运营比率，也不是慈善机构自身总预算的回报率。它将投资回报率从组织视角（我们运营得有多高效）重新定位为捐赠者视角（我的边际贡献改变了什么），而这两个数字常常被人们错误地当作同一件事。

## 为何重要

慈善机构自身所说的"投资回报率"，在这个说法真的被使用的情况下，通常描述的是类似[单位受益人成本](../cost-per-beneficiary/)或[慈善机构管理费用比率](../charity-overhead-ratio/)这样的组织效率衡量指标。而捐赠者的投资回报率是一个完全不同的问题：既然这家慈善机构已经拥有其他收入来源，*这位*捐赠者的钱在边际上究竟增加了什么？如果一家慈善机构无论有没有某笔 10,000 英镑的捐赠都会交付同样的项目——因为它拥有充裕的储备金，或者因为另一位资助方本会填补这个缺口——那么这笔捐赠的捐赠者投资回报率就接近于零，无论该慈善机构整体的管理费用比率或单位成果成本看起来多么亮眼。

这与支撑英国公共支出中[物有所值](../value-for-money/)评估、以及项目评估中[增益性与无谓损失](../additionality-and-deadweight/)的是同一个增益性问题：所创造的价值，只有在其原本不会发生的程度上，才能被归功于一位资助方。主要的捐赠建议平台与有效行善组织（Giving What We Can、GiveWell）都明确围绕这一区分来构建其推荐意见，它们所问的不是"这是不是一家好的慈善机构"，而是"这家慈善机构是否还有未被填补的资金缺口，使得我的捐赠具有增益性"。

## 数学原理

```
捐赠者投资回报率 ≠ 慈善机构的运营效率

捐赠者投资回报率  ≈  （有该笔捐赠时所实现的成果） − （若无该笔捐赠
                       本会发生的成果，即反事实情形）
                     ─────────────────────────────────────────────
                                      捐赠金额

关键输入项：
  - 追加资金空间（该慈善机构在边际上是否受资金约束？）
  - 资金替代效应（是否会有另一位捐赠者填补这一缺口？）
  - 特定资金水平下的边际成本效果（随着一项干预措施
    超出其最容易触达的人群而扩大规模，成本往往上升）
```

关于 GiveWell 如何将"追加资金空间"这一问题付诸实践，参见[有效利他主义的成本效果](../effective-altruism-cost-effectiveness/)；关于通用方法，参见[反事实分析](../counterfactual-analysis/)。

## 实例演算

一位捐赠者正在两笔各 5,000 英镑的捐赠之间做选择：

- **慈善机构 C**：拥有一个资金已完全到位的核心项目，储备金达 200 万英镑，还有一份资助方候补名单；边际上的这 5,000 英镑很可能只是被计入储备金，或用于优先级较低的活动。估计的捐赠者增益成果：微乎其微——这笔钱显然没有改变任何事情的走向。
- **慈善机构 D**：一个规模较小、有证据支撑的项目，已公开表示如果下季度得不到额外 50,000 英镑，将不得不拒绝 200 人；目前已筹得其中的 42,000 英镑。边际上的这 5,000 英镑极有可能资助真正的额外交付——比如说，按该慈善机构自己所述的单位受益人成本 250 英镑计算，可多服务 20 人。

同样的捐赠金额，同一位捐赠者，捐赠者投资回报率却截然不同——这并不是因为慈善机构 C 是一家更差的机构（它整体的单位成果成本可能反而更好），而是因为它边际上的资金缺口已经被填补了。

## 与软件工程的关联

捐赠平台和捐赠建议工具往往只展示机构层面的效率指标（管理费用比率、单位受益人成本），因为这些正是慈善机构在年度报告中公开的、也最容易拉入比较表格的数据。要恰当地呈现捐赠者投资回报率，需要一个不同的、更难获取的数据点：慈善机构当前所声明的资金缺口，即"追加资金空间"，这一数字全年都在变化，也很少以结构化数据形式存在。想要支持真正的捐赠者投资回报率推理的平台，要么需要一个来自资金缺口披露信息的直接数据源（就像 GiveWell 为其推荐的慈善机构手动维护的那样），要么需要明确声明其比较表格展示的是机构效率，而不是捐赠者增益性。关于捐赠者投资回报率最常、也最错误地被混淆的指标，参见[慈善机构管理费用比率](../charity-overhead-ratio/)。

## 常见陷阱

- **将慈善机构效率与捐赠者增益性混为一谈。** 一家运营良好、管理费用低的慈善机构，如果并未受到资金约束，其边际捐赠者投资回报率仍可能接近于零。
- **忽视资金替代效应。** 如果一位大型机构资助方无论如何都会填补这一缺口，那么一位个人捐赠者的捐赠就只是替代了该资助方的资金，而不是增加了新的交付。
- **假定规模化时成本效果是线性的。** 最容易触达的受益人往往最先被服务；随着一个项目扩大规模，单位成果的边际成本往往会上升，因此下一英镑的投资回报率并不等同于已花费的平均一英镑的投资回报率。
- **没有明确声明的资金缺口。** 一家无法说清下一笔 X 英镑将用于资助什么的慈善机构或平台，无法支撑真正的捐赠者投资回报率主张，只能支撑一个平均成本主张。
