# 公民满意度指标（Citizen Satisfaction Metrics）

公民满意度指标衡量的是人们对公共服务直接体验的评价——它不同于对整体机构的信任，也不同于该服务是否真正取得了良好成果。一项服务可能广受喜爱却效果不彰，也可能效果显著却不受欢迎；这两者之间的差距本身，就是交付团队应当密切关注的诊断信息。

## 为何重要

满意度在两个经常被混为一谈的不同层面上被测量。在服务层面，英国已退役的 Performance Platform 以及如今的 GOV.UK 服务手册（Service Manual）都要求每项服务进行满意度调查（通常采用五级量表，从"非常满意"到"非常不满意"，在交易完成时发放），作为四项强制性服务关键绩效指标之一——参见[服务标准与交易指标](../service-standards-and-transaction-metrics/)。在机构层面，英国公务员人员调查（Civil Service People Survey）每年在中央政府各部门衡量员工敬业度与体验；另外，经济合作与发展组织（OECD）的"政府信任"（Trust in Government）项目则在各成员国之间调查公众对国家政府的信任度，其长期走势呈现出深受危机影响的下滑与回升模式（2008 年金融危机和新冠疫情都在 OECD 信任度数据中造成了明显而剧烈的波动）。构建面向公民服务的工程师之所以需要将满意度与成果区分开来，是因为这是服务设计中一种已知的失败模式：一份设计精美、易于使用的福利申领数字表单，可能获得非常高的满意度评分，而其背后的政策本身——资格规则、处理积压、发放金额——却丝毫没有让申领人受益更多。满意度衡量的是界面，而不是界面背后所交付的价值。

## 数学原理

```
净满意度 = 满意（或非常满意）百分比 − 不满意（或非常不满意）百分比
           （中立/无意见的回答不计入这两项，但计入用于计算
           各自百分比的应答基数）

满意度与成果差距 = 满意度分数 − 成果达成分数
           （两者均归一化为 0–100；正向差距较大，
           意味着一项服务"感觉不错"但实质交付不足）

信任指数（OECD 式） = 在"您对[国家政府]是否有信心？"这一问题上
           回答"是"的受访者百分比，作为时间序列跟踪，
           通常按年龄、收入和教育程度进行分类
```

## 实例演算

**某地方政府市政税电子账单服务**：在成功完成交易时进行的满意度调查显示，共 2,400 名受访者：1,650 人满意/非常满意，250 人不满意/非常不满意，500 人持中立态度。

```
净满意度 = (1,650/2,400 × 100) − (250/2,400 × 100)
          = 68.75% − 10.42%
          = +58.3 净满意度
```

单看这一数字表现强劲。但该调查只向*成功*完成交易的用户展示——这是一种已知的测量偏差（参见下文的常见陷阱）。将其与[服务标准与交易指标](../service-standards-and-transaction-metrics/)中的完成率指标结合来看，完成率只有 71%，这意味着：

```
放弃办理旅程的 29% 用户，其真实满意度从未被测量——
这很可能正是最不满意的群体，因为放弃行为本身
就是一个该调查从未捕获过的强烈负面信号。
```

**全国层面示例（OECD 式信任度序列的结构）**：国家政府信任度在第一年报告为 42%，在第二年（一个危机年份）降至 34%，第三年回升至 39%——这正是 OECD 在各成员国重大危机之后所记录的典型冲击与部分回升模式。

## 与软件工程的关联

应当在用户旅程中每一个有意义的退出节点上都进行满意度调查的仪表化，而不仅仅是在成功完成时——这是该领域最常见的工程错误，它会在不知不觉中将满意度指标变成一个存在幸存者偏差的虚荣指标。在可能的情况下，应将满意度分数与同一仪表盘上的完成率或成果指标配对展示，避免团队在完成率悄然下降的同时还在为满意度上升而庆祝（关于最初就被排除在数字满意度抽样之外的人群，非数字用户和辅助数字用户在服务内调查中系统性地代表不足，参见[单笔交易成本](../cost-per-transaction/)和[数字包容](../digital-inclusion/)）。满意度与信任数据也直接构成 [Moore 战略三角](../public-value/)中正当性这一条边的输入，并且应当归入[公共价值计分卡](../public-value-scorecard/)的"客户"与"正当性"视角之中——关于该服务层面指标在机构层面的对应指标，参见[信任与正当性指标](../trust-and-legitimacy-metrics/)。

## 常见陷阱

- **完成时点调查中的幸存者偏差**：放弃办理旅程的用户永远不会看到该调查，因此服务内的高满意度分数完全可能与低完成率、以及一大群未被看见的不满意未完成用户群体同时存在。
- **将满意度当作成果的代理指标**：一个为设计糟糕的政策打造的精心设计界面，会在满意度上得分很高、在成果上得分很差——应当始终同时报告两者，绝不能用其中一个替代另一个。
- **以虚假精确度报告小规模、非代表性样本**：来自几百名自我选择受访者的满意度分数，若报告到小数点后一位，会暗示一种样本规模根本无法支撑的置信度。
- **忽视人口统计学层面的分类**：未按年龄、收入、残障状况或数字接入方式细分的全国信任度与满意度数字，可能掩盖不同群体之间截然不同的体验——OECD 自身发布的"政府信任"报告就明确对此进行了分类。
