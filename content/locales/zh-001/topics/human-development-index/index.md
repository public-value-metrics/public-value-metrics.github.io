# 人类发展指数（Human Development Index, HDI）

人类发展指数是联合国用于替代仅凭收入对各国进行排名的旗舰指标：它将预期寿命、教育和收入合并为一个介于 0 到 1 之间的单一数字，其前提——由经济学家阿马蒂亚·森（Amartya Sen）提出、并由 Mahbub ul Haq 为联合国发展而成——是发展的意义在于扩展人们能够做什么、能够成为什么，而不仅仅是他们赚多少钱。自 1990 年以来，它每年都在联合国开发计划署（UNDP）的《人类发展报告》中发布。

## 为何重要

在 HDI 出现之前，"发展"几乎完全以人均国民生产总值来衡量，而这丝毫说明不了增长是否惠及了普通人的健康或教育。森的能力方法（capability approach）将发展重新定位为真实自由的扩展，而 ul Haq 则将其转化为一个可供 UNDP 用来对每个国家进行排名的可发布指数，迫使那些仅凭收入变得富裕、却忽视了健康或教育的政府，面对比其 GDP 所暗示的更差的排名（海湾产油国和一些资源型经济体是典型例子）。HDI 的三分结构也是[多维贫困指数](../multidimensional-poverty-index/)的直接方法论先驱：两者都拒绝让一个维度的高分弥补另一个维度的不足，都使用几何平均数而非算术平均数。UNDP 为每一版报告都发布了完整的技术说明和底层数据（<https://hdr.undp.org/data-center/human-development-index>），这是任何在该指数基础上进行研究、而不是重新推导它的人的权威来源。

## 数学原理

```
预期寿命指数（LEI）     = (预期寿命 − 20) / (85 − 20)

平均受教育年限指数      = 平均受教育年限 / 15
预期受教育年限指数      = 预期受教育年限 / 18
教育指数（EI）          = (平均年限指数 + 预期年限指数) / 2

收入指数（II）          = (ln(人均国民总收入) − ln(100)) / (ln(75000) − ln(100))

HDI = (LEI × EI × II) ^ (1/3)     【三个子指数的几何平均数】
```

采用几何平均数是刻意为之的：因为它是相乘而非取平均，一个维度上极高的分数无法完全抵消另一个维度上极低的分数——这是 UNDP 在 2010 年专门为惩罚失衡而采用的设计，取代了此前的算术平均公式。

## 实例演算

**某中等收入国家**：预期寿命 72 岁，平均受教育年限 8 年，预期受教育年限 13 年，人均国民总收入 12,000 美元。

```
LEI = (72 − 20) / (85 − 20)              = 52 / 65   = 0.800
平均年限指数 = 8 / 15                               = 0.533
预期年限指数 = 13 / 18                              = 0.722
EI = (0.533 + 0.722) / 2                            = 0.628
II = (ln(12000) − ln(100)) / (ln(75000) − ln(100))
   = (9.393 − 4.605) / (11.225 − 4.605)
   = 4.788 / 6.620                                  = 0.723

HDI = (0.800 × 0.628 × 0.723) ^ (1/3)
    = (0.363) ^ (1/3)                               ≈ 0.713
```

0.713 的 HDI 落在 UNDP"高人类发展水平"区间（0.700–0.799）内；"极高"水平从 0.800 起。注意该结果对最弱子指数有多敏感：如果平均受教育年限是 4 年而非 8 年（平均年限指数 = 0.267，EI = 0.494），HDI 将降至 (0.800 × 0.494 × 0.723)^(1/3) ≈ 0.639——整整下降一个等级区间——即便其他一切都没有变化。

## 与软件工程的关联

- 几何平均数模式可以直接复用于任何你不希望某一强项维度掩盖某一关键弱项维度的复合服务或产品评分——例如，将一项公共数字服务的无障碍性、性能和可靠性分数以相乘方式而非加权平均方式合并，使一个速度快但无法访问的服务无法得到"良好"评分。
- HDI 对收入进行对数变换（额外一英镑的边际价值递减），与评估中[分布性加权](../distributional-weighting/)背后的逻辑相同：额外 1,000 美元对一个贫困家庭的意义，远大于对一个富裕家庭的意义，将两者线性对待会错误地为影响力定价。
- 任何报告单一混合"数字包容"或"公民成果"分数的仪表盘，都应当像 UNDP 的技术说明那样明确记录其汇总公式——参见[公共部门关键绩效指标](../public-sector-kpis/)和[公共价值计分卡](../public-value-scorecard/)。

## 常见陷阱

- **使用平均数而非几何平均数。** 算术平均数会让高收入完全掩盖健康或教育方面的不足；2010 年方法论变更的全部意义就在于阻止这种替代。
- **像对待经通胀调整的 GDP 那样逐年比较 HDI。** UNDP 会定期对该指数进行重新基准化（新的最小值/最大值边界、修订后的受教育年限上限），因此排名变化可能反映的是方法论更新，而非真实的变化；应始终核实某一数字来自哪一版《人类发展报告》。
- **将 HDI 当作贫困衡量指标。** 它是一个国家层面的平均值，丝毫说明不了一国内部的分布情况；要衡量分布，应使用[多维贫困指数](../multidimensional-poverty-index/)或 UNDP 单独发布的不平等调整后 HDI。
