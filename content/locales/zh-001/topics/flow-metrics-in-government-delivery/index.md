# 政府交付中的流动指标（Flow Metrics in Government Delivery）

流动指标——利特尔法则（Little's Law）、在制品（WIP）限制和流动效率——描述的是工作在一个容量有限的系统中流转的速度。一块冲刺看板就是这样一个系统；一条福利申领队列、一份规划申请登记册，或一批签证个案积压，本质上是同一套数学、只是穿着不同的制服。

## 为何重要

政府的案件负荷本质上是排队系统，而排队系统无论有没有人去测量，都遵循排队论的规律。法定裁定期限将这一点明确化：在《城乡规划法》体制下，大多数小型规划申请都有 8 周的法定裁定目标，重大申请则为 13 周——一项直接写入法律的周期时间承诺。内政部的庇护个案积压问题，经国家审计署和内政事务特别委员会反复审查，是一个有充分记录的公共系统案例：在长期持续的时间里，在制品的增长速度超过了吞吐量，导致周期时间远远超出任何法定或服务预期。流动指标为工程师和个案管理经理提供了一套共同的、量化的词汇，来精确描述这种失败模式，而不是将其留作一个定性的"积压问题"。

## 数学原理

```
利特尔法则：  在制品数 = 吞吐量 × 周期时间
         →   周期时间 = 在制品数 / 吞吐量

流动效率 = 有效（处理）时间 / 总周期时间   （Vacanti）

在制品限制效应：在吞吐量固定的情况下，将在制品数减半
大致会使平均周期时间减半（利特尔法则的变形）——这是
一个无需增加人手即可运用的杠杆。
```

关于将同样的数学应用于软件部署流水线而非个案处理的对应做法，参见[面向公共价值的 DORA 指标](../dora-metrics-for-public-value/)。

## 实例演算

**某地方政府规划部门**：任意时刻在办申请数（在制品）为 400 宗，团队每周处理 50 宗申请（吞吐量）。

```
周期时间 = 在制品数 / 吞吐量 = 400 / 50 = 8 周
```

这恰好达到小型申请 8 周的法定目标——没有任何缓冲余地，这意味着任何进入需求的波动，或任何被咨询方响应时间的波动，都会将裁定推向超出法定期限。

**流动效率**：在这 8 周（56 个日历日）中，一宗申请通常只有大约 6 小时的实际个案工作人员处理时间。

```
流动效率 = 6 小时 / (56 天 × 每天 8 个工作小时)
         = 6 / 448 ≈ 1.3%
```

Vacanti 为软件团队设定的基准是典型流动效率为 15%至20%；而政府个案处理，由于涉及多个法定咨询方的交接和公众咨询窗口期，其流动效率往往要低一个数量级。那 98.7% 的"等待"时间，才是这八周真正消耗掉的地方——而不是消耗在个案工作人员的处理能力上。

**在制品限制干预**：将每位个案工作人员的在办申请上限从不设限的 25 宗降至 15 宗（保持吞吐量不变），会使一个 16 人团队的在制品数从 400 降至约 240：

```
新周期时间 = 240 / 50 = 4.8 周
```

一项政策变化——而非增加人手——就使周期时间接近减半。这正是 DORA 式交付团队限制冲刺在制品数量时所运用的同一杠杆。

## 与软件工程的关联

流动指标是交付团队的看板与其所构建软件所服务的个案处理一线之间的共同语言：个案工作人员的队列与拉取请求（pull request）队列同样受利特尔法则支配，也以同样的方式突破各自的周期时间目标——相对于吞吐量而言在制品过多。这与[公共项目中的延迟成本](../cost-of-delay-in-public-programmes/)直接相关：周期时间 × 延迟成本，就是此刻正滞留在队列中的英镑数；这也与[服务标准与交易指标](../service-standards-and-transaction-metrics/)相关——一项已公布的处理周期目标，本质上是一项周期时间承诺，只有流动指标才能在它未被达成时诊断出原因。一套个案处理系统的软件，应当将在制品数和周期时间作为一等运营指标展示出来，而不是将它们埋藏在一个无人查询的个案管理系统内部。

## 常见陷阱

- **在不解决真正瓶颈的情况下添加在制品限制**：如果约束来自外部法定咨询方的响应时间，限制个案工作人员的在制品数只会把队列推向上游，而不会真正缩短周期时间。
- **将流动效率当作可操纵的目标**：加快那 1.3% 的有效处理时间对周期时间的影响微乎其微；杠杆几乎总是在等待状态之中，这通常意味着需要流程重新设计，而不是加快个案工作人员的处理速度。
- **忽视波动性**：利特尔法则描述的是平均值；一个需求波动性高的案件负荷需要缓冲产能，而不仅仅是更严格的在制品限制，否则即便平均值有所改善，法定期限仍会在波动的尾部案例上被错过。
- **不一致地测量在制品**：一宗在记录系统中显示为"在办"但实际上正因等待第三方而停滞的案件，仍然是在制品；将其排除在外会美化数字，却不会改变公民所面对的实际情况。
