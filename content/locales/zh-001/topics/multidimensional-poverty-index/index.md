# 多维贫困指数（Multidimensional Poverty Index, MPI）

多维贫困指数将贫困衡量为一个人同时经历的多重叠加剥夺——健康、教育和生活水平方面的剥夺——而不仅仅是收入低于某条贫困线。它由牛津贫困与人类发展倡议组织（Oxford Poverty and Human Development Initiative，OPHI）与 Sabina Alkire 和 James Foster 共同开发，自 2010 年以来一直与[人类发展指数](../human-development-index/)一同，出现在联合国开发计划署每一版《人类发展报告》中。

## 为何重要

收入贫困线会遗漏那些拥有足够现金收入、却缺乏清洁水源或教育、或正在承受子女夭折之痛的人——而且它们也会遗漏一个事实：各种剥夺往往聚集出现——一个没有电力的家庭，同时也缺乏卫生设施、家中有营养不良儿童的可能性不成比例地更高。MPI 所基于的 Alkire-Foster 方法，在十项指标上统计每个人所经历的剥夺，这些指标被归入三个权重相等的维度——健康、教育、生活水平——只有当一个人的加权剥夺分数超过一个固定阈值时，才将其归类为"MPI 贫困"，从而捕捉到一组分开的单一指标统计所无法捕捉到的重叠情况。OPHI 在 <https://ophi.org.uk/multidimensional-poverty-index/> 上发布了完整的方法论和各国数据；它与联合国开发计划署共同维护的全球 MPI，如今覆盖超过 110 个国家。对于为反贫困项目（现金转移、社会关怀分诊、援助定位）构建的软件而言，MPI 的指标集，往往是最接近于一套已经在数十个国家统计局中得到验证的标准化剥夺框架。

## 数学原理

```
10 项指标，3 个维度，每个维度权重为 1/3：

健康 (1/3)：             营养 (1/6)、儿童死亡率 (1/6)
教育 (1/3)：             受教育年限 (1/6)、就学情况 (1/6)
生活水平 (1/3)：         烹饪燃料、卫生设施、饮用水、
                        电力、住房、资产（各 1/18）

剥夺分数 (c) = 一个人所遭受剥夺的各项指标权重之和

若 c ≥ 1/3（贫困临界值，k = 33%），此人被归类为"MPI 贫困"

H（人头率） = MPI 贫困人数 / 总人口
A（强度）   = 仅在 MPI 贫困人群中的平均剥夺分数

MPI = H × A
```

因为 MPI 是将贫困*人群占比*乘以他们*贫困的程度*，两个人头率相同的地区，如果其中一个地区的剥夺程度更为严重，其 MPI 分数可能大不相同——这与 HDI 几何平均数背后"各维度之间不可替代"的逻辑如出一辙。

## 实例演算

**某全国性调查，1,000 人**：其中 350 人被认定为多维贫困（剥夺分数 ≥ 33%）。仅在这 350 名贫困个体中，平均剥夺分数为 45%。

```
H = 350 / 1000                = 0.350
A = 0.45
MPI = H × A = 0.350 × 0.45    = 0.1575
```

**比较两个人头率相同的地区**：地区 A 的 H = 0.30，A = 0.40（贫困人数多，但剥夺程度中等）；地区 B 的 H = 0.30，A = 0.60（贫困人数相同，但剥夺程度更为严重——同时缺乏电力*、*卫生设施*和*就学）。

```
MPI_A = 0.30 × 0.40 = 0.120
MPI_B = 0.30 × 0.60 = 0.180
```

人头率相同，但地区 B 的 MPI 高出 50%——一个仅基于人头贫困率的定位系统会将这两个地区排在同一位置，从而遗漏地区 B 需要更深层次干预这一事实。

## 与软件工程的关联

- 社会项目的个案管理和资格认定系统，往往已经将十项指标中的若干项（住房、就学、健康指标）分别存储在各自的信息孤岛中；Alkire-Foster 计数方法提供了一套现成的框架，可以将它们合并为一个剥夺分数，而不必从头构建一套定制的评分模型。
- 人头率/强度的拆分（H × A）对任何需要同时报告"有多少人受影响"和"受影响程度有多深"的仪表盘而言，都是一种普遍有用的模式——像原始流行率统计那样将两者压缩成一个数字，恰恰会掩盖最需要资源的那些情况。
- MPI 式的指标仪表盘，与反贫困项目的[单位受益人成本](../cost-per-beneficiary/)报告天然契合：每降低一个 MPI 点数的成本，是比较截然不同干预措施（现金转移与卫生基础设施）的一个可辩护单位。

## 常见陷阱

- **将十项指标当作普适通用的。** OPHI 的全球 MPI 指标是为跨国可比性而校准的；各国 MPI（包括南亚和非洲的许多国家都发布了自己的版本）会根据本地情境调整指标和权重，两者不能直接比较。
- **只报告 H。** 人头率完全忽略了强度；应始终同时报告 A，或直接报告 MPI 本身。
- **假定 MPI 贫困人群与收入贫困人群是同一批人。** OPHI 自己发布的各国简报通常显示，两者之间只有部分重叠；一个只针对收入贫困人群的项目，会系统性地遗漏相当一部分多维贫困人群。
