# 自然资本核算（Natural Capital Accounting）

自然资本核算，将环境置于与任何其他国家或组织资产同等的地位：它以实物和货币两种方式，测量自然资源（林地、土壤、河流、湿地、大气）的存量及其所产生服务（碳封存、防洪、休闲游憩、食物）的流量，使环境消耗能够像消耗金融资本那样，真实地体现在决策之中。英国是系统性推行这一做法最为领先的政府之一，其动力来自《25 年环境计划》（25 Year Environment Plan，2018），并通过英国国家统计局（ONS）的英国自然资本账户和财政部《绿皮书》补充指南得以实施。

## 为何重要

无论是企业还是政府，传统会计方式都将一片森林视为毫无价值，直到它被砍伐并作为木材出售，此时它才计入 GDP。自然资本核算的存在正是为了填补这一鸿沟：英国《25 年环境计划》承诺政府将自然资本思维嵌入各项政策，明确宣示要成为"第一代将环境状况改善得比我们所继承时更好的一代人"。此后，ONS 每年发布英国自然资本账户（<https://www.ons.gov.uk/economy/environmentalaccounts/bulletins/uknaturalcapitalaccounts/latest>），使用与生产性资本相同的国民账户框架，估算生态系统服务——从林地休闲游憩到城市绿地的健康效益，再到泥炭地的碳储存——的货币价值，从而使自然资本最终能够与道路、建筑和设备一同出现在同一份资产负债表上。财政部作为《绿皮书》补充指南发布的《促成自然资本方法》（Enabling a Natural Capital Approach，ENCA，<https://www.gov.uk/government/publications/enabling-a-natural-capital-approach-enca-guidance>），规定了评估人员应当如何在商业论证中为环境成本和效益定价，使得一项摧毁古老林地的道路方案与一项恢复湿地的防洪方案，能够以一致的货币化条款进行比较，而不是一个有数字、另一个只有一段附带说明。

## 数学原理

```
生态系统服务资产价值 = 该资产所提供服务流的净现值

资产价值 = Σ (t = 1 到 T) [第 t 年的服务流价值 / (1 + r)^t]

其中：
  第 t 年的服务流价值 = 第 t 年的服务数量 × 单位价值
                        （例如：休闲游憩人次 × 每人次价值；
                        封存的碳吨数 × 碳价格）
  r = 折现率（《绿皮书》社会折现率——参见
      [社会折现率](../social-discount-rate/)）
  T = 该资产预期提供该服务的时间跨度
```

这与用于评估生产性资本、或在[绿皮书评估](../green-book-appraisal/)下评估任何公共投资的净现值结构完全相同——自然资本核算的贡献在于，为此前被定价为零的服务，提供了可信的实物数量和单位价值。

## 实例演算

**城市林地，休闲游憩价值**：一片 50 公顷的林地每年估计接待 80,000 人次休闲游憩访问，通过旅行成本法或陈述性偏好法（参见[显示性偏好估值](../revealed-preference-valuation/)和[陈述性偏好估值](../stated-preference-valuation/)）估值，每人次 3 英镑。该林地预计将在 50 年内持续提供这项服务，按 3.5% 折现率评估。

```
年度休闲游憩价值 = 80,000 × 3 英镑 = 240,000 英镑/年

50 年净现值（3.5%折现率）≈ 240,000 英镑 × 年金系数(3.5%, 50年)
年金系数(3.5%, 50) ≈ 21.4

资产价值 ≈ 240,000 英镑 × 21.4 ≈ 5,136,000 英镑
```

**加上碳储存**：同一片林地每年估计封存 400 吨二氧化碳，按政府非交易碳价格约每吨 75 英镑估值（示例性数字——实际评估应使用商业、能源和产业战略部/能源安全与净零排放部当前公布的碳价值）。

```
年度碳价值 = 400 × 75 英镑 = 30,000 英镑/年
50 年净现值（3.5%折现率）≈ 30,000 英镑 × 21.4 ≈ 642,000 英镑

林地总资产价值（休闲游憩+碳储存）≈ 5,136,000 + 642,000
                                    ≈ 5,778,000 英镑
```

这还没有加上 ENCA 指南同样要求评估人员考虑的防洪缓解、生物多样性或空气质量服务价值——这一总数刻意设定为下限，而非上限。

## 与软件工程的关联

- 地方政府和机构的环境与资产管理系统（公园、公路、水体），可以在其实物资产登记册旁边附加一份自然资本登记册，采用与该组织维护的任何其他[单位成本数据库](../unit-cost-databases/)相同的"服务流量 × 单位价值"模式。
- 由于自然资本净现值对折现率高度敏感（参见实例演算中的年金系数），任何计算它的工具都应将利率和评估周期作为可见的输入项展示出来，而不是将其埋藏起来——这与[代际公平与可持续性折现](../intergenerational-equity-and-sustainability-discounting/)中所涉及的透明度原则相同。
- 自然资本账户正日益成为[绿皮书评估](../green-book-appraisal/)商业论证中环境影响部分的必需输入项；构建商业论证工具的交付团队，应当将 ONS 账户和 ENCA 单位价值视为需要集成的参考数据，而不是让评估人员每次都从头重新计算的东西。

## 常见陷阱

- **对重叠的生态系统服务重复计算。** 同一地点的休闲游憩价值和生物多样性价值，可能共享底层的支付意愿数据；ENCA 指南明确警告不要将源自重叠调查工具的估值直接相加。
- **将自然资本资产价值当作静态不变的。** 服务流量会随气候、管理方式和土地利用压力而变化；一片林地在这十年间的碳储存和防洪缓解价值，并非该地点的永久固有属性。
- **将全国平均单位价值用于高度地方性的决策。** 一公顷易于到达的城市林地，与一公顷偏远的高地，其休闲游憩价值截然不同；ENCA 指南建议在可获得的情况下使用地方性或场地专属的价值，而不是默认套用全国平均值。
