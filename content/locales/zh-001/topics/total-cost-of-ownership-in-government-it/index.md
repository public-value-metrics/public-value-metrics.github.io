# 政府 IT 中的总拥有成本（Total Cost of Ownership, TCO）

总拥有成本是一个系统的全生命周期成本——采购成本加上每一年的运行成本——折现到同一个基准日期。在政府 IT 领域，最常见、最可靠的预测错误，就是仅凭采购价格对供应商或方案进行比较，而运营和维护成本通常占据全生命周期总账单的一半到五分之四之多。

## 为何重要

财政部《绿皮书》要求任何五个论证案例模型商业论证中的财务论证都必须覆盖全生命周期成本，而不仅仅是资本支出——然而国家审计署一再发现，各部门在批准 IT 投资时所依据的运行成本预测不完整或过于乐观，直到系统上线、资本预算科目已经结项之后，才发现真实的运营成本。政府数字服务局和中央数字与数据办公室的《技术操守准则》（<https://www.gov.uk/guidance/the-technology-code-of-practice>）之所以推动各部门转向云端和通用托管，部分原因正是它能使持续性成本变得可见、可比较，而不是被埋藏在一个单一的资本采购数字中——这个数字在获批时看起来诱人的低，三年后却昂贵得错得离谱。

## 数学原理

```
TCO = 采购成本 + Σ(t=1..N) 第t年年度运营成本 / (1+r)^t
      − 残值（已折现）

r = 财政部《绿皮书》标准社会折现率，3.5%/年
    （超过 30 年周期的递减利率时间表）

运营成本组成部分：托管/授权、支持与维护、
安全补丁与合规、员工工时、计划性更新/迁移
```

关于折现系数在典型的 5 至 10 年系统生命周期内为何重要，参见[社会折现率](../social-discount-rate/)；关于 TCO 如何输入自建/外购决策，参见[政府中的自建与外购之争](../build-vs-buy-in-government/)。

## 实例演算

某部门在《绿皮书》3.5% 折现率下，以 5 年为周期比较两套个案管理系统。

```
系统 A：资本支出 3,500,000 英镑，运营支出 250,000 英镑/年
系统 B：资本支出 1,800,000 英镑（看起来更便宜），
       运营支出 650,000 英镑/年（更重的供应商支持
       和集成负担）

仅凭资本支出的朴素比较：B 胜出，180万 < 350万。

5 年折现系数之和，3.5%：0.966+0.934+0.902+0.871+0.842 ≈ 4.515

TCO_A = 3,500,000 + 250,000 × 4.515 = 3,500,000 + 1,128,750 = 4,628,750 英镑
TCO_B = 1,800,000 + 650,000 × 4.515 = 1,800,000 + 2,934,750 = 4,734,750 英镑
```

TCO 颠覆了这一朴素决策：在对运营成本进行折现并加总后，系统 B 在五年内略贵一些，因为其运营支出占全生命周期成本的比例高达 62%（2,934,750 / 4,734,750），而系统 A 只有 24%——这正是"维护占账单大头"这一发现的一个具体实例，而仅凭标价比较会将其完全掩盖。

## 与软件工程的关联

TCO 应当是规范每一次[自建与外购](../build-vs-buy-in-government/)决策和每一份[技术债](../technical-debt-as-public-value-erosion/)偿还论证的数字，因为债务利息和被推迟的维护，都是应当计入同一个折现总额中的运营成本科目，无论是否有人一直在跟踪它们。提出平台或供应商选择方案的工程师，应当呈现完整的 TCO 表格，而不是采购价格，因为采购价格正是《绿皮书》财务论证设计初衷所要阻止各部门单独依赖的那个数字。TCO 也是[物有所值](../value-for-money/)判断的诚实分母——VFM 比较的是效益与成本，而一个被低估的成本科目，会夸大商业论证中的每一个 VFM 比率。

## 常见陷阱

- **仅比较资本支出**：最常见的采购错误——在没有为每个方案匹配运营成本预测的情况下，仅比较供应商标价。
- **排除退出和迁移成本**：合同终止时的数据提取、重新平台化和供应商锁定罚金，都是真实的 TCO 科目，却很少出现在原始商业论证中。
- **排除安全和合规成本**：补丁节奏、认证更新和审计成本会随系统年龄和复杂度而增长——参见[公共部门网络安全价值](../public-sector-cybersecurity-value/)——却常常被排除在运营支出预测之外。
- **在成本结构不同的方案之间进行未折现比较**：在不进行折现的情况下，将一个资本支出密集型方案与一个运营支出密集型方案相比较，会系统性地偏向那个恰好将更多成本推迟到后期年份的方案。
