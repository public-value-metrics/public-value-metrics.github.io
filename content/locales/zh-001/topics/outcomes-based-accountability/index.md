# 成果导向问责制（Outcomes-Based Accountability, OBA）

成果导向问责制，又称结果导向问责制（Results-Based Accountability，RBA），是 Mark Friedman 提出的框架，用于分离两个公共部门报告中习惯性地混为一谈的问题："人群状况是否良好？"（人群层面问责）与"这个具体项目本身表现是否良好？"（绩效层面问责）。在 Friedman 看来，将这两者混为一谈，是运营良好的项目被归咎于其根本无力左右的人群层面趋势的最常见原因。

## 为何重要

Friedman 在《光努力是不够的》（*Trying Hard Is Not Good Enough*，2005）一书中提出了这一框架，指出大多数公共报告要么让决策者淹没在没有任何单一机构能够控制的人群层面统计数据中（青少年怀孕率、失业率、预期寿命），要么让他们淹没在丝毫说明不了任何人生活是否得到改善的项目层面活动计数中（服务的客户数、发出的转介数）。RBA 的贡献在于提供了一套精简而严谨的词汇，将两者区分开来：人群成果（一个整体人群的福祉状况，例如"儿童健康出生"）不属于任何单一机构，需要许多合作方共同努力；绩效衡量指标（一个具体项目为其具体客户服务的成效如何）属于一个机构，应当仅按该机构实际能够施加影响的范围来评判。Friedman 提出的"三个绩效问题"——我们做了多少、我们做得有多好、有没有人因此变得更好——如今已嵌入美国各州县的人类服务合同管理体系，并通过与 RBA 理念一致的咨询和工具机构 Clear Impact，被广泛应用于英国和英联邦国家的地方政府采购之中。这一点的实际利害关系是合同性的：一个住房项目不应仅仅因为该城市的无家可归率由于其无法触及的宏观经济原因而上升就被撤资，但如果它自己的客户根本没有被安置进住房，那它绝对应该被撤资。

## 数学原理

```
人群层面问责（一个社区、地区或国家共同面对的"大局"）：
  结果         — 一种福祉状态（例如"居民经济上有保障"）
  指标         — 衡量该状态的指标（例如失业率、家庭收入中位数）
  → 没有任何单一项目拥有该指标；其变动需要许多贡献者共同努力

绩效层面问责（一个项目自身负责的内容）：
  我们做了多少？    — 活动量（服务的客户数、交付的单位数）
  我们做得有多好？  — 质量/效率（项目完成率、每客户成本）
  有没有人变得更好？— 真正重要的成果（项目结束后 6 个月的
                     就业比例，前后对比或与对照组相比较）

一个项目应根据第三个绩效问题来评判，而不应直接根据
人群指标来评判，除非其规模和设计确实有可能单独左右
该指标。
```

## 实例演算

**某城市资助的就业支持项目**，每年 500 名参与者，由地方政府按 RBA 式绩效框架签约管理：

```
人群指标（背景信息，而非该项目的成绩单）：
  该市失业率：6.2%（较上年的 5.8% 上升，原因是该项目
  无法控制的一次工厂关闭）

绩效衡量指标（该项目真正的问责内容）：
  做了多少：招募了 500 名参与者（目标 480）——达标
  做得多好：78% 完成率；每名完成者成本 = 340,000 英镑 /
            390 名完成者 ≈ 872 英镑
  是否变好：390 名完成者中有 260 人在 6 个月后仍保持就业，
            占 66.7%，相较于匹配对照组的 41%
            （参见 counterfactual-analysis）
```

按人群层面问责来解读，该项目看起来像是失败的——该市失业率在其运行期间上升了。而按 RBA 的绩效层面问责来解读，该项目是成功的：它达成了招募量目标，保持了质量稳定，并产出了比匹配对照组高出 25.7 个百分点的就业成果，而人群指标的变动，则完全是由该项目无法控制的原因（一次工厂关闭）所致。

## 与软件工程的关联

RBA 与一个熟悉的 SRE 区分直接对应：人群指标就像没有任何单一工程团队能够端到端拥有的业务层面"北极星"指标（公司收入、市场份额），而绩效衡量指标则像一个团队自己的服务级别目标（SLO）——即该团队的设计决策真正能够左右的事项。一个同时报告两者、却不标注哪个是哪个的仪表盘，恰恰会招致 RBA 旨在防止的那种错误归因：一位值班工程师因一项由依赖团队所控制的指标而被追责。在为成果合同委托或构建报告工具时，应将"做了多少/做得多好/是否变好"这一三元组构建为一等的、可分别筛选的字段，而不是一个单一的混合关键绩效指标——这与在[公共部门关键绩效指标](../public-sector-kpis/)中区分领先指标和滞后指标是同一种纪律。RBA 也是[按效果付费与社会效益债券](../payment-by-results-and-social-impact-bonds/)背后的问责逻辑：一份按效果付费的合同只能公平地按"是否变好"这一绩效指标付款，而绝不能按人群指标付款，除非该干预措施确实是该指标的主导驱动因素。

## 常见陷阱

- **依据一个项目无法控制的人群指标对其进行付款或惩罚**：这正是 RBA 旨在防止的那个错误；在为某个人群成果附加后果之前，应始终先追溯该项目对其贡献是主要的还是次要的。
- **将"做了多少"当作"是否变好"来报告**：活动计数（服务的客户数）是最容易收集、也最缺乏信息量的数据；应坚持用真实的成果数据、最好是对照一个反事实情形（参见[反事实分析](../counterfactual-analysis/)）来回答"有没有人变得更好"这个问题。
- **将 RBA 指标当作永久固定不变的。** Friedman 的方法明确是迭代式的——一个"数据、故事、有效做法、行动计划"的循环——而不是一次性的计分卡设计工作。
- **"是否变好"没有对照组**：一次没有反事实情形的前后对比，会将项目效应与人群本来就会呈现的趋势混为一谈。
