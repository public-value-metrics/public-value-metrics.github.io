# การจ่ายตามผลงานและพันธบัตรผลกระทบทางสังคม (PbR/SIBs)

การจ่ายตามผลงาน (payment by results, PbR) จ่ายให้ผู้ให้บริการตามผลลัพธ์ที่ยืนยันแล้วว่าบรรลุ ไม่ใช่กิจกรรมที่ดำเนินการ พันธบัตรผลกระทบทางสังคม (social impact bond, SIB) คือโครงสร้างการจัดหาเงินทุนแบบ PbR โดยเฉพาะ ซึ่งนักลงทุนเอกชนหรือผู้บริจาคให้ทุนการส่งมอบบริการล่วงหน้า และได้รับคืน — พร้อมผลตอบแทน — จากหน่วยงานว่าจ้างของรัฐเฉพาะเมื่อผลลัพธ์ที่วัดโดยอิสระถึงเกณฑ์ที่ตกลงกัน ย้ายความเสี่ยงด้านการส่งมอบจากผู้เสียภาษีไปยังนักลงทุน

## เหตุใดจึงสำคัญ

SIB แรกของโลกเริ่มที่ HMP Peterborough ในเดือนกันยายน 2010: Social Finance ระดมทุน 5 ล้านปอนด์จากนักลงทุน 17 ราย เพื่อสนับสนุน "One Service" ซึ่งทำงานกับนักโทษโทษสั้น (ต่ำกว่า 12 เดือน) เพื่อลดการกระทำผิดซ้ำ โดยกระทรวงยุติธรรมและ Big Lottery Fund ตกลงจะคืนเงินนักลงทุนก็ต่อเมื่อเหตุการณ์ถูกตัดสินลงโทษซ้ำลดลงอย่างน้อย 7.5% เทียบกับกลุ่มเปรียบเทียบระดับชาติที่จับคู่ กลุ่มสุดท้ายของโครงการนำร่อง Peterborough บันทึกการลดลงของการตัดสินลงโทษซ้ำ 9.7% สูงกว่าเกณฑ์อย่างสบาย และนักลงทุนได้รับคืนพร้อมผลตอบแทน กลไกนี้สำคัญเพราะแก้ปัญหาการจัดจ้างเฉพาะอย่าง: รัฐบาลต้องการจ่ายเพื่อผลลัพธ์แทนปัจจัยนำเข้า แต่ไม่สามารถรับความเสี่ยงทางการเงินของการแทรกแซงที่อาจไม่ได้ผล โครงสร้าง SIB จึงย้ายความเสี่ยงนั้นไปยังนักลงทุนที่เต็มใจรับประกัน Government Outcomes Lab (GO Lab) ที่ Blavatnik School of Government ของ Oxford ปัจจุบันดูแลฐานหลักฐานสาธารณะที่สมบูรณ์ที่สุดเกี่ยวกับผลการดำเนินงานของ PbR และ SIB ทั่วโลก ติดตามพันธบัตรผลกระทบเกิน 200 ฉบับทั่วโลก และเผยแพร่งานวิจัยว่าคุณลักษณะการออกแบบใดสัมพันธ์กับความสำเร็จหรือความล้มเหลว บทเรียนที่ฐานหลักฐานกลับมาเสมอคือ *ตัวชี้วัดผลลัพธ์ที่เลือก* และใครรับความเสี่ยงของการพลาดมัน เป็นตัวกำหนดเกือบทุกอย่างอื่นเกี่ยวกับพฤติกรรมของสัญญา PbR ในทางปฏิบัติ

## คณิตศาสตร์

```
การจ่าย PbR = การจ่ายฐาน (ถ้ามี) + Σ (ผลลัพธ์ที่บรรลุ × ราคาต่อหน่วยต่อผลลัพธ์)

ผลตอบแทนนักลงทุนพันธบัตรผลกระทบทางสังคม:
  เงินลงทุนของนักลงทุน   = ทุนล่วงหน้าที่สนับสนุนการส่งมอบบริการ
  การจ่ายตามผลลัพธ์       = หน่วยงานว่าจ้างจ่ายเมื่อผลลัพธ์ ≥ เกณฑ์เท่านั้น ปรับตาม
                            ว่าผลงานสูงกว่าเกณฑ์มากเพียงใด
  ผลตอบแทนนักลงทุน       = การจ่ายตามผลลัพธ์ที่ได้รับ − เงินลงทุนของนักลงทุน
                            (อัตราผลตอบแทน มักมีเพดาน สะท้อนความเสี่ยงที่รับ)

พารามิเตอร์การออกแบบหลักที่กำหนดพฤติกรรมของสัญญาทั้งฉบับ:
  ตัวชี้วัดผลลัพธ์        — ต้องเป็นผลลัพธ์ ไม่ใช่ผลผลิต (ดู outcomes-vs-outputs)
  การเปรียบเทียบ/สภาพตรงข้ามกับข้อเท็จจริง — โดยปกติกลุ่มที่จับคู่ (ดู counterfactual-analysis)
  เกณฑ์การจ่าย           — การปรับปรุงขั้นต่ำก่อนมีการจ่ายใด ๆ
  เส้นโค้งการจ่าย        — เชิงเส้น เป็นขั้น หรือมีเพดานเหนือเกณฑ์
  ส่วนลดการระบุที่มา/ส่วนสูญเปล่า — ดู additionality-and-deadweight
```

## ตัวอย่างการคำนวณ

**Peterborough One Service** (ตัวเลขเพื่อการอธิบายจากการประเมินที่เผยแพร่):

```
ทุนนักลงทุนที่ระดม:          5,000,000 ปอนด์
กลุ่ม:                       นักโทษชายโทษสั้นราว ~3,000 คน ในสองกลุ่ม
เกณฑ์:                       ลดลง ≥7.5% ของเหตุการณ์ถูกตัดสินลงโทษซ้ำเทียบกับ
                              กลุ่มเปรียบเทียบระดับชาติที่จับคู่ มิฉะนั้นไม่มีการจ่าย
ผลกลุ่มที่ 1:                 ลดลง 8.4% — ต่ำกว่าเกณฑ์ตามสัญญาสำหรับกลุ่มนั้น
                              เพียงลำพังภายใต้กฎเดิม
ผลกลุ่มรวม/สุดท้าย:          ลดลง 9.7% — สูงกว่าเกณฑ์
การจ่ายตามผลลัพธ์:           รัฐบาล (กระทรวงยุติธรรม / Big Lottery Fund)
                              จ่ายต่อจุดเปอร์เซ็นต์ที่สูงกว่าเกณฑ์ เป็นทุนคืน
                              นักลงทุนพร้อมผลตอบแทน
```

**สัญญา PbR ของหน่วยงานท้องถิ่น (เพื่อการอธิบาย)**: บริการแทรกแซงครอบครัวถูกว่าจ้างที่ 4,000 ปอนด์ต่อครอบครัวที่ส่งต่อ (ค่ากิจกรรม) บวก 6,000 ปอนด์ต่อครอบครัวที่ไม่มีการส่งต่อเรื่องคุ้มครองเด็กอีก 12 เดือนหลังปิดคดี (ค่าผลลัพธ์) ส่งต่อ 200 ครอบครัว ปิดคดี 150 กรณี 96 กรณียังไม่มีการส่งต่อที่ 12 เดือน:

```
ค่ากิจกรรม  = 200 × 4,000 ปอนด์ = 800,000 ปอนด์
ค่าผลลัพธ์  = 96 × 6,000 ปอนด์  = 576,000 ปอนด์
ต้นทุนสัญญารวม = 1,376,000 ปอนด์สำหรับผลลัพธ์ยั่งยืนที่ยืนยันแล้ว 96 รายการ
ต้นทุนต่อผลลัพธ์ที่ยืนยัน ≈ 14,333 ปอนด์ (ดู cost-per-outcome)
```

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

การจ่ายตามผลงานเป็นปัญหาการจัดแนวแรงจูงใจก่อนจะเป็นปัญหาข้อมูล และระบบข้อมูลคือที่ที่การจัดแนวนั้นคงอยู่หรือแตกสลาย การยืนยันผลลัพธ์โดยอิสระและป้องกันการแก้ไขคือทั้งเกม: หน่วยงานว่าจ้างและผู้ให้บริการมีแรงจูงใจตรงข้ามกันว่ากรณีคลุมเครือถูกลงรหัสอย่างไร ระบบที่บันทึกผลลัพธ์จึงต้องมีร่องรอยการตรวจสอบ ข้อตกลงแบ่งปันข้อมูลกับผู้ตรวจสอบอิสระ (มักเป็นหน่วยงานอื่นนอกเหนือจากผู้ให้บริการ บางครั้งเป็นหน่วยงานสถิติทางการที่จับคู่กับบันทึกตำรวจหรือสวัสดิการ) และการควบคุมเวอร์ชันของนิยามผลลัพธ์ที่แก้ไขไม่ได้ — สิ่งเทียบเท่าใน PbR ของข้อผิดพลาด "การนิยามตัวชี้วัดใหม่" ใน [ตัวชี้วัดผลงานหลักของภาครัฐ](../ตัวชี้วัดผลงานหลักของภาครัฐ/) การคำนวณการระบุที่มาขึ้นกับวิธีจับคู่กลุ่มของ [การวิเคราะห์สภาพตรงข้ามกับข้อเท็จจริง](../การวิเคราะห์สภาพตรงข้ามกับข้อเท็จจริง/) ซึ่งต้องการโค้ดที่ทำซ้ำและตรวจสอบได้ ไม่ใช่สเปรดชีตครั้งเดียว และตัวชี้วัดเองต้องเป็นผลลัพธ์แท้ ไม่ใช่กิจกรรมตัวแทน — ดู [ผลลัพธ์กับผลผลิต](../ผลลัพธ์กับผลผลิต/) — เพราะสัญญา PbR ที่จ่ายสำหรับผลผลิตเพียงเปลี่ยนป้ายเงินทุนปกติโดยมีต้นทุนธุรกรรมเพิ่ม เมื่อผลตอบแทนทางสังคมของ SIB ถูกสร้างแบบจำลองล่วงหน้า การประเมินนั้นมักยืมโดยตรงจากระเบียบวิธี [ผลตอบแทนทางสังคมจากการลงทุน](../ผลตอบแทนทางสังคมจากการลงทุน/)

## ข้อผิดพลาดที่พบบ่อย

- **จ่ายสำหรับผลลัพธ์ตัวแทนที่เล่นแร่แปรธาตุได้ง่าย**: "การเข้าร่วมเซสชัน" คือกิจกรรมที่แต่งตัวเป็นผลลัพธ์ ยืนกรานตัวชี้วัดที่สะท้อนการเปลี่ยนแปลงที่ต้องการจริง (การกระทำผิดซ้ำ การจ้างงาน เสถียรภาพที่อยู่อาศัย)
- **ไม่มีสภาพตรงข้ามกับข้อเท็จจริงที่น่าเชื่อถือ**: หากไม่มีกลุ่มเปรียบเทียบที่จับคู่ การปรับปรุงอาจเป็นการถดถอยเข้าหาค่าเฉลี่ยหรือแนวโน้มที่กว้างกว่า ไม่ใช่ผลของโครงการ — ดู [การวิเคราะห์สภาพตรงข้ามกับข้อเท็จจริง](../การวิเคราะห์สภาพตรงข้ามกับข้อเท็จจริง/) และ [ผลเพิ่มเติมและส่วนสูญเปล่า](../ผลเพิ่มเติมและส่วนสูญเปล่า/)
- **ประเมินต้นทุนธุรกรรมและการประเมินผลต่ำเกินไป**: การยืนยันโดยอิสระ การเชื่อมโยงข้อมูล และการบริหารสัญญาของโครงการ PbR/SIB มักสูงถึงตัวเลขสองหลักในรูปเปอร์เซ็นต์ของมูลค่าสัญญา — ฐานหลักฐานของ GO Lab บันทึกสิ่งนี้เป็นปัจจัยที่เกิดซ้ำของการยุติโครงการ
- **เลือกเฉพาะรายที่ง่ายหรือ "จอดไว้"**: ผู้ให้บริการที่ได้รับเงินต่อผลลัพธ์มีแรงจูงใจโดยตรงที่จะให้ความสำคัญกับลูกค้าที่น่าจะสำเร็จอยู่แล้วและลดความสำคัญกรณียากที่สุด — ออกแบบระดับการจ่ายหรือการปรับตามส่วนผสมของกรณีเพื่อรับมือ
