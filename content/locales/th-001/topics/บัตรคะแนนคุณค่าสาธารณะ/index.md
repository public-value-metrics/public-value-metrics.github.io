# บัตรคะแนนคุณค่าสาธารณะ

บัตรคะแนนคุณค่าสาธารณะปรับบัตรคะแนนสมดุล (balanced scorecard) ปี 1992 ของโรเบิร์ต แคปแลน (Robert Kaplan) และเดวิด นอร์ตัน (David Norton) — ที่สร้างสำหรับบริษัทที่ปรับกำไรให้เหมาะสมที่สุดข้ามมุมมองด้านการเงิน ลูกค้า กระบวนการภายใน และการเรียนรู้และการเติบโต — ให้เข้ากับองค์กรที่บรรทัดสุดท้ายคือพันธกิจ ไม่ใช่กำไรส่วนเกิน บังคับให้หน่วยงานรัฐรายงานผลงานข้ามหลายมิติที่ลดทอนไม่ได้พร้อมกัน แทนที่จะยุบทุกอย่างเป็นตัวเลขเดียวที่ซ่อนการแลกเปลี่ยน

## เหตุใดจึงสำคัญ

ข้อโต้แย้งเดิมของแคปแลนและนอร์ตันใน Harvard Business Review คือ ตัวชี้วัดทางการเงินตัวเดียวเป็นตัวชี้วัดตามที่ไม่บอกอะไรเกี่ยวกับ *เหตุใด* ผลงานจะเปลี่ยนในไตรมาสหน้า ในภาคเอกชน การแก้ไขคือสี่มุมมองที่เชื่อมโยงกัน ในภาครัฐ "สามเหลี่ยมเชิงยุทธศาสตร์" ของมาร์ก มัวร์ (จาก *Creating Public Value*, 1995) ให้โครงสร้างที่เทียบเท่า: บริการต้องส่งมอบ **คุณค่าสาธารณะ** (ผลลัพธ์ตามพันธกิจ) พร้อมกับรักษา **ความชอบธรรมและการสนับสนุน** (การหนุนหลังทางการเมืองและสาธารณะ) และ **ดำเนินการได้ในเชิงปฏิบัติการ** (ส่งมอบได้ด้วยทรัพยากรและขีดความสามารถที่มีอยู่จริง) *Balanced Scorecard: Step-by-Step for Government and Nonprofit Agencies* (2003) ของพอล นิเวน (Paul Niven) เป็นคู่มือของผู้ปฏิบัติในการแปลสี่กล่องของแคปแลนและนอร์ตันเป็นสามเหลี่ยมนี้ — โดยทั่วไปเปลี่ยนป้าย "การเงิน" เป็น "การบริหารทรัพยากรอย่างผู้ดูแล" วาง "พันธกิจ" ไว้ด้านบนแทน "มูลค่าผู้ถือหุ้น" ที่ด้านล่าง และปฏิบัติต่อมุมมองลูกค้าและผู้มีส่วนได้ส่วนเสียเท่าเทียมกัน แทนที่จะรองจากกำไร เหตุผลที่เรื่องนี้สำคัญต่อทีมส่งมอบคือ บริการดิจิทัลภาครัฐที่ตัดสินจากตัวชี้วัดทางการเงินหรือประสิทธิภาพเพียงอย่างเดียว (เช่น ต้นทุนต่อธุรกรรม) จะลงทุนน้อยเกินไปอย่างเป็นระบบในมิติความชอบธรรมและผลลัพธ์ที่ตัวชี้วัดทางการเงินมองไม่เห็น

## คณิตศาสตร์

บัตรคะแนนคุณค่าสาธารณะเป็นกรอบแนวคิด ไม่ใช่สูตร แต่โครงสร้างของมันตายตัวและควรทำซ้ำให้ตรงตามนี้:

```
มุมมอง                 คำถามของภาครัฐ                            ตัวอย่างตัวชี้วัด
--------------------------------------------------------------------------------
พันธกิจ / ผลลัพธ์       เรากำลังบรรลุคุณค่าสาธารณะที่เรามีอยู่      มาตรวัดผลลัพธ์ระดับประชากร
                        เพื่อสร้างหรือไม่?                        (ดู outcomes-vs-outputs)
การบริหารทรัพยากร       เราใช้เงินสาธารณะอย่างมีประสิทธิภาพ      ต้นทุนต่อผลลัพธ์ ส่วนต่างงบประมาณ
                        และอยู่ในขอบเขตที่ได้รับอนุญาตหรือไม่?
ลูกค้า / ผู้ใช้          ผู้ใช้และประชาชนเข้าถึงและได้รับ          อัตราความสำเร็จ ความพึงพอใจ

ความชอบธรรม / การสนับสนุน ผู้มีอำนาจทางการเมือง หน่วยกำกับดูแล      ตัวชี้วัดความไว้วางใจ ผลการตรวจสอบ
                        และสาธารณชนยังหนุนหลังเราอยู่หรือไม่?     ข้อร้องเรียนที่ยืนยัน
กระบวนการภายใน / การเรียนรู้ เรามีขีดความสามารถและกระบวนการ         การลาออกของบุคลากร รอบเวลา

เล่นแร่แปรธาตุมุมมองเดียวไม่ได้โดยไม่มีความเสียหายปรากฏในมุมมองอื่น
```

## ตัวอย่างการคำนวณ

**แผนกบริการสังคมผู้ใหญ่ของหน่วยงานท้องถิ่น**: บัตรคะแนนสำหรับบริการฟื้นฟูสมรรถภาพ (การสนับสนุนระยะสั้นเพื่อช่วยให้ผู้คนกลับมาพึ่งพาตนเองได้หลังพักรักษาตัวในโรงพยาบาล) รายงาน:

```
พันธกิจ:        68% ของผู้ใช้บริการไม่ต้องการการดูแลต่อเนื่องอีกหลัง 6 สัปดาห์ (เป้า 65%)
การบริหารทรัพยากร: ต้นทุนต่อช่วงฟื้นฟูที่เสร็จสิ้น = 1,850 ปอนด์ (สมมติฐานงบประมาณ 2,000 ปอนด์)
ลูกค้า:         ความพึงพอใจผู้ใช้ 82% เวลารอเฉลี่ยก่อนเริ่มบริการ 4.1 วัน
ความชอบธรรม:    ข้อร้องเรียนที่ยืนยัน 3 รายการต่อ 1,000 ช่วง; คณะกรรมการคุ้มครองผู้ใหญ่
                จัดอันดับบริการ "ดี"
กระบวนการ:     อัตราตำแหน่งว่างของบุคลากร 14% ปริมาณงานต่อคนเฉลี่ย 23 (เพดานปริมาณงานปลอดภัย: 25)
```

เมื่ออ่านโดด ๆ ตัวเลขพันธกิจและการบริหารทรัพยากรดูเป็นเรื่องความสำเร็จตรงไปตรงมา: ต่ำกว่างบและสูงกว่าเป้าผลลัพธ์ เมื่ออ่านร่วมกับแถวกระบวนการ อัตราตำแหน่งว่าง 14% เทียบกับเพดานปริมาณงาน 25 แสดงว่าผลลัพธ์ที่ดีถูกซื้อด้วยการดำเนินงานใกล้ระดับบุคลากรที่ไม่ปลอดภัย — คำเตือนที่ตัวเลขพันธกิจอย่างเดียวไม่มีทางเผยให้เห็น และเป็นรูปแบบความล้มเหลวพอดีที่ KPI มุมมองเดียว (ดู [ตัวชี้วัดผลงานหลักของภาครัฐ](../ตัวชี้วัดผลงานหลักของภาครัฐ/)) เชิญชวนให้เกิด

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

สำหรับทีมที่สร้างแดชบอร์ดภายในหรือสาธารณะ บัตรคะแนนเป็นข้อโต้แย้งโดยตรงต่อวิดเจ็ต "คะแนนสุขภาพ" เดียว: สร้างหนึ่งแผงต่อมุมมอง และต้านแรงกดดันของผลิตภัณฑ์ที่จะสังเคราะห์เป็นไฟจราจร เพราะขั้นตอนการสังเคราะห์คือจุดที่ข้อมูลการแลกเปลี่ยนถูกทำลาย ยังแมปได้อย่างสะอาดกับโครงสร้าง OKR ของทีมผลิตภัณฑ์: OKR พันธกิจที่ไม่มี OKR การบริหารทรัพยากรหรือกระบวนการจับคู่ทำซ้ำรูปแบบความล้มเหลวของตัวชี้วัดเดียวที่แคปแลนและนอร์ตันเขียนต่อต้านในปี 1992 ดู [คุณค่าสาธารณะ](../คุณค่าสาธารณะ/) สำหรับทฤษฎีเบื้องหลังของมัวร์ว่ากล่อง "พันธกิจ" ควรมีอะไรจริง ๆ และ [ตัวชี้วัดความไว้วางใจและความชอบธรรม](../ตัวชี้วัดความไว้วางใจและความชอบธรรม/) สำหรับวิธีเติมมุมมองความชอบธรรมด้วยตัวชี้วัดจริงที่มีแหล่งที่มา แทนตัวแทนที่ไม่มีใครป้องกันได้

## ข้อผิดพลาดที่พบบ่อย

- **ยุบบัตรคะแนนเป็นคะแนนเดียว**: การเฉลี่ยสี่มุมมองเป็นตัวเลขเดียวนำปัญหาเดิมกลับมา — คะแนนความชอบธรรมแย่ที่ถูกบังด้วยคะแนนการบริหารทรัพยากรที่ดี — ซึ่งบัตรคะแนนมีไว้ป้องกัน
- **คัดลอกมุมมอง "การเงิน" ของภาคเอกชนโดยไม่เปลี่ยน**: มุมมองการบริหารทรัพยากรของหน่วยงานรัฐเกี่ยวกับการอยู่ในงบประมาณที่ได้รับอนุญาต ซึ่งมักถูกกันไว้เฉพาะ ไม่ใช่การเพิ่มรายได้สูงสุด — การเปลี่ยนป้ายของนิเวนไม่ใช่เรื่องผิวเผิน
- **เลือกตัวชี้วัดที่ทีมเจ้าของบัตรคะแนนขยับได้ฝ่ายเดียว**: ตัวชี้วัดความชอบธรรมที่มาจากทีมเดียวกับที่มันตัดสิน (เช่น การจัดการข้อร้องเรียนที่รายงานเอง) ไม่ใช่หลักฐานอิสระ
- **สร้างบัตรคะแนนครั้งเดียวและไม่เคยทบทวนน้ำหนักหรือตัวชี้วัด**: แคปแลนและนอร์ตันตั้งใจให้ทบทวนยุทธศาสตร์รายปี บัตรคะแนนที่แช่แข็งหลายปีเบี่ยงออกจากพันธกิจที่สร้างมาเพื่อติดตาม
