# การบัญชีทุนธรรมชาติ

การบัญชีทุนธรรมชาติวางสิ่งแวดล้อมบนพื้นฐานเดียวกับทรัพย์สินระดับชาติหรือองค์กรอื่น ๆ: วัดสต็อกทรัพยากรธรรมชาติ (ป่าไม้ ดิน แม่น้ำ พื้นที่ชุ่มน้ำ ชั้นบรรยากาศ) และกระแสบริการที่ทรัพยากรเหล่านั้นผลิต (การดูดซับคาร์บอน การป้องกันน้ำท่วม นันทนาการ อาหาร) ทั้งในรูปกายภาพและตัวเงิน เพื่อให้การเสื่อมโทรมของสิ่งแวดล้อมปรากฏในการตัดสินใจเหมือนที่การใช้ทุนการเงินจนหมดจะปรากฏ สหราชอาณาจักรเป็นหนึ่งในรัฐบาลที่ก้าวหน้าที่สุดในการทำเช่นนี้อย่างเป็นระบบ ขับเคลื่อนโดย 25 Year Environment Plan (2018) และปฏิบัติผ่านบัญชีทุนธรรมชาติสหราชอาณาจักรของ ONS และแนวทางเสริม Green Book ของ HM Treasury

## เหตุใดจึงสำคัญ

การบัญชีแบบดั้งเดิม — ทั้งของบริษัทและรัฐบาล — ถือว่าป่าไม้ไร้มูลค่าจนกว่าจะถูกโค่นและขายเป็นไม้ซุง ซึ่งเมื่อนั้นกลายเป็น GDP การบัญชีทุนธรรมชาติมีอยู่เพื่อปิดช่องว่างนั้น: 25 Year Environment Plan ของสหราชอาณาจักรผูกพันรัฐบาลให้ฝังแนวคิดทุนธรรมชาติทั่วนโยบาย โดยระบุความทะเยอทะยานชัดเจนว่าจะเป็น "คนรุ่นแรกที่ทิ้งสิ่งแวดล้อมไว้ในสภาพที่ดีกว่าที่เราพบ" ONS เผยแพร่บัญชีทุนธรรมชาติสหราชอาณาจักรรายปีตั้งแต่นั้น (<https://www.ons.gov.uk/economy/environmentalaccounts/bulletins/uknaturalcapitalaccounts/latest>) ซึ่งประมาณมูลค่าเป็นตัวเงินของบริการระบบนิเวศ — ตั้งแต่นันทนาการในป่าไม้ ผลประโยชน์ด้านสุขภาพของพื้นที่สีเขียวในเมือง ไปจนถึงการกักเก็บคาร์บอนของพรุ — โดยใช้กรอบบัญชีประชาชาติเดียวกับที่ใช้กับทุนที่ผลิตขึ้น เพื่อให้ทุนธรรมชาติอยู่ในงบดุลเดียวกับถนน อาคาร และอุปกรณ์ในที่สุด แนวทาง Enabling a Natural Capital Approach (ENCA) ของ HM Treasury ซึ่งเป็นส่วนเสริมของ Green Book (<https://www.gov.uk/government/publications/enabling-a-natural-capital-approach-enca-guidance>) กำหนดว่าผู้ประเมินควรประเมินมูลค่าต้นทุนและประโยชน์ด้านสิ่งแวดล้อมในกรณีทางธุรกิจอย่างไร เพื่อให้โครงการถนนที่ทำลายป่าไม้โบราณหรือโครงการน้ำท่วมที่ฟื้นฟูพื้นที่ชุ่มน้ำเปรียบเทียบกันได้ในเงื่อนไขตัวเงินที่สอดคล้อง แทนที่จะมีอันหนึ่งเป็นตัวเลขและอีกอันเป็นย่อหน้าของข้อควรระวัง

## คณิตศาสตร์

```
มูลค่าสินทรัพย์บริการระบบนิเวศ = NPV ของกระแสบริการที่สินทรัพย์ให้

มูลค่าสินทรัพย์ = Σ (t = 1 ถึง T) [มูลค่ากระแสบริการรายปี_t / (1 + r)^t]

โดยที่:
  มูลค่ากระแสบริการ_t = ปริมาณบริการในปี t × มูลค่าต่อหน่วย
                        (เช่น การเยี่ยมชมเพื่อนันทนาการ × มูลค่าต่อการเยี่ยมชม;
                         ตันคาร์บอนที่ดูดซับ × ราคาคาร์บอน)
  r = อัตราคิดลด (อัตราคิดลดทางสังคมของ Green Book — ดู
      [อัตราคิดลดทางสังคม](../อัตราคิดลดทางสังคม/))
  T = ขอบเขตเวลาที่สินทรัพย์คาดว่าจะให้บริการ
```

นี่คือโครงสร้างมูลค่าปัจจุบันสุทธิเดียวกันกับที่ใช้ประเมินมูลค่าทุนที่ผลิตขึ้นหรือประเมินการลงทุนสาธารณะใด ๆ ภายใต้ [การประเมินตาม Green Book (แบบจำลองห้ากรณี)](../การประเมินตาม-green-book/) — สิ่งที่การบัญชีทุนธรรมชาติมีส่วนร่วมคือการให้ปริมาณกายภาพและมูลค่าต่อหน่วยที่น่าเชื่อถือสำหรับบริการที่ก่อนหน้านี้ถูกตีราคาเป็นศูนย์

## ตัวอย่างการคำนวณ

**ป่าไม้ในเมือง มูลค่าด้านนันทนาการ**: ป่าไม้ 50 เฮกตาร์ได้รับการเยี่ยมชมเพื่อนันทนาการประมาณ 80,000 ครั้งต่อปี แต่ละครั้งประเมิน (ด้วยวิธีต้นทุนการเดินทางหรือวิธีความพึงพอใจที่แถลง — ดู [การประเมินมูลค่าจากความพึงพอใจที่เปิดเผย](../การประเมินมูลค่าจากความพึงพอใจที่เปิดเผย/) และ [การประเมินมูลค่าจากความพึงพอใจที่แถลง](../การประเมินมูลค่าจากความพึงพอใจที่แถลง/)) ที่ 3 ปอนด์ต่อการเยี่ยมชม ป่าคาดว่าจะให้บริการนี้ต่อไป 50 ปี ประเมินที่อัตราคิดลด 3.5%

```
มูลค่านันทนาการรายปี = 80,000 × 3 ปอนด์ = 240,000 ปอนด์/ปี

NPV ตลอด 50 ปีที่ 3.5% ≈ 240,000 ปอนด์ × ตัวประกอบเงินงวด(3.5%, 50 ปี)
ตัวประกอบเงินงวด(3.5%, 50) ≈ 21.4

มูลค่าสินทรัพย์ ≈ 240,000 × 21.4 ≈ 5,136,000 ปอนด์
```

**เพิ่มการกักเก็บคาร์บอน**: ป่าเดียวกันดูดซับ CO2 ประมาณ 400 ตันต่อปี ประเมินที่ราคาคาร์บอนนอกระบบซื้อขายของรัฐบาลราว 75 ปอนด์/ตัน (เพื่อการอธิบาย — ใช้มูลค่าคาร์บอนที่ BEIS/DESNZ เผยแพร่ล่าสุดสำหรับการประเมินจริง)

```
มูลค่าคาร์บอนรายปี = 400 × 75 ปอนด์ = 30,000 ปอนด์/ปี
NPV ตลอด 50 ปีที่ 3.5% ≈ 30,000 × 21.4 ≈ 642,000 ปอนด์

มูลค่าสินทรัพย์ป่ารวม (นันทนาการ + คาร์บอน) ≈ 5,136,000 + 642,000
                                              ≈ 5,778,000 ปอนด์
```

นี่ยังไม่รวมการหน่วงน้ำท่วม ความหลากหลายทางชีวภาพ หรือบริการคุณภาพอากาศที่แนวทาง ENCA ขอให้ผู้ประเมินพิจารณาเช่นกัน — ยอดรวมเป็นพื้นขั้นต่ำโดยเจตนา ไม่ใช่เพดาน

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

- ระบบสิ่งแวดล้อมและบริหารสินทรัพย์ของหน่วยงานท้องถิ่นและหน่วยงานรัฐ (สวนสาธารณะ ทางหลวง แหล่งน้ำ) สามารถแนบทะเบียนทุนธรรมชาติควบคู่กับทะเบียนสินทรัพย์กายภาพ โดยใช้รูปแบบกระแสบริการคูณมูลค่าต่อหน่วยเดียวกับ [ฐานข้อมูลต้นทุนต่อหน่วย](../ฐานข้อมูลต้นทุนต่อหน่วย/) อื่นใดที่องค์กรดูแล
- เนื่องจาก NPV ของทุนธรรมชาติไวต่ออัตราคิดลด (ดูตัวประกอบเงินงวดในตัวอย่าง) เครื่องมือใดที่คำนวณควรเปิดเผยอัตราและขอบเขตเวลาเป็นปัจจัยนำเข้าที่มองเห็นได้ ไม่ใช่ฝังไว้ — หลักความโปร่งใสเดียวกันที่ครอบคลุมใน [ความเป็นธรรมระหว่างรุ่นและการคิดลดเพื่อความยั่งยืน](../ความเป็นธรรมระหว่างรุ่นและการคิดลดเพื่อความยั่งยืน/)
- บัญชีทุนธรรมชาติเป็นปัจจัยนำเข้าที่ต้องมีมากขึ้นสำหรับส่วนผลกระทบต่อสิ่งแวดล้อมของกรณีทางธุรกิจ [การประเมินตาม Green Book (แบบจำลองห้ากรณี)](../การประเมินตาม-green-book/) ทีมส่งมอบที่สร้างเครื่องมือกรณีทางธุรกิจควรถือบัญชี ONS และมูลค่าต่อหน่วยของ ENCA เป็นข้อมูลอ้างอิงที่ต้องบูรณาการ ไม่ใช่สิ่งที่ผู้ประเมินคำนวณใหม่ตั้งแต่ต้นทุกครั้ง

## ข้อผิดพลาดที่พบบ่อย

- **นับบริการระบบนิเวศที่ซ้อนทับกันซ้ำ** — มูลค่านันทนาการและมูลค่าความหลากหลายทางชีวภาพของที่เดียวกันอาจใช้ข้อมูลความเต็มใจจ่ายพื้นฐานร่วมกัน แนวทาง ENCA เตือนชัดเจนไม่ให้รวมมูลค่าที่ได้จากเครื่องมือสำรวจที่ซ้อนทับกัน
- **ถือว่ามูลค่าสินทรัพย์ทุนธรรมชาติเป็นสถิต** — กระแสบริการเปลี่ยนตามสภาพภูมิอากาศ การจัดการ และแรงกดดันการใช้ที่ดิน มูลค่าคาร์บอนและการหน่วงน้ำท่วมของป่าในทศวรรษนี้ไม่ใช่คุณสมบัติถาวรของที่นั้น
- **ใช้มูลค่าต่อหน่วยเฉลี่ยระดับชาติกับการตัดสินใจที่เป็นท้องถิ่นมาก** — ป่าในเมืองที่เข้าถึงได้หนึ่งเฮกตาร์กับที่สูงห่างไกลหนึ่งเฮกตาร์มีมูลค่านันทนาการต่างกันมาก แนวทาง ENCA แนะนำให้ใช้มูลค่าเฉพาะท้องถิ่นหรือเฉพาะพื้นที่เมื่อมี แทนที่จะใช้ค่าเฉลี่ยระดับชาติเป็นค่าเริ่มต้น
