# ฐานข้อมูลต้นทุนต่อหน่วย

ฐานข้อมูลต้นทุนต่อหน่วยคือคลังตัวแทนทางการเงินที่วิจัยไว้ล่วงหน้าและอิงหลักฐานสำหรับผลลัพธ์ทางสังคม — มูลค่าของการเปลี่ยนจากว่างงานเป็นมีงานทำ ของความเหงาที่ลดลง ของการเช่าที่อยู่อาศัยที่มั่นคง — ซึ่งช่วยให้ผู้ปฏิบัติแปลงผลลัพธ์เป็นตัวเงินได้โดยไม่ต้องว่าจ้างงานวิจัยประเมินมูลค่าเฉพาะทุกครั้ง มีไว้เพื่อให้องค์กรการกุศลเล็ก ๆ ที่เขียนข้อเสนอขอทุนใช้ความเข้มงวดเดียวกับบริษัทที่ปรึกษาที่มีทรัพยากรพร้อม โดยนำตัวแทนที่คนอื่นหาไว้และเผยแพร่แล้วมาใช้ซ้ำ

## เหตุใดจึงสำคัญ

UK Social Value Bank ของ HACT พัฒนาร่วมกับนักเศรษฐศาสตร์ แดเนียล ฟูจิวารา (Daniel Fujiwara) โดยใช้วิธีประเมินมูลค่าความเป็นอยู่ที่ดี และ Global Value Exchange ฐานข้อมูลเปิดที่ผู้คนร่วมกันสร้างของตัวแทนทางการเงิน เป็นสองแห่งที่ใช้กันกว้างขวางที่สุดในภาคที่สามและภาครัฐของสหราชอาณาจักร ทั้งสองมีอยู่เพราะงานประเมินมูลค่าเบื้องหลัง — [การประเมินมูลค่าความเป็นอยู่ที่ดี](../การประเมินมูลค่าความอยู่ดีมีสุข/) และ [การประเมินมูลค่าจากความพึงพอใจที่แสดงออก](../การประเมินมูลค่าจากความพึงพอใจที่แถลง/) — มีราคาแพง ต้องการวิธีวิทยาเข้มงวด และช้าหากทำจากศูนย์ทุกโครงการ คลังตัวแทนที่เผยแพร่ร่วมกันเปลี่ยนสิ่งที่ควรเป็นงานวิจัยหลายเดือนให้เป็นการค้นหา ซึ่งเป็นเหตุผลที่สำคัญต่อทั้งการคำนวณ [ผลตอบแทนทางสังคมจากการลงทุน](../ผลตอบแทนทางสังคมจากการลงทุน/) และการประเมินข้อเสนอตาม [พระราชบัญญัติคุณค่าทางสังคม](../พระราชบัญญัติคุณค่าทางสังคม/): หากไม่มี การแปลงเป็นตัวเงินอย่างเข้มงวดจะทำได้เฉพาะองค์กรที่ใหญ่พอจะว่าจ้างการศึกษาของตนเอง

## คณิตศาสตร์

ฐานข้อมูลต้นทุนต่อหน่วยไม่ได้คำนวณอะไรเอง แต่ให้ปัจจัยนำเข้าหนึ่งอย่างแก่การคำนวณที่ทำที่อื่น:

```
ค่าตัวแทนทางการเงิน = ราคาตลาด หรือ ราคาเงา หรือ การประเมินมูลค่าความเป็นอยู่ที่ดี
                      หรือ ค่าจากความพึงพอใจที่แสดงออก
                      สำหรับหน่วยของการเปลี่ยนแปลงผลลัพธ์ที่นิยามไว้
                      (เช่น "ต่อคนที่เปลี่ยนจากว่างงานเป็นมีงานทำ ต่อปี")

ค่าที่นำไปใช้ = จำนวนผลลัพธ์ที่ได้ × ค่าตัวแทนต่อหน่วย
```

ดู [การกำหนดราคาเงา](../การกำหนดราคาเงา/) ว่าสร้างตัวแทนอย่างไรเมื่อไม่มีราคาตลาด และ [ผลตอบแทนทางสังคมจากการลงทุน](../ผลตอบแทนทางสังคมจากการลงทุน/) ว่าค่าที่นำไปใช้ป้อนเข้าอัตราส่วนอย่างไรหลังการปรับเรื่องสิ่งที่จะเกิดขึ้นอยู่แล้วและการระบุที่มา

## ตัวอย่างการคำนวณ

**องค์กรการกุศล (SROI ของบริการเพื่อนเยี่ยม)**: รายการในฐานข้อมูลต้นทุนต่อหน่วยสำหรับ "ความเหงาที่ลดลง" ให้ตัวแทนตัวอย่าง 1,100 ปอนด์ต่อคนต่อปี เมื่อใช้กับผู้รับประโยชน์ 80 คน: 80 × 1,100 ปอนด์ = 88,000 ปอนด์มูลค่ารวม หากฐานข้อมูลเดียวกันมีตัวแทนสำหรับ "สุขภาพจิตที่ดีขึ้น" ซึ่งอิงข้อคำถามแบบสำรวจความเป็นอยู่ที่ดีที่ซ้อนทับกัน การรวมตัวแทนทั้งสองสำหรับ 80 คนเดียวกันจะนับซ้ำส่วนหนึ่งของการเปลี่ยนแปลงพื้นฐานเดียวกัน — ฐานข้อมูลให้ตัวเลข แต่การหลีกเลี่ยงการซ้อนทับนี้เป็นความรับผิดชอบของนักวิเคราะห์

**หน่วยงานท้องถิ่น (SROI ของชมรมหางาน)**: รายการในฐานข้อมูลต้นทุนต่อหน่วยสำหรับ "การเปลี่ยนจากว่างงานเป็นการมีงานทำอย่างต่อเนื่อง" ใช้กับผู้เข้าร่วม 45 คนที่ตัวแทนตัวอย่าง 8,500 ปอนด์ต่อคนต่อปี: 45 × 8,500 ปอนด์ = 382,500 ปอนด์มูลค่ารวม ก่อนการปรับเรื่องสิ่งที่จะเกิดขึ้นอยู่แล้วและการระบุที่มาที่แสดงใน [ผลตอบแทนทางสังคมจากการลงทุน](../ผลตอบแทนทางสังคมจากการลงทุน/)

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

ทีมที่สร้างเครื่องมือรายงานสำหรับองค์กรการกุศลหรือผู้ว่าจ้างได้ประโยชน์จาก "แคตตาล็อกผลลัพธ์" ภายใน — ตารางที่แมปแต่ละผลลัพธ์ที่ผลิตภัณฑ์หรือบริการอ้างได้อย่างสมเหตุสมผลเข้ากับตัวแทนที่มีชื่อ ฐานข้อมูลต้นทาง วันที่เผยแพร่ และตัวระบุเวอร์ชัน — เพื่อให้ทีมต่าง ๆ ในองค์กรไม่เลือกค่าที่แตกต่างกันเล็กน้อยสำหรับผลลัพธ์เดียวกัน การห่อข้อมูลเปิดของ Global Value Exchange ไว้หลังบริการค้นหา โดยแสดงแหล่งที่มาและวันที่ไว้ข้างตัวเลขเสมอ ทำให้ตัวแทนตรวจสอบได้แทนที่จะเป็นตัวเลขวิเศษที่ฝังในสเปรดชีต ดู [ผลตอบแทนทางสังคมจากการลงทุน](../ผลตอบแทนทางสังคมจากการลงทุน/) และ [พระราชบัญญัติคุณค่าทางสังคม](../พระราชบัญญัติคุณค่าทางสังคม/) สำหรับสองที่หลักที่ใช้ตัวแทนเหล่านี้

## ข้อผิดพลาดที่พบบ่อย

- **ถือว่าตัวแทนแม่นยำ** ตัวแทนที่เผยแพร่ส่วนใหญ่เป็นค่าเฉลี่ยจากแบบจำลองของการศึกษาประเมินมูลค่าความเป็นอยู่ที่ดีที่มีช่วงความเชื่อมั่นกว้าง การอ้างถึงระดับปอนด์เกินกว่าความแม่นยำที่งานวิจัยรองรับ
- **นับซ้ำตัวแทนที่ซ้อนทับ** การรวมตัวแทน (เช่น "ความเหงาที่ลดลง" และ "สุขภาพจิตที่ดีขึ้น") ที่มาจากโครงสร้างแบบสำรวจที่ซ้อนทับกันประเมินมูลค่าการเปลี่ยนแปลงพื้นฐานเดียวกันสองครั้ง
- **ใช้ตัวแทนนอกบริบทโดยไม่ปรับ** ตัวแทนที่ปรับเทียบกับประชากรและปีหนึ่ง เมื่อนำไปใช้ที่อื่นโดยไม่ปรับเงินเฟ้อหรือบริบท ระบุมูลค่าผิดอย่างเงียบ ๆ
- **ไม่ตรวจสอบที่มา** Global Value Exchange เปิดและผู้คนร่วมสร้าง คุณภาพของรายการจึงแตกต่างตามผู้ร่วมสร้าง ตรวจแหล่งต้นทางก่อนอ้างตัวเลขในข้อเสนอขอทุนหรือการยื่นจัดซื้อ
