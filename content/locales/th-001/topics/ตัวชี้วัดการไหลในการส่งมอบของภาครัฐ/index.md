# ตัวชี้วัดการไหลในการส่งมอบของภาครัฐ

ตัวชี้วัดการไหล (flow metrics) — กฎของลิตเติล (Little's Law) ขีดจำกัดงานที่กำลังทำ (WIP) และประสิทธิภาพการไหล — อธิบายว่างานเคลื่อนผ่านระบบที่มีกำลังจำกัดได้เร็วเพียงใด กระดานสปรินต์เป็นระบบหนึ่งเช่นนั้น; คิวคำขอสวัสดิการ ทะเบียนคำขออนุญาตก่อสร้าง หรือคิวงานค้างของคดีวีซ่า คือคณิตศาสตร์เดียวกันที่สวมเครื่องแบบต่างกัน

## เหตุใดจึงสำคัญ

ปริมาณคดีของภาครัฐคือระบบคิว และระบบคิวทำตามกฎของคิวไม่ว่าจะมีใครวัดหรือไม่ ระยะเวลาพิจารณาตามกฎหมายทำให้ชัดเจน: ภายใต้ระบอบ Town and Country Planning คำขออนุญาตก่อสร้างขนาดเล็กส่วนใหญ่มีเป้าหมายพิจารณา 8 สัปดาห์ตามกฎหมายและคำขอขนาดใหญ่ 13 สัปดาห์ — ข้อผูกพันด้านรอบเวลาที่ถูกฝังไว้ในกฎหมายโดยตรง งานค้างของคดีขอลี้ภัยที่ Home Office ซึ่ง National Audit Office และ Home Affairs Select Committee ตรวจสอบซ้ำแล้วซ้ำเล่า เป็นกรณีที่บันทึกไว้ดีของระบบสาธารณะที่งานที่กำลังทำเติบโตเร็วกว่าปริมาณงานที่สำเร็จเป็นเวลานาน ผลักรอบเวลาให้เกินความคาดหวังตามกฎหมายหรือบริการไปไกล ตัวชี้วัดการไหลให้ทั้งวิศวกรและผู้จัดการงานคดีมีคำศัพท์เชิงปริมาณร่วมกันสำหรับรูปแบบความล้มเหลวนี้ แทนที่จะปล่อยให้เป็น "ปัญหางานค้าง" เชิงคุณภาพ

## คณิตศาสตร์

```
กฎของลิตเติล:  WIP = ปริมาณงานที่สำเร็จ × รอบเวลา
           →   รอบเวลา = WIP / ปริมาณงานที่สำเร็จ

ประสิทธิภาพการไหล = เวลาทำงานจริง (สัมผัสงาน) / รอบเวลารวม   (Vacanti)

ผลของขีดจำกัด WIP: เมื่อปริมาณงานที่สำเร็จคงที่ การลด WIP ลงครึ่งหนึ่งจะลด
รอบเวลาเฉลี่ยลงประมาณครึ่งหนึ่ง (กฎของลิตเติลจัดรูปใหม่) — คันโยก
ที่มีโดยไม่ต้องเพิ่มกำลังคน
```

ดู [ตัวชี้วัด DORA เพื่อคุณค่าสาธารณะ](../ตัวชี้วัด-dora-เพื่อคุณค่าสาธารณะ/) สำหรับคณิตศาสตร์เทียบเท่าที่ใช้กับไปป์ไลน์การ deploy ซอฟต์แวร์แทนงานคดี

## ตัวอย่างการคำนวณ

**แผนกผังเมืองของหน่วยงานท้องถิ่น**: มีคำขอเปิดอยู่ 400 รายการตลอดเวลา (WIP) ทีมพิจารณาเสร็จ 50 รายการ/สัปดาห์ (ปริมาณงานที่สำเร็จ)

```
รอบเวลา = WIP / ปริมาณงานที่สำเร็จ = 400 / 50 = 8 สัปดาห์
```

ตกพอดีที่เป้าหมายตามกฎหมาย 8 สัปดาห์สำหรับคำขอขนาดเล็ก — โดยไม่มีส่วนเผื่อเลย หมายความว่าความผันแปรใด ๆ ในอุปสงค์ที่เข้ามาหรือเวลาตอบของผู้ให้ความเห็นจะผลักการพิจารณาเกินกำหนดเวลาตามกฎหมาย

**ประสิทธิภาพการไหล**: จาก 8 สัปดาห์นั้น (56 วันตามปฏิทิน) คำขอหนึ่งมักมีเวลาประมวลผลจริงโดยเจ้าหน้าที่ประมาณ 6 ชั่วโมง

```
ประสิทธิภาพการไหล = 6 ชั่วโมง / (56 วัน × 8 ชั่วโมงทำงาน/วัน)
                  = 6 / 448 ≈ 1.3%
```

เกณฑ์ของ Vacanti สำหรับทีมซอฟต์แวร์ระบุประสิทธิภาพการไหลทั่วไปที่ 15–20%; งานคดีภาครัฐ ซึ่งมีการส่งต่อผู้ให้ความเห็นตามกฎหมายหลายราย และช่วงรับฟังความเห็นสาธารณะ มักต่ำกว่าหนึ่งอันดับขนาด 98.7% ของเวลา "รอ" คือที่ที่แปดสัปดาห์หายไปจริง — ไม่ใช่ในกำลังของเจ้าหน้าที่

**การแทรกแซงด้วยขีดจำกัด WIP**: การจำกัดคำขอที่เปิดอยู่ต่อเจ้าหน้าที่ที่ 15 แทนที่จะไม่จำกัดที่ 25 (ถือปริมาณงานที่สำเร็จคงที่) ย้าย WIP จาก 400 เหลือประมาณ 240 ทั่วทีม 16 คน:

```
รอบเวลาใหม่ = 240 / 50 = 4.8 สัปดาห์
```

รอบเวลาลดลงเกือบครึ่งจากการเปลี่ยนนโยบาย ไม่ใช่การเพิ่มบุคลากร — คันโยกเดียวกับที่ทีมส่งมอบแบบ DORA ดึงเมื่อจำกัด WIP ของสปรินต์

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

ตัวชี้วัดการไหลคือภาษากลางระหว่างกระดานคัมบังของทีมส่งมอบกับพื้นที่ปฏิบัติงานคดีที่ทีมกำลังสร้างซอฟต์แวร์ให้: คิวของเจ้าหน้าที่และคิว pull request ถูกกำกับด้วยกฎของลิตเติลทั้งคู่ และทั้งคู่ทำลายเป้ารอบเวลาด้วยวิธีเดียวกัน — WIP มากเกินไปเมื่อเทียบกับปริมาณงานที่สำเร็จ เรื่องนี้สำคัญโดยตรงต่อ [ต้นทุนของความล่าช้าในโครงการภาครัฐ](../ต้นทุนของความล่าช้าในโครงการภาครัฐ/): รอบเวลา × CoD คือเงินปอนด์ที่นั่งรออยู่ในคิว ณ ขณะใดก็ตาม และต่อ [มาตรฐานบริการและตัวชี้วัดธุรกรรม](../มาตรฐานบริการและตัวชี้วัดธุรกรรม/) ซึ่งเป้าหมายระยะเวลาดำเนินการที่เผยแพร่คือข้อผูกพันรอบเวลาที่มีเพียงตัวชี้วัดการไหลเท่านั้นที่วินิจฉัยได้เมื่อพลาด ซอฟต์แวร์ของระบบงานคดีควรเปิดเผย WIP และรอบเวลาเป็นตัวชี้วัดเชิงปฏิบัติการชั้นหนึ่ง ไม่ใช่ฝังไว้ในระบบบริหารจัดการกรณีที่ไม่มีใครสอบถาม

## ข้อผิดพลาดที่พบบ่อย

- **เพิ่มขีดจำกัด WIP โดยไม่แก้คอขวดที่แท้จริง**: หากข้อจำกัดคือเวลาตอบของผู้ให้ความเห็นตามกฎหมายภายนอก การจำกัด WIP ของเจ้าหน้าที่เพียงย้ายคิวไปต้นน้ำแทนที่จะทำให้สั้นลง
- **ถือประสิทธิภาพการไหลเป็นเป้าหมายให้เล่นแร่แปรธาตุ**: การเร่งเวลาทำงานจริง 1.3% แทบไม่ทำให้รอบเวลาขยับ แรงส่งแทบทั้งหมดอยู่ในสถานะรอ ซึ่งมักหมายถึงการออกแบบกระบวนการใหม่ ไม่ใช่ความเร็วของเจ้าหน้าที่
- **เพิกเฉยต่อความแปรปรวน**: กฎของลิตเติลอธิบายค่าเฉลี่ย; ปริมาณคดีที่อุปสงค์แปรปรวนสูงต้องการกำลังสำรอง ไม่ใช่เพียงขีดจำกัด WIP ที่เข้มขึ้น มิฉะนั้นกำหนดเวลาตามกฎหมายจะยังพลาดที่หางที่ผันผวนแม้ค่าเฉลี่ยจะดีขึ้น
- **วัด WIP ไม่สม่ำเสมอ**: คดีที่ "เปิด" ในระบบบันทึกแต่จริง ๆ ชะงักรอบุคคลที่สามยังเป็น WIP การตัดออกทำให้ตัวเลขดูดีโดยไม่เปลี่ยนความเป็นจริงที่ประชาชนเผชิญ
