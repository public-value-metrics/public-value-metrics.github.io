# การวิเคราะห์ต้นทุนและผลประโยชน์ทางสังคม (SCBA)

การวิเคราะห์ต้นทุนและผลประโยชน์ทางสังคมแปลงทุกต้นทุนและประโยชน์ของนโยบายหรือโครงการ — ในตลาดและนอกตลาด — เป็นหน่วยเงินร่วม คิดลดกระแสในอนาคตเป็นมูลค่าปัจจุบัน และหักลบกันเพื่อให้ตัวเลขเดียว: ข้อเสนอนี้ทำให้สังคมดีขึ้นหรือไม่ และเท่าใด?

## เหตุใดจึงสำคัญ

SCBA เป็นวิธีเชิงปริมาณค่าเริ่มต้นในกรณีเชิงเศรษฐกิจของ [การประเมินตาม Green Book (แบบจำลองห้ากรณี)](../การประเมินตาม-green-book/): แนวทางของ HM Treasury กำหนดให้ข้อเสนอแสดงมูลค่าปัจจุบันสุทธิทางสังคม (NPSV) เป็นบวกทุกที่ที่ประเมินประโยชน์เป็นตัวเงินได้อย่างน่าเชื่อถือ โดยใช้ความเต็มใจจ่ายเป็นหลักการประเมินมูลค่าพื้นฐานสำหรับสินค้านอกตลาด (<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>, บทที่ 5) วินัยที่บังคับคือการวิเคราะห์ต้นทุนและผลประโยชน์ "ทางสังคม" ไม่ใช่แบบฝึกหัดเดียวกับการประเมินการลงทุนของภาคเอกชน: ต้องรวมต้นทุนและประโยชน์ที่ตกแก่บุคคลที่สามซึ่งไม่ใช่คู่สัญญาของธุรกรรม (ผลกระทบภายนอก) ต้องใช้ [อัตราคิดลดทางสังคม](../อัตราคิดลดทางสังคม/) แทนต้นทุนทุนเชิงพาณิชย์ และควรใช้ [การถ่วงน้ำหนักตามการกระจาย](../การถ่วงน้ำหนักตามการกระจาย/) เมื่อหนึ่งปอนด์มีความหมายต่อครัวเรือนที่ยากจนกว่ามากกว่าครัวเรือนที่ร่ำรวยกว่า

SCBA พังตรงที่ผู้วิจารณ์คาดไว้: สินค้าที่ไม่มีสิ่งเทียบเคียงในตลาด — อากาศสะอาด ความสามัคคีทางสังคม มูลค่าของชีวิตที่ช่วยไว้ — ต้องประเมินเป็นตัวเงินโดยใช้วิธี [ความพึงพอใจที่แถลง](../การประเมินมูลค่าจากความพึงพอใจที่แถลง/) หรือ [ความพึงพอใจที่เปิดเผย](../การประเมินมูลค่าจากความพึงพอใจที่เปิดเผย/) หรือต้องสร้าง [ราคาเงา](../การกำหนดราคาเงา/) เมื่อการประเมินเป็นตัวเงินเป็นที่โต้แย้งมากกว่าเพียงแค่ยาก Green Book เองแนะนำให้ถอยไปใช้ [การวิเคราะห์ต้นทุนประสิทธิผล](../การวิเคราะห์ต้นทุนประสิทธิผลในภาครัฐ/) หรือ [การวิเคราะห์การตัดสินใจหลายเกณฑ์](../การวิเคราะห์การตัดสินใจหลายเกณฑ์/) แทนที่จะบังคับตัวเลขที่ไม่มีใครเชื่อ

## คณิตศาสตร์

```
NPSV = Σ [t=0 ถึง T] (ประโยชน์_t − ต้นทุน_t) / (1 + r)^t

โดยที่:
  ประโยชน์_t = ประโยชน์ทั้งหมดที่ประเมินเป็นตัวเงินในปี t รวมสินค้านอกตลาด
               ที่ประเมินด้วยความพึงพอใจที่แถลง/เปิดเผยหรือราคาเงา
  ต้นทุน_t   = ต้นทุนทั้งหมดที่ประเมินเป็นตัวเงินในปี t รวมต้นทุนค่าเสียโอกาส
               ของทรัพยากร (ดู ../opportunity-cost-in-public-spending/)
  r          = อัตราคิดลดทางสังคม (HM Treasury กำหนด 3.5% ลดลงเป็น
               อัตราต่ำกว่าเกินปีที่ 30 ตาม Annex A ของ Green Book)
  T          = ช่วงเวลาประเมิน

อัตราส่วนประโยชน์ต่อต้นทุน (BCR) = Σ PV(ประโยชน์) / Σ PV(ต้นทุน)
```

BCR สูงกว่า 1 (หรือ NPSV สูงกว่าศูนย์) บ่งชี้มูลค่าทางสังคมสุทธิ ประเภทความคุ้มค่าของเงินของ Green Book (ที่ใช้ในการประเมินการขนส่งและโครงสร้างพื้นฐาน) กำกับช่วง BCR: ต่ำกว่า 1.0 คือความคุ้มค่าต่ำ 1.0–1.5 คือต่ำ 1.5–2.0 คือปานกลาง 2.0–4.0 คือสูง และสูงกว่า 4.0 คือสูงมาก การวิเคราะห์ความไว — การรัน NPSV ใหม่ภายใต้สมมติฐานมองโลกในแง่ร้ายและแง่ดี — เป็นข้อบังคับ ไม่ใช่ทางเลือก เพราะประโยชน์นอกตลาดที่ประเมินเป็นตัวเงินมีแถบความไม่แน่นอนกว้าง

## ตัวอย่างการคำนวณ

**หน่วยงานท้องถิ่น**: สภาประเมินการลงทุน 3 ล้านปอนด์ในเครือข่ายจักรยานและเดินเท้าใหม่ ในช่วงประเมิน 20 ปีที่อัตราคิดลด 3.5%

```
ต้นทุน: ทุน 3 ล้านปอนด์ในปีที่ 0 บำรุงรักษา 50,000 ปอนด์/ปี (ปีที่ 1-20)
PV(บำรุงรักษา) ≈ 50,000 × 14.2 (ตัวประกอบเงินงวด 20 ปีที่ 3.5%) ≈ 710,000 ปอนด์
PV(ต้นทุน) รวม ≈ 3.71 ล้านปอนด์

ประโยชน์ (ทั้งหมดประเมินเป็นตัวเงินด้วยเครื่องมือประเมินมูลค่าที่เผยแพร่ของ DfT/WHO):
  ประโยชน์ด้านสุขภาพจากกิจกรรมทางกายที่เพิ่มขึ้น: 180,000 ปอนด์/ปี
  การลดการขาดงาน: 40,000 ปอนด์/ปี
  ลดความแออัด (เที่ยวรถยนต์น้อยลง): 60,000 ปอนด์/ปี
  กระแสประโยชน์รวม: 280,000 ปอนด์/ปี
PV(ประโยชน์) ≈ 280,000 × 14.2 ≈ 3.98 ล้านปอนด์

NPSV = 3.98 ล้าน − 3.71 ล้าน = +0.27 ล้านปอนด์
BCR = 3.98 / 3.71 = 1.07 → ความคุ้มค่าของเงิน "ต่ำ"
```

โครงการผ่านเกณฑ์แต่เฉียดฉิว การรันความไวที่ประมาณประโยชน์ด้านสุขภาพต่ำลง 20% (สะท้อนความไม่แน่นอนที่แท้จริงในการประเมินค่ากิจกรรมทางกาย) ทำให้ BCR ต่ำกว่า 1.0 ซึ่งเป็นเหตุผลพอดีที่ Green Book กำหนดให้เผยแพร่ตารางความไวควบคู่กับตัวเลขพาดหัว ไม่ใช่เฉพาะค่าประมาณกลาง

**องค์กรการกุศล**: โครงการป้องกันการเสียชีวิตของทารกที่มีต้นทุน 500,000 ปอนด์/ปี ประเมินโดยใช้มูลค่าของชีวิตทางสถิติ (VSL) — ราคาเงา ไม่ใช่ราคาตลาดที่สังเกตได้ — ประมาณ 2.1 ล้านปอนด์ (ตัวเลขที่ปรับปรุงปี 2023 ของ HM Treasury ซึ่งเองมาจากการศึกษาความพึงพอใจที่แถลง) การป้องกันการเสียชีวิตของทารกหนึ่งรายต่อปีเทียบกับต้นทุน 500,000 ปอนด์ให้ BCR 4.2 ความคุ้มค่าของเงิน "สูงมาก" อย่างสบาย — แต่ผลทั้งหมดขึ้นกับตัวเลข VSL ซึ่งเป็นเหตุผลที่ SCBA ใด ๆ ที่ใช้ VSL ต้องเปิดเผยเป็นสมมติฐาน ไม่ใช่ข้อเท็จจริง

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

SCBA เป็นกรอบตามธรรมชาติสำหรับการตัดสินใจลงทุนแพลตฟอร์มและโครงสร้างพื้นฐานในซอฟต์แวร์ภาครัฐ — การเปรียบเทียบแพลตฟอร์มยืนยันตัวตนร่วมกับโซลูชันเฉพาะจุดของกระทรวง เช่น ต้องประเมินประโยชน์เป็นตัวเงิน เช่น ต้นทุนการลงทะเบียนซ้ำซ้อนที่ลดลง การฉ้อโกงที่ลดลง และเวลาถึงบริการที่เร็วขึ้น ซึ่งโดยตัวมันเองไม่มีราคาตลาด วิศวกรที่สร้างบริการเบื้องหลังควรคาดว่าผู้นำโครงการจะขอปัจจัยนำเข้าของการวิเคราะห์นี้: ต้นทุนต่อหน่วยของธุรกรรม (ดู [ต้นทุนต่อธุรกรรม](../ต้นทุนต่อธุรกรรม/)) ปริมาณที่คาดไว้ และต้นทุนการเสื่อมถอย/ระบบหยุดทำงาน วินัยที่สำคัญที่สุดที่ควรนำเข้า: คิดลดประโยชน์ในอนาคต ระบุฐานสภาพตรงข้ามกับข้อเท็จจริงอย่างชัดเจน (ดู [การวิเคราะห์สภาพตรงข้ามกับข้อเท็จจริง](../การวิเคราะห์สภาพตรงข้ามกับข้อเท็จจริง/)) และอย่านำเสนอค่าประมาณจุดเดียวโดยไม่มีช่วงความไวของมัน

## ข้อผิดพลาดที่พบบ่อย

- **นับประโยชน์ซ้ำ** การนับทั้ง "เวลาที่ประหยัด" และ "ผลิตภาพที่ได้จากเวลานั้น" เป็นรายการประโยชน์แยกกันทำให้กรณีพองเกินจริง เวลาที่ประหยัดคือประโยชน์ การใช้ในภายหลังไม่ใช่ประโยชน์เพิ่มเติม เว้นแต่มีหลักฐานเป็นอิสระ
- **ละเลยต้นทุนที่ถูกเคลื่อนย้าย** โครงการที่ย้ายความแออัดจากถนนเส้นหนึ่งไปอีกเส้น หรือย้ายการฉ้อโกงจากช่องทางหนึ่งไปอีกช่องทาง ไม่ได้สร้างประโยชน์สุทธิที่ NPSV พาดหัวบ่งชี้ — ดู [การเคลื่อนย้ายผลและการระบุที่มา](../การเคลื่อนย้ายผลและการระบุที่มา/)
- **ใช้อัตราคิดลดของภาคเอกชน** การใช้ต้นทุนทุนเชิงพาณิชย์ (เช่น 8–10%) แทนอัตราคิดลดทางสังคมประเมินประโยชน์สาธารณะระยะยาวต่ำเกินไปอย่างเป็นระบบ เช่น ประโยชน์ด้านสุขภาพและสิ่งแวดล้อม — ดู [อัตราคิดลดทางสังคม](../อัตราคิดลดทางสังคม/)
- **ประเมินเป็นตัวเงินสิ่งที่ไม่มีใครโต้แย้งแล้วปัดสิ่งที่ถูกโต้แย้ง** หากสองในสามของประโยชน์ข้อเสนอคือการประหยัดประสิทธิภาพที่ประเมินเป็นตัวเงินอย่างมั่นใจ และหนึ่งในสามคือประโยชน์ด้านความอยู่ดีมีสุขที่ประเมินอย่างง่อนแง่น NPSV พาดหัวผสมตัวเลขแข็งกับตัวเลขอ่อนอย่างเงียบ ๆ รายงานแยกกัน
