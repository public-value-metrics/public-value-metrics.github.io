# ดัชนีการพัฒนามนุษย์ (HDI)

HDI คือทางเลือกหลักของสหประชาชาติแทนการจัดอันดับประเทศด้วยรายได้เพียงอย่างเดียว: รวมอายุขัยคาดเฉลี่ย การศึกษา และรายได้เป็นตัวเลขเดียวระหว่าง 0 ถึง 1 บนหลักการ — ที่นักเศรษฐศาสตร์ อมาร์ตยา เซน (Amartya Sen) โต้แย้งและมาห์บุบ อุล ฮัก (Mahbub ul Haq) พัฒนาให้แก่สหประชาชาติ — ว่าการพัฒนาคือการขยายสิ่งที่ผู้คนทำได้และเป็นได้ ไม่ใช่แค่สิ่งที่พวกเขาหามาได้ เผยแพร่ทุกปีใน Human Development Report ของโครงการพัฒนาแห่งสหประชาชาติ (UNDP) ตั้งแต่ปี 1990

## เหตุใดจึงสำคัญ

ก่อนมี HDI "การพัฒนา" ถูกวัดเกือบทั้งหมดด้วย GNP ต่อหัว ซึ่งไม่ได้บอกอะไรเลยว่าการเติบโตไปถึงสุขภาพหรือการศึกษาของคนทั่วไปหรือไม่ แนวทางขีดความสามารถ (capability approach) ของเซนเปลี่ยนกรอบการพัฒนาเป็นการขยายเสรีภาพที่แท้จริง และอุล ฮักแปลงมันเป็นดัชนีที่เผยแพร่ได้ซึ่ง UNDP จัดอันดับทุกประเทศได้ บังคับให้รัฐบาลที่ร่ำรวยขึ้นด้วยรายได้อย่างเดียวแต่ละเลยสุขภาพหรือการศึกษาต้องเผชิญอันดับที่แย่กว่าที่ GDP ของตนบ่งชี้ (รัฐน้ำมันในอ่าวเปอร์เซียและเศรษฐกิจสกัดทรัพยากรบางแห่งเป็นตัวอย่างมาตรฐาน) โครงสร้างสามส่วนของ HDI ยังเป็นบรรพบุรุษเชิงระเบียบวิธีโดยตรงของ [ดัชนีความยากจนหลายมิติ (MPI)](../ดัชนีความยากจนหลายมิติ/): ทั้งสองปฏิเสธที่จะให้มิติหนึ่งชดเชยส่วนที่ขาดในอีกมิติหนึ่ง โดยใช้ค่าเฉลี่ยเรขาคณิตแทนเลขคณิต UNDP เผยแพร่หมายเหตุทางเทคนิคฉบับเต็มและข้อมูลพื้นฐานของทุกฉบับ (<https://hdr.undp.org/data-center/human-development-index>) ซึ่งเป็นแหล่งอ้างอิงมาตรฐานสำหรับผู้ที่ต่อยอดจากดัชนีแทนที่จะคำนวณขึ้นใหม่

## คณิตศาสตร์

```
ดัชนีอายุขัยคาดเฉลี่ย (LEI)     = (LE − 20) / (85 − 20)

ดัชนีค่าเฉลี่ยปีการศึกษา       = ค่าเฉลี่ยปีการศึกษา / 15
ดัชนีปีการศึกษาที่คาดหวัง      = ปีการศึกษาที่คาดหวัง / 18
ดัชนีการศึกษา (EI)             = (ดัชนีค่าเฉลี่ยปี + ดัชนีปีที่คาดหวัง) / 2

ดัชนีรายได้ (II)               = (ln(GNI ต่อหัว) − ln(100)) / (ln(75000) − ln(100))

HDI = (LEI × EI × II) ^ (1/3)     [ค่าเฉลี่ยเรขาคณิตของดัชนีย่อยทั้งสาม]
```

ค่าเฉลี่ยเรขาคณิตเป็นการออกแบบโดยเจตนา: เพราะคูณแทนที่จะหาค่าเฉลี่ย คะแนนที่สูงมากในมิติหนึ่งไม่อาจชดเชยคะแนนที่ต่ำมากในอีกมิติหนึ่งได้เต็มที่ — การออกแบบที่ UNDP นำมาใช้ในปี 2010 เพื่อลงโทษความไม่สมดุลโดยเฉพาะ แทนที่สูตรค่าเฉลี่ยเลขคณิตก่อนหน้า

## ตัวอย่างการคำนวณ

**ประเทศรายได้ปานกลาง**: อายุขัยคาดเฉลี่ย 72 ปี ค่าเฉลี่ยปีการศึกษา 8 ปีการศึกษาที่คาดหวัง 13 GNI ต่อหัว 12,000 ดอลลาร์

```
LEI = (72 − 20) / (85 − 20)              = 52 / 65   = 0.800
MYSI = 8 / 15                                        = 0.533
EYSI = 13 / 18                                       = 0.722
EI = (0.533 + 0.722) / 2                             = 0.628
II = (ln(12000) − ln(100)) / (ln(75000) − ln(100))
   = (9.393 − 4.605) / (11.225 − 4.605)
   = 4.788 / 6.620                                   = 0.723

HDI = (0.800 × 0.628 × 0.723) ^ (1/3)
    = (0.363) ^ (1/3)                                ≈ 0.713
```

HDI 0.713 อยู่ในช่วง "การพัฒนามนุษย์ระดับสูง" ของ UNDP (0.700–0.799) "สูงมาก" เริ่มที่ 0.800 สังเกตว่าผลลัพธ์อ่อนไหวต่อดัชนีย่อยที่อ่อนที่สุดเพียงใด: หากค่าเฉลี่ยปีการศึกษาเป็น 4 แทนที่จะเป็น 8 (MYSI = 0.267, EI = 0.494) HDI ลดลงเป็น (0.800 × 0.494 × 0.723)^(1/3) ≈ 0.639 — ตกลงมาทั้งช่วง — ทั้งที่ไม่มีอะไรอื่นเปลี่ยน

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

- รูปแบบค่าเฉลี่ยเรขาคณิตนำกลับมาใช้ได้โดยตรงกับคะแนนรวมของบริการหรือผลิตภัณฑ์ใด ๆ ที่คุณไม่ต้องการให้มิติที่แข็งแกร่งหนึ่งมิติบังจุดอ่อนที่สำคัญ — เช่น การรวมคะแนนการเข้าถึง ประสิทธิภาพ และความน่าเชื่อถือของบริการดิจิทัลภาครัฐด้วยการคูณแทนค่าเฉลี่ยถ่วงน้ำหนัก เพื่อให้บริการที่เร็วแต่เข้าถึงไม่ได้ไม่อาจได้คะแนน "ดี"
- การแปลงล็อกของ HDI ต่อรายได้ (มูลค่าส่วนเพิ่มที่ลดลงของเงินปอนด์ที่เพิ่ม) เป็นตรรกะเดียวกับเบื้องหลัง [การถ่วงน้ำหนักตามการกระจาย](../การถ่วงน้ำหนักตามการกระจาย/) ในการประเมิน: เงินเพิ่ม 1,000 ดอลลาร์มีความหมายมากกว่ามากสำหรับครัวเรือนยากจนเมื่อเทียบกับร่ำรวย และการปฏิบัติต่อทั้งสองเป็นเส้นตรงตีราคาผลกระทบผิด
- แดชบอร์ดใดก็ตามที่รายงานคะแนนรวมเดียวของ "การเข้าถึงดิจิทัลอย่างทั่วถึง" หรือ "ผลลัพธ์ของประชาชน" ควรบันทึกสูตรการรวมให้ชัดเจนเท่ากับที่หมายเหตุทางเทคนิคของ UNDP ทำ — ดู [ตัวชี้วัดผลงานหลักของภาครัฐ](../ตัวชี้วัดผลงานหลักของภาครัฐ/) และ [บัตรคะแนนคุณค่าสาธารณะ](../บัตรคะแนนคุณค่าสาธารณะ/)

## ข้อผิดพลาดที่พบบ่อย

- **ใช้ค่าเฉลี่ยแทนค่าเฉลี่ยเรขาคณิต** — ค่าเฉลี่ยเลขคณิตให้รายได้สูงบังสุขภาพหรือการศึกษาที่แย่ได้หมด; จุดประสงค์ทั้งหมดของการเปลี่ยนระเบียบวิธีในปี 2010 คือหยุดการทดแทนนั้น
- **เปรียบเทียบ HDI ปีต่อปีราวกับเป็น GDP ที่ปรับเงินเฟ้อ** — UNDP ปรับฐานดัชนีเป็นระยะ (ขอบเขตต่ำสุด/สูงสุดใหม่ เพดานการศึกษาที่ปรับ) ดังนั้นการเปลี่ยนอันดับอาจสะท้อนการปรับปรุงระเบียบวิธี ไม่ใช่การเปลี่ยนแปลงจริง ตรวจสอบเสมอว่าตัวเลขมาจาก HDR ฉบับใด
- **ถือว่า HDI เป็นตัววัดความยากจน** — เป็นค่าเฉลี่ยระดับชาติและไม่ได้บอกอะไรเกี่ยวกับการกระจายภายในประเทศ; สำหรับเรื่องนั้นให้ใช้ [ดัชนีความยากจนหลายมิติ (MPI)](../ดัชนีความยากจนหลายมิติ/) หรือ HDI ที่ปรับด้วยความเหลื่อมล้ำแยกต่างหากของ UNDP
