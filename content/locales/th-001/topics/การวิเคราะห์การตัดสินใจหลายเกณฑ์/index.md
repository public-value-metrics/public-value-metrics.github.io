# การวิเคราะห์การตัดสินใจหลายเกณฑ์ (MCDA)

MCDA ให้คะแนนและถ่วงน้ำหนักทางเลือกเทียบกับเกณฑ์ที่แตกต่างกันหลายเกณฑ์พร้อมกัน ให้การเปรียบเทียบที่จัดอันดับโดยไม่บังคับให้ทุกเกณฑ์อยู่ในมาตราเงินตราหรือหน่วยธรรมชาติเดียว เป็นวิธีประเมินสำหรับการตัดสินใจที่ผลลัพธ์ที่สำคัญไม่อาจลดทอนเป็นตัวเลขเดียวได้จริง

## เหตุใดจึงสำคัญ

Green Book รับรอง MCDA อย่างชัดเจน (ภาคผนวกกรณีศึกษา Box 2 และ Annex A ต่างพูดถึงโดยตรง) สำหรับการประเมินที่ประโยชน์ "เทียบกันไม่ได้อย่างแท้จริง" — คือเมื่อการแปลงทุกอย่างเป็นเงินผ่าน [การวิเคราะห์ต้นทุนและผลประโยชน์ทางสังคม](../การวิเคราะห์ต้นทุนและผลประโยชน์ทางสังคม/) หรือเป็นผลลัพธ์เดียวผ่าน [การวิเคราะห์ต้นทุนประสิทธิผล](../การวิเคราะห์ต้นทุนประสิทธิผลในภาครัฐ/) จะบิดเบือนการตัดสินใจแทนที่จะทำให้กระจ่าง (<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>) การเลือกสถานที่สำหรับเรือนจำแห่งใหม่ เช่น แลกเปลี่ยนต้นทุนทุนกับผลกระทบต่อชุมชน การเชื่อมต่อการคมนาคม ผลกระทบต่อสิ่งแวดล้อม และความสามารถในการสรรหาบุคลากร — เกณฑ์ที่ไม่มีหน่วยร่วมและการบังคับหน่วยร่วม (โดยทั่วไปคือเงิน) จะแอบนำการตัดสินคุณค่าว่าความสำคัญสัมพัทธ์ของผลกระทบต่อสิ่งแวดล้อมกับต้นทุนเป็นอย่างไรเข้ามา โดยแต่งตัวเป็นเลขคณิตเชิงวัตถุวิสัย

ความซื่อตรงของ MCDA ยังเป็นจุดอ่อนหลักของมัน: เพราะน้ำหนักถูกกำหนดโดยผู้ดำเนินการประเมิน (หรือคณะกรรมการ) วิธีนี้จึงชอบธรรมเท่ากับกระบวนการถ่วงน้ำหนักเท่านั้น แนวทางของ Green Book ชัดเจนว่าเกณฑ์และน้ำหนักต้องตกลงและเผยแพร่ *ก่อน* ให้คะแนนทางเลือก ก็เพื่อป้องกันผู้ทบทวนทำงานย้อนกลับจากทางเลือกที่ชอบไปหาน้ำหนักที่ให้เหตุผลสนับสนุนมัน

## คณิตศาสตร์

```
สำหรับแต่ละทางเลือก i และเกณฑ์ j:
  คะแนน_ij  = ผลการดำเนินงานของทางเลือกเทียบกับเกณฑ์นั้น (มักเป็น 0-100
              หรือ 1-10 จากหลักฐาน การตัดสินของผู้เชี่ยวชาญ หรือการให้คะแนนของผู้มีส่วนได้ส่วนเสีย)
  น้ำหนัก_j  = ความสำคัญสัมพัทธ์ของเกณฑ์ j น้ำหนักรวมเป็น 1 (หรือ 100)

คะแนนถ่วงน้ำหนักของทางเลือก i = Σ_j (คะแนน_ij × น้ำหนัก_j)

ขั้นตอน:
1. ตกลงชุดเกณฑ์และน้ำหนัก ก่อน ให้คะแนนทางเลือกใด ๆ (การถ่วงน้ำหนักแบบสวิง
   หรือการเปรียบเทียบเป็นคู่ เช่น AHP เป็นวิธีเก็บน้ำหนักที่พบบ่อย)
2. ให้คะแนนทุกทางเลือกเทียบกับทุกเกณฑ์บนมาตราร่วม จากหลักฐานเท่าที่เป็นไปได้
3. คำนวณผลรวมถ่วงน้ำหนัก จัดอันดับทางเลือก
4. ทดสอบความไวของน้ำหนัก: อันดับยังคงอยู่หรือไม่เมื่อมีความเห็นต่างที่เป็นไปได้
   ว่าแต่ละเกณฑ์ควรสำคัญเท่าใด?
```

MCDA ไม่ให้ค่าสัมบูรณ์ที่ป้องกันได้แบบมูลค่าปัจจุบันสุทธิของ SCBA — ให้เพียงอันดับที่มีเงื่อนไขตามน้ำหนักที่ตกลงกัน นี่เป็นคุณสมบัติเมื่อการตัดสินใจเกี่ยวกับการแลกเปลี่ยนสิ่งดีที่เทียบกันไม่ได้จริง และเป็นภาระหากใช้หลบงานที่ยากกว่าของการประเมินเป็นตัวเงินในกรณีที่ทำได้จริง

## ตัวอย่างการคำนวณ

**หน่วยงานท้องถิ่น**: สภาที่เลือกสถานที่สำหรับศูนย์รีไซเคิลขยะครัวเรือนแห่งใหม่ให้คะแนนสามสถานที่เทียบสี่เกณฑ์ ถ่วงน้ำหนักโดยคณะกรรมการข้ามแผนกก่อนไปเยี่ยมชมสถานที่ใด ๆ:

```
เกณฑ์ (น้ำหนัก):          ต้นทุนทุน (30%)  การเข้าถึงการคมนาคม (25%)
                           ผลกระทบต่อชุมชน (25%)  ผลกระทบต่อสิ่งแวดล้อม (20%)

คะแนนสถานที่ (0-100 ยิ่งสูงยิ่งดี):
สถานที่ A: ต้นทุน 80 การเข้าถึง 60 ชุมชน 40 สิ่งแวดล้อม 70
สถานที่ B: ต้นทุน 60 การเข้าถึง 90 ชุมชน 70 สิ่งแวดล้อม 50
สถานที่ C: ต้นทุน 90 การเข้าถึง 50 ชุมชน 80 สิ่งแวดล้อม 60

ผลรวมถ่วงน้ำหนัก:
สถานที่ A = 80(.30) + 60(.25) + 40(.25) + 70(.20) = 24+15+10+14 = 63
สถานที่ B = 60(.30) + 90(.25) + 70(.25) + 50(.20) = 18+22.5+17.5+10 = 68
สถานที่ C = 90(.30) + 50(.25) + 80(.25) + 60(.20) = 27+12.5+20+12 = 71.5
```

สถานที่ C อันดับสูงสุด การรันความไวที่เลื่อนน้ำหนักผลกระทบต่อชุมชนจาก 25% เป็น 35% (ลดจากต้นทุนทุน 10 จุด) เปลี่ยนผลรวมของ C เป็น 71.5 − 3 + 8 = 76.5 และของ B เป็น 68 − 6 + 7 = 69 — C ยังนำอยู่ ดังนั้นอันดับทนต่อความเห็นต่างที่เป็นไปได้เรื่องน้ำหนักนั้น ซึ่งเป็นการตรวจสอบที่ Green Book คาดหวังให้รายงานพอดี

**องค์กรการกุศล**: มูลนิธิให้ทุนที่เลือกระหว่างสนับสนุนบริการให้คำปรึกษาด้านหนี้ เครือข่ายธนาคารอาหาร และโครงการความรู้ทางการเงิน ใช้ MCDA แทน SROI (ดู [ผลตอบแทนทางสังคมจากการลงทุน](../ผลตอบแทนทางสังคมจากการลงทุน/)) ก็เพราะกรรมการมูลนิธิเห็นต่างกันโดยสุจริตว่าการบรรเทาวิกฤตหรือการป้องกันควรมีน้ำหนักมากกว่า — MCDA ช่วยให้ตกลงกัน *รูปทรง* ของความเห็นต่าง (ช่วงน้ำหนัก) แทนที่จะแสร้งว่าอัตราส่วน SROI เดียวแก้ได้

## ความเชื่อมโยงกับวิศวกรรมซอฟต์แวร์

MCDA เป็นเครื่องมือตามธรรมชาติสำหรับการเลือกผู้ขายและสถาปัตยกรรมเมื่อเกณฑ์ขัดแย้งกันจริง — การเลือกระหว่างระบบบริหารจัดการกรณีบนคลาวด์กับแบบติดตั้งในองค์กรแลกเปลี่ยนต้นทุน ความเสี่ยงอธิปไตยข้อมูล การเข้าถึง และความเร็วในการส่งมอบ ในแบบที่ลดทอนเป็นตัวเลขเดียวไม่ได้ หัวหน้าทีมวิศวกรรมควรยืนกรานให้การถ่วงน้ำหนักเกิดขึ้นก่อนให้คะแนนทางเลือก ตามที่ Green Book กำหนดพอดี เพราะการถ่วงน้ำหนักที่ทำหลังเห็นรายชื่อสั้นมักเอนไปทางทางเลือกที่ห้องประชุมชอบอยู่แล้วอย่างแน่นอน ดู [สร้างเองหรือซื้อในภาครัฐ](../สร้างเองหรือซื้อในภาครัฐ/) สำหรับการประยุกต์ใช้ MCDA ที่พบบ่อย และ [บัตรคะแนนคุณค่าสาธารณะ](../บัตรคะแนนคุณค่าสาธารณะ/) สำหรับเครื่องมือให้คะแนนเชิงโครงสร้างที่เกี่ยวข้องซึ่งใช้หลังการตัดสินใจแทนก่อน

## ข้อผิดพลาดที่พบบ่อย

- **กำหนดน้ำหนักหลังเห็นทางเลือก** นี่เป็นวิธีเดียวที่พบบ่อยที่สุดที่ MCDA ถูกเล่นแร่แปรธาตุ โดยตั้งใจหรือไม่ก็ตาม เผยแพร่น้ำหนักก่อนให้คะแนน และบันทึกว่าใครเป็นผู้กำหนด
- **ถือผลรวมถ่วงน้ำหนักเป็นตัวเลขแข็ง** คะแนน 71.5 เทียบกับ 68 ไม่ใช่ช่องว่างที่มีนัยสำคัญทางสถิติ เว้นแต่การวิเคราะห์ความไวยืนยันว่าอันดับเสถียร รายงานเป็นช่วง ไม่ใช่ความแม่นยำเท็จ
- **ใช้ MCDA เพื่อเลี่ยงการประเมินเป็นตัวเงินที่ทำได้จริง** หากเกณฑ์ส่วนใหญ่กำหนดราคาได้อย่างน่าเชื่อถือ การเลือก MCDA เป็นค่าเริ่มต้นแทน [SCBA](../การวิเคราะห์ต้นทุนและผลประโยชน์ทางสังคม/) ทิ้งข้อมูลที่การประเมินใช้ได้
- **ให้ผู้มีส่วนได้ส่วนเสียรายใหญ่รายเดียวกำหนดน้ำหนักทั้งหมดตามลำพัง** แนวปฏิบัติที่ดีของ Green Book คาดหวังให้เก็บน้ำหนักจากคณะกรรมการตัวแทน ไม่ใช่ผู้อำนวยการผู้สนับสนุน เพื่อหลีกเลี่ยงไม่ให้การประเมินเพียงอนุมานสิ่งที่บุคคลนั้นต้องการอยู่แล้ว
