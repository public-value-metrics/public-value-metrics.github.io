# Базы данных удельных затрат (Unit Cost Databases)

База данных удельных затрат — это библиотека заранее исследованных, основанных на доказательствах
финансовых заместителей для социальных результатов — ценности перехода от безработицы к занятости,
снижения одиночества, стабильной аренды жилья, — позволяющих практику монетизировать результат без
заказа отдельного исследования оценки каждый раз. Они существуют, чтобы небольшая благотворительная
организация, пишущая заявку на финансирование, могла применять ту же строгость, что и хорошо
обеспеченная ресурсами консалтинговая компания, переиспользуя заместитель, уже выведенный и
опубликованный кем-то другим.

## Почему это важно

UK Social Value Bank организации HACT, разработанный совместно с экономистом Дэниелом Фудзиварой с
использованием методов оценки благополучия, и Global Value Exchange, открытая краудсорсинговая база
данных финансовых заместителей, — два наиболее широко используемых инструмента в британском третьем и
государственном секторах. Оба существуют потому, что лежащая в основе работа по оценке —
[оценка благополучия](../wellbeing-valuation/) и [оценка по заявленным предпочтениям](../stated-preference-valuation/)
— дорога, методологически требовательна и медленна для проведения с нуля для каждого проекта. Общая,
опубликованная библиотека заместителей превращает то, что было бы многомесячным исследовательским
упражнением, в простой поиск, и именно поэтому они важны как для расчётов
[социальной отдачи от инвестиций](../social-return-on-investment/), так и для оценки заявок по
[Закону об общественной ценности](../social-value-act/): без них строгая монетизация была бы доступна
только организациям, достаточно крупным, чтобы заказывать собственные исследования.

## Математика

База данных удельных затрат сама по себе ничего не вычисляет; она даёт один входной параметр для
расчёта, выполняемого в другом месте:

```
Financial proxy value = market price, OR shadow price, OR wellbeing valuation,
                         OR stated-preference value
                         for a defined unit of outcome change
                         (e.g. "per person moving from unemployment to employment, per year")

Applied value = number of outcomes achieved × unit proxy value
```

См. [теневое ценообразование](../shadow-pricing/) о том, как строится заместитель, когда рыночной
цены не существует, и [социальную отдачу от инвестиций](../social-return-on-investment/) о том, как
применённая ценность затем питает коэффициент после поправок на «мёртвый груз» и атрибуцию.

## Практический пример

**Благотворительная организация (SROI услуги дружеской поддержки)**: запись в базе данных удельных
затрат для «снижения одиночества» даёт иллюстративный заместитель в 1100 £ на человека в год.
Применённый к 80 благополучателям: 80 × 1100 £ = 88 000 £ валовой стоимости. Если та же база данных
также содержит заместитель для «улучшенного психического благополучия», опирающийся на перекрывающийся
элемент опроса благополучия, наложение обоих заместителей для тех же 80 человек дважды учло бы часть
одного и того же лежащего в основе изменения — база данных даёт число, но избежание этого наложения —
ответственность аналитика.

**Орган местного самоуправления (SROI клуба поиска работы)**: запись в базе данных удельных затрат для
«перехода от безработицы к устойчивой занятости» применяется к 45 участникам по иллюстративному
заместителю в 8500 £ на человека в год: 45 × 8500 £ = 382 500 £ валовой стоимости, до поправок на
«мёртвый груз» и атрибуцию, показанных в [социальной отдаче от инвестиций](../social-return-on-investment/).

## Связь с разработкой программного обеспечения

Командам, создающим инструменты отчётности для благотворительных организаций или заказчиков услуг,
полезен внутренний «каталог результатов» — таблица, сопоставляющая каждый результат, который продукт
или услуга правдоподобно может заявить, с именованным заместителем, его исходной базой данных, датой
публикации и идентификатором версии, — чтобы разные команды внутри организации не выбирали каждая
слегка отличающиеся значения для одного и того же результата. Обёртывание открытых данных Global Value
Exchange службой поиска, с источником и датой, всегда отображаемыми рядом с цифрой, сохраняет
заместитель поддающимся аудиту, а не магическим числом, похороненным в электронной таблице. См.
[социальную отдачу от инвестиций](../social-return-on-investment/) и [закон об общественной ценности](../social-value-act/)
о двух главных местах потребления этих заместителей.

## Подводные камни

- **Отношение к заместителям как к точным значениям.** Большинство опубликованных заместителей —
  смоделированные средние значения из исследований оценки благополучия с широкими доверительными
  интервалами; цитирование одного из них с точностью до фунта завышает точность, которую поддерживает
  лежащее в основе исследование.
- **Двойной учёт перекрывающихся заместителей.** Объединение заместителей (например, «сниженное
  одиночество» и «улучшенное психическое благополучие»), выведенных из перекрывающихся опросных
  конструктов, дважды оценивает одно и то же лежащее в основе изменение.
- **Использование вырванного из контекста заместителя без корректировки.** Заместитель, откалиброванный
  для одной национальной популяции и года, применённый в другом месте без корректировки на инфляцию или
  контекст, незаметно искажает ценность.
- **Непроверка происхождения.** Global Value Exchange открыт и краудсорсингов, поэтому качество записей
  варьируется в зависимости от автора; проверяйте исходный источник, прежде чем цитировать цифру в
  заявке на финансирование или закупочной заявке.
