# 信任與正當性指標

正當性與支援，是 Mark Moore 在《創造公共價值》（1995）中提出的"戰略三角"三條邊之一——與公共價值本身和操作能力並列——也是最經常未被測量的一條邊，因為與預算或產出計數不同，正當性沒有一個顯而易見的單一數位與之對應。信任與正當性指標，是各國政府用來填補這一空白的一系列代理衡量指標：機構信任調查、監督機構信心評級、投訴與上訴資料，以及政治/立法支援指標。

## 為何重要

Moore 的論點是：一位交付了真實價值、卻失去了政治和公眾正當性的公共管理者，最終會失去維持這種交付所需的授權環境——資金被削減，授權被收窄，無論其成果多麼優秀，該服務都會被斷糧。因此，正當性不是附加在交付計分卡上的公關事後考量；它是決定該使命能否繼續存在的承重輸入，這正是它在[公共價值計分卡](../公共價值計分卡/)中作為一個同等重要的視角、而非一條腳註的原因所在。OECD 的"政府信任"調查專案，是量化這一點最領先的跨國嘗試：它跟蹤 OECD 各成員國中表示信任本國政府的公民佔比，其長期資料顯示，信任對沖擊高度敏感——2008 年金融危機和新冠疫情都造成了劇烈的國家層面波動，且往往只出現部分回升，OECD 的分析一貫發現，感知到的*能力*（政府是否兌現其承諾）和感知到的*公平性/廉潔性*（政府是否被認為不偏不倚、不徇私舞弊）是信任數位最強的兩個驅動因素，與對任何單筆交易的滿意度截然不同。各國政府也日益嘗試在更細粒度的層面將正當性付諸實踐——英國的獨立監管機構和督察機構（國家審計署、議會與衛生服務申訴專員、Ofsted 和護理品質委員會等行業監管機構）發揮著制度化正當性檢驗的作用，將"公眾是否依然信任這項服務"轉化為可審計的評級。

## 數學原理

信任與正當性是一個框架性的話題，其可用的定量代理指標包括：

```
機構信任指數（OECD 式）
  = 在一項政府信心問題上回答"是"的受訪者百分比，
    隨時間跟蹤，按人口統計學群體分類

正當性代理指標集（沒有單一數位能替代這一構念）：
  - 每 1,000 名服務使用者中獲支援的投訴數（申訴專員
    或內部投訴資料）
  - 針對該機構決定的司法複核/上訴成功率
  - 獨立監管機構/督察機構評級（例如從"卓越"到"不合格"的分級）
  - 立法/監督委員會的信任投票或批評性報告的頻率
  - 資訊公開請求量及披露/拒絕率，作為感知透明度的代理指標

正當性是透過相互印證得出的，而非計算出來的：一份站得住腳
的正當性評估，會綜合以上若干項進行三角驗證，而不是依賴
任何單一的代理指標。
```

## 實例演算

**國家稅務機關**：為一份年度公共價值報告進行正當性三角驗證。

```
OECD 式信任代理指標（部門專屬信心調查）：
  58% 的受訪者表示信任該機構"公平對待我"
  （兩年前為 64%，有所下降）

投訴資料：
  獲支援的投訴：每 1,000 次納稅人互動 4.2 起
  （較此前的每 1,000 次 3.1 起有所上升）

申訴專員轉介：
  當年向獨立裁決辦公室（Adjudicator's Office）的轉介
  共 1,850 起，其中 61% 全部或部分支援申訴人、反對該機構
  （較上一年的 48% 有所上升）

綜合來看這三項：信任度在下降，獲支援的投訴在上升，獨立
申訴專員的裁決也日益不利於該機構——三個獨立訊號朝著同一
方向趨同，這正是使這成為一項可信的正當性發現、而非任何
單一資料系列中的噪音的原因所在。
```

這三項數位中任何一項單獨變動都是薄弱的證據；而三項獨立指標在同一時期內同步變動，才是使一項正當性主張站得住腳的模式。

## 與軟體工程的關聯

正當性指標很少由某一個團隊的儀表盤單獨產出，這本身就是一條設計教訓：應建置能夠攝取並核對來自獨立外部來源（申訴專員個案系統、監管機構評級資料流、調查供應商）資料的報告流水線，而不是將正當性報告架構為一項純內部指標，因為內部來源的正當性主張（"我們自評為值得信賴"）幾乎沒有證據分量——這與[公共價值計分卡](../公共價值計分卡/)中針對正當性視角所指出的獨立性問題如出一轍。投訴和上訴資料流水線，理應獲得與任何輸入[按效果付費](../按效果付費與社會效益債券/)合同的成果流水線同等的資料品質嚴謹度，因為一個漏報或分類不當的投訴資料集，會在一年後的信任調查中顯現出來之前，悄悄低估一個正當性問題。關於這一機構層面衡量指標在交易層面的對應物，參見[公民滿意度指標](../公民滿意度指標/)；關於這條邊所屬的 Moore 完整戰略三角框架，參見[公共價值](../公共價值/)。

## 常見陷阱

- **將滿意度當作正當性的代理指標。** 一位公民可能對某一筆交易的介面感到滿意，卻對該機構整體不信任（反之亦然）——參見[公民滿意度指標](../公民滿意度指標/)，瞭解為何兩者必須分開報告。
- **依賴單一的自我報告指標。** 一項沒有獨立佐證（申訴專員資料、監管機構評級）的內部信任調查，很容易被視為自我評分而遭到質疑；應進行三角驗證。
- **忽視人口統計學層面的分類。** 彙總的全國信任數位可能掩蓋特定群體（按年齡、族裔、收入或地區）之間截然不同的正當性狀況——OECD 自身釋出的"政府信任"報告正是出於這一原因進行分類的。
- **將單次衝擊驅動的下滑解讀為永久趨勢。** 信任數位會圍繞危機（金融崩潰、疫情、高關注度醜聞）劇烈波動，並部分回升；在沒有更多資料支撐的情況下，不應將衝擊後的單一資料點外推為長期下滑趨勢。
