# 社會成本效益分析（SCBA）

社會成本效益分析，將一項政策或專案的每一項成本和效益——無論是否具有市場性——都換算成一個共同的貨幣單位，將未來的流量折現為現值，再相減得出一個單一數位：這項提案是否讓社會變得更好，好了多少？

## 為何重要

SCBA 是[綠皮書評估](../綠皮書評估/)經濟論證中的預設定量方法：財政部指南要求，只要效益能夠被可信地貨幣化，提案就必須證明其淨現值社會價值（NPSV）為正，並以支付意願作為非市場性物品估值的基本原則（<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>，第五章）。它所強制推行的紀律是："社會"成本效益分析與私營部門的投資評估並不是同一回事：它必須涵蓋落在非交易方第三方身上的成本和效益（外部性），必須使用[社會折現率](../社會折現率/)而非商業資本成本，並應在一英鎊對貧困家庭比對富裕家庭意義更大的場合應用[分佈性加權](../分佈性加權/)。

SCBA 崩潰的地方恰恰是其批評者所預料的：沒有市場類比物的商品——清潔空氣、社會凝聚力、挽救一條生命的價值——必須使用[陳述性偏好](../陳述性偏好估值/)或[顯示性偏好](../顯示性偏好估值/)方法來貨幣化，或者必須建置一個[影子價格](../影子定價/)。當貨幣化不僅僅是困難、而是存在爭議時，《綠皮書》自身建議退回到[成本效果分析](../政府中的成本效果分析/)或[多準則決策分析](../多準則決策分析/)，而不是強行給出一個無人相信的數位。

## 數學原理

```
NPSV = Σ [t=0 到 T] (效益_t − 成本_t) / (1 + r)^t

其中：
  效益_t = 第 t 年所有已貨幣化的效益，包括透過陳述性/
           顯示性偏好或影子價格估值的非市場性物品
  成本_t = 第 t 年所有已貨幣化的成本，包括資源的機會成本
           （參見 ../opportunity-cost-in-public-spending/）
  r      = 社會折現率（財政部設定為 3.5%，第 30 年之後按
           《綠皮書》附錄 A 降至更低利率）
  T      = 評估週期

效益成本比（BCR） = Σ PV(效益) / Σ PV(成本)
```

BCR 高於 1（或 NPSV 高於零）表示淨社會價值為正。《綠皮書》的物有所值分類（用於交通和基礎設施評估）為 BCR 區間設定了標籤：低於 1.0 為物有所值差，1.0–1.5 為低，1.5–2.0 為中等，2.0–4.0 為高，高於 4.0 為極高。敏感性分析——在悲觀和樂觀假設下重新運作 NPSV 計算——是強制性的，而非可選項，因為已貨幣化的非市場性效益帶有很寬的不確定性區間。

## 實例演算

**地方政府**：某議會對一項 300 萬英鎊的騎行與步行網路投資進行評估，評估週期為 20 年，折現率 3.5%。

```
成本：第 0 年資本支出 300 萬英鎊，第 1-20 年每年維護費 50,000 英鎊
PV(維護) ≈ 50,000 × 14.2（20年期3.5%年金係數）≈ 710,000 英鎊
總 PV(成本) ≈ 371萬英鎊

效益（均透過已釋出的交通部/世衛組織估值工具貨幣化）：
  體力活動增加帶來的健康效益：180,000 英鎊/年
  缺勤減少：40,000 英鎊/年
  擁堵緩解（減少汽車出行）：60,000 英鎊/年
  效益流合計：280,000 英鎊/年
PV(效益) ≈ 280,000 × 14.2 ≈ 398萬英鎊

NPSV = 398萬 − 371萬 = +27萬英鎊
BCR = 3.98 / 3.71 = 1.07 → "低"物有所值
```

該方案勉強透過了門檻，但也僅僅是勉強透過；一項將健康效益估計下調 20%（反映體力活動估值中真實存在的不確定性）的敏感性測試，會使 BCR 翻轉到 1.0 以下，這正是《綠皮書》要求將敏感性表格與頭條數位一併公佈、而不僅僅是公佈中心估計值的原因所在。

**慈善機構**：一項每年耗資 50 萬英鎊的嬰兒死亡率預防專案，使用統計生命價值（VSL，一個影子價格，而非觀測到的市場價格）約 210 萬英鎊（財政部 2023 年更新的數位，本身也源自陳述性偏好研究）進行評估。以 50 萬英鎊的成本每年避免一例嬰兒死亡，得出 BCR 為 4.2，輕鬆達到"極高"物有所值——但整個結果都建立在 VSL 這個數位之上，這正是任何使用 VSL 的 SCBA 都必須將其作為一項假設、而非一個事實來披露的原因。

## 與軟體工程的關聯

SCBA 是政府軟體中平臺和基礎設施投資決策的天然框架——例如，將一個共享身份驗證平臺與各部門各自為政的解決方案相比較，需要將諸如減少重複入職成本、減少欺詐、更快的服務上線時間等本身沒有市場價格的效益貨幣化。建置底層服務的工程師，應當預期專案負責人會要求提供這一分析所需的輸入：交易的單位成本（參見[單筆交易成本](../單筆交易成本/)）、預期交易量，以及效能下降/停機成本。最值得借鑑的紀律是：對未來效益進行折現，明確指出反事實基線（參見[反事實分析](../反事實分析/)），並且絕不在沒有敏感性區間的情況下只呈現一個單點估計。

## 常見陷阱

- **效益重複計算。** 將"節省的時間"和"由此獲得的生產力提升"都作為獨立的效益項來計算，會誇大論證；節省的時間本身就是效益，其下游用途除非有獨立證據支援，否則不是一項額外效益。
- **遺漏被轉移的成本。** 一個將擁堵從一條道路轉移到另一條道路、或將欺詐從一個渠道轉移到另一個渠道的方案，並沒有創造其頭條 NPSV 所暗示的淨效益——參見[置換與歸因](../置換與歸因/)。
- **使用私營部門折現率。** 使用商業資本成本（比如 8–10%）而非社會折現率，會系統性地低估健康和環境收益等長週期公共效益的價值——參見[社會折現率](../社會折現率/)。
- **將無爭議的部分貨幣化、對有爭議的部分含糊其辭。** 如果一項提案三分之二的效益是一項被自信地貨幣化的效率節約，而三分之一是一項估值不穩固的福祉增益，頭條 NPSV 就會在不知不覺中將一個硬數位與一個軟數位混合在一起；應分開報告兩者。
