# 置換與歸因

置換（displacement）是指一個專案表面上的效益，是透過從別處奪走活動或效益、而不是創造出新事物而實現的——你的勝利是別人的損失。歸因（attribution）是一個相關的問題：當其他行動者和因素也做出了貢獻時，一項被觀察到的成果中，究竟有多少可以真正歸功於你的介入。這兩者都是英國公共部門評估指南中的標準調整項，與無謂損失和洩漏並列，但兩者也都經常被那些看起來遠比實際情況強勁的影響力宣告所忽略。

## 為何重要

某地方政府的企業撥款計劃，幫助 50 家商鋪遷入一個再生區，可以報告"支援了 50 家企業，創造了 200 個就業崗位"——但如果這些企業只是從鄰近的商業街搬過來，而不是真正擴張，那麼這些崗位就是被置換的，而非新創造的，全區（或全地區）層面的淨效應可能接近於零。英國財政部《洋紅皮書》以及歷史悠久的《增益性指南》都將置換視為一項必須扣除的調整項，正是因為即便沒有產生任何全國或區域層面的淨效益，地方性的成功故事也屢見不鮮——價值只是發生了轉移，往往還對失去它的地區或行動者不利。結構性基金評估指南（用於原歐盟區域發展基金專案及其國內後繼專案，例如英國共同繁榮基金）將這一問題正式確立在三個空間尺度上：地方性置換（城鎮內部）、區域性置換（地區內部）和全國性置換（英國範圍內），因為一項介入措施可能在一個尺度上是增益性的，而在更大的尺度上卻純粹是置換——一個從鄰鎮吸引工人的就業專案，在全國層面是中性的，即便它在地方層面看起來是一項成功。

歸因是夥伴關係密集型交付中的姐妹問題，而這如今已是社會部門和跨機構公共服務工作的常態。當三家機構聯合交付一項無家可歸預防服務時，每一家機構的年度報告都可能各自獨立地宣稱對同一項露宿人數下降的成果擁有功勞——將各報告的數位相加，所宣稱的影響力可能超過觀察到的實際變化，有時會超出好幾倍。《洋紅皮書》關於貢獻分析（contribution analysis）的指南之所以存在，正是因為在多機構交付中，將結果隨機歸因於單一行動者往往是不可能的，而誠實的答案往往是"我們為這一成果做出了貢獻"，而不是"這一成果是我們造成的"。

## 數學原理

置換作為標準淨影響序列的一部分（完整鏈條參見[增益性與無謂損失](../增益性與無謂損失/)）：

```
淨增益影響 = 總產出 − 無謂損失 − 置換 − 洩漏，× 乘數

置換率 = 從別處轉移而來的效益/活動
        / 觀察到的總體效益/活動
```

當多個行動者共同為同一成果做出貢獻時，歸因通常以貢獻份額而非精確百分比來表示，因為它通常無法以與置換相同的嚴謹程度來測量：

```
可歸因份額 ≈ f(因果貢獻的強度、其他行動者的貢獻、
              外部/情境因素)

所宣稱的影響力永遠不應超過：
  Σ (各合作方的可歸因份額) ≤ 觀察到的總成果的 100%
```

## 實例演算

**再生撥款**：某議會的商業街撥款計劃報告稱，在受資助區域內創造了 200 個新零售崗位。後續跟蹤調查研究發現，其中 60 個崗位來自同一自治市內一條未受資助的鄰近商業街上企業的遷入，另有 30 個崗位來自全國連鎖企業開設的分店，而這些分店無論有無該項撥款，本來都會在該地區某處開設。

```
宣稱的總體崗位數 = 200
地方性置換 = 60（在自治市內部遷移）
區域性置換 = 30（本來就會在區域內開設）

淨增益崗位數（自治市層面） = 200 − 60 = 140
淨增益崗位數（區域層面） = 200 − 60 − 30 = 110
```

誠實的頭條數位取決於資助方所關心的地理尺度——一份在全國或區域層面評估的財政部商業案例應當使用 110，而不是自治市層面的 140，更不能使用原始的 200。

**多機構無家可歸服務**：三家合作機構（一家議會、一家住房慈善機構、一家醫療信託機構）聯合交付一項減少露宿人數的服務。該地區當年露宿人數下降了 30 人。每家機構各自的年度報告都宣稱"我們減少了 30 人的露宿"——三份報告相加，共宣稱幫助了 90 人，是實際降幅的三倍。一項貢獻分析，根據已記錄的角色和獨立評估為各合作方分配份額（例如議會 40%、慈善機構 35%、醫療信託機構 25%），將分別報告 12 人、10.5 人和 7.5 人，正確地加總為觀察到的 30 人。

## 與軟體工程的關聯

置換與歸因決定了多站點或多合作方交付的影響力跟蹤和成果報告系統應當如何設計：

- 地理和組織範圍應當是任何影響力儀表盤中明確的一等欄位——"針對自治市"報告的數位與"針對區域"報告的同一數位是不同的數位，一個將兩者混為一談的系統會產出在專案組合層面無法調和的數位。
- 當多個合作方聯合交付時，成果系統應當記錄貢獻份額（或至少標註聯合歸因），而不是讓每個合作方的報告模組各自獨立地對同一共享成果宣稱 100% 的功勞——否則專案組合層面的彙總將高估總體影響力，有時會嚴重高估。
- 這與[社會投資回報](../社會投資回報/)和[撥款成果報告](../撥款成果報告/)相關：一項忽視置換或對共享成果過度歸因的 SROI 或 IRIS+ 計算，會產出一個經不起審計或復現的虛高比率。

## 常見陷阱

- **報告地方性成功卻不核查更廣泛的置換。** 一個專案在最小的報告尺度上可能看起來非常成功，而在更大的尺度上卻是中性甚至負面的；應當始終明確說明淨值數位所適用的地理尺度。
- **讓聯合交付中的每個合作方都宣稱全部功勞。** 除非貢獻份額已經商定並記錄在案，否則跨合作方的彙總報告會高估總體影響力——應核實各合作方層面的宣告相加不超過觀察到的總數。
- **將歸因當作一個精確百分比，而它實際上是一種判斷。** 與隨機化的反事實情形不同，貢獻分析產出的是一個可辯護的估計值，而非一個已測量的事實；應以恰當的不確定性來呈現它，而不是假裝精確。
- **忽視面向市場的介入措施中的置換問題。** 企業支援、就業計劃和以地方為基礎的再生專案是典型的高置換類別；對這些專案，置換檢查應當是強制性的，而非可選的。
