# 公共專案中的延遲成本（CoD）

延遲成本，是指一項專案、服務或系統變更每延遲一個單位時間*尚未*交付所損失的公共價值。它是本章的核心橋樑指標：它將"上線延後了六個月"轉化為每週多少英鎊，或每週多少 WELLBY，從而使人們能夠用與商業案例本身相同的"貨幣"來討論延遲問題。

## 為何重要

Reinertsen 的法則——"如果你只量化一件事，那就量化延遲成本"——幾乎原封不動地適用於政府領域，因為公共專案對這一問題的暴露程度格外高：商業案例是按照預測的效益流獲批的，但該效益流只有在上線之後才開始流動，而每一週的延誤都是一週被放棄的價值，卻從來沒有人在風險登記冊上為它定價。國家審計署（National Audit Office）對 Universal Credit 推行工作的多次審查（參見其"Rolling Out Universal Credit"系列報告，<https://www.nao.org.uk/>）正說明了這種模式：進度延誤被跟蹤和報告，但改革後的系統*尚未*交付給下一批申領人所造成的每週英鎊成本，卻很少被作為頭條數位明確列出，儘管這正是本應驅動優先順序排序和上報升級的數位。沒有延遲成本數位，一個延誤的專案對交付委員會而言看起來只是一個進度問題；有了它，它就是會計官員必須面對的一個價值侵蝕問題。

## 數學原理

```
延遲成本 = 尚未交付期間每單位時間所放棄的效益   （英鎊/周 或 WELLBY/周）

總延遲損失 = 延遲成本 × 延遲時長

公共專案應加總的效益流：
  可釋放現金的節約  （欺詐/差錯減少、避免的臨時性成本）
+ 非現金型釋放產能  （個案工作人員/官員工時 × 全成本）
+ 福祉效益         （WELLBY × 每 WELLBY 13,000 英鎊，財政部
                     《綠皮書》福祉補充指南，2019 年價格）
```

對於面向公民的服務，應同時以福祉和金錢計價——關於其基礎單位，參見[福祉調整生命年](../福祉調整生命年/)；關於延遲的那筆錢原本還能資助什麼，參見[公共支出中的機會成本](../公共支出中的機會成本/)。

## 實例演算

**地方政府**：某住房福利系統升級，使 2 萬份在辦申領案件的多付差錯每份每年減少 150 英鎊。

```
年度效益 = 150 × 20,000 = 3,000,000 英鎊/年
延遲成本 = 3,000,000 / 52 ≈ 57,700 英鎊/周
延遲實施 12 個月將造成 52 × 57,700 ≈ 3,000,000 英鎊的本可避免差錯。
```

**中央政府機構**：某殘障福利評估服務比計劃推遲六個月（26 周）交付，意味著每年 20 萬名申領人平均要多等三週才能拿到決定結果。每多等一週所帶來的財務不確定性，按 −0.0018 個 WELLBY（生活滿意度點數）的效應建模：

```
每名申領人的 WELLBY 損失 = 3 × 0.0018 = 0.0054
年度 WELLBY 損失 = 200,000 × 0.0054 = 1,080 WELLBY/年
福祉延遲成本 = 1,080 / 52 ≈ 每週 20.8 個 WELLBY
貨幣化延遲成本 = 20.8 × 13,000 英鎊 ≈ 每週 270,000 英鎊的福祉價值
```

因此，26 周的延遲大約"耗費"了 540 個 WELLBY——按《綠皮書》的福祉估值約合 700 萬英鎊——這將一個錯過的上線日期重新定性為一起公民福祉事件，而不只是專案管理層面的一條註腳。

## 與軟體工程的關聯

正是延遲成本，使得 [DORA 指標](../面向公共價值的-dora-指標/)與[政府交付中的流動指標](../政府交付中的流動指標/)具備了財務上的可讀性：流水線中的交付前置時間 × 延遲成本，就是在排隊等候期間、在觸達公民之前被消耗掉的金錢（或福祉）。具體而言：

- **優先順序排序**：按延遲成本 ÷ 工期而非利益相關方的級別對積壓工作進行排序——這是《綠皮書》要求按價值而非提出者身份評估方案這一原則在軟體工程中的對應做法。
- **採購**：一個 12 至 18 個月的框架採購週期本身就有延遲成本；為其定價會改變加速採購路徑的緊迫性論證，並直接影響[自建與外購之爭](../政府中的自建與外購之爭/)中價值實現時間作為決策驅動因素的決策。
- **效益論證**：在獲批時引用的每一個延遲成本數位，都應在[效益實現](../效益實現/)階段重新出現——如果延遲成本是真實的，那麼加速帶來的效益就應當在上線後是可測量的。

## 常見陷阱

- **假定延遲成本是線性的**：某些公共服務的價值呈"截止日期形"（例如某個法定合規日期——延遲成本在該日期之後跳升至執法風險水平，之前則接近於零），而非平滑的周成本率。應先對緊迫性特徵進行分類，再進行乘算。
- **為無人需要的產出計算延遲成本**：只有當未交付之物具有價值時，延遲才具有成本；一個無人會使用的系統，無論多晚交付，其延遲成本都為零。
- **將延遲成本與折現重複計算**：[社會折現率](../社會折現率/)已經為跨年度評估週期中的時間定價；延遲成本是評估週期*內*、以周和月為單位的營運層面版本。進度延誤使用延遲成本，多年度重新分期使用淨現值變化。
