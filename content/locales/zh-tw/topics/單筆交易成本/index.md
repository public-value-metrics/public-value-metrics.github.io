# 單筆交易成本

單筆交易成本，是政府數位服務的頭條單位經濟性指標：交付某一渠道的總成本，除以透過該渠道完成的交易數量。它曾是舊版 GOV.UK Performance Platform 上的旗艦數位，也是資助了十年"數位優先"投資的那個數位——而這正是它也最容易被操縱的原因所在。

## 為何重要

內閣辦公室（Cabinet Office）2012 年的《數位效率報告》（Digital Efficiency Report）以一種令人印象深刻的方式給出了渠道成本比較：數位交易的成本被發現約為電話渠道的二十分之一、約為面對面渠道的五十分之一，地方政府的示例數位大致為每筆網路交易 0.15 英鎊，對比每筆電話交易 2.83 英鎊和每筆面對面交易 8.62 英鎊。這一單一比較，成為了重新設計《政府數位戰略》（Government Digital Strategy）中所列 25 項示範服務的理由，也成為此後每一份引用渠道轉移節約的部門商業案例的依據。作為一個數量級訊號，這個數位確實有用，但其比率完全取決於雙方各自計入了哪些內容：一個公允的電話渠道成本應包括呼叫中心的人員、電話合同、培訓和場地；一個公允的數位渠道成本應包括託管費用、持續性的產品團隊薪酬、辦理失敗旅程所需的支援臺工時，以及[數位服務標準](../數位服務標準/)第 5 條所要求的輔助數位渠道。只要從數位一側剔除足夠多這類成本，任何服務看起來都會很便宜。

## 數學原理

```
單筆交易成本 = 渠道總分攤成本 / 已完成交易數

渠道總分攤成本應包括：
  + 託管與基礎設施
  + 產品/工程/支援團隊成本（攤銷）
  + 內容與服務設計成本（攤銷）
  + 輔助數位/無障礙支援成本
  + 失敗需求成本（數位渠道辦理失敗、轉回電話的使用者）
  − 一次性建設成本應按預期服務生命週期攤銷，
    而不是全部計入第一年費用

常見的會計花招：
  將"邊際單筆交易成本"（建成後僅計託管費用）當作
  "平均單筆交易成本"（包含持續建置與運作該服務的
  團隊在內的總成本）來引用。對於擁有龐大、活躍交付
  團隊的服務而言，兩者可相差 10 倍甚至更多。
```

## 實例演算

**車輛稅續期服務**：每年 400 萬筆交易。

```
僅邊際成本數位（花招版）：
  僅託管費+支付處理 = 180,000 英鎊/年
  單筆交易成本 = 180,000 / 4,000,000 = 0.045 英鎊
  → 在商業案例中引用的頭條數位

全成本數位（誠實版）：
  託管+支付                        180,000 英鎊
  產品/工程團隊（8 名全職員工）     720,000 英鎊
  支援臺（失敗/諮詢交易）           310,000 英鎊
  輔助數位電話熱線                  140,000 英鎊
  合計                            1,350,000 英鎊
  單筆交易成本 = 1,350,000 / 4,000,000 = 0.3375 英鎊

全成本數位仍然比《數位效率報告》中 2.83 英鎊的電話渠道
對照數位便宜約 8 倍——這是一筆真實且站得住腳的節省——
但比捷徑版本中引用的僅邊際成本數位高出 7.5 倍。兩個數位
都是"真實的"；但只有一個數位才能與它所對照的電話渠道
成本相比較。
```

## 與軟體工程的關聯

單筆交易成本正是架構決策轉化為財務數位的地方：一項能夠平穩自動擴充套件、幾乎不需要人工介入的服務，會隨著時間推移壓低這個數位；而一項因令人困惑的錯誤狀態而產生大量支援工單的服務，無論託管效率多高，都會推高這個數位。它是[數位服務標準](../數位服務標準/)第 10 條（"定義成功的樣子，併發布效能資料"）以及[服務標準與交易指標](../服務標準與交易指標/)（其中列出了這一數位所屬的更完整關鍵績效指標集合）的天然搭檔指標。它還直接輸入到[渠道轉移節約](../渠道轉移節約/)的計算之中，並應與[政府 IT 中的總擁有成本](../政府-it-中的總擁有成本/)相互核對，以確保平臺與共享服務的間接成本不會被悄悄遺漏。

## 常見陷阱

- **將邊際成本包裝成平均成本**：在服務建成後只引用僅託管成本的數位，遺漏了持續維護、迭代和支援它的團隊——參見上文的實例演算。
- **排除輔助數位成本**：如果[數位包容](../數位包容/)所要求的電話/紙質備用渠道被單獨計價或被忽略，那麼一個渠道就不符合"數位優先"的要求，其真實成本也未被真正捕獲。
- **忽視失敗需求**：以數位方式開始辦理卻失敗、進而仍然產生一通電話或一份紙質表格的交易，其成本應算在數位渠道頭上，而不是算在接住這次失敗的渠道頭上。
- **在不同複雜度的交易之間跨渠道比較**：電話不成比例地處理更多疑難案例（多個受撫養人、糾錯、弱勢申請人）；除非交易組合是匹配的，否則將平均電話成本與平均數位成本相比較會誇大兩者的比率。
