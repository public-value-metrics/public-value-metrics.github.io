# 技術債作為公共價值侵蝕

技術債是 Ward Cunningham 在 1992 年提出的隱喻，用以描述過去權宜性編碼決策所隱含的未來成本：一筆**本金**（所欠下的整改工作）和一份**利息**（它對交付施加的持續拖累）。在一個遺留的政府 IT 資產中，這份利息是直接從公共價值中支付的——更慢的法定變更交付速度、面向公民服務更高的失敗率，以及一個能夠安全觸碰該系統的人才庫正日益萎縮。

## 為何重要

英國各政府部門的遺留大型機和 COBOL 時代系統——其中最常被提及的是稅務海關總署（HMRC）和就業與養老金部（DWP）——承載著國家審計署反覆標註的、有充分記錄且不斷升級的風險，包括在其《政府數位化轉型》（*Digital Transformation in Government*，<https://www.nao.org.uk/>）報告中所指出的：老化的平臺變更成本高昂、安全保障日益困難，並依賴於一支退休速度快於補充速度的專業人才隊伍。與私營部門的積壓不同，這筆債務直接橫亙在公民與其法定權益之間——一個無法被安全變更的福利計算引擎，是一項政策交付層面的約束，而不僅僅是工程上的不便。2013 年 Universal Credit IT 專案的重啟——當時國家審計署發現原始建置方案無法實現物有所值，相當一部分軟體資產不得不被登出——是未被定價的技術債追上一個部長級公眾可見的在辦公共專案的典型例證。

## 數學原理

```
SQALE 本金 = Σ 各違規項 (整改時間) × 開發者成本費率
技術債比率（TDR） = 整改成本 / 重新開發成本 × 100
                   （SonarQube 分級：A ≤5%，B ≤10%，C ≤20%，D ≤50%）

利息（為償還債務提供理由的數位）：
  年利息 = Δ交付速度 × 單位速度價值
         + Δ面向公民事件率 × 單位事件成本
         + 專業技能溢價 × 受影響人頭數
償還方案 = PV(評估週期內避免的利息) − 整改成本
          （按《綠皮書》社會折現率折現，參見
          social-discount-rate.md）
```

本金陳述的是負債；利息才是向公共賬目委員會證明該投資合理性的數位。

## 實例演算

一個用遺留第四代語言編寫的 25 萬行理賠處理引擎。使用 CAST Appmarq 基準，每行程式碼約 3.61 美元的技術債本金（按常見匯率折算約 2.85 英鎊）：

```
本金 ≈ 250,000 × 2.85 英鎊 ≈ 712,500 英鎊
TDR ≈ 16%（C 級）
```

已測量的利息：該部門保留了三名專業合同工，其日薪比標準高階工程師高出 40%，因為內部技能已經流失——一個六人團隊因此每年多花費 180,000 英鎊。該系統每年還導致四次重大處理中斷，每次都使約 5,000 名申領人的決定被暫停，並將他們轉向呼叫中心，每通電話成本約 25 英鎊：

```
利息 ≈ 180,000 英鎊（技能溢價）
     + 4 × 5,000 × 25 英鎊 = 500,000 英鎊（轉移接觸成本）
     ≈ 680,000 英鎊/年
```

針對表現最差模組的定向整改，成本為 1,200,000 英鎊，建模預計可削減 70% 的利息：

```
利息削減 = 0.70 × 680,000 = 476,000 英鎊/年
回收期 ≈ 1,200,000 / 476,000 ≈ 2.5 年
```

定向性很重要：整改極少被觸碰的程式碼毫無收益，因為利息集中在變更頻率和債務密度都達到峰值的地方。

## 與軟體工程的關聯

將技術債論證提升到超越"程式碼老舊"層次的公共價值框架是：將遺留資產表述為一份"已損失交付能力集中在何處"的清單，並將其明確與[總擁有成本](../政府-it-中的總擁有成本/)關聯起來，因為無論財務部門是否曾要求過，利息都是應當計入總擁有成本科目的一項營運成本。負債累累的系統也帶有不成比例的[網路安全](../公共部門網路安全價值/)暴露風險，因為補丁節奏與債務密度是相關的——一個無法打補丁的遺留系統，其技術債的利息是以事件風險、而非英鎊的形式支付的。而每一次整改與新功能之間的權衡取捨，本身就是一項[延遲成本](../公共專案中的延遲成本/)決策：償還債務會推遲下一次法定變更，而後者本身也有其延遲成本，必須與所節省的利息相權衡。

## 常見陷阱

- **只報告本金。** 一個龐大、令人擔憂的整改估算，如果沒有配套的利息數位，無法向支出審批人證明任何合理性。
- **將工具生成的債務數位照單全收。** SQALE 式掃描工具統計的是規則違規；它們會遺漏最昂貴的那類債務——架構決策和未被記錄的遺留業務規則——卻會標註一些瑣碎細節。
- **"推倒重寫能避免這一切"。** 替代方案專案必須經受住與任何其他商業案例同樣的紀律考驗——反事實成本、成功機率和折現——而不能豁免於此，2013 年 Universal Credit 的重啟就證明了這一點。
- **零債務的烏托邦主義。** 最優的債務水平不是零；債務是一種曾經換來更早交付的槓桿。真正的問題永遠是利率是多少，而不是債務是否存在。
