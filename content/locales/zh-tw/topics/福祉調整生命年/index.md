# 福祉調整生命年（WELLBY）

一個 WELLBY，是在標準的 0–10 福祉量表上，一個人在一年內生活滿意度提升一個點。它在結構上與衛生經濟學中使用的 QALY（品質調整生命年）相對應——都是一個能讓你比較結果毫無共同之處的各種介入措施的單一單位——但它建立在主觀福祉之上，而非臨床健康狀態之上，並在財政部《評估福祉指南：綠皮書補充指南》（2021）中被明確規定。

## 為何重要

成本效益評估需要一個共同單位，來比較一項青年俱樂部撥款、一項道路安全方案和一項心理健康服務，而這三者沒有任何共同的成果衡量指標。衛生經濟學透過 QALY——一個從 0（死亡）到 1（完全健康）加權的品質調整生命年——為臨床介入解決了這一問題。財政部的福祉指南，將同樣的邏輯延伸到非衛生類公共支出，使用 ONS 統一的生活滿意度問題（"總體而言，您對目前的生活滿意程度如何？"，以 0–10 分作答）作為成果階梯，取代健康狀態指數。一個 WELLBY 為 1，意味著一個人的生活滿意度在一年內提升了整整一個點（等價地，也可以是十個人的滿意度在一年內各提升 0.1 點——WELLBY 像 QALY 一樣在人群範圍內相加）。財政部的指南透過將主觀福祉資料與其他生命年價值評估方法相協調，設定了每個 WELLBY 的示例性貨幣價值（約 13,000 英鎊，2019/20 年價格），使評估人員能夠為孤獨感減輕、社群凝聚力、綠地可及性等成果貨幣化——而這些成果，此前[福祉估值](../福祉估值/)技術只能描述，卻無法與健康或安全支出在同一基礎上進行比較。

## 數學原理

```
WELLBY = Δ生活滿意度（0–10量表）× 該變化持續的年數
        （在所有受影響人群中加總）

福祉的貨幣化效益 = 產生的 WELLBY 數 × 每個 WELLBY 的價值（財政部參考值）

對照：QALY = Δ健康狀態效用（0–1量表）× 處於該狀態下的生存年數
```

0–10 的滿意度量表與 0–1 的 QALY 效用量表，若不經過轉換步驟是不能互換的；財政部的指南討論瞭如何協調兩者，例如，使一項以 QALY 評估的衛生介入與一項以 WELLBY 評估的社會介入，不會在同一份[綠皮書評估](../綠皮書評估/)中被悄悄重複計算或變得無法比較。

## 實例演算

**地方政府孤獨症服務**：一項陪伴計劃服務於 400 名孤立的老年居民。後續跟蹤調查顯示，平均生活滿意度從 5.2 上升到 6.0（提升 0.8 點），該效應估計將持續 2 年後逐漸消退。

```
WELLBY 數 = 400 人 × 0.8 點 × 2 年 = 640 個 WELLBY

貨幣化價值 = 640 × 13,000 英鎊 = 8,320,000 英鎊
```

相對於每年 300,000 英鎊（2 年共 600,000 英鎊）的專案成本，效益成本比約為 8,320,000 / 600,000 ≈ **13.9:1**——如今這個數位可以與一項衛生方案的每 QALY 成本、或一項交通方案的旅程時間節約，出現在同一張評估表格中。

**慈善機構，較小規模**：一項社群藝術專案觸達了 50 名參與者，測得滿意度提升 0.3 點，持續 1 年。

```
WELLBY 數 = 50 × 0.3 × 1 = 15 個 WELLBY
貨幣化價值 = 15 × 13,000 英鎊 = 195,000 英鎊
```

## 與軟體工程的關聯

- 任何已經收集了生活滿意度或福祉調查專案的面向公民服務（許多地方政府和健康與關懷平臺都遵循 ONS 的四項標準福祉問題），都可以直接從現有資料流水線中計算 WELLBY，而不必為每一次服務變更都委託定製的經濟評估。
- WELLBY 為建置[社會價值法](../社會價值法/)報告或[社會投資回報](../社會投資回報/)的工程團隊，提供了一個全國標準化、經財政部認可的分母，避免了各種無法在不同合同或供應商之間比較的定製"影響力分數"氾濫成災。
- 由於 WELLBY 可以在人群和時間上相加，它能夠清晰地融入[成果導向問責制](../成果導向問責制/)系統中所使用的那種人群層面成果跟蹤——一個服務儀表盤可以像衛生系統報告已獲得的 QALY 一樣，報告每季度產生的累計 WELLBY 數。

## 常見陷阱

- **假定自我報告的滿意度提升完全歸因於該項介入。** 沒有反事實情形（對照組或帶控制變數的前後對比設計），你無法將 WELLBY 增益與一般趨勢區分開來；參見[反事實分析](../反事實分析/)。
- **在未經協調的情況下將 WELLBY 和 QALY 混合成一個總數。** 財政部的指南明確指出，兩者使用不同的量表和不同的底層價值理論；簡單地將兩者相加會對重疊的福祉進行重複計算。
- **不加批判地使用參考貨幣價值。** 每 WELLBY 的英鎊數位是一個具有真實不確定性區間的全國平均估計值；財政部指南建議進行敏感性分析，而不是將其視為一個固定匯率。
