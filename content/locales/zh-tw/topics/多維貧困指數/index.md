# 多維貧困指數（MPI）

多維貧困指數將貧困衡量為一個人同時經歷的多重疊加剝奪——健康、教育和生活水平方面的剝奪——而不僅僅是收入低於某條貧困線。它由牛津貧困與人類發展倡議組織（Oxford Poverty and Human Development Initiative，OPHI）與 Sabina Alkire 和 James Foster 共同開發，自 2010 年以來一直與[人類發展指數](../人類發展指數/)一同，出現在聯合國開發計劃署每一版《人類發展報告》中。

## 為何重要

收入貧困線會遺漏那些擁有足夠現金收入、卻缺乏清潔水源或教育、或正在承受子女夭折之痛的人——而且它們也會遺漏一個事實：各種剝奪往往聚集出現——一個沒有電力的家庭，同時也缺乏衛生設施、家中有營養不良兒童的可能性不成比例地更高。MPI 所基於的 Alkire-Foster 方法，在十項指標上統計每個人所經歷的剝奪，這些指標被歸入三個權重相等的維度——健康、教育、生活水平——只有當一個人的加權剝奪分數超過一個固定閾值時，才將其歸類為"MPI 貧困"，從而捕捉到一組分開的單一指標統計所無法捕捉到的重疊情況。OPHI 在 <https://ophi.org.uk/multidimensional-poverty-index/> 上釋出了完整的方法論和各國資料；它與聯合國開發計劃署共同維護的全球 MPI，如今覆蓋超過 110 個國家。對於為反貧困專案（現金轉移、社會關懷分診、援助定位）建置的軟體而言，MPI 的指標集，往往是最接近於一套已經在數十個國家統計局中得到驗證的標準化剝奪框架。

## 數學原理

```
10 項指標，3 個維度，每個維度權重為 1/3：

健康 (1/3)：             營養 (1/6)、兒童死亡率 (1/6)
教育 (1/3)：             受教育年限 (1/6)、就學情況 (1/6)
生活水平 (1/3)：         烹飪燃料、衛生設施、飲用水、
                        電力、住房、資產（各 1/18）

剝奪分數 (c) = 一個人所遭受剝奪的各項指標權重之和

若 c ≥ 1/3（貧困臨界值，k = 33%），此人被歸類為"MPI 貧困"

H（人頭率） = MPI 貧困人數 / 總人口
A（強度）   = 僅在 MPI 貧困人群中的平均剝奪分數

MPI = H × A
```

因為 MPI 是將貧困*人群佔比*乘以他們*貧困的程度*，兩個人頭率相同的地區，如果其中一個地區的剝奪程度更為嚴重，其 MPI 分數可能大不相同——這與 HDI 幾何平均數背後"各維度之間不可替代"的邏輯如出一轍。

## 實例演算

**某全國性調查，1,000 人**：其中 350 人被認定為多維貧困（剝奪分數 ≥ 33%）。僅在這 350 名貧困個體中，平均剝奪分數為 45%。

```
H = 350 / 1000                = 0.350
A = 0.45
MPI = H × A = 0.350 × 0.45    = 0.1575
```

**比較兩個人頭率相同的地區**：地區 A 的 H = 0.30，A = 0.40（貧困人數多，但剝奪程度中等）；地區 B 的 H = 0.30，A = 0.60（貧困人數相同，但剝奪程度更為嚴重——同時缺乏電力*、*衛生設施*和*就學）。

```
MPI_A = 0.30 × 0.40 = 0.120
MPI_B = 0.30 × 0.60 = 0.180
```

人頭率相同，但地區 B 的 MPI 高出 50%——一個僅基於人頭貧困率的定位系統會將這兩個地區排在同一位置，從而遺漏地區 B 需要更深層次介入這一事實。

## 與軟體工程的關聯

- 社會專案的個案管理和資格認定系統，往往已經將十項指標中的若干項（住房、就學、健康指標）分別儲存在各自的資訊孤島中；Alkire-Foster 計數方法提供了一套現成的框架，可以將它們合併為一個剝奪分數，而不必從頭建置一套定製的評分模型。
- 人頭率/強度的拆分（H × A）對任何需要同時報告"有多少人受影響"和"受影響程度有多深"的儀表盤而言，都是一種普遍有用的模式——像原始流行率統計那樣將兩者壓縮成一個數位，恰恰會掩蓋最需要資源的那些情況。
- MPI 式的指標儀表盤，與反貧困專案的[單位受益人成本](../單位受益人成本/)報告天然契合：每降低一個 MPI 點數的成本，是比較截然不同介入措施（現金轉移與衛生基礎設施）的一個可辯護單位。

## 常見陷阱

- **將十項指標當作普適通用的。** OPHI 的全球 MPI 指標是為跨國可比性而校準的；各國 MPI（包括南亞和非洲的許多國家都發布了自己的版本）會根據本地情境調整指標和權重，兩者不能直接比較。
- **只報告 H。** 人頭率完全忽略了強度；應始終同時報告 A，或直接報告 MPI 本身。
- **假定 MPI 貧困人群與收入貧困人群是同一批人。** OPHI 自己釋出的各國簡報通常顯示，兩者之間只有部分重疊；一個只針對收入貧困人群的專案，會系統性地遺漏相當一部分多維貧困人群。
