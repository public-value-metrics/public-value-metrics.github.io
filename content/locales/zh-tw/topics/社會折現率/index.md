# 社會折現率

社會折現率將未來的成本和效益轉化為當前價值，使得回報跨越數十年分散的專案能夠在同一基礎上進行比較。財政部《綠皮書》基於拉姆齊公式，規定了一套遞減的時間表，前 30 年固定為 3.5%——這是一個具體、可引用的數位，每當它被應用於氣候政策或基礎設施等長週期承諾時，都會成為一場活躍的政治和倫理爭論。

## 為何重要

30 年後收到的一英鎊效益，並不等同於今天收到的一英鎊效益，原因部分在於純時間偏好（人們和社會都偏好更早獲得好事物），部分在於增長（未來社會預期會更富裕，因此邊際上一英鎊對它的意義較小）。《綠皮書》附錄 6 依據拉姆齊公式推匯出英國的標準折現率，將純時間偏好率與預期消費增長率及消費邊際效用彈性相結合，得出第 0–30 年每年 3.5% 的公佈利率，第 31 年及以後按公佈的時間表遞減（第 301 年及以後降至 1%）。這一時間表之所以存在，正是因為一個世紀內恆定的 3.5% 複利，會使幾乎任何長週期效益——一項在 80 年後挽救生命的防洪工程、一項在 100 年後避免損害的減碳措施——在現值意義上顯得微不足道，財政部認為，對於真正長壽命的基礎設施和環境決策而言，這是一個站不住腳的倫理結論。

折現率之所以充滿爭議，正是因為這一選擇並非一箇中立的技術引數：它編碼了一種關於社會當下應為尚未出生的人犧牲多少的判斷。《斯特恩氣候變化經濟學評估》（2006）使用了接近於零的折現率（純時間偏好接近 0.1%），認為當損害（災難性氣候變化）不可逆轉時，以接近市場利率的方式對未來世代的福祉進行折現，在倫理上是站不住腳的。批評者——尤其是 William Nordhaus——認為 Stern 那個接近零的利率，透過使幾乎任何當下的成本相對於一個幾乎未被折現的未來效益都顯得合理，從而誇大了立即進行氣候支出的理由。這場分歧的焦點不在於數學本身；而在於應當由誰的倫理框架來設定這一利率，它至今仍是說明折現率是一項政策選擇、而不僅僅是一個精算輸入的標準例證。

## 數學原理

《綠皮書》利率背後的拉姆齊公式：

```
r = ρ + η·g

其中：
  r = 社會折現率
  ρ = 純時間偏好率（不耐煩程度 + 災難風險）
  η = 消費邊際效用彈性
  g = 預期人均消費年增長率
```

《綠皮書》的遞減時間表（附錄 6，示例性——具體公佈表格應核實當前版本）：

```
第 0–30 年：    3.5%
第 31–75 年：   3.0%
第 76–125 年：  2.5%
第 126–200 年： 2.0%
第 201–300 年： 1.5%
第 301 年以上： 1.0%
```

未來金額的現值：

```
PV = FV / (1 + r)^t
```

## 實例演算

**防洪工程**：某專案在第 40 年實現 1,000 萬英鎊的避免洪水損害效益。

使用固定 3.5% 利率：PV = 10,000,000 / (1.035)^40 ≈ 252萬英鎊——這一效益看起來很小。

使用《綠皮書》的遞減時間表（第 0–30 年 3.5%，此後 3.0%），計算按前 30 年 3.5%、第 31–40 年 3.0% 複利：

```
PV = 10,000,000 / [(1.035)^30 × (1.03)^10]
   = 10,000,000 / [2.807 × 1.344]
   ≈ 10,000,000 / 3.773
   ≈ 265萬英鎊
```

相對於一個固定的高利率，遞減時間表適度提高了長週期效益的現值——這正是該時間表的明確用意，因為一個世紀內固定的 3.5% 利率，會把第 100 年一項 1 億英鎊的效益折現到不足 330 萬英鎊。

**數位基礎設施**：一項現耗資 400 萬英鎊的政府雲遷移專案，預計在 15 年內每年可避免 500,000 英鎊的遺留維護成本。按 3.5% 計算，該年金的現值約為 500,000 × 11.52（3.5% 利率下 15 年期年金係數）≈ 576萬英鎊——遠超 400 萬英鎊的成本，是一個淨現值為正的案例，若樸素地選用一個更高的利率，這一案例會明顯減弱（按 7% 計算，同樣的年金係數降至約 9.11，得出 456萬英鎊，仍為正值，但利潤率明顯收窄）。

## 與軟體工程的關聯

大多數軟體商業案例的週期為 3 至 5 年，完全處於固定的 3.5% 區間之內，因此遞減時間表很少直接產生影響——但對於任何具有長資產壽命的政府技術投資（一個全國性平臺、一項資料基礎設施專案、一份跨越數十年的合同），其背後的紀律仍然重要：

- 應使用《綠皮書》公佈的利率，而不是從私營金融領域借用的內部"門檻利率"；審計人員和財政部審查人員會期望看到標準時間表。
- 對於多年後才實現的效益（一個平臺長期的維護節約、一個開放資料生態系統的複利式價值增長——參見[開放資料的價值](../開放資料的價值/)），折現選擇可能使一份商業案例從正轉負；應將利率和評估週期作為明確的假設，而不是埋藏在預設值之中。
- 這直接輸入到[綠皮書評估](../綠皮書評估/)——正式要求進行折現現金流計算的五個論證案例模型——以及[福祉估值](../福祉估值/)，後者對非貨幣性福祉效益提出了同樣的折現問題。
- 另請參見[代際公平與可持續性折現](../代際公平與可持續性折現/)，其中專門針對環境與氣候技術投資探討了 Stern 與 Nordhaus 之爭。

## 常見陷阱

- **對非常長的週期使用固定利率。** 《綠皮書》的遞減時間表之所以存在，正是因為固定利率會低估真正長壽命的效益；應核實適用哪個區間，而不是預設全程使用 3.5%。
- **將折現率視為倫理中立的。** Stern-Nordhaus 之爭表明，這一利率編碼了一種關於未來世代的價值判斷；改變它會改變哪些專案看起來合理，因此它應當被明確說明並加以論證，而不是隱藏在電子表格預設值之中。
- **將社會折現率與私營部門資本成本相混淆。** 政府借貸成本和私營部門門檻利率，是與源自拉姆齊公式的社會利率不同的概念，在公共評估中用其中一個替代另一個，通常會使結果朝著有利於短期回報的方向扭曲。
- **不一致地對實際和名義現金流進行折現。** 《綠皮書》的利率是一個實際（經通脹調整後）利率；用它對名義現金流進行折現，會實質性地低估現值。
