# 人類發展指數（HDI）

人類發展指數是聯合國用於替代僅憑收入對各國進行排名的旗艦指標：它將預期壽命、教育和收入合併為一個介於 0 到 1 之間的單一數位，其前提——由經濟學家阿馬蒂亞·森（Amartya Sen）提出、並由 Mahbub ul Haq 為聯合國發展而成——是發展的意義在於擴充套件人們能夠做什麼、能夠成為什麼，而不僅僅是他們賺多少錢。自 1990 年以來，它每年都在聯合國開發計劃署（UNDP）的《人類發展報告》中釋出。

## 為何重要

在 HDI 出現之前，"發展"幾乎完全以人均國民生產總值來衡量，而這絲毫說明不了增長是否惠及了普通人的健康或教育。森的能力方法（capability approach）將發展重新定位為真實自由的擴充套件，而 ul Haq 則將其轉化為一個可供 UNDP 用來對每個國家進行排名的可釋出指數，迫使那些僅憑收入變得富裕、卻忽視了健康或教育的政府，面對比其 GDP 所暗示的更差的排名（海灣產油國和一些資源型經濟體是典型例子）。HDI 的三分結構也是[多維貧困指數](../多維貧困指數/)的直接方法論先驅：兩者都拒絕讓一個維度的高分彌補另一個維度的不足，都使用幾何平均數而非算術平均數。UNDP 為每一版報告都發布了完整的技術說明和底層資料（<https://hdr.undp.org/data-center/human-development-index>），這是任何在該指數基礎上進行研究、而不是重新推導它的人的權威來源。

## 數學原理

```
預期壽命指數（LEI）     = (預期壽命 − 20) / (85 − 20)

平均受教育年限指數      = 平均受教育年限 / 15
預期受教育年限指數      = 預期受教育年限 / 18
教育指數（EI）          = (平均年限指數 + 預期年限指數) / 2

收入指數（II）          = (ln(人均國民總收入) − ln(100)) / (ln(75000) − ln(100))

HDI = (LEI × EI × II) ^ (1/3)     【三個子指數的幾何平均數】
```

採用幾何平均數是刻意為之的：因為它是相乘而非取平均，一個維度上極高的分數無法完全抵消另一個維度上極低的分數——這是 UNDP 在 2010 年專門為懲罰失衡而採用的設計，取代了此前的算術平均公式。

## 實例演算

**某中等收入國家**：預期壽命 72 歲，平均受教育年限 8 年，預期受教育年限 13 年，人均國民總收入 12,000 美元。

```
LEI = (72 − 20) / (85 − 20)              = 52 / 65   = 0.800
平均年限指數 = 8 / 15                               = 0.533
預期年限指數 = 13 / 18                              = 0.722
EI = (0.533 + 0.722) / 2                            = 0.628
II = (ln(12000) − ln(100)) / (ln(75000) − ln(100))
   = (9.393 − 4.605) / (11.225 − 4.605)
   = 4.788 / 6.620                                  = 0.723

HDI = (0.800 × 0.628 × 0.723) ^ (1/3)
    = (0.363) ^ (1/3)                               ≈ 0.713
```

0.713 的 HDI 落在 UNDP"高人類發展水平"區間（0.700–0.799）內；"極高"水平從 0.800 起。注意該結果對最弱子指數有多敏感：如果平均受教育年限是 4 年而非 8 年（平均年限指數 = 0.267，EI = 0.494），HDI 將降至 (0.800 × 0.494 × 0.723)^(1/3) ≈ 0.639——整整下降一個等級區間——即便其他一切都沒有變化。

## 與軟體工程的關聯

- 幾何平均數模式可以直接複用於任何你不希望某一強項維度掩蓋某一關鍵弱項維度的複合服務或產品評分——例如，將一項公共數位服務的無障礙性、效能和可靠性分數以相乘方式而非加權平均方式合併，使一個速度快但無法訪問的服務無法得到"良好"評分。
- HDI 對收入進行對數變換（額外一英鎊的邊際價值遞減），與評估中[分佈性加權](../分佈性加權/)背後的邏輯相同：額外 1,000 美元對一個貧困家庭的意義，遠大於對一個富裕家庭的意義，將兩者線性對待會錯誤地為影響力定價。
- 任何報告單一混合"數位包容"或"公民成果"分數的儀表盤，都應當像 UNDP 的技術說明那樣明確記錄其彙總公式——參見[公共部門關鍵績效指標](../公共部門關鍵績效指標/)和[公共價值計分卡](../公共價值計分卡/)。

## 常見陷阱

- **使用平均數而非幾何平均數。** 算術平均數會讓高收入完全掩蓋健康或教育方面的不足；2010 年方法論變更的全部意義就在於阻止這種替代。
- **像對待經通脹調整的 GDP 那樣逐年比較 HDI。** UNDP 會定期對該指數進行重新基準化（新的最小值/最大值邊界、修訂後的受教育年限上限），因此排名變化可能反映的是方法論更新，而非真實的變化；應始終核實某一數位來自哪一版《人類發展報告》。
- **將 HDI 當作貧困衡量指標。** 它是一個國家層面的平均值，絲毫說明不了一國內部的分佈情況；要衡量分佈，應使用[多維貧困指數](../多維貧困指數/)或 UNDP 單獨釋出的不平等調整後 HDI。
