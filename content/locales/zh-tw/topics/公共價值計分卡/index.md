# 公共價值計分卡

公共價值計分卡，改編自 Robert Kaplan 和 David Norton 於 1992 年提出的平衡計分卡——該計分卡最初是為在財務、客戶、內部流程和學習與成長四個視角之間最佳化利潤的企業而設計的——使其適用於那些以使命而非利潤為底線的組織。它迫使一個公共機構同時在若干個不可歸約的維度上報告績效，而不是將一切壓縮成一個掩蓋了權衡取捨的單一數位。

## 為何重要

Kaplan 和 Norton 在《哈佛商業評論》上提出的原始論點是：單一的財務指標是一項滯後指標，它絲毫說明不了*為什麼*下個季度的業績會發生變化。在私營部門，解決方案是四個相互關聯的視角。在政府領域，Mark Moore 的"戰略三角"（出自《創造公共價值》，1995）提供了對應的結構：一項服務必須同時交付**公共價值**（使命成果）、維持**正當性與支援**（政治和公眾的支援），並且**在操作上可行**（能夠憑藉實際可獲得的資源和能力交付）。Paul Niven 的《平衡計分卡：政府與非營利機構逐步指南》（*Balanced Scorecard: Step-by-Step for Government and Nonprofit Agencies*，2003）是將 Kaplan 和 Norton 的四個方框轉化為這一三角結構的實踐手冊——通常將"財務"重新標註為"資源管理"，將"使命"置於頂端，而非將"股東價值"置於底端，並將客戶和利益相關方視角視為與其他視角同等重要，而不是從屬於利潤。這一點之所以對交付團隊而言至關重要，是因為一項僅按財務或效率指標（比如單筆交易成本）來評判的公共數位服務，會系統性地對財務指標無法看見的正當性和成果維度投入不足。

## 數學原理

公共價值計分卡是一個框架，而非一個公式，但其結構是固定的，值得原樣復現：

```
視角              公共部門的問題                            示例指標
--------------------------------------------------------------------------------
使命/成果          我們是否正在實現我們存在的目的所要       人群成果衡量指標
                   創造的公共價值？                        （參見 outcomes-vs-outputs）
資源管理           我們是否在授許可權額內高效使用了公共資金？  單位成果成本、預算差異
客戶/使用者          使用者和公民能否獲取並從該服務中受益？      完成率、滿意度
正當性/支援        政治負責人、監督機構和公眾是否仍然        信任指標、審計發現、
                   支援我們？                              獲支援的投訴數
內部流程/學習      我們是否具備持續改進所需的能力和流程？    員工流動率、週期時間、
                                                           積壓案件賬齡

一份站得住腳的計分卡，每個視角報告 3-5 項指標，
其選擇應確保沒有任何一個視角能夠被單獨操縱，
而不在另一個視角上留下可見的損害痕跡。
```

## 實例演算

**地方政府成人社會關懷部門**：一份針對康復支援服務（幫助人們在住院後短期內恢復獨立生活能力）的計分卡報告：

```
使命：      68% 的服務使用者在 6 周後不再需要持續性關懷（目標 65%）
資源管理：  每次完成的康復支援成本 = 1,850 英鎊（預算假設為 2,000 英鎊）
客戶：      使用者滿意度 82%，服務啟動平均等待時間 4.1 天
正當性：    每 1,000 次服務中有 3 起獲支援的投訴；成人安全保障
           委員會將該服務評為"良好"
流程：      員工空缺率 14%，平均案件負荷 23（安全案件負荷上限：25）
```

單獨解讀時，使命和資源管理這兩項數位看起來是一個簡單明瞭的成功故事：低於預算、高於成果目標。但結合流程這一行來看，14% 的空缺率相對於 25 的案件負荷上限，顯示出這一良好成果，是以接近不安全人員配備水平為代價換來的——這是一個使命數位本身永遠不會揭示出來的警示，也正是單一視角 KPI（參見[公共部門關鍵績效指標](../公共部門關鍵績效指標/)）所招致的那種失敗模式。

## 與軟體工程的關聯

對於建置內部或面向公眾儀表盤的團隊而言，該計分卡直接反對使用單一的"健康分數"小元件：應為每個視角建置一個獨立面板，並抵制將它們綜合成一盞紅綠燈的產品壓力，因為綜合這一步驟恰恰是權衡取捨資訊被摧毀的地方。它也與產品團隊的 OKR 結構清晰對應：一個沒有配對資源管理或流程 OKR 的使命 OKR，會重現 Kaplan 和 Norton 在 1992 年所反對的那種單一指標失敗模式。關於 Moore 提出的"使命"方框本應包含什麼內容的基礎理論，參見[公共價值](../公共價值/)；關於如何用真實的、有據可查的指標（而不是一個無人能為之辯護的代理指標）來填充正當性視角，參見[信任與正當性指標](../信任與正當性指標/)。

## 常見陷阱

- **將計分卡壓縮成一個分數。** 將四個視角平均成一個數位，會重新引入該計分卡本應防止的確切問題——一個糟糕的正當性分數被一個良好的資源管理分數所掩蓋。
- **原封不動地照搬私營部門的"財務"視角。** 一個公共機構的資源管理視角關注的是留在獲授權的、往往是專款專用的預算之內，而不是最大化收入——Niven 的重新標註絕非表面文章。
- **選擇計分卡所有者團隊能夠單方面左右的指標。** 一項來自被評判團隊自身的正當性指標（例如自我報告的投訴處理情況）算不上獨立證據。
- **一次性建置計分卡後就再也不重新審視權重或指標。** Kaplan 和 Norton 本意是要進行年度戰略複核；一份被凍結多年的計分卡，會逐漸偏離它本應跟蹤的使命。
