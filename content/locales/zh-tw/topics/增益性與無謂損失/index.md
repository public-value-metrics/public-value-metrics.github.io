# 增益性與無謂損失

增益性（additionality）追問的是：某項介入是否促成了一個原本不會發生的結果。無謂損失（deadweight）則是它的映象：即便沒有該專案、撥款或補貼，某一結果原本也會發生的那部分比例。幾乎所有來自政府專案或慈善機構的影響力宣告，在扣除無謂損失之前都會高估其效果，這正是英國評估指南將其視為任何頭條數位第一項、也是最重要一項調整的原因。

## 為何重要

"我們支援了 500 家企業實現增長"聽起來是一項成就，但如果其中 300 家企業本來就會增長——因為當地經濟正在復甦，因為它們還有其他融資渠道，因為它們在專案開始前就已處於增長軌道——那麼該專案真正的增益性貢獻是 200 家，而不是 500 家。英國財政部（HM Treasury）的《洋紅皮書》（Magenta Book）以及歷史悠久的財政部/BIS《增益性指南》（Additionality Guide，最初為區域發展與再生專案而制定，此後被廣泛用於英國政府評估）將無謂損失確立為標準淨影響序列中的起始調整項：總效果減去無謂損失，再減去置換，再減去洩漏，並按乘數效應調整，等於淨增益影響。跳過這一步驟，是公共部門和社會部門影響力宣告被誇大（無論是否出於故意）最常見的方式——一個只衡量參與者總體結果、沒有對照組的撥款專案，根本無法區分自身的效果與本來就會發生的情況。

無謂損失不是一個固定百分比；它完全取決於特定人群和介入措施的反事實情形（參見[反事實分析](../反事實分析/)）。在此前的區域發展局（Regional Development Agencies）體制下，英格蘭區域發展評估發現，根據企業支援型別的不同，無謂損失率通常在 20% 至 60% 之間，這正是可信的專案評估報告使用經無謂損失調整後的區間、而非單一假設數位的原因，也是國家彩票社群基金（National Lottery Community Fund）和 Big Society Capital 等資助方要求受助方在成果報告中明確處理無謂損失、而不是僅報告參與者總數的原因。

## 數學原理

英國評估指南（《洋紅皮書》；財政部/BIS《增益性指南》；歐洲結構與投資基金評估指南）所規定的標準淨影響調整序列：

```
總產出
  − 無謂損失      （原本就會發生的部分）
  − 置換          （從別處轉移而來、並非新創造的活動/效益——參見
                    displacement-and-attribution）
  − 洩漏          （惠及目標群體/地區之外的效益）
  × 乘數           （若為正值，指額外的間接/引致經濟活動）
  = 淨增益影響
```

無謂損失率作為比例：

```
無謂損失率 = 若無該介入本也會發生的結果數
              / 觀察到的總產出數

淨增益產出 = 總產出 × (1 − 無謂損失率)
```

## 實例演算

**企業支援撥款專案**：某區域撥款計劃報告稱，500 家受支援企業在次年增加了就業，平均每家增加 3 個崗位——總體宣告為 1,500 個工作崗位。

一個由類似的未受支援企業組成的匹配對照組（參見[反事實分析](../反事實分析/)）顯示，根據該對照組在同一時期的表現，受支援企業就業增長中有 40% 原本也會發生。

```
無謂損失率 = 40%
淨增益崗位 = 1,500 × (1 − 0.40) = 900 個崗位
```

該專案可如實報告的成就是 900 個崗位，而非 1,500 個——僅無謂損失調整一項就使數位減少了 40%，這還沒有考慮置換或洩漏。

**慈善就業專案**：某慈善機構以 60 萬英鎊的成本（每個安置崗位總成本 3,000 英鎊）幫助 200 名長期失業者找到工作。全國勞動力市場資料顯示，若無任何介入，一個可比的長期失業群體中約有 15% 會在同一時期內透過自然的勞動力市場流動找到工作。

```
無謂損失率 = 15%
淨增益安置人數 = 200 × (1 − 0.15) = 170
真實的每個增益安置崗位成本 = 600,000 英鎊 / 170 ≈ 3,529 英鎊
```

總體的每崗位成本數位（3,000 英鎊）將該慈善機構真實增益貢獻的成本低估了約 15%。

## 與軟體工程的關聯

對於任何為公共或社會部門建置影響力衡量或撥款管理軟體的人而言，增益性與無謂損失都有直接的現實意義：

- 成果報告系統在設計之初就應當捕獲對照組或基線資料，而不只是參與者的結果——在系統上線後再為其補建反事實機制，要比從一開始就納入這種捕獲能力困難得多（參見[反事實分析](../反事實分析/)）。
- 只報告參與者總數的儀表盤，會系統性地向資助方和監督機構誇大影響力；當存在無謂損失估算（來自評估文獻或對照組）時，軟體應當同時展示扣除無謂損失後的淨值與總體數位，而不是隻展示其中一個。
- 這與[社會投資回報](../社會投資回報/)直接相關：其 SROI 比率只有在從總體宣告的結果中扣除無謂損失（以及置換）之後才可信——省略這一步驟的 SROI 計算器會產生虛高的比率，經不起推敲。

## 常見陷阱

- **將總體產出當作全部都是增益性的來報告。** 這是撥款和專案報告中最常見的影響力衡量錯誤；在公佈頭條數位之前，務必先問"這原本是否也會發生？"
- **假定單一的無謂損失百分比適用於所有情況。** 無謂損失因行業、人群和當地經濟狀況而差異巨大；應使用對照組或行業專屬證據，而不是套用一個來自不相關評估的數位。
- **將無謂損失與置換混淆。** 無謂損失關注的是同一批參與者的反事實結果；置換關注的是對其他人或其他地方的影響——參見[置換與歸因](../置換與歸因/)。混淆兩者會導致調整時重複計算或漏算。
- **由參與者自行報告無謂損失。** 詢問受益人"如果沒有我們的幫助，這會發生嗎？"通常會系統性地得出偏低的無謂損失估算（參與者往往傾向於將功勞歸於專案本身）；獨立的對照組要可靠得多。
