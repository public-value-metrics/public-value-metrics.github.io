# 分佈性加權

分佈性加權根據受益者是誰來調整一項成本或效益的貨幣價值，其原則是：對一個貧困家庭而言，多一英鎊的價值高於對一個富裕家庭而言的價值。英國財政部《綠皮書》提供了應用這種加權的明確方法，建立在收入邊際效用遞減這一原理之上，使評估不會在不知不覺中把最富裕十分位人群多得的一英鎊，等同於最貧困人群多得的一英鎊。

## 為何重要

標準成本效益分析在加總英鎊數額時，並不追問這些英鎊屬於誰，這隱含地假定一英鎊對每個人的價值都相同——而經濟學家早已知道這一假設是錯誤的。一個年收入 15,000 英鎊的家庭，對獲得 1,000 英鎊收益的體驗，與一個年收入 150,000 英鎊的家庭截然不同，因為收入的邊際效用隨收入增加而遞減。如果不加權，標準評估會系統性地偏向那些惠及更富裕、境況已然更好群體的介入措施，因為這些群體更高的消費能力，會抬高其所獲效益的貨幣估值（一處昂貴住宅附近的公園升級，"顯示出"的房產價值收益，會比同樣的升級發生在廉價住宅附近時更大，這純粹是因為價格更高，而不是因為福祉增益更大）。

《綠皮書》關於分佈性分析的補充指南，在財政部 2020 年評估方法審查回應了"評估方法系統性偏向倫敦及東南部地區"的批評之後得到了強化，提出了一種基於假定的收入邊際效用彈性約為 1.3 的正式加權方法——意味著收入翻倍大致會使額外一英鎊的邊際價值減半（具體而言，是 2^-1.3 ≈ 0.41 倍）。這不是一項舍入調整：應用它可能會改變兩個競爭專案中哪一個顯示出更高的淨現值，尤其是在將一項集中於貧困地區的介入措施與一項面向一般人群的介入措施進行比較時。

## 數學原理

《綠皮書》為收入水平為 y 的家庭所獲得的一英鎊效益、相對於全國平均收入水平 ȳ 所設定的分佈性權重：

```
權重(y) = (ȳ / y)^e

其中：
  y  = 家庭收入（或受影響群體的收入）
  ȳ  = 平均（參照）家庭收入
  e  = 收入邊際效用彈性（《綠皮書》：約為 1.3）
```

將權重應用於淨效益：

```
加權效益 = Σ [群體 i 的未加權效益 × 權重(y_i)]
```

一個收入為全國平均水平一半（y = 0.5ȳ）的群體，權重為 (1/0.5)^1.3 = 2^1.3 ≈ 2.46——該群體每獲得一英鎊效益，其價值大致相當於平均收入家庭獲得的 2.46 英鎊。

## 實例演算

**兩個競爭性地方專案**，未加權淨效益均為每年 200 萬英鎊，正在爭奪同一筆區域增長基金：

- **專案 A**：位於一個富裕城鎮的企業支援計劃，平均家庭收入 45,000 英鎊（約為假定全國平均水平 35,000 英鎊的 1.3 倍）。
- **專案 B**：位於一個貧困選區的技能培訓專案，平均家庭收入 18,000 英鎊（約為全國平均水平的 0.51 倍）。

```
權重(A) = (35,000 / 45,000)^1.3 = (0.778)^1.3 ≈ 0.72
權重(B) = (35,000 / 18,000)^1.3 = (1.944)^1.3 ≈ 2.53

加權效益 A = 2,000,000 英鎊 × 0.72 = 144 萬英鎊
加權效益 B = 2,000,000 英鎊 × 2.53 = 506 萬英鎊
```

未加權時，兩個專案打成平手。經過分佈性影響加權後，專案 B 的效益是專案 A 的三倍多——這一結果逆轉了資助建議，也正體現了《綠皮書》要求展示加權結果、而不僅僅是未加權效益成本比的明確用意。

**慈善撥款分配**：一個資助方在比較一筆 50 萬英鎊的撥款惠及 1,000 戶低收入家庭（權重 ≈ 2.0，加權價值相當於 100 萬英鎊）與同樣 50 萬英鎊惠及 1,000 戶中等收入家庭（權重 ≈ 1.0，加權價值相當於 50 萬英鎊）時，應當在董事會檔案中明確展示這一分佈性論證，而不是留待他人自行推斷。

## 與軟體工程的關聯

分佈性加權很少直接出現在軟體交付指標中，但它應當塑造工程和資料團隊設計測量與定位方式的方式：

- 在建置影響力儀表盤或效益計算器時，應當展示受影響人群的收入或貧困程度概況，而不僅僅是一個彙總效益總數——沒有分佈性細分的彙總數位，恰恰會掩蓋上文所示的那種逆轉結果。
- 將服務設計中的定位邏輯與《綠皮書》所使用的同一套貧困資料關聯起來——參見[多重貧困指數](../多重貧困指數/)——使一項數位服務的觸達範圍能夠按公平性（[物有所值](../物有所值/)中飽受爭議的第四個"E"）而非僅按效率來評估。
- 當一個演算法用於分配稀缺資源（預約名額、個案工作人員的時間、一項補貼）時，一個未加權的"最大化總效益"目標函式，從其構造方式上就會復現《綠皮書》加權機制原本要糾正的那種偏差——應在最佳化之前明確向政策負責人標註這一點。

## 常見陷阱

- **在一個專案組合中不一致地應用分佈性權重。** 只為某一個專案的效益加權、而不為其對照專案加權，會產出一個有偏差、而非更公平的比較；《綠皮書》要求進行同等對待。
- **未經調整地使用房產或市場價值作為福祉的代理指標。** 市場價格本身就受到既有收入不平等的扭曲，而這正是分佈性加權本應糾正的問題；使用未經調整的市場價值可能會使這種偏差被重複計算。
- **忽視群體內部的差異。** 按地區平均收入（例如某個多重貧困指數十分位）加權，可能無法準確代表與所在地區平均水平不符的個體；應使用合理可得的、最細粒度的收入資料。
- **將 1.3 這一彈性係數視為普適常數。** 《綠皮書》本身也指出這只是一個具有合理區間的估計值；對重大決策應針對不同彈性係數進行敏感性檢驗，而不是將 1.3 視為精確值。
