# 公民滿意度指標

公民滿意度指標衡量的是人們對公共服務直接體驗的評價——它不同於對整體機構的信任，也不同於該服務是否真正取得了良好成果。一項服務可能廣受喜愛卻效果不彰，也可能效果顯著卻不受歡迎；這兩者之間的差距本身，就是交付團隊應當密切關注的診斷資訊。

## 為何重要

滿意度在兩個經常被混為一談的不同層面上被測量。在服務層面，英國已退役的 Performance Platform 以及如今的 GOV.UK 服務手冊（Service Manual）都要求每項服務進行滿意度調查（通常採用五級量表，從"非常滿意"到"非常不滿意"，在交易完成時發放），作為四項強制性服務關鍵績效指標之一——參見[服務標準與交易指標](../服務標準與交易指標/)。在機構層面，英國公務員人員調查（Civil Service People Survey）每年在中央政府各部門衡量員工敬業度與體驗；另外，經濟合作與發展組織（OECD）的"政府信任"（Trust in Government）專案則在各成員國之間調查公眾對國家政府的信任度，其長期走勢呈現出深受危機影響的下滑與回升模式（2008 年金融危機和新冠疫情都在 OECD 信任度資料中造成了明顯而劇烈的波動）。建置面向公民服務的工程師之所以需要將滿意度與成果區分開來，是因為這是服務設計中一種已知的失敗模式：一份設計精美、易於使用的福利申領數位表單，可能獲得非常高的滿意度評分，而其背後的政策本身——資格規則、處理積壓、發放金額——卻絲毫沒有讓申領人受益更多。滿意度衡量的是介面，而不是介面背後所交付的價值。

## 數學原理

```
淨滿意度 = 滿意（或非常滿意）百分比 − 不滿意（或非常不滿意）百分比
           （中立/無意見的回答不計入這兩項，但計入用於計算
           各自百分比的應答基數）

滿意度與成果差距 = 滿意度分數 − 成果達成分數
           （兩者均歸一化為 0–100；正向差距較大，
           意味著一項服務"感覺不錯"但實質交付不足）

信任指數（OECD 式） = 在"您對[國家政府]是否有信心？"這一問題上
           回答"是"的受訪者百分比，作為時間序列跟蹤，
           通常按年齡、收入和教育程度進行分類
```

## 實例演算

**某地方政府市政稅電子賬單服務**：在成功完成交易時進行的滿意度調查顯示，共 2,400 名受訪者：1,650 人滿意/非常滿意，250 人不滿意/非常不滿意，500 人持中立態度。

```
淨滿意度 = (1,650/2,400 × 100) − (250/2,400 × 100)
          = 68.75% − 10.42%
          = +58.3 淨滿意度
```

單看這一數位表現強勁。但該調查只向*成功*完成交易的使用者展示——這是一種已知的測量偏差（參見下文的常見陷阱）。將其與[服務標準與交易指標](../服務標準與交易指標/)中的完成率指標結合來看，完成率只有 71%，這意味著：

```
放棄辦理旅程的 29% 使用者，其真實滿意度從未被測量——
這很可能正是最不滿意的群體，因為放棄行為本身
就是一個該調查從未捕獲過的強烈負面訊號。
```

**全國層面示例（OECD 式信任度序列的結構）**：國家政府信任度在第一年報告為 42%，在第二年（一個危機年份）降至 34%，第三年回升至 39%——這正是 OECD 在各成員國重大危機之後所記錄的典型衝擊與部分回升模式。

## 與軟體工程的關聯

應當在使用者旅程中每一個有意義的退出節點上都進行滿意度調查的儀表化，而不僅僅是在成功完成時——這是該領域最常見的工程錯誤，它會在不知不覺中將滿意度指標變成一個存在倖存者偏差的虛榮指標。在可能的情況下，應將滿意度分數與同一儀表盤上的完成率或成果指標配對展示，避免團隊在完成率悄然下降的同時還在為滿意度上升而慶祝（關於最初就被排除在數位滿意度抽樣之外的人群，非數位使用者和輔助數位使用者在服務內調查中系統性地代表不足，參見[單筆交易成本](../單筆交易成本/)和[數位包容](../數位包容/)）。滿意度與信任資料也直接構成 [Moore 戰略三角](../公共價值/)中正當性這一條邊的輸入，並且應當歸入[公共價值計分卡](../公共價值計分卡/)的"客戶"與"正當性"視角之中——關於該服務層面指標在機構層面的對應指標，參見[信任與正當性指標](../信任與正當性指標/)。

## 常見陷阱

- **完成時點調查中的倖存者偏差**：放棄辦理旅程的使用者永遠不會看到該調查，因此服務內的高滿意度分數完全可能與低完成率、以及一大群未被看見的不滿意未完成使用者群體同時存在。
- **將滿意度當作成果的代理指標**：一個為設計糟糕的政策打造的精心設計介面，會在滿意度上得分很高、在成果上得分很差——應當始終同時報告兩者，絕不能用其中一個替代另一個。
- **以虛假精確度報告小規模、非代表性樣本**：來自幾百名自我選擇受訪者的滿意度分數，若報告到小數點後一位，會暗示一種樣本規模根本無法支撐的置信度。
- **忽視人口統計學層面的分類**：未按年齡、收入、殘障狀況或數位接入方式細分的全國信任度與滿意度數位，可能掩蓋不同群體之間截然不同的體驗——OECD 自身釋出的"政府信任"報告就明確對此進行了分類。
