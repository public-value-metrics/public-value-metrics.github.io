# 公共服務生產力

公共服務生產力衡量的是公共支出將投入（人員、資本、貨物與服務）轉化為經品質調整後產出的效率，適用於那些沒有市場價格、因此也就沒有一個可用來分攤成本的收入數位的服務——醫療、教育、治安、社會關懷。英國國家統計局（ONS）自 2000 年代中期以來一直髮布這一系列資料，它仍然是方法論上最為成熟的、試圖回答"政府將資金轉化為公共服務的能力是在變好還是變差"這一問題的國家級嘗試。

## 為何重要

在市場中，生產力是（產出價值）/（投入成本），而產出價值是可觀察的，因為有人為之付費。一次髖關節置換手術、一個學位名額、一次警察巡邏都沒有銷售價格，因此樸素地看，你只能測量*投入*（花費了什麼）——這誘使評論者把不斷上升的公共支出自動當作壞事，因為投入增加而頭條活動量持平看起來就像生產力下降。ONS 在其關於公共服務生產力的《資料來源與方法》出版物中所闡述的方法論，透過從活動量（進行的手術數、教授的學生數、調查的犯罪案件數）建置一個*產出*指數，再對該產出指數進行*品質調整*來解決這一問題——對醫療領域，納入存活率和候診時間；對教育領域，納入學業成就；對治安領域，納入案件結案等成果——從而使一項完成同樣數量手術、卻取得了更高存活率的服務被記錄為生產力更高，而不僅僅是花費更多。ONS 各版釋出中反覆出現的頭條發現令人警醒：英國公共服務生產力在新冠疫情期間急劇下降，而根據 ONS 自己在 2020 年代中期釋出的資料，包括醫療保健在內的若干子行業至今仍未恢復到 2019 年的水平，即便支出一直在上升——這一差距使"更多資金"和"更高生產力"成為兩個完全獨立的問題。

## 數學原理

```
產出指數（量）= Σ (活動量_i × 相對單位成本權重_i)，以基年為
                權重，涵蓋所有服務活動（例如髖關節手術、白內障
                手術、全科醫師問診），類似於拉斯拜爾/帕歇量指數

品質調整      = 產出指數 × 品質調整係數
                （例如將存活率、候診時間、學業成就或再犯率
                的變化，作為原始量的一個乘數納入計算）

投入指數      = Σ (勞動工時 × 勞動成本權重) + （已折現的
                貨物/服務成本） + （資本消耗）

全要素生產力增長 = 經品質調整後產出指數的百分比變化
                   − 投入指數的百分比變化
```

## 實例演算

**示例性的 NHS 急症部門生產力計算**（結構遵循 ONS 方法論）：

```
第一年：產出量指數 = 100.0（基年），投入指數 = 100.0
        → 生產力指數 = 100.0

第二年：活動量上升 3.0%（更多手術，更多預約），
        但平均候診時間惡化，施加 −1.0% 的品質調整折扣
        經品質調整後的產出指數 = 100 × 1.030 × 0.990 = 101.97

        投入上升：員工人數 +4.0%，其他成本（已折現）+1.5%，
        加權投入指數 = 100 × 1.032 = 103.2

生產力增長 = (101.97 / 100 − 1) − (103.2 / 100 − 1)
           = 1.97% − 3.2% = −1.23 個百分點

解讀：活動量上升了，但投入上升得更快、品質也略有下降，
因此生產力——每單位投入的產出——是下降的，即便
"提供了更多的關懷服務"。
```

這正是 ONS 各版釋出反覆報告的、疫情後 NHS 部分領域所呈現的模式：支出上升、原始活動量上升，但一旦同時計入品質調整和投入增長，測得的生產力卻在下降。

## 與軟體工程的關聯

公共服務生產力是工程生產力爭論（已交付的故事點數 vs [DORA 指標](../面向公共價值的-dora-指標/) vs [流動指標](../政府交付中的流動指標/)）在人群層面的對應物：沒有品質調整的原始吞吐量，在一家醫院裡和在一個軟體團隊裡同樣具有誤導性，就像"已交付的程式碼行數"一樣。為各部門建置績效資料流水線的團隊，應將品質調整視為一個一等的、有版本管理的轉換階段，而不是一條腳註——因為 ONS 自身的可信度，正建立在該調整過程透明、可復現、並能隨著更優質資料的到來而修訂這一基礎之上（ONS 會隨著底層品質資料——例如存活率——的最終確定而修訂以往年份的生產力估計，因此任何消費這些統計資料的下游系統都必須能夠處理追溯性修訂，而不僅僅是追加新週期的資料）。它也與[總擁有成本](../政府-it-中的總擁有成本/)和[公共部門中的 AI 生產力](../公共部門中的-ai-生產力/)直接相關：按 ONS 自己的定義，一個在不改善或維持品質的情況下提高原始活動量的系統，並不算是生產力的提升。

## 常見陷阱

- **將投入增長當作生產力增長。** 更多支出資助更多員工，產生的是更多的*活動*，而不是更高的*生產力*，除非每單位投入的產出也隨之上升——這兩者在政治評論中經常被混為一談。
- **完全忽視品質調整。** 一個僅由原始活動計數建置的產出指數，會將從事更多低價值或低品質工作顯示為"生產力提升"；ONS 的品質調整機制正是專門為捕捉這一點而設的。
- **在未匹配方法論版本的情況下跨子行業比較生產力指數。** 醫療、教育和治安的生產力各自由不同的活動和品質資料來源、按不同的修訂週期建置而成——樸素的跨行業比較是在比較不可相容的度量工具。
- **將單一年份的生產力下降解讀為永久趨勢。** 疫情期間及疫情後的生產力數位，隨著品質資料本身（例如候診名單、擇期手術恢復情況）的變化而呈現出顯著的逐年波動；ONS 一貫提醒不要過度解讀單一年份的變動。
