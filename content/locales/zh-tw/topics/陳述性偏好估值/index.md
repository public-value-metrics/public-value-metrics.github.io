# 陳述性偏好估值

陳述性偏好方法，透過直接詢問人們願意為一件非市場性物品支付多少、或願意接受多少補償來放棄它，來估計其價值，通常透過一份描述假設情景的結構化調查來進行。或有價值評估法（Contingent valuation）是這一方法家族中最著名的技術。

## 為何重要

《綠皮書》附錄 2（關於非市場性影響估值的補充指南）認可將陳述性偏好方法用於那些根本沒有可觀察市場交易可供推斷價值的物品——空氣品質、生物多樣性、防洪保護，以及一處某人可能永遠不會造訪的景觀的存在價值（<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>）。環境、食品與鄉村事務部（Defra）已釋出了自己針對環境評估的陳述性偏好指南，正是因為大量的環境價值（棲息地保護、水質）根本沒有代理市場存在，這與噪音（至少與可觀察的房價相關，參見[顯示性偏好估值](../顯示性偏好估值/)）不同。

陳述性偏好方法的核心吸引力——它幾乎可以為任何東西估值，包括從未有人交易過的物品——同時也是其可信度問題的根源。由於受訪者並未真正花錢，或有價值評估調查容易受到假設性偏差（在沒有真實預算約束的情況下，人們會誇大自己的支付意願）、嵌入效應（同一件物品，根據調查中還包含了什麼其他內容而被賦予不同的價值），以及競價博弈設計中起點偏差的影響。1993 年，在埃克森·瓦爾迪茲號漏油事件訴訟之後召集的 NOAA 或有價值評估專家小組，提出了一套設計標準——採用二元的"你願意支付 X 英鎊嗎？是/否"公投式格式，而非開放式競價，並強制提醒受訪者其實際的預算約束——這些標準至今仍是站得住腳調查的參考標準。

## 數學原理

```
或有價值評估（公投格式）：
  提出一個二元選擇："你願意每年為結果 Y 支付 X 英鎊嗎？是/否"
  在受訪者之間隨機變化 X 的數值。
  以每個 X 值下"是"的應答率為函式擬合支付意願。

平均支付意願 = 估計需求曲線下方的面積
總體價值 = 平均支付意願 × 受影響人口

選擇實驗（離散選擇建模）變體：
  向受訪者反覆展示若干組屬性組合（包括一個成本屬性）
  之間的選擇，從受訪者所揭示的權衡取捨中估計出
  每個非成本屬性的隱含價格。
```

在當前英國實踐中，相較於單一問題的或有價值評估，選擇實驗變體通常更受青睞，因為反覆迫使受訪者在若干屬性與成本之間進行權衡，所產出的估計值內部一致性更強、也更難被操縱，優於單一的是/否問題。

## 實例演算

**中央政府**：Defra 委託開展一項或有價值評估調查，為一項河流水質改善專案估值。一份公投格式的調查，針對 2,000 戶家庭，發現 62% 的家庭願意透過一項假設性的水費附加費每年支付 40 英鎊，估計得出的需求曲線給出每戶平均支付意願為每年 28 英鎊。

```
平均支付意願 = 每戶每年 28 英鎊
流域內家庭數 = 340,000
年度總體價值 = 28 × 340,000 = 952萬英鎊/年

按 3.5% 折現率計算的 20 年評估週期（年金係數 ≈ 14.2）：
PV(效益) ≈ 952萬 × 14.2 ≈ 1.35億英鎊
```

這一總體數位隨後會與該專案[社會成本效益分析](../社會成本效益分析/)中的成本一側相比較。《綠皮書》要求將此類陳述性偏好證據連同其置信區間和調查方法一併報告，而不是作為一個裸露的點估計值，正是因為其底層數位比市場價格要脆弱得多。

**慈善機構**：某遺產信託機構對到訪者和非到訪者都進行了支付意願調查，詢問他們是否願意支付以防止一座歷史建築（兩個群體都未必會去參觀）關閉（即其存在價值）。因為那些永遠不會去看這座建築的非到訪者，依然報告了正的支付意願，該調查捕捉到了一種簡單的門票收入統計（一種顯示性偏好代理指標）會完全遺漏的存在價值和遺贈價值——這正體現了在根本不存在任何市場交易可揭示價值的情況下，陳述性偏好方法的真正優勢。

## 與軟體工程的關聯

陳述性偏好方法很少直接應用於軟體工程工作本身，但建置公民諮詢平臺、預算參與工具或公共調查基礎設施的工程師，往往正在建置這一經濟學方法所依賴的工具。正確設計調查細節——隨機化的競價金額、二元公投式框架而非開放式問題、明確的預算約束提醒——不是一個 UX 層面的錦上添花之舉，而是使最終估值經得起審查的關鍵所在；一份設計糟糕的應用內調查，可能會使後續數月的經濟分析全部失效。關於獲取能夠承載分析權重的公眾意見資料這一更普遍的紀律，參見[公民滿意度指標](../公民滿意度指標/)。

## 常見陷阱

- **開放式的"你願意支付多少？"問題。** 相較於二元公投式框架，這類問題遠更容易受到策略性偏差和錨定偏差的影響；NOAA 專家小組建議採用公投格式，正是因為開放式詢問表現不佳。
- **沒有提醒受訪者其實際的預算約束。** 若無此提醒，陳述的支付意願通常會超過同一批人在面對真實預算權衡時願意支付的金額——即假設性偏差。
- **忽視嵌入效應。** 同一件物品單獨估值與作為更大一攬子內容的一部分來估值，會產出不同的支付意願估計值；應報告調查框架中還包含了哪些其他內容（如果有的話）。
- **將單次調查的點估計值當作定論。** 《綠皮書》的實踐期望提供一個區間以及對已知偏差的討論，而不是把一個裸露的數位直接帶入成本效益表格，彷彿它是一個市場價格。
