# 志願者時間價值

志願者時間價值，是賦予無償勞動的貨幣化估計，最常用於陳述一家慈善機構真實的經濟足跡——其賬目加上其本無需支付的勞動——或用於論證某項特定介入措施比其現金預算單獨所暗示的更具成本效益。有兩套全國性方法論佔據主導地位：美國的 Independent Sector 估演算法和英國國家統計局/NCVO 方法，二者對同一小時勞動的定價相當不同。

## 為何重要

Independent Sector 每年與馬里蘭大學 Do Good Institute 合作，基於勞工統計局的工資資料——具體而言是私營非農業薪資單上生產和非監督人員的平均時薪，加上一項附加福利調整——釋出全國性的志願者時間小時價值，並按美國各州細分。其最新一版資料將該價值定為**2025 年每小時 36.14 美元**，較上一年上升 3.9%，各州數值從華盛頓特區的超過 50 美元到波多黎各的不足 20 美元不等。在英國，國家統計局單獨估算了正式志願服務的替代成本為**每小時 14.43 英鎊**（2017 年估算），NCVO 的《英國公民社會年鑑 2024》則使用志願服務參與資料——2021-22 年間約有 1,420 萬人正式參與志願服務——估算該部門志願服務的總貢獻約為**180 億英鎊**，約佔英國 GDP 的 0.8%。

這一點之所以重要，而不僅僅是會計上的表面文章：一個高度依賴志願者勞動的專案，在純現金的[單位成果成本](../單位成果成本/)基礎上，可能看起來比一個依賴帶薪員工的專案便宜得多，即便真實的資源成本——即替換這份勞動所需的花費——相近甚至更高。忽視志願者時間價值的資助方和評估人員，會系統性地低估以志願者為主的交付模式的真實成本，從而扭曲與實現同一成果的帶薪員工模式之間的效率比較。

## 數學原理

```
志願者時間價值 = 貢獻的志願工時 × 每小時費率

費率的選擇會影響結果，而且很重要：
  - 替代成本法：由一名帶薪員工完成同樣任務所需的工資
    （例如一名合格青年工作者的替代成本費率，而非
    通用平均工資）——對具體任務估值最具說服力
  - 機會成本法：志願者自身被放棄的工資——對衡量
    志願者所付出的代價最具說服力
  - 全國平均法：Independent Sector 或 ONS 的單一
    混合費率——對頭條數位、跨行業可比性最具說服力
```

對於同樣的一小時，這三種方法可能相差數倍之多（一位以董事會受託人身份提供志願服務的律師，其機會成本費率與全國平均費率截然不同），因此任何報告出的數位都需要說明是用哪種方法得出的。

## 實例演算

**英國慈善機構，全國平均法**：一年內 5,000 志願工時，按每小時 14.43 英鎊（ONS 替代成本估算）估值：

```
價值 = 5,000 × 14.43 英鎊 = 72,150 英鎊
```

如果該慈善機構當年的現金支出為 300,000 英鎊，其真實資源成本——現金加志願者勞動——為 372,150 英鎊，比單純的現金數位高出約 24%。僅使用 300,000 英鎊現金數位計算的單位成果成本，會以同樣的幅度低估真實成本。

**美國慈善機構，全國平均法**：2,000 志願工時，按每小時 36.14 美元（Independent Sector，2025 年釋出）估值：

```
價值 = 2,000 × 36.14 美元 = 72,280 美元
```

**同一家美國慈善機構，機會成本法**：如果志願者中不成比例地包含收入曾平均達每小時 60 美元的退休專業人士，機會成本估值將為 120,000 美元——比全國平均數位高出三分之二，這說明了為何必須明確說明所用的方法。

## 與軟體工程的關聯

記錄志願工時的系統（排班工具、志願者管理平臺）應當在任務或角色層面捕獲工時，而不僅僅是一個總數，從而使替代成本費率能夠按角色分別應用，而不是對一支構成混雜的志願者隊伍統一套用一個全國平均費率（一名受託人的一小時與一名引導員的一小時，在經濟學意義上並不等價）。將所用的費率和方法論與計算出的價值一併儲存——而不僅僅是最終的貨幣數位——使下游報告（年度賬目、[社會投資回報](../社會投資回報/)計算、資助方報告）日後能夠復現或質疑這個數位，而不是將其當作一個不透明的常數來對待。關於省略志願者時間價值為何會系統性地低估真實交付成本，參見[單位成果成本](../單位成果成本/)。

## 常見陷阱

- **對結構上不同的角色使用單一的統一費率。** 將全國平均工資費率應用於一小時專業無償服務（法律、財務、臨床），會嚴重低估其價值；只要任務具有專業技能性，就應將費率與被替代的角色相匹配。
- **與帶薪員工成本重複計算。** 如果志願者替代的是原本需要付費的工作，應確保該估值是現金支出之外的附加項，而不是疊加在一個已經被誇大的人員配置估算之上。
- **引用過時的費率卻不註明日期。** Independent Sector 和 ONS 的費率每年都會變化（在 ONS 的情況下，只是定期重新估算）；報告中一個未標註日期的志願者時間數位，對比較而言幾乎毫無意義。
- **將志願者時間價值當作籌款資產。** 它是一項用於理解真實資源成本的成本核算調整，而不是一筆慈善機構可以支配的新資金；將兩者混為一談會誤導閱讀賬目的董事會成員。
