# 成果導向問責制（OBA）

成果導向問責制，又稱結果導向問責制（Results-Based Accountability，RBA），是 Mark Friedman 提出的框架，用於分離兩個公共部門報告中習慣性地混為一談的問題："人群狀況是否良好？"（人群層面問責）與"這個具體專案本身表現是否良好？"（績效層面問責）。在 Friedman 看來，將這兩者混為一談，是營運良好的專案被歸咎於其根本無力左右的人群層面趨勢的最常見原因。

## 為何重要

Friedman 在《光努力是不夠的》（*Trying Hard Is Not Good Enough*，2005）一書中提出了這一框架，指出大多數公共報告要麼讓決策者淹沒在沒有任何單一機構能夠控制的人群層面統計資料中（青少年懷孕率、失業率、預期壽命），要麼讓他們淹沒在絲毫說明不了任何人生活是否得到改善的專案層面活動計數中（服務的客戶數、發出的轉介數）。RBA 的貢獻在於提供了一套精簡而嚴謹的詞彙，將兩者區分開來：人群成果（一個整體人群的福祉狀況，例如"兒童健康出生"）不屬於任何單一機構，需要許多合作方共同努力；績效衡量指標（一個具體專案為其具體客戶服務的成效如何）屬於一個機構，應當僅按該機構實際能夠施加影響的範圍來評判。Friedman 提出的"三個績效問題"——我們做了多少、我們做得有多好、有沒有人因此變得更好——如今已嵌入美國各州縣的人類服務合同管理體系，並透過與 RBA 理念一致的諮詢和工具機構 Clear Impact，被廣泛應用於英國和英聯邦國家的地方政府採購之中。這一點的實際利害關係是合同性的：一個住房專案不應僅僅因為該城市的無家可歸率由於其無法觸及的宏觀經濟原因而上升就被撤資，但如果它自己的客戶根本沒有被安置進住房，那它絕對應該被撤資。

## 數學原理

```
人群層面問責（一個社群、地區或國家共同面對的"大局"）：
  結果         — 一種福祉狀態（例如"居民經濟上有保障"）
  指標         — 衡量該狀態的指標（例如失業率、家庭收入中位數）
  → 沒有任何單一專案擁有該指標；其變動需要許多貢獻者共同努力

績效層面問責（一個專案自身負責的內容）：
  我們做了多少？    — 活動量（服務的客戶數、交付的單位數）
  我們做得有多好？  — 品質/效率（專案完成率、每客戶成本）
  有沒有人變得更好？— 真正重要的成果（專案結束後 6 個月的
                     就業比例，前後對比或與對照組相比較）

一個專案應根據第三個績效問題來評判，而不應直接根據
人群指標來評判，除非其規模和設計確實有可能單獨左右
該指標。
```

## 實例演算

**某城市資助的就業支援專案**，每年 500 名參與者，由地方政府按 RBA 式績效框架簽約管理：

```
人群指標（背景資訊，而非該專案的成績單）：
  該市失業率：6.2%（較上年的 5.8% 上升，原因是該專案
  無法控制的一次工廠關閉）

績效衡量指標（該專案真正的問責內容）：
  做了多少：招募了 500 名參與者（目標 480）——達標
  做得多好：78% 完成率；每名完成者成本 = 340,000 英鎊 /
            390 名完成者 ≈ 872 英鎊
  是否變好：390 名完成者中有 260 人在 6 個月後仍保持就業，
            佔 66.7%，相較於匹配對照組的 41%
            （參見 counterfactual-analysis）
```

按人群層面問責來解讀，該專案看起來像是失敗的——該市失業率在其運作期間上升了。而按 RBA 的績效層面問責來解讀，該專案是成功的：它達成了招募量目標，保持了品質穩定，併產出了比匹配對照組高出 25.7 個百分點的就業成果，而人群指標的變動，則完全是由該專案無法控制的原因（一次工廠關閉）所致。

## 與軟體工程的關聯

RBA 與一個熟悉的 SRE 區分直接對應：人群指標就像沒有任何單一工程團隊能夠端到端擁有的業務層面"北極星"指標（公司收入、市場份額），而績效衡量指標則像一個團隊自己的服務級別目標（SLO）——即該團隊的設計決策真正能夠左右的事項。一個同時報告兩者、卻不標註哪個是哪個的儀表盤，恰恰會招致 RBA 旨在防止的那種錯誤歸因：一位值班工程師因一項由依賴團隊所控制的指標而被追責。在為成果合同委託或建置報告工具時，應將"做了多少/做得多好/是否變好"這一三元組建置為一等的、可分別篩選的欄位，而不是一個單一的混合關鍵績效指標——這與在[公共部門關鍵績效指標](../公共部門關鍵績效指標/)中區分領先指標和滯後指標是同一種紀律。RBA 也是[按效果付費與社會效益債券](../按效果付費與社會效益債券/)背後的問責邏輯：一份按效果付費的合同只能公平地按"是否變好"這一績效指標付款，而絕不能按人群指標付款，除非該介入措施確實是該指標的主導驅動因素。

## 常見陷阱

- **依據一個專案無法控制的人群指標對其進行付款或懲罰**：這正是 RBA 旨在防止的那個錯誤；在為某個人群成果附加後果之前，應始終先追溯該專案對其貢獻是主要的還是次要的。
- **將"做了多少"當作"是否變好"來報告**：活動計數（服務的客戶數）是最容易收集、也最缺乏資訊量的資料；應堅持用真實的成果資料、最好是對照一個反事實情形（參見[反事實分析](../反事實分析/)）來回答"有沒有人變得更好"這個問題。
- **將 RBA 指標當作永久固定不變的。** Friedman 的方法明確是迭代式的——一個"資料、故事、有效做法、行動計劃"的迴圈——而不是一次性的計分卡設計工作。
- **"是否變好"沒有對照組**：一次沒有反事實情形的前後對比，會將專案效應與人群本來就會呈現的趨勢混為一談。
