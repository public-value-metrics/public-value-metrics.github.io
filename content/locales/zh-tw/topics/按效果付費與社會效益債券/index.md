# 按效果付費與社會效益債券（PbR/SIBs）

按效果付費（Payment by results，PbR）依據已核實達成的成果、而非已執行的活動，向服務提供方付款。社會效益債券（Social Impact Bond，SIB）是一種具體的 PbR 融資結構，在該結構中，私人或慈善投資者預先為服務交付提供資金，只有在獨立測量的成果達到商定門檻時，才由政府委託方連本帶息償還——將交付風險從納稅人轉移到投資者身上。

## 為何重要

世界上第一支 SIB 於 2010 年 9 月在彼得伯勒監獄（HMP Peterborough）啟動：Social Finance 從 17 名投資者處籌集了 500 萬英鎊，用於資助"一站式服務"（One Service），面向短刑期囚犯（12 個月以下）開展工作以降低再犯率；司法部和大樂透基金（Big Lottery Fund）同意，只有當再犯事件相對於一個匹配的全國對照佇列下降至少 7.5% 時，才向投資者償還本金。彼得伯勒試點的最終佇列記錄了 9.7% 的再犯率下降，遠高於門檻，投資者獲得了本金加回報的償還。這一機制之所以重要，是因為它解決了一個具體的採購問題：政府希望為成果而非投入付費，但無法承擔一項可能不奏效的介入措施所帶來的財務風險，因此 SIB 結構將這一風險轉移給了願意為其承保的投資者。牛津大學布拉瓦特尼克政府學院（Blavatnik School of Government）下設的政府成果實驗室（Government Outcomes Lab，GO Lab），如今維護著全球範圍內關於 PbR 和 SIB 表現最完整的公開證據庫，跟蹤著全球超過 200 支影響力債券，併發布關於哪些設計特徵與成功或失敗相關的研究。這一證據庫反覆得出的教訓是：*所選定的成果指標*，以及誰承擔未達標的風險，幾乎決定了一份 PbR 合同在實踐中如何運作的一切。

## 數學原理

```
PbR 付款 = 基礎付款（如有） + Σ (已達成的成果 × 每項成果單價)

社會效益債券投資者回報：
  投資者出資   = 預先投入用於資助服務交付的資本
  成果付款     = 委託方僅在成果 ≥ 門檻時付款，
                根據表現超出門檻的幅度按比例調整
  投資者回報   = 獲得的成果付款 − 投資者出資
                （一個回報率，通常設有上限，反映所承擔的風險）

決定整份合同行為的關鍵設計引數：
  成果指標            — 必須是一項成果，而非產出（參見 outcomes-vs-outputs）
  對照/反事實情形     — 通常是一個匹配佇列（參見 counterfactual-analysis）
  付款門檻            — 觸發任何付款所需的最低改善幅度
  付款曲線            — 線性、階梯式，或在門檻之上設有上限
  歸因/無謂損失折扣   — 參見 additionality-and-deadweight
```

## 實例演算

**彼得伯勒一站式服務**（示例數位取自已發表的評估）：

```
籌集的投資者資本：       5,000,000 英鎊
佇列：                   約 3,000 名短刑期男性囚犯，分兩批佇列
門檻：                   相對於匹配的全國對照組，再犯事件
                         下降 ≥7.5%，否則不予付款
第一批佇列結果：         下降 8.4%——按原規則單獨計算，
                         未達到該批佇列的合同門檻
合併/最終佇列結果：      下降 9.7%——超過門檻
成果付款：               政府（司法部/大樂透基金）按超出
                         門檻的每個百分點付款，用於資助
                         償還投資者本金及回報
```

**地方政府 PbR 合同（示例性）**：某家庭介入服務的委託方式為，每轉介一個家庭支付 4,000 英鎊（活動付款），加上結案 12 個月後未再有兒童保護轉介的每個家庭再支付 6,000 英鎊（成果付款）。共轉介 200 個家庭，150 宗結案，96 宗在 12 個月後仍未再被轉介：

```
活動付款   = 200 × 4,000 英鎊 = 800,000 英鎊
成果付款   = 96 × 6,000 英鎊  = 576,000 英鎊
合同總成本 = 1,376,000 英鎊，對應 96 個已確認的持續性成果
每個已確認成果的成本 ≈ 14,333 英鎊（參見 cost-per-outcome）
```

## 與軟體工程的關聯

按效果付費首先是一個激勵對齊問題，其次才是一個資料問題，而資料系統正是這種對齊得以維繫或破裂的地方。獨立、防篡改的成果核驗是全部關鍵所在：委託方和服務提供方在一個含糊不清的案例應當如何編碼這一問題上，存在相反的激勵，因此記錄成果的系統需要一條審計軌跡、一份與獨立核驗方（往往是與服務提供方不同的機構，有時是與警方或福利記錄進行比對的官方統計機構）的資料共享協議，以及成果定義的不可變版本管理——這是[公共部門關鍵績效指標](../公共部門關鍵績效指標/)中"重新定義指標"陷阱在 PbR 領域的對應版本。歸因計算依賴於[反事實分析](../反事實分析/)中的匹配佇列方法，這需要可復現、可審計的程式碼，而不是一份一次性的電子表格。而這項指標本身必須是一個真正的成果，而不是一個代理活動——參見[成果與產出](../成果與產出/)——因為一份為產出付費的 PbR 合同，只是給一如既往的常規資助貼上了新標籤、還附加了額外的交易成本。當一支 SIB 的社會回報被前瞻性地建模時，這種評估通常直接借用[社會投資回報](../社會投資回報/)的方法論。

## 常見陷阱

- **為一個容易被操縱的代理成果付費**："參加了課程"是一項被包裝成成果的活動；應堅持使用一個真正反映所尋求變化的衡量指標（再犯率、就業、住房穩定性）。
- **沒有可信的反事實情形**：沒有匹配對照組，一次改善可能是均值迴歸或更廣泛的趨勢，而非該專案的效果——參見[反事實分析](../反事實分析/)和[增益性與無謂損失](../增益性與無謂損失/)。
- **低估交易和評估成本**：PbR/SIB 計劃的獨立核驗、資料關聯和合同管理成本，經常達到合同價值的兩位數百分比——GO Lab 的證據庫將其記錄為計劃終止的一個反覆出現的驅動因素。
- **挑揀客戶或"雪藏"難案**：按成果付費的服務提供方，有直接的激勵去優先服務本來就更可能成功的客戶，而將最棘手的案例排在後面——應設計付款分層或案例組合調整機制來加以應對。
