# 顯示性偏好估值

顯示性偏好方法，從相關市場中可觀察到的行為、而不是直接詢問人們的意見，來推斷一項非市場性物品的價值。享樂定價法（hedonic pricing）和旅行成本法是兩種主力技術：兩者都從一筆真實的交易出發，為一件從未被直接出售過的東西反推出一個隱含價格。

## 為何重要

[陳述性偏好](../陳述性偏好估值/)方法提出的是一個假設性問題，而顯示性偏好方法觀察的是人們實際為之付費的行為，在其他條件相同的情況下，《綠皮書》通常將後者視為更為可信的證據，因為它不受假設性偏差的影響——一項享樂式房價研究中的受訪者，是真實支付了正在被測量的那份溢價或折價的（<https://www.gov.uk/government/publications/the-green-book-appraisal-and-evaluation-in-central-government>，附錄 2）。享樂定價法將一個市場價格——通常是房價——分解為該商品每一個屬性的隱含價格，使分析人員能夠分離出，例如，家庭為居住在更安靜或空氣品質更好的地方而實際支付的價格溢價，同時以統計方式控制其他所有同樣影響房價的屬性（面積、地段、學區）。旅行成本法對沒有門票的休閒遊憩場所做類似的事情：人們前往某地所花費的時間和金錢，揭示了該地對他們而言價值的一個下限，因為沒有人會承擔超出這次到訪對自己價值的成本。

這兩種方法都有一個共同的結構性侷限：它們只能為已經嵌入某筆現有市場交易中的價值進行估值。跑道附近的噪音會體現在房價中，因為在意噪音的人會自行選擇更安靜的住房；而一個無人到訪、也無人居住其附近的物種的存在價值，則根本不會體現在任何交易中——這正是[陳述性偏好](../陳述性偏好估值/)方法所要填補的空白。

## 數學原理

```
享樂定價法：
  房價 = f(結構屬性, 地段屬性,
           所關注的環境屬性, ...)
  透過迴歸估計；在保持其他一切不變的情況下，
  環境屬性的係數就是其隱含價格。

  屬性 X 的隱含價格 = ∂(房價) / ∂X

旅行成本法：
  到訪率（來自地區 i 的人均到訪次數）= f(來自地區 i 的
           旅行成本, 替代場所, 社會經濟控制變數)
  估計到訪次數作為旅行成本函式的需求曲線。
  消費者剩餘 = 估計需求曲線下方的面積
             = 該場所對到訪者的價值
```

這兩種方法都需要一套統計上合理的控制變數集合——遺漏一個混雜屬性（享樂定價法）或一個鄰近的替代場所（旅行成本法），會使隱含價格產生偏差，而這種偏差的方向往往事先並不明顯，這正是《綠皮書》附錄 2 要求報告迴歸設定和控制變數、而不僅僅是頭條係數的原因。

## 實例演算

**中央政府**：《綠皮書》自身的碳影子價格方法論，部分借鑑了享樂性證據，但一個更簡單的示例性案例是飛機噪音。一項享樂性研究，將航線區域內的房屋售價對按距離加權的噪音暴露進行迴歸，同時控制面積、房齡和學區，發現平均噪音暴露每增加 1 分貝，房價就下降 0.5%。以受影響地區一棟典型的 28 萬英鎊房屋為例：

```
每分貝的隱含價格 = 280,000 英鎊 × 0.5% = 每戶 1,400 英鎊
因新跑道導致噪音增加 3 分貝而受影響的家庭數 = 18,000
噪音增加所隱含的總成本 = 1,400 × 3 × 18,000 = 7,560萬英鎊
```

這是一次性的資本化成本（已嵌入房價之中），評估時必須注意不要將其與一個單獨估計的年度噪音困擾成本流重複計算。

**慈善機構**：一家環保慈善機構使用旅行成本法，為一處免費入場的自然保護區估值。基於到訪者郵編的調查資料顯示，平均往返旅行成本（時間按《綠皮書》建議的非工作時間價值計價，另加燃油費）為每次到訪 14 英鎊，每年到訪 40,000 人次。所估計的需求曲線——隨著來自某地區的旅行成本上升，到訪率下降——表明每次到訪的消費者剩餘，在實際花費的 14 英鎊之上，約為 9 英鎊。

```
年度總價值 = 40,000 次到訪 × (14 英鎊花費 + 9 英鎊消費者剩餘)
           = 40,000 × 23 英鎊 ≈ 920,000 英鎊/年
```

這遠遠超過該保護區零門票收入的規模，為該慈善機構的受託人在向資助方論證該場地的休閒遊憩價值時，提供了一個站得住腳的數位。

## 與軟體工程的關聯

顯示性偏好思維在公共部門產品分析中出現的頻率，比從業者所意識到的要高：一項免費政府數位服務的使用資料，本身就是價值的顯示性偏好證據（使用頻率、會話時長，以及——最能說明問題的——重複使用與一次性使用模式，可以用旅行成本模型處理到訪頻率與距離關係的同一種方式來分析）。當一項服務存在真正的替代方案（紙質渠道、電話熱線）時，公民為改用數位渠道所付出的"成本"（時間、流量、裝置）可以被估算出來，並與使用情況相比較，這直接呼應了旅行成本法的邏輯。參見[數位服務標準](../數位服務標準/)，以及面臨著完全相同的無直接市場價格物品估值問題的[開放資料的價值](../開放資料的價值/)。

## 常見陷阱

- **享樂模型中的遺漏變數偏差。** 遺漏一個相關屬性（例如學校品質，它同時與房價和所關注的環境變數相關）會使隱含價格估計產生偏差；應報告並審查模型設定，而不僅僅是結果。
- **旅行成本研究中忽視替代場所。** 如果存在一個更近的替代場所卻未加以控制，到訪者對該場所的顯示性價值就會被低估——他們到訪可能主要是因為它是免費的，而不是因為它具有獨特價值。
- **將顯示性偏好方法應用於完全沒有市場回聲的物品。** 存在價值、選擇價值和遺贈價值都不會體現在任何交易中，也無法透過享樂定價法或旅行成本法恢復出來——這一空白屬於[陳述性偏好估值](../陳述性偏好估值/)的範疇。
- **將資本化的（一次性）價值與年度流量相混淆。** 享樂性房價效應通常是一次性的資本化價值；將其當作年度效益流來對待，會誇大評估結果。
