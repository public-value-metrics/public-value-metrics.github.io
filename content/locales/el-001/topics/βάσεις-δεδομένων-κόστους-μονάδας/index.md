# Βάσεις δεδομένων κόστους μονάδας

Μια βάση δεδομένων κόστους μονάδας (unit cost database) είναι μια βιβλιοθήκη προ-ερευνημένων, τεκμηριωμένων χρηματοοικονομικών υποκατάστατων για κοινωνικά αποτελέσματα — η αξία της μετάβασης από την ανεργία στην απασχόληση, της μειωμένης μοναξιάς, μιας σταθερής μίσθωσης — που επιτρέπουν σε έναν επαγγελματία να χρηματοποιήσει ένα αποτέλεσμα χωρίς να αναθέτει εξατομικευμένη έρευνα αποτίμησης κάθε φορά. Υπάρχουν ώστε ένας μικρός φιλανθρωπικός οργανισμός που γράφει μια αίτηση χρηματοδότησης να μπορεί να εφαρμόσει την ίδια αυστηρότητα με μια καλά εξοπλισμένη συμβουλευτική εταιρεία, επαναχρησιμοποιώντας ένα υποκατάστατο που κάποιος άλλος έχει ήδη εξαγάγει και δημοσιεύσει.

## Γιατί έχει σημασία

Η UK Social Value Bank του HACT, που αναπτύχθηκε με τον οικονομολόγο Daniel Fujiwara χρησιμοποιώντας μεθόδους αποτίμησης ευημερίας, και το Global Value Exchange, μια ανοιχτή, συλλογική βάση δεδομένων χρηματοοικονομικών υποκατάστατων, είναι οι δύο πιο ευρέως χρησιμοποιούμενες στον βρετανικό τρίτο και δημόσιο τομέα. Και οι δύο υπάρχουν επειδή η υποκείμενη εργασία αποτίμησης — η [αποτίμηση ευημερίας](../αποτίμηση-ευημερίας/) και η [αποτίμηση με δηλωμένες προτιμήσεις](../αποτίμηση-με-δηλωμένες-προτιμήσεις/) — είναι δαπανηρή, μεθοδολογικά απαιτητική και αργή να εκτελεστεί από το μηδέν για κάθε έργο. Μια κοινή, δημοσιευμένη βιβλιοθήκη υποκατάστατων μετατρέπει ό,τι θα ήταν μια πολύμηνη ερευνητική άσκηση σε αναζήτηση, γι' αυτό και έχουν σημασία τόσο για τους υπολογισμούς [κοινωνικής απόδοσης επένδυσης](../κοινωνική-απόδοση-επένδυσης/) όσο και για τις αξιολογήσεις προσφορών του [Social Value Act](../νόμος-για-την-κοινωνική-αξία/): χωρίς αυτές, η αυστηρή χρηματοποίηση θα ήταν προσιτή μόνο σε οργανισμούς αρκετά μεγάλους ώστε να αναθέτουν τις δικές τους μελέτες.

## Τα μαθηματικά

Μια βάση δεδομένων κόστους μονάδας δεν υπολογίζει η ίδια τίποτα· προσφέρει μία εισροή σε έναν υπολογισμό που γίνεται αλλού:

```
Αξία χρηματοοικονομικού υποκατάστατου = τιμή αγοράς, Ή σκιώδης τιμή, Ή αποτίμηση ευημερίας,
                                         Ή αξία δηλωμένης προτίμησης
                                         για έναν ορισμένο τύπο μονάδας μεταβολής αποτελέσματος
                                         (π.χ. «ανά άτομο που μεταβαίνει από την ανεργία στην
                                         απασχόληση, ανά έτος»)

Εφαρμοζόμενη αξία = αριθμός αποτελεσμάτων που επιτεύχθηκαν × αξία υποκατάστατου μονάδας
```

Βλ. [σκιώδης τιμολόγηση](../σκιώδης-τιμολόγηση/) για το πώς κατασκευάζεται ένα υποκατάστατο όταν δεν υπάρχει τιμή αγοράς, και [κοινωνική απόδοση επένδυσης](../κοινωνική-απόδοση-επένδυσης/) για το πώς η εφαρμοζόμενη αξία τροφοδοτεί στη συνέχεια έναν λόγο μετά τις προσαρμογές νεκρού βάρους και απόδοσης.

## Επεξεργασμένο παράδειγμα

**Φιλανθρωπικός οργανισμός (SROI υπηρεσίας φιλίας)**: μια καταχώριση βάσης δεδομένων κόστους μονάδας για τη «μείωση της μοναξιάς» δίνει ένα ενδεικτικό υποκατάστατο £1.100 ανά άτομο ανά έτος. Εφαρμοσμένο σε 80 δικαιούχους: 80 × £1.100 = £88.000 ακαθάριστη αξία. Αν η ίδια βάση δεδομένων έχει επίσης υποκατάστατο για «βελτιωμένη ψυχική ευημερία» που βασίζεται σε επικαλυπτόμενο στοιχείο έρευνας ευημερίας, η στοίβαξη και των δύο υποκατάστατων για τα ίδια 80 άτομα θα διπλομετρούσε μέρος της ίδιας υποκείμενης αλλαγής — η βάση δεδομένων προσφέρει τον αριθμό, αλλά η αποφυγή αυτής της επικάλυψης είναι ευθύνη του αναλυτή.

**Τοπική αρχή (SROI λέσχης εργασίας)**: μια καταχώριση βάσης δεδομένων κόστους μονάδας για τη «μετάβαση από την ανεργία σε διαρκή απασχόληση» εφαρμόζεται σε 45 συμμετέχοντες με ενδεικτικό υποκατάστατο £8.500 ανά άτομο ανά έτος: 45 × £8.500 = £382.500 ακαθάριστη αξία, πριν από τις προσαρμογές νεκρού βάρους και απόδοσης που φαίνονται στην [κοινωνική απόδοση επένδυσης](../κοινωνική-απόδοση-επένδυσης/).

## Σύνδεση με τη μηχανική λογισμικού

Οι ομάδες που χτίζουν εργαλεία αναφοράς για φιλανθρωπικούς οργανισμούς ή αναθέτουσες αρχές ωφελούνται από έναν εσωτερικό «κατάλογο αποτελεσμάτων» — έναν πίνακα που αντιστοιχίζει κάθε αποτέλεσμα που ένα προϊόν ή μια υπηρεσία μπορεί εύλογα να διεκδικήσει σε ένα ονομασμένο υποκατάστατο, τη βάση δεδομένων προέλευσής του, την ημερομηνία δημοσίευσής του και έναν αναγνωριστικό έκδοσης — ώστε οι διαφορετικές ομάδες ενός οργανισμού να μην επιλέγουν η καθεμία ελαφρώς διαφορετικές τιμές για το ίδιο αποτέλεσμα. Η περιτύλιξη των ανοιχτών δεδομένων του Global Value Exchange πίσω από μια υπηρεσία αναζήτησης, με την πηγή και την ημερομηνία πάντα εμφανιζόμενες δίπλα στον αριθμό, διατηρεί το υποκατάστατο ελέγξιμο αντί για έναν μαγικό αριθμό θαμμένο σε ένα λογιστικό φύλλο. Βλ. [κοινωνική απόδοση επένδυσης](../κοινωνική-απόδοση-επένδυσης/) και [Social Value Act](../νόμος-για-την-κοινωνική-αξία/) για τα δύο κύρια σημεία όπου καταναλώνονται αυτά τα υποκατάστατα.

## Παγίδες

- **Η αντιμετώπιση των υποκατάστατων ως ακριβών.** Τα περισσότερα δημοσιευμένα υποκατάστατα είναι μοντελοποιημένοι μέσοι όροι από μελέτες αποτίμησης ευημερίας με ευρέα διαστήματα εμπιστοσύνης· η παράθεσή τους με ακρίβεια λίρας υπερβάλλει την ακρίβεια που υποστηρίζει η υποκείμενη έρευνα.
- **Η διπλομέτρηση επικαλυπτόμενων υποκατάστατων.** Ο συνδυασμός υποκατάστατων (π.χ. «μειωμένη μοναξιά» και «βελτιωμένη ψυχική ευημερία») που προέρχονται από επικαλυπτόμενες έννοιες ερευνών αποτιμά την ίδια υποκείμενη αλλαγή δύο φορές.
- **Η χρήση ενός εκτός πλαισίου υποκατάστατου χωρίς προσαρμογή.** Ένα υποκατάστατο βαθμονομημένο σε έναν εθνικό πληθυσμό και έτος, εφαρμοσμένο αλλού χωρίς προσαρμογή για πληθωρισμό ή πλαίσιο, παραποιεί σιωπηλά την αξία.
- **Η μη επαλήθευση της προέλευσης.** Το Global Value Exchange είναι ανοιχτό και συλλογικό, οπότε η ποιότητα των καταχωρίσεων ποικίλλει ανά συνεισφέροντα· ελέγξτε την υποκείμενη πηγή πριν παραθέσετε έναν αριθμό σε μια αίτηση χρηματοδότησης ή υποβολή προμήθειας.
